# 词典与索引数据规范（供内容撰写使用）

所有文件都是 UTF-8 的 JSON 数组，**每个条目必须严格按下面的字段输出，不得增减字段名**。
`id` 必须与给定清单完全一致（清单见对应任务给定的 id 列表文件），不得自造、不得改写大小写。

## 1. concepts —— 概念词典
```json
{
  "id": "c-sublime",
  "term": "崇高",
  "en": "sublime",
  "grk": "hypsos（ὕψος）",
  "field": "范畴",
  "brief": "对象在数量或力量上压倒想象力时产生的震撼性愉悦。",
  "body": "与优美相对。康德把崇高从对象属性移到主体心意状态：面对绝对巨大或绝对强力，想象力无法总括，理性却显示出超越感性尺度的能力，于是产生「消极的愉悦」。博克则用「自我保全的恐惧」作生理学解释。",
  "source": "朗吉弩斯《论崇高》；博克 1757；康德《判断力批判》1790"
}
```
- `term` 用课程统一译名；`en` 小写英文；`grk` 只在有希腊语/拉丁语原文时给，否则省略该字段。
- `field` 取值只用这几个：`范畴`、`本体论`、`认识论`、`心理学`、`艺术理论`、`批评术语`、`社会学`、`当代议题`。
- `brief` ≤ 40 字，一句话说清是什么。
- `body` 60–140 字，必须包含「辨析」或「一个具体例子」，不能只是同义反复。
- `source` 写提出者与著作/年份，多个用 `；` 分隔。若该词非某人独创，写通行的最早出处。

## 4. timeline —— 思想史时间轴
```json
{
  "year": -530,
  "label": "前 530",
  "title": "毕达哥拉斯学派兴起",
  "text": "以数为本原解释宇宙秩序，提出和谐（harmonia）观念，为西方第一个客观主义美学纲领奠定基础。",
  "era": "古希腊罗马"
}
```
- `year` 为整数，公元前用负数（如 -530），公元后用正数。同一年可有多条。
- `label` 为显示用字符串，公元前写「前 530」，公元后写「1750」。
- `text` 40–70 字，写「发生了什么 + 它在美学史上的意义」。
- `era` 只能是：`古希腊罗马`、`中世纪`、`文艺复兴`、`启蒙时期`、`德国古典`、`19 世纪`、`20 世纪`、`当代`。
- 覆盖范围要求：从公元前 6 世纪到 2020 年代，每个时代至少 3 条，总数不少于 44 条；必须包含这些节点：毕达哥拉斯学派、柏拉图创办学园、《诗学》、普洛丁、奥古斯丁《忏悔录》、阿奎那《神学大全》、阿尔伯蒂《论绘画》、达·芬奇、布瓦洛《诗的艺术》、夏夫兹博里、哈奇生、休谟《论趣味的标准》、博克《崇高与美》、鲍姆嘉通《美学》1750、康德《判断力批判》1790、席勒《审美教育书简》1795、谢林《艺术哲学》、黑格尔《美学》讲演、叔本华、尼采《悲剧的诞生》1872、车尔尼雪夫斯基 1855、唯美主义、克罗齐《美学》1902、贝尔《艺术》1914、弗洛伊德、海德格尔《艺术作品的本源》1935/1950、杜威《艺术即经验》1934、本雅明 1935、阿多诺《美学理论》1970、丹托「艺术界」1964、伽达默尔《真理与方法》1960、姚斯 1967、利奥塔《后现代状况》1979、环境美学兴起、互联网与数字艺术、生成式 AI 艺术。
