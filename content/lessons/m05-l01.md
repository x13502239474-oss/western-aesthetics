## 一、本节导入

1750 年，奥德河畔法兰克福出版了一部拉丁文著作，作者是法兰克福（奥德河畔）的哲学教授鲍姆嘉通（Alexander Gottlieb Baumgarten），书名就叫《美学》（Aesthetica）。它做了一件此前没人做过的事：给关于感性与美的零散讨论一个正式学科名。这个词来自希腊语 aisthesis，本义是感觉。

耐人寻味的是，这个命名自带贬义。当时的学院哲学把「感性认识」看作低于理性认识的一层：它具体、生动、混杂，却说不清道理。把它单独拿出来研究，等于承认有一类知识天然够不上科学的门槛。美学从诞生之日起就尴尬：它要证明自己配得上一门科学，而它赖以成立的对象，恰好被判为次等。

不理解「感性」在这个体系里为什么低人一等，就无法理解鲍姆嘉通在辩护什么，也无法理解康德后来为什么换问题。

## 二、核心知识：从「混乱的知觉」到「感性学」

::: def 单子（monas）
莱布尼茨的基本实体。单子没有部分、没有窗子，不与其他实体直接交往；每一个单子从自己的视角映现整个宇宙，彼此之间的协调由上帝预先安排，称为「前定和谐」。
例子：同一座城市从不同山头看，轮廓各不相同，却没有一个视角是假的。单子就是这样的山头。
:::

::: def 感性认识（cognitio sensitiva）
鲍姆嘉通赋予美学的对象：通过感官获得的、具体的、丰富的认识。它把握整体印象，却未必能分析出构成整体的要素。
例子：你一眼认出朋友的脸，却说不出哪几条线的比例让你认出；你能尝出汤里放了姜，却报不出姜的化学构成。两种「知道」都是真知道，只是清晰的方式不同。
:::

::: def 理性主义（rationalismus）
这里特指十七至十八世纪欧陆的哲学传统：以数学为知识模型，相信世界的秩序可以被理性完整把握，哲学的任务是把含混的表象还原为清晰的概念与根据。
例子：斯宾诺莎用几何学的方式写伦理学，从定义与公理推出命题。
:::

莱布尼茨用两个维度交叉出四种知觉，即「明晰／含混」（klar/verworren）与「明确／不明确」（deutlich/undeutlich）：

| | 明确的 | 不明确的 |
|---|---|---|
| **明晰的** | 概念认识：能说出要素与根据 | 感性认识：整体清楚，要素未分 |
| **含混的** | —— | 黑暗的知觉：如无数细小的刺激 |

关键在「verworren」的译法。中文常译「混乱」，容易读成「糊里糊涂」。莱布尼茨的用法是逻辑学的：指「未分解」，诸要素混在一起而尚未被打散。他自己用过海浪的例子：你听见涛声，整体的声音极其清楚，却听不出每一道浪。这是「明晰而含混」的知觉，它是一个有限视角对整个宇宙的浓缩。

由此可以理解单子论的用意：人的灵魂处在知觉等级的中间，既能上升为理性，又带着感性底色。感性与理性属于同一个连续统，差别在清晰度，不在真伪。这为鲍姆嘉通提供了形而上学的许可：如果感性是宇宙的一个真实视角，美学就有资格研究它自己的完善。

::: warn 「感性认识」等于「不准确的认识」
一种流行的简化是：理性主义认为感性只是模糊的理性，等理性看清了，感性就没用了。这个说法漏掉了鲍姆嘉通的关键一步。他承认感性不及理性明确，却主张感性另有优点：它在一瞬间给出的内容丰富、具体、有生命。用他的术语，感性享有「广延的清晰」，理性享有「强度的清晰」。
:::

## 三、代表人物：从莱布尼茨到梅尔

莱布尼茨（Gottfried Wilhelm Leibniz，1646—1716）的著述面极广，哲学作品多为短篇与书信。单子论要解决实体何以既独立又互相协调：笛卡尔的实体需要外力，斯宾诺莎的实体只剩一个，两者都不令人满意。单子加前定和谐是他的答案。他对美学的贡献是间接的：给了「感性的清晰」一个本体论位置，却没有建立美学。

沃尔夫（1679—1754）把莱布尼茨的洞见改写成可讲授的链条，用德语写作，影响远超学院。局限也在这里：为了让一切都可推论，他把「完善」变成几乎万能的解释项，美、善、真都成了完善的不同显现。

鲍姆嘉通（1714—1762）在哈勒听沃尔夫的课，后在法兰克福（奥德河畔）任教。三部作品构成一条线：1735 年的《关于诗的哲学默想》首次使用 aesthetica 一词；1750 年的《美学》第一卷建立理论部分；1758 年的第二卷处理实践部分，未及完成。他要解决的问题很具体：诗与修辞的规则已在课堂里教了两百年，却没有一门学科说明这些规则凭什么成立。他的回答是：它们属于感性认识自身的完善，不必向逻辑学借光。

梅尔（Georg Friedrich Meier，1718—1777）是鲍姆嘉通的学生，把老师的拉丁文体系改写成德文教科书《一切美的科学之基础》。他做了三件事：把美学做成可讲授、可考试的规则体系；把「审美真理」与「逻辑真理」并列，前者指感性表象之间的一致性；把美学规定为「美的思维的艺术」。他还使用「混合感受」一词，指感官与情绪交织而成的复合感受。梅尔的意义在于制度化，美学从此进入大学课程，「可教的规则」与「不可教的天才」之间的裂缝也随之暴露。

## 四、理论解析：辩护的三步与它的失败

**体系的挤压。** 沃尔夫（Christian Wolff）把这套形而上学整理成教科书：哲学分作逻辑、形而上学、实践哲学，形而上学再分本体论、宇宙论、心理学、自然神学。美被安放在经验心理学与逻辑学的交界处，它是「感官所认识的完善」，快乐则被解释为「对完善的直观」。这门学问因此有了位置，却也从属于逻辑学与形而上学。

**三步辩护。** 第一步是命名划地。鲍姆嘉通把美学定义为「感性认识的科学」，这个定义同时宣称感性有资格成为学科对象，又把对象限定在「感性」这一层；抬举与限制写在同一条定义里。

第二步是重新估价「含混」，这是整条链条的核心。他把「含混」从缺陷改写成特征：诸要素尚未被分析开，正因如此才保留了丰富性。他列出感性认识之完善的要素——丰富、伟大、真、清晰、确信；美于是被规定为「完善之感性显现」。好处是美有了可讨论的内容，代价是鉴赏成了「感到一个对象的完善」，而「感到」只是「认识到」的弱化版本。

第三步是梅尔把美学做成学。既然美是感性认识的完善，达到完善就可以写成规则：怎样安排材料，怎样使用比喻，怎样让描写生动。美学成了「美的思维的艺术」。

三步走完，困难出现。规则从成功作品里归纳，再被当作规范教给学生，于是有了循环：好作品因为符合规则而好，规则因为好作品符合它而成立。更要紧的是，能教的东西天才不需要，天才做的东西规则说不清。美学的合法性被它自己的对象掏空。

**康德早年的立场。** 1764 年的《关于优美感与崇高感的考察》是另一副笔墨：康德把优美与崇高分配给气质、性别与民族，写哪种人容易被哪种感受打动。书里没有先验论证，只有观察与分类，但有一个重要转向：美与崇高被当作「感受」，放在主体这一边。研究者常指出，其中已有「无利害」的萌芽，康德注意到对人格的美感与对物品的占有欲属于不同的东西（大意）。前批判期的康德也不相信美学能成为科学：规则教不出感受，感受只能被唤醒。这个怀疑保留到 1790 年，只是被改造成一个批判的纲领：不建立「美的科学」，只考察「鉴赏的判断」。

**康德为什么瞧不上「美的科学」。** 理由有三。第一，美的规则无法像逻辑规则那样被教授：逻辑能教人避免矛盾，却教不出好诗，「描写要生动」这类规则要么空洞，要么是事后总结。康德后来在《判断力批判》的导论里说得干脆：关于美，没有科学，只有批判（大意）。第二，用「完善」规定美，等于让鉴赏依赖一个理性概念，审美判断的独立性就没了。第三，「感性」一词在康德那里要留给空间与时间的形式；他在《纯粹理性批判》的一条注里提到，鲍姆嘉通把对美的批判纳入理性原则的尝试白费了力气（大意）。

**如何腾出位置。** 康德换问题。鲍姆嘉通问「美是什么」，康德问「审美判断如何可能」；前者要一门关于对象的学说，后者要一种关于判断的批判。这一步带来三个变化。

1. 美从对象的属性转移到主体的心意状态。
2. 规则变成原则，即合目的性；美学不再提供写作指南。
3. 学科变成批判，不扩充知识，只澄清权利。

于是美学从「低级的认识论」变成「关于愉快与不快的批判」，不必再向逻辑学借光。「感性认识的完善」没有被原样继承，它被分到两处：一处是感性直观的形式，一处是审美判断的合目的性。

## 五、经典原著：从《美学》到《判断力批判》的导论

鲍姆嘉通的《美学》用拉丁文写成。第一卷 1750 年出版，处理「理论美学」：定义、美、材料与方法；第二卷 1758 年出版，处理「实践美学」。全书大量引用古典诗人与修辞学家的例子，风格接近经院讲义。

::: quote 鲍姆嘉通《美学》开篇的定义（拉丁文原文，中文为大意）
Aesthetica est scientia cognitionis sensitivae.
—— 美学是感性认识的科学。
:::

这句定义的重量落在 scientia 上。把美学称作「科学」，等于宣称感性有资格成为学科对象；但对象随即被限定为 cognitionis sensitivae，又被钉在「低级的认识」上。一句定义里同时有抬举与限制，这就是学科的出生证明。后来的争论都围绕这一点：感性若要成为科学，它的「完善」必须有独立标准；而标准一旦找到，又往往变成理性概念的翻版。

康德没有沿用这个定义：他把「审美的」改为「关于愉快与不快的情感」，并声明关于美没有科学，只有批判（大意）。

## 六、艺术案例：《米洛的维纳斯》

这尊大理石像约作于公元前二世纪末，高约二百零四厘米，由上下两段石料拼接。她的身体轴线呈 S 形：重心落在右腿，左膝微屈，骨盆向右倾，肩部反向倾斜，头部略向左转。衣褶从髋部滑落，堆在脚边，形成密集的竖向褶痕，与上身的平滑形成强对比。双臂缺失。

在鲍姆嘉通的框架里，这尊像几乎是标本：观者一眼感到整体的和谐，却无法把它还原为某条比例规则。你量不出「美」在哪根线上，能感到的是各部分在视觉上互相支持的均衡。这正是「明晰而含混」。

这个解释也有代价：把美说成完善，残缺、怪异、丑的地位就成了问题。维纳斯的断臂并未削减她的美，这对「完善」论是小小的反例：按定义，残缺应当减损完善，实际感受并非如此。十八世纪更愿意谈「理想美」，把残缺交给修复师；现代观者则在残缺里看时间。

:::

## 七、思想联系

向前追溯，理性主义美学继承了三个源头：柏拉图的美本身，为「完善」提供原型；亚里士多德的秩序与比例，为感性形式的合规律性提供模型；奥古斯丁的统一、数、秩序，把美与神的秩序连在一起。鲍姆嘉通把这些要素压缩成一个可定义的概念，使它第一次成为学科对象。

向后看，康德把美从「完善」里解放出来，交给判断力；席勒把审美转为教育问题；黑格尔说美是理念的感性显现。这个表述与鲍姆嘉通的「完善之感性显现」只差一个词：理念。赫尔德则批评「感性学」把活生生的感受切成规则的碎片。

## 八、本节总结

::: key 本讲要点
- 莱布尼茨用「明晰而含混」给感性一个本体论位置：感性是对宇宙的浓缩视角，并非错误的理性。
- 沃尔夫把体系整理成教科书，美成为「感官所认识的完善」，美学有了位置，也从属于逻辑学。
- 鲍姆嘉通命名并重新估价「含混」，把美规定为「感性认识的完善」；梅尔把它做成可教的规则体系。
- 规则的可教性与天才的不可教性构成两难，这是康德接手时的局面。
- 康德换掉问题：从「美是什么」转为「审美判断如何可能」，美学由此从「学」变为「批判」。
:::

教训在于：一门学科的地位由它继承的困难决定，不由它给自己起的名字决定。鲍姆嘉通争到了名字，没有争到原则；原则要等到 1790 年才补上。

值得追问：如果美学从一开始就是为「低级的认识」辩护，那么它对「感性」的重视，是否始终带着补偿性的焦虑？今天的「感性学」「身体美学」在多大程度上重复了鲍姆嘉通的动作？
