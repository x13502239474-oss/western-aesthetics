## 一、本节导入

一首诗被译成另一种语言，它还是原来那首诗吗？同一部交响曲，两位指挥给出相差二十分钟的演奏，哪一次更「忠实」于作品？一幅画被高质量复制，复制品算不算那件作品？

这三个问题的日常答案都依赖于一个假设：作品存在于乐谱、纸张、颜料之外的某个地方，演奏与复制只是接近它或远离它。这个假设听起来像常识，却需要一个理论来支撑。1902 年，那不勒斯的克罗齐给出了一个极端的答案：作品确实在别处，它在艺术家的心灵里，是一次「直觉」；乐谱、颜料、声音只是为了让别人想起来而留下的记号。这个答案一下子解决了全部三个问题，也一下子制造了新的问题：如果作品在心灵里，艺术史研究的是什么？批评凭什么说某次演奏「失败」？

## 二、核心知识：直觉、表现、心灵四阶段

::: def 直觉（intuizione）
克罗齐意义上的直觉，指心灵把杂多的感觉材料整理成一个统一形象的活动。它已经是一种认识，只是这种认识关于个体形象，不关于普遍概念。关键处在于：直觉活动与它所形成的形象同时发生，没有先于形象的「材料」可以被单独把握。
例子：你听见窗外一片含混的声响，忽然辨认出「是雨」。在辨认出「雨」的那一瞬间，杂音被组织成一个形象；此前它只是刺激，此后它是直觉。
:::

::: def 表现（espressione）
直觉所成就的那个形象本身。克罗齐用「表现」一词，强调形象总已经是「被说出」的：一旦有直觉，就有形式；一旦有形式，就可以被直观。因此表现不需要外在的媒介，它是内在的、精神的。
例子：你在心里听见一句旋律，还没唱出来，它已经有高低、有节奏、有结束感。这句话在心里成形，就是表现；唱出来只是把它记录到空气中。
:::

克罗齐的体系把心灵活动分成四级。这张表是理解他全部论证的钥匙。

| 级别 | 活动 | 形式 | 产物 | 是否有价值区分 |
|---|---|---|---|---|
| 一 | 直觉 | 形象 | 个别之物（艺术） | 美／丑 |
| 二 | 概念 | 判断 | 普遍之物（科学、哲学） | 真／假 |
| 三 | 经济 | 意志（手段） | 有用之物 | 利／害 |
| 四 | 道德 | 意志（目的） | 善 | 善／恶 |

四级的关系是「依存而不相同」：后一级必须以前一级为前提，前一级却不依赖后一级。概念需要直觉提供材料，直觉不需要概念批准。这个结构直接来自他对黑格尔的改造：黑格尔的辩证法让对立面互相扬弃，克罗齐则主张「相异者」（distinti）彼此并列，只有同一级内部才有真正的对立（美与丑）。这一步很技术，后果却很大：它让艺术不必再向哲学借地位，因为艺术处在自己的级别上，拥有自己的完善标准。

## 三、代表人物：克罗齐

克罗齐（Benedetto Croce，1866—1952）生于阿布鲁佐山区，1883 年卡萨米乔拉地震中父母与姐姐遇难，他本人被埋受伤，此后由叔父、政治家斯帕文塔带到罗马抚养。他在罗马大学学法律，很快放弃，回到那不勒斯做独立学者，靠家产与稿费生活，一生没有担任过大学教授。1903 年他与秦梯利创办《批评》杂志，此后四十年几乎每期都有他的文章；1920 至 1921 年出任教育部长；1925 年领衔发表《反法西斯知识分子宣言》，此后与政权长期对立。

他的写作量惊人，哲学核心是四卷《精神哲学》：《美学》（1902）、《逻辑学》（1909）、《实践哲学》（1909）、《历史学的理论与历史》（1917）。他的美学由一个体系的需要驱动：他要一个既不取消艺术自律、又不放弃精神一元论的位置。贡献在于，他把「表现」从技巧问题里解放出来，让艺术不再依赖模仿与修饰；局限在于，这一解放走得太远，媒介与公共性被他一起丢掉了。

## 四、理论解析：一条公式，四个否定

**第一步：问题从哪里来。** 黑格尔把美定义为「理念的感性显现」，艺术因此是理念的一个阶段，低于宗教与哲学。这个安排有两个后果：艺术的内容由理念给出，艺术的地位由体系给出。十九世纪末的模仿论与快感论各占一半市场：前者让艺术依附于对象，后者让艺术依附于感官。克罗齐要同时摆脱两者，办法是把艺术放回心灵本身：艺术是心灵的第一级活动，它不需要对象批准，也不需要概念批准。

**第二步：直觉为什么就是表现。** 论证可以分成三小步。

1. 感觉材料本身是无形式的杂多，只有被赋形才成为「某物」。
2. 赋形活动就是直觉；直觉的结果是一个形象。
3. 形象一旦成形，就已经是可直观的、被说出的东西，即表现。

由此得出「一切直觉都是表现」。这个结论的反面同样重要：不存在「未表现的感觉」。你可能觉得某种情绪在心里翻涌却说不出，克罗齐会说，那种「说不出」只是一个模糊的、尚未完成的形象，它仍然是表现，只是表现得不充分。凡是已经进入意识的东西，都已经带上了形式。

**第三步：表现不需要技巧。** 这一步最容易误解。克罗齐承认画家要调颜料、诗人要推敲字句，但这些属于「外在化」，属于实践活动的范围，是技术而非艺术。艺术在心灵里已经完成；外在化只是把它保存下来，供自己和别人回忆。他用「备忘录」这个词来形容物理作品：画布上的颜料是一份备忘录，帮助你重新唤起那个直觉。所以同一首诗可以有不同的译本，同一部曲子可以有无数演奏，它们都是备忘录的不同抄本。

**第四步：四个否定。** 克罗齐在《美学》里逐一排除了四种流行的艺术定义，这四步构成一条否定链。

1. **艺术不是物理事实。** 声音、颜色、大理石是物理事实，受因果律支配；艺术是心灵的直觉，不受物理规律支配。若艺术是物理事实，那么只要复制声波就等于复制了音乐，这显然不成立。
2. **艺术不是快感。** 快感属于经济一级，是功利的满足；审美愉快伴随表现而来，却不能定义表现。若艺术是快感，那么美食与按摩也是艺术，而悲剧带来的痛苦就无法解释。
3. **艺术不是道德。** 艺术不进行意志的选择，因此不能用善恶评价。克罗齐并不否认艺术家作为人可以道德败坏，他只是说，作品的好坏与道德的善恶不在同一个坐标上。
4. **艺术不是概念。** 艺术不表达普遍，不做判断，不追求真理。若艺术是概念，那么诗与哲学就没有区别，而诗的力量恰恰在于它停留在个别形象上。

这四个否定有一条共同的支撑：每一级心灵活动都有自己的形式与价值，不能还原为另一级。代价是，艺术被彻底隔离在认识的第一级，它与真理、伦理、功利都不发生内在关系。

**第五步：艺术不可分类。** 既然每一次直觉都是个别的、不可重复的，那么「抒情诗」「悲剧」「风景画」这些门类就只是经验的抽象，是批评家的方便工具。克罗齐反对「修辞学」，因为修辞学把表现拆成「风格」「辞格」这些可移植的零件，好像内容可以从一种形式搬到另一种形式。他的结论是：艺术只有一种门类，就是艺术；真正的批评只能做一件事，判断这个表现是成功还是失败。

**第六步：美与丑。** 美是「成功的表现」，丑是「失败的表现」。这个定义看似简洁，实则把全部重量压在「成功」上。成功的标准是什么？克罗齐的回答倾向于：表现是否达到完全的统一与清晰，是否让材料彻底被形式吸收。问题立刻出现：判断一个表现是否成功，需要先认出它是一个表现；可如果它失败了，它还算不算表现？如果算，那么失败的表现也是表现，与「一切直觉都是表现」冲突；如果不算，那么丑就根本不存在，而我们明明经验到「想说说不出」的窘境。

克罗齐自己的解法是把丑规定为「不成功的表现」，即程度不足的表现，仍然留在表现的范围内。这个解法保住了体系，却让「成功」与「失败」的区分变成同一件事的两种说法：成功的表现就是美的，美的就是成功的表现。

::: warn 「直觉即表现」等于「想到就算做到」
常见的误会是拿这句话为懒惰辩护：既然心里想到就是艺术，那就不必练技巧。克罗齐的意思恰好相反：他心里那个「想到」已经是完整的形象，而不是一个模糊的念头；能达到这种完整，需要极高的精神修养。他贬低的是技巧，抬高的是内在形式的严密。真正被这句话取消的，是媒介在艺术中的构成作用。
:::

**最强反对意见。** 第一路批评针对循环。要判定表现成功，必须已经把握到作品；要把握到作品，必须它已经成功。标准与对象互为前提，理论因此无法说明批评如何可能。塔塔凯维奇在《美学史》里指出，这类公式把作品化约为心理事件，难以解释同一作品为何能跨越时代持续存在（转述）。第二路批评针对媒介。贡布里希在《艺术与错觉》里反对「先有完整印象、再把它外化」的图式，认为画家总是在材料与图式中工作，所谓「纯真之眼」并不存在（转述）。第三路批评针对「人人都是艺术家」。克罗齐自己承认，人只要是人，就总有直觉，因此在一定意义上人人都是艺术家（大意）。这句话有解放意义，却让「艺术家」这个称号失去区分力，也让「失败」失去判准：如果人人都能直觉，凭什么说某人的表现失败？

公允地说，克罗齐的成就在于把艺术从模仿与快感中解救出来，并第一次把「形式」放在艺术定义的核心。他的失败在于，为了保住形式的纯粹，他把形式与媒介切开了。二十世纪对媒介的重视，很大程度上是对这一刀的反动。

## 五、经典原著：《美学》（1902）

全名《作为表现的科学和一般语言学的美学》。全书分两部分：原理部分与美学史部分。原理部分讨论直觉与表现、艺术与语言、艺术与技术、艺术与道德、以及美与丑的区分；美学史部分从希腊一直写到十九世纪，用意是证明以往的失误都来自把艺术放在错误的级别上。

书名里的「一般语言学」是关键。克罗齐主张，语言学研究的对象就是表现，而表现就是艺术，因此美学与语言学是同一门学科的两个名字。这个主张的锋芒指向当时的语言学：语言若只是符号系统，那么诗与语法就没有区别；反过来，若语言本质上是表现活动，那么语法规则只是事后归纳。

::: quote 《美学》原理部分（原书核心公式）
intuizione = espressione（直觉即表现）；后期更完整的表述是 arte = intuizione lirica（艺术是抒情的直觉）。
:::

「抒情的直觉」这个补充值得注意。1902 年的公式强调形式，1913 年的《美学纲要》与 1928 年的《美学要义》加入「抒情」，是为了回答一个质疑：如果艺术只是形式，它为什么动人？克罗齐的答案是，形式从来不是空的，情感在赋形中被吸收进形象，所以纯粹的直觉同时是抒情的。这个补充让理论更丰满，也让「形式」与「内容」的界限更模糊。

## 六、艺术案例：《印象·日出》

1872 年，莫奈在勒阿弗尔港画下《印象·日出》，一幅小幅油画，现藏巴黎马尔莫坦美术馆。画面以灰蓝为底，左上方一轮橙红的太阳，水面上一条抖动的橙色倒影；前景两只小艇是深色的剪影；远处工厂的烟囱与吊车隐在雾里；笔触短促、方向各异，几乎不交代细节。

1874 年，这幅画参加巴黎摄影家纳达尔工作室里的展览，批评家勒鲁瓦借它的标题写下讽刺文章，「印象派」这个名字就此传开。

用克罗齐的框架读它，会得到一种很顺的解释：画家在港口捕捉到一个清晨的直觉——雾、光、水的统一形象；「印象」这个词正好是直觉的自我命名；画布上的颜料只是备忘录，帮助我们唤起那个形象。这个解释有力地说明了一件事：印象派的价值不在题材，而在形象的统一。

但案例也暴露了理论的裂缝。第一，画面的感染力大量来自笔触的物质性：短促的、未调匀的颜料在画布上留下的厚度，本身就是「清晨的湿冷」的一部分。若笔触只是备忘录的笔迹，观众感到的东西就无处安放。第二，莫奈后来画鲁昂大教堂、睡莲，同一对象在不同光线下反复成画。这说明直觉并非先在心中完成、再被记录；它是在画的过程中被一点点找出来的。第三，展览史上的「印象派」是一个公共事件，名称、争论、市场共同构成了作品的意义，这些都不在克罗齐的「内在表现」之内。

::: fig a-impression-sunrise | 《印象·日出》：橙红的太阳与水面倒影形成唯一的暖色轴，灰蓝的雾气把远景压平，短促笔触让光成为画面的事件
:::

克罗齐可以回应说，这些都是「传达」的问题，与艺术无关。这个回应保住了理论，也把理论推到了墙角：如果连笔触都不是艺术，那么艺术批评还能谈什么？

## 七、思想联系

向前追溯，克罗齐的直接先驱是维柯。维柯在《新科学》里把「诗性智慧」放在逻辑之先，主张人类最初以形象思维，这与克罗齐把直觉置于概念之下同构（参见第 3 模块）。另一条线索是黑格尔：克罗齐接受了「精神自我展开」的框架，却用「相异者」替换了「对立面」，因此艺术不再被哲学扬弃。还有一条是意大利批评传统：德·桑克蒂斯把批评理解为对作品形式的鉴赏，克罗齐把这句直觉化的口号变成了体系。

向后看，最有名的继承者是柯林武德（R. G. Collingwood，1889—1943）。他在 1938 年的《艺术原理》里主张艺术是情感的表现，并把「艺术」与「技艺」严格分开：技艺有手段与目的之分，艺术没有。柯林武德比克罗齐多走了一步，他强调表现是一个「澄清情感」的过程，可以失败，失败源于「意识的腐化」。这一步部分回应了循环的批评，也把理论推向心理学。

在中国语境里，朱光潜 1930 年代的《文艺心理学》明显借用了克罗齐的框架，后来他又写专文述评，指出其忽视媒介与社会条件的弱点（转述）。二十世纪后期分析美学的「表现论」——把作品看作情感的表达而非情感的引起——也可以追溯到这条线上，只是它们多半放弃了克罗齐的形而上学。

## 八、本节总结

::: key 本讲要点
- 心灵四级（直觉、概念、经济、道德）互相依存而不相同，艺术因此获得自律的位置。
- 直觉是赋形活动，赋形即表现；不存在未表现的感觉，因此「一切直觉都是表现」。
- 表现不需要技巧，物理作品只是备忘录；这一刀切开了形式与媒介。
- 四个否定（非物理事实、非快感、非道德、非概念）共同守护艺术的独立性，也把艺术与真理、伦理隔绝。
- 美是成功的表现，丑是失败的表现；「成功」的标准无法独立给出，这是理论最受攻击处。
:::

把这一讲压成一句：克罗齐用「形式」救了艺术，又用「内在」把艺术关进了心灵。

值得继续追问的问题：如果作品在心灵里，那么博物馆、乐谱、修复、翻拍这些实践算不算艺术的一部分？今天我们在屏幕上观看一幅画，看到的究竟是备忘录，还是作品本身？
