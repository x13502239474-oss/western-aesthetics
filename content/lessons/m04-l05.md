## 一、本节导入

一个人站在海边，光在水上碎成一片。忽然他想起这一带的渔汛，开始估算这片海一年能出多少鱼。夏夫兹博里（Shaftesbury，1671—1713）会指出：估算开始的那一刻，美的感受就退场了。

这个观察包含两个判断：美的感受是直接的，不依赖计算，也不需要知道对象的用途；它又是无利害的，一旦掺杂占有或利用就变质。两者合起来，构成 18 世纪美学的两块基石。

问题在于，这样的感受凭什么要求别人同意？若它只是此刻的心情，说「这海很美」与说「我爱吃鱼」就没有区别。夏夫兹博里与哈奇生（Francis Hutcheson，1694—1746）的回答是：人有一种专门的知觉能力，像眼睛一样直接，也像眼睛一样为人共有。这一讲检验这个回答。

## 二、核心知识

::: def 内在感官（inner sense）
夏夫兹博里与哈奇生假设的一种知觉能力：不经推理、不经利害计算，直接把握对象中的和谐、比例与秩序，并在把握中感到愉快或不快。它不是生理器官，是一种「内在的眼睛」。
例子：看一座比例匀称的立面，你立刻觉得「正」，却说不出哪几条尺寸造成了它；这种直接性就是内在感官的工作方式。
:::

::: def 无利害（disinterestedness）
审美感受不涉及对象的实际用途、占有与个人利益。它关心对象呈现的样子，不关心对象能为我做什么。
例子：欣赏一片风景时若开始盘算地价，感受就换成了另一种；风景未变，态度变了。
:::

::: def 多样性中的齐一性（uniformity amidst variety）
哈奇生用以度量美的原则：对象在「多样」与「统一」同时达到较高程度时最美。齐一性相同则多样性大者更美，多样性相同则齐一性大者更美。
例子：一个圆由无穷多点构成却只有一个轮廓，比不规则的四边形更美；一条定理统摄无数个案例，比一堆零散观察更美。
:::

::: def 共通感（sensus communis）
源自古典修辞学，指共同体成员共享的判断力与同情能力。夏夫兹博里用它指人对公共善的自然感受，康德用它指鉴赏的普遍可传达性。
例子：一个人对公然的不义感到难堪，即使受害者与他无关；这种反应预设了他与旁人共享某种尺度。
:::

两者容易混：内在感官是能力，共通感是这种能力的公共性。夏夫兹博里把两者绑在一起，哈奇生只保留前者。

## 三、代表人物：两个人，一条路线

夏夫兹博里 1671 年生于伦敦，原名 Anthony Ashley Cooper，第三代沙夫茨伯里伯爵。祖父是第一代伯爵、洛克的赞助人，洛克参与了他的教育。这个细节有意味：他受经验主义教养，后来却用目的论对抗经验主义的结论。1708 至 1710 年发表《论狂热的信》《共通感》《道德家们》，1711 年汇编为三卷《论特征》，1713 年病逝于那不勒斯。

哈奇生 1694 年生于爱尔兰唐郡，苏格兰长老会背景，在格拉斯哥大学受教育并任教。1725 年匿名出版《关于美与德性观念起源的探究》，一部论美，一部论德性。他把夏夫兹博里的诗性直觉整理成可教学的论证，也因此更容易被反驳。

## 四、理论解析

### （一）问题处境：美与善同时失去根据

要理解这套方案为何出现，得先看它要对付的两个对手。

霍布斯把人的行为还原为自我保存与权力欲：人赞美一件事，因为它对我有利；善是欲望的对象。洛克把知识的材料还原为感觉：美是颜色与形状的组合，而颜色不在物中。两条合起来，美与善都成了主观的、可还原的、没有规范性的东西。

夏夫兹博里的策略是一举两得：如果美与善有同一个根据，反驳一次就够了。这个根据是和谐。

宇宙在他眼里是有秩序的整体，各部分相互配合而成其美。人作为宇宙的一部分，天生对和谐敏感；这种敏感不需推理，不需利害，直接发生并伴随愉悦。美与善因此共享一个对象结构（和谐）与一个能力（内在感官）：对物的和谐的感受叫美感，对品格与行为的和谐的感受叫道德感。

这一步把美从感官快适里拉出来，也把善从利己计算里拉出来，用的是同一根绳子。

### （二）三重形式与「内在的眼睛」

夏夫兹博里在《道德家们》里把美分三层。

第一层是「死的形式」，即无生命之物与人工制品：一块石头、一座建筑。它们有比例，却没有形成比例的能力。

第二层是「形成的形式」，即有生命、有心灵的东西：一个人、一种品格、一部作品。它们不只被安排，自己在安排，美高于第一层，因为含动因。

第三层是「形成形式的形式」，即宇宙的创造原则，是最高美，也是前两层可能的根据。

三层之间是上升关系：先爱形体之美，再爱心灵之美，最后爱那使一切成形者。这个结构带着柏拉图—普罗提诺的血统，区别在于夏夫兹博里把起点放在感官经验里。

「内在的眼睛」工作在这三层上。它看的不是颜色与线条，是其中的比例；不是行为的结果，是行为中的动机与秩序。同一个能力因此既能审美，也能判断品格。

### （三）无利害的论证

无利害有一个可以还原的论证结构。

1. 审美感受的对象是对象呈现的形式，与其实际存在状态无关。
2. 感受若掺杂占有或利用，就会随利害变化：能到手时愉快，到不了手时不快。
3. 观察中，审美感受并不随占有与否变化：不属于任何人的海，与属于我的海，看起来同样美；甚至在我永远无法拥有它时，感受更完整。
4. 所以审美感受不以利害为根据；以利害为根据的感受属于另一类。

论证的说服力在第三步，弱点也在这里：观察可以举出反例——收藏家对一幅画的欣赏常随市价波动。夏夫兹博里的回应会把这些例子判为「不纯」，而「不纯」的标准又来自论证本身，这就有了循环的苗头。

### （四）哈奇生的技术化

哈奇生做了三件事，把直觉变成可讨论的命题。

第一，把内在感官限定为知觉美的独立能力：它不再是既看美又看善的「内在的眼睛」，而与道德感官并列。美的观念来自前者，德的观念来自后者。

第二，提出相对独立性命题：美与德各有来源，不能互相还原——我们并非因为一个行为美才赞许它，也并非因为它有德才觉得它美。两条线平行，各有直接性。

第三，给出反理性主义的论证。大意有三条：我们常不知道对象的用途与构造，却已感到它美，不懂建筑的人也能赞一座立面；教育与习惯无法解释某些比例在不同文化中被一致赞赏；最美的东西常在微小无用之处，如一块石头的纹理，利害解释无从下手。

三条都指向直接性：美感在知识之前发生。弱点也一致：它们只能证明美感不依赖推理，不能证明它有普遍性。从「不依赖推理」到「人人应当同意」还差一步，哈奇生用「造物主给了人类同一套感官结构」来跨这一步。这一步是神学的。

### （五）多样性中的齐一：一个想变成公式的原则

哈奇生的核心命题是：美与对象中「多样性」和「齐一性」的结合程度成正比。

这个原则的解释力相当强：一条物理定律统摄无数现象，齐一与多样都极高；一个圆由无穷多点构成，却只有一个轮廓。反过来，一堆杂物多样高而齐一低，一片白墙齐一高而多样低，都不美。

需要一层分寸。哈奇生相信美可以被「计算」，他谈论美的「量」，相信两个对象的美可以比较。严格说来，他给的是比较原则，不能代入数值：齐一同则多样大者更美，多样同则齐一大者更美。它能排序，不能算出数值。

失败在哪里？四处。

1. **崇高。** 崇高中齐一性被压倒：混沌、晦暗、无限、巨大的对象，按公式应当最不美，经验上却最动人。博克后来正是抓住这一点，把崇高与美判为两个种类。
2. **丑的愉悦。** 怪诞、畸形、废墟在经验中带来强烈快感，公式只能判为负数。18 世纪中叶「如画」（picturesque）的流行，就是对这条公式的集体反叛。
3. **表现。** 一张脸的美常在表情与眼神，不在比例。公式处理不了「这张脸在说什么」。
4. **循环。** 什么算「齐一」，本身依赖知觉。若说「我们觉得齐一的东西才美」，那么公式就成了同义反复。

第三条与第四条最要命。前两条可以靠扩充范畴来救（把崇高另立一类），后两条伤及方法的根基。

### （六）循环论证的指控与辩护

指控是这样的：用「人有内在感官」解释「人为何能知觉美」，等于用「能知觉」解释「能知觉」——只给名字，没给机制。

辩护有两条。第一条是类比：问「眼睛为什么能看见」，最终只能答「它就是这样构造的」；某些能力是最终事实。内在感官只是把审美归入这类事实。第二条是现象学的：感受的直接性是可描述的现象，描述它就是哲学的工作；要求进一步解释，等于要求把感受还原成非感受。

反辩护同样有力。若它只是最终事实，就不可检验：无法区分「他有这种感官」与「他恰好喜欢这个」。趣味差异更难办：人人既有同一套感官，差异只能归为「感官失灵」，而这一诊断既无法独立证实，也把大量真实分歧一笔勾销。

争论在此悬置，正是康德出场的地方。他保留无利害与普遍性，扔掉「内在感官」这个假设，改用先验论证：鉴赏判断的普遍性来自判断的结构。

::: warn 「内在感官就是第六感」
这个说法把比喻当成了生理学。夏夫兹博里与哈奇生都没有说它有一个器官、一套神经；他们用它命名一种直接的情感反应能力，并主张这种能力不可再还原为推理或利害。麻烦在于：一旦它被当成器官，就该接受生理学检验；一旦它只是比喻，就难承担论证。18 世纪后期的批评者抓住的正是这一点。
:::

### （七）两人的分工

| 比较项 | 夏夫兹博里 | 哈奇生 |
|---|---|---|
| 形而上学基础 | 宇宙是和谐整体，美是和谐的显现 | 不谈宇宙，只谈心灵的结构 |
| 内在感官 | 「内在的眼睛」，美感与道德感同源 | 明确为独立的审美感官，与道德感官并列 |
| 美的分层 | 三级：死的形式、形成的形式、形成形式的形式 | 两类：本原美与比较美（模仿的美） |
| 无利害 | 以「不掺杂占有欲」界定 | 接受并技术化，作为美感的定义性特征 |
| 普遍性的根据 | 宇宙秩序与人的自然本性 | 造物主赋予人类同一套感官结构 |
| 与德性的关系 | 美善同源，一个能力两个方向 | 各有独立来源，不能互相还原 |
| 主要困难 | 目的论承诺无法证明 | 公式无法解释崇高与丑的愉悦 |

这张表说明一件事：哈奇生让理论变得可反驳，这既是进步也是损失。夏夫兹博里的含混保护了他，哈奇生的清晰暴露了他。

## 五、经典原著

《论特征》1711 年出版，三卷，收六篇论文，形式多样：书信、对话、随笔、格言。这种形式与主张相配。《道德家们》用一场山间对话展开三重形式的上升，是全书文学性最强的部分。

哈奇生的《探究》第一部《论美、秩序、和谐与设计》，先驳「美在比例」的理性主义说法，再提出内在感官，最后给出齐一性原则；第二部《论道德善恶》把同一方法用于德性。

核心表述可浓缩为：

::: quote 《关于美与德性观念起源的探究》第一部
uniformity amidst variety（多样性中的齐一）
:::

这个短语是中介结构，两个极端都不是美的充分条件，美发生在两者的比例里。这解释了哈奇生为什么相信美可以比较：比例可比较，两个对象的美也就可以排序。

但也正是这里埋下困难：崇高是齐一性失效时的经验，丑的愉悦是比例失调时的快感。一个以比例为核心的原则，遇上了以超出比例为核心的经验。

## 六、艺术案例：奇斯威克别墅与它的反面

奇斯威克别墅（Chiswick House，1725—1729）由伯灵顿伯爵三世 Richard Boyle 与肯特（William Kent）合作，蓝本是帕拉第奥的圆厅别墅。看形式：严格左右对称；中央八角穹顶统摄全局；六柱门廊的高度与柱径成固定比例；窗、壁柱、檐口由同一模数生成。整座建筑可以从一个数字推出来。

这是「多样性中的齐一」最理想的实物：同一模数生出无数变化，又被统摄在一个轮廓里；眼睛不必计算就感到秩序。

再看反面。18 世纪中叶，英国园林开始拆除围墙与直线，改用曲折小径、不经意的水面、突然出现的废墟。钱伯斯 1760 年代在丘园建中国塔，把异域的惊奇搬进园林。这些对象齐一性低、意外性高：路径不告诉你通向哪里，景色在转角处突然打开。

按公式，前者应远胜后者；实际发生的却是后者在 18 世纪下半叶迅速走红。公式并未错，只是覆盖面有限：对象在比例之内时有效，以超出比例取胜时失效。崇高论正是为接管这个区间而兴起。

## 七、思想联系

向前追溯，这套方案有三处源头。柏拉图《会饮》的美的阶梯提供了上升结构。普罗提诺把「形成形式的形式」推到超越者的位置。西塞罗的 sensus communis 提供公共性概念，夏夫兹博里把它从修辞学挪到伦理学。

向后看，影响沿两条线走。一条通向休谟与博克：休谟接受「美在感受中」，用理想批评家补普遍性；博克把无利害与生理机制结合，用自我保全解释崇高（参见本模块第 6、7 讲）。另一条通向康德：他在《判断力批判》开篇把鉴赏判断规定为无利害的、普遍的，这两条都可看作对哈奇生问题的重新回答。区别在于康德拒绝了「道德感官」这一心理学假设，也拒绝把美与善混为一谈。

## 八、本节总结

::: key 本讲要点
- 夏夫兹博里用「和谐」同时安置美与善：美感与道德感是同一内在感官的两个方向。
- 美分三层：死的形式、形成的形式、形成形式的形式；上升结构承自柏拉图—普罗提诺，起点在感官经验。
- 无利害的论证靠一条观察支撑：感受不随占有变化；反例存在，标准带上循环。
- 哈奇生把它技术化为独立的审美能力，并提出美与德的相对独立性。
- 「多样性中的齐一」是比较原则，不能代入数值；它解释不了崇高、丑的愉悦与表现。
- 循环论证的指控与辩护各有强处：一方要机制，一方主张直接性是最终事实。
:::

一句话收束：夏夫兹博里给了美学一个器官，哈奇生给了它一把尺子；器官无法解剖，尺子量不了出格的东西。

值得继续追问的问题：如果趣味分歧不能用「感官失灵」解释，「人人共有同一感官」这个假设还剩下什么用？它是否只是把共识愿望写成了事实？
