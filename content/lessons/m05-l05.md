## 一、本节导入

夏天的河堤上站满了人。上游连日暴雨，水面比平时宽出两倍，浑黄的水推着树枝与塑料桶往下走。堤是去年新修的，水泥面上还留着模板的印子。人们靠着栏杆拍照，有人说「太壮观了」，有人说「腿有点软」。没有人真的害怕，因为堤不会垮；可也没有人愿意离开。

把这个场景与另一种对照：在美术馆里看一幅巨大的画，画面上的暴力与碎裂迎面扑来，你退后半步，又往前一步。两种经验里都有一种「被压倒」的感觉，也都有一种奇特的吸引力。康德把这类经验叫崇高。

崇高在十八世纪是一门显学。博克用神经的紧张解释它，旅行者跑到阿尔卑斯山去寻找它，风景画里开始出现暴风雨与废墟。康德要做的是把这团混杂的经验清理出一个结构：它为什么先痛后快？这种愉悦凭什么可以被要求？

## 二、核心知识：两种崇高与一种负愉悦

::: def 崇高（das Erhabene）
康德用来描述一类审美经验的术语：对象的表象超出想象力的把握能力，先引起不快与压迫感，随后由理性（或道德使命）显示出的优越性转为愉悦。崇高不属于对象的形式，属于主体的心意状态。
例子：仰望无云的星空、面对风暴中的海面、站在巨大的瀑布前。对象没有给出「合适的形式」，人却在失措之后感到自己被提升。
:::

::: def 数学的崇高（das mathematisch Erhabene）
对象在数量上「绝对大」，超出想象力把它总括为一个直观整体的能力，因而唤起理性对「无限」的要求。愉悦来自理性能够思维一个感官无法给出的总体。
例子：金字塔、圣彼得大教堂的内部、银河。康德提醒，看金字塔不能太近也不能太远：太近则无法总括，太远则失去尺度。
:::

::: def 力学的崇高（das dynamisch Erhabene）
对象在力量上压倒一切，显得可以摧毁我们；但在安全的距离上，我们意识到自己有一种不受自然威力支配的能力（道德人格），于是恐惧转为敬重。
例子：从安全的岸上观看风暴中的海。若真的身处险境，崇高立刻消失，只剩恐惧。
:::

::: def 消极愉悦（negative Lust）
崇高感的愉悦经由不快而达到，因此是间接的、否定的。它不以顺畅的和谐为特征，而以「失败之后的提升」为结构。
例子：恐怖片里，观众在安全的座位上受惊，散场后说「真过瘾」；这个「过瘾」建立在「我其实没事」的前提上。
:::

三种形态的差别可以列成一张表：

| | 美 | 数学的崇高 | 力学的崇高 |
|---|---|---|---|
| 形式 | 有边界、可把握 | 无形式、超出尺度 | 无形式、显示威力 |
| 想象力 | 与知性自由游戏 | 在总括上失败 | 在抵抗上无力 |
| 相关能力 | 知性 | 理性（总体理念） | 理性（道德使命） |
| 愉悦 | 直接的 | 间接的（经由不快） | 间接的（经由恐惧） |
| 前提 | 无须文化 | 需要文化 | 需要安全与文化 |

表中最容易被忽略的是最后一行：崇高需要文化前提，美不需要。

::: warn 「崇高就是更大的美」
把崇高当成美的加强版，会推出「越大的东西越崇高」。一间巨大的仓库不崇高，因为它仍可被一眼丈量；一片雾中的山脊尺度并不惊人，却能让人失去方位感。崇高依赖想象力的失败，与尺寸的纪录无关。
:::

## 三、代表人物：康德与博克

康德（Immanuel Kant，1724—1804）对崇高的兴趣早于对美的兴趣。一七六四年的《关于优美感与崇高感的考察》还是人类学笔调，把崇高分配给不同的气质、性别与民族。到一七九〇年的《判断力批判》，问题换成了先验的：崇高判断凭什么要求普遍同意？这个转变让崇高从「哪些人容易被感动」变成「主体能力之间的何种关系」。

博克（Edmund Burke，1729—1797）提供了经验的底本。他在《关于我们崇高与美观念之根源的哲学探讨》里把崇高归于自我保存的情欲：凡危及生命、让人联想到痛苦与危险的对象，都激起崇高感；其生理机制是神经的紧张，紧张解除时产生的快感，他称为 delight，与正面的 pleasure 不同。康德保留了博克的观察清单，换掉了根据：神经的紧张变成想象力的失败，delight 变成「消极愉悦」。

康德对博克的批评很明确：经验描述无法说明必然性。若崇高只是神经的反应，那么「你应当觉得这崇高」就没有根据，只能说「你的神经如此反应」。康德的方案是先验的，代价是必须为崇高设置前提：安全、文化与理性理念的发达。

## 四、理论解析：两套机制与一个命题

**共同的结构。** 崇高与美都是反思判断，都要求普遍同意，都不涉利害。差别在两处：美关乎形式，崇高关乎无形式；美的愉悦直接，崇高的愉悦经由不快。康德用「消极愉悦」标记后者：愉悦由挫败促成。

**数学的崇高，四步。**

1. 对象必须被表象为「绝对大」，即大到超出一切比较。任何「多大」都要有尺度，尺度总可以再大；绝对大要求一个不再有尺度的尺度。
2. 想象力有两个动作：把握（把部分逐一收进意识）与总括（把全体合成一个直观）。把握可以无限进行，总括有上限。
3. 理性却要求总体，甚至要求无限。这个要求超出想象力，于是总括失败，产生痛感。
4. 失败显示了一种超出感性的能力：理性能思维感官无法给出的总体。痛感转为愉悦，愉悦的对象是自己身上的理性。

康德举金字塔与圣彼得大教堂：太近无法总括，太远失去尺度。尺度落在主体能力上，因此「大」算不上对象的属性。

**力学的崇高，三步。**

1. 自然被表象为威力：它能摧毁我们，肉体无法抵抗。
2. 这表象要成为崇高，必须有安全的前提。岸上看风暴是崇高，船上看风暴是恐惧。
3. 在安全前提下，我们意识到自己有一种独立于自然的能力：道德人格。自然的威力可以毁灭生命，却无法支配准则。恐惧转为敬重，敬重的对象是自己身上的理性。

两套机制的共同点是「失败—提升」：数学的崇高里失败的是总括，力学的崇高里失败的是肉体抵抗；提升的都是一种超感性的能力。

**「崇高不在自然中，而在心灵中」。** 自然对象只是契机，真正被称作崇高的是心意状态。康德用「偷换」（Subreption）描述这种倾向：把内心的感受误置到对象上，说「这座山很崇高」，其实崇高在判断者心里（大意）。这有两个后果：崇高论从风景的理论转为主体的理论；崇高与道德哲学接通，所以康德说「美是道德的象征」。

**文化前提。** 康德承认崇高要求心灵的感受性，而这需要教养。未受教化的人面对风暴只感到恐惧。这并非时代的偏见，它有结构上的理由：崇高要求理性理念的发达，而理念的发达需要文化。于是崇高判断的普遍性带了条件：它要求于人人，却只对已经具备条件的人生效。

**最强反对：用胜利掩盖失败。** 这个批评有四个版本。

其一，意识形态的版本。布尔迪厄式的质疑指出，审美距离预设了与必然性的距离：能把风暴当作崇高的人，先得有不被风暴威胁的位置。崇高感因此是文化资本的展示。康德的「安全」前提恰好暴露了这一点。

其二，性别与身体的版本。崇高被分配给理性、男性、超越，优美被分配给感性、女性、依附。这分配在早期文本里已出现，后来虽被先验化，却没有消失。

其三，生态的版本。若崇高只在心灵中，自然就只是道具，自然自身的价值被抹掉。

其四，利奥塔的版本。他把崇高读成「不可表现之物的呈现」：重点在于表象能力的极限被暴露，而非主体的提升。结构保留，胜利的结局取消。

**辩护与限度。** 一种辩护是：康德的文本比「胜利叙事」复杂，他强调愉悦是消极的，想象力的失败只是被承受。另一种辩护是：即使崇高感有社会条件，也不推翻它的规范性，正如「识字需要教育」不推翻「人人应当识字」。两种辩护都有限度。难以回答的是：若崇高感以安全与文化为前提，它在灾难现场还剩下什么？

## 五、经典原著：崇高的分析论

《判断力批判》的「崇高的分析论」紧接美的分析论，康德先做否定的工作：崇高不属于任何形式，因此不能从「形式的合目的性」去解释；再做肯定的工作：想象力的失败对理性而言是合目的性的，愉悦由此产生；最后做限定的工作：这一切以安全与文化为条件。

写法与美的分析论不同：美的分析论从单纯的愉悦出发，层层分析；崇高的分析论从冲突出发，先描述冲突，再说明冲突如何转为和谐。美是顺畅的，崇高是颠簸的。

::: quote 《判断力批判》崇高的分析论（大意，据通行中译）
崇高的情感是一种通过不快而产生的愉悦。
:::

还有一个容易被忽略的区分：严格意义的崇高只属于自然，艺术只能「表现」崇高。艺术总有边界与意图，崇高要求无形式、无意图。这限制使后来的讨论很尴尬：大量作品在制造崇高效果，却不符合康德的严格定义。

## 六、艺术案例：毕加索《格尔尼卡》

一九三七年，毕加索为巴黎世界博览会的西班牙馆画了这幅巨作，高三点四九米，宽七点七六米。画面是黑白灰的，没有一种鲜艳的颜色。中央是一匹被长矛刺穿的马，身体扭曲，舌头伸出；左边是一个抱着死婴的母亲，头向后仰，嘴张着；右边是一个举着灯的女人，手臂伸得很长；地上躺着一个断剑的士兵，手掌上有一个钉痕般的孔。上方偏中，一只眼睛形状的灯泡发着光。

形式上最突出的是「碎裂」。人物的身体被拆成块面，正面与侧面同时出现，眼睛与乳房错位；空间没有透视，前后关系被压平。构图有一个大致的三角形，以马为中心，但三角形的边被跌倒的人体打断，稳定感不断被破坏。黑白灰的选择让画面接近新闻照片，颜料的表面是哑光的，像报纸的印刷。

从康德的框架看，这幅画具备崇高的几个要素：尺度的压迫（观众必须仰头或后退）、形式的瓦解（没有统一视点）、痛感的直接（哭泣、死亡、断裂）。愉悦在哪里？按康德的模型，愉悦来自「理性意识到自己不被压倒」。看这幅画时，类似的感觉确实会出现：人被击穿之后，仍能站立着看下去。

但这个「提升」并不稳固。画面没有给出慰藉：没有英雄，没有救赎，没有胜利的暗示。灯泡像一只冷漠的眼睛，也像现代技术的太阳，照亮却不温暖。这正是它与康德模型最不同处：失败没有被转化，只是被呈现。

于是《格尔尼卡》成了一个检验案例。若坚持康德的严格定义，它不算崇高，因为它的对象是历史暴力，而观者并不安全；若放宽定义，承认艺术可以制造崇高效果，那么「理性的胜利」这一环就松动了。这幅画让人感到的，更像是利奥塔所说的「不可表现之物的呈现」：表象能力被推到极限，极限之外没有补偿。

::: fig a-guernica | 《格尔尼卡》：黑白灰的碎裂构图，以马为中心的三角形被跌倒的人体打断，灯泡像一只冷漠的眼睛
:::

还有一个细节：画中没有飞机，没有炸弹，没有明确的敌人。暴力的来源被抽掉，只剩下承受暴力的生命。画面因此从「事件报道」变成「苦难的普遍形式」，接近康德所说的「审美理念」：直观远超确定概念，拒绝把苦难收编为有意义的故事。

## 七、思想联系

向前追溯，崇高概念从修辞学中生长出来。朗吉弩斯的《论崇高》关心的是文体效果：什么样的句子让人惊心动魄。布瓦洛的翻译把它送入古典主义的论争，博克把它变成经验科学的问题，康德把它变成先验哲学的问题。三次转手，对象换了三次。

向后看，席勒在《论崇高》里把崇高与道德自由连接，认为崇高感证明人能够超越感性；叔本华把它读成意志的暂时受挫与超越；利奥塔在二十世纪重新启用崇高，把它理解为现代艺术对「不可表现」的承担；环境美学则批评崇高话语把自然当作主体自我确证的舞台。四条线都从康德出发，走向不同方向。

## 八、本节总结

::: key 本讲要点
- 崇高是想象力受挫后由理性补偿的间接愉悦，其结构是「失败—提升」。
- 数学的崇高处理「绝对大」，靠总括的失败显露理性的总体能力；力学的崇高处理「绝对强」，靠道德人格显露对自然的独立。
- 崇高不在自然中，而在心灵中；自然只是契机，康德用「偷换」描述我们把它误置到对象上的倾向。
- 崇高比美更依赖安全与文化，这个前提使它的普遍性带有条件。
- 最强的反对指出：把感性的挫败读成理性的胜利，可能是一种意识形态的补偿。
:::

结论：崇高论的力度来自它承认失败，危险来自它急着把失败兑换成胜利。康德的文本在这两者之间摇摆，后来的读法各取一端。

值得继续追问的问题：看一场远处的灾难直播，我们感到的震颤属于崇高，还是属于消费？如果「安全」是崇高感的构成条件，那么媒介给我们的一层屏幕，究竟是在制造崇高，还是在取消它？
