## 一、本节导入

1910 年 11 月，伦敦格拉夫顿画廊。罗杰·弗莱策划的「马奈与后印象派」展览开幕，展室里挂着塞尚、梵高、高更、马蒂斯。观众的反应可以用一份当时的报道概括：有人笑，有人怒，有人要求退票。批评界的主流判断是这些画家不会画——透视不对，解剖不对，笔触粗糙，颜色刺眼。

这场争吵提出了一个理论问题：如果一幅画既不像对象，也不讲好故事，还不讨人喜欢，我们凭什么说它是艺术？为它辩护需要一种新语言，这种语言不能说「画得真像」，也不能说「寓意深刻」，只能说「形式本身有价值」。四年后，克莱夫·贝尔把这种语言压缩成一个短语：有意味的形式（significant form）。

这个短语在二十世纪的力量与它的麻烦来自同一处：它把审美价值完全交给了形式，因此既能为最激进的新艺术开路，也无法说明形式为什么值得看。

## 二、核心知识：形式、意味、纯粹性

::: def 有意味的形式（significant form）
贝尔的术语，指线条与色彩以某种特定方式组合而成的形式与形式关系；这种组合激起一种特殊的审美情感。按贝尔的用法，「意味」并不指向故事、象征或道德寓意，它指向形式自身所承载的情感分量。
例子：一块拜占庭镶嵌画上的金色背景，没有透视，没有解剖，却能让人感到一种非人间的静止；贝尔会说，起作用的是色块的排布与轮廓的关系。
:::

::: def 形式主义（formalism）
一种主张：艺术的价值与意义主要由形式（构图、线条、色彩、结构、语言手法）决定，题材与内容处于从属地位。形式主义在十九世纪有音乐上的先例，在二十世纪分为视觉的与文学的两支，彼此并不共享同一套论证。
例子：汉斯利克论音乐时说，音乐的美是「音乐特有的」，来自音的运动形式，与它唤起的情绪无关；这是听觉上的形式主义。
:::

::: def 媒介纯粹性（medium specificity）
格林伯格的术语，指每种艺术应当在自己的媒介独有的条件下发展，把借自其他艺术的效果清除出去。绘画的独有条件被他定为平面性、画布的矩形与颜料的性质。
例子：他认为现代绘画的出路是承认画布是平的，因此放弃透视纵深，转向平面上的色与形；雕塑则应以三维性为自己的条件。
:::

三种形式主义常被混为一谈，其实问题意识不同。下面这张表把它们分开：

| | 贝尔、弗莱（视觉） | 俄国形式主义（文学） | 格林伯格（媒介） |
|---|---|---|---|
| 核心概念 | 有意味的形式 | 陌生化、手法 | 媒介纯粹性 |
| 要解决的问题 | 为看不懂的新艺术辩护 | 文学研究如何成为科学 | 现代主义如何自我批判 |
| 方法 | 形式描述与趣味判断 | 语言学分析 | 艺术史叙事 |
| 时间 | 1910 年代 | 1916 年起 | 1939 年起 |
| 遗留困难 | 循环论证 | 忽视社会历史 | 目的论式的进步叙事 |

## 三、代表人物：贝尔、弗莱、格林伯格

贝尔（Clive Bell，1881—1964）出身伦敦富裕家庭，在剑桥读历史，之后在巴黎学画，属于布卢姆茨伯里圈。他既不是学院哲学家，也不是职业批评家，写《艺术》（1914）时三十三岁。这本书的口气是宣言式的：他要给「审美假说」一个定义，并用它重排整个艺术史——把拜占庭、中国、日本、墨西哥与前哥伦布时期的作品放进正典，把十九世纪的叙事绘画赶出去。贡献在于提供了一个可操作的判别标准；局限在于这个标准无法独立于它要解释的对象。

弗莱（Roger Fry，1866—1934）是这场运动真正的实践者。他受过自然科学训练，后来画画、写批评，1933 年任剑桥斯莱德讲席。1910 年与 1912 年两次后印象派展览由他策划，他为塞尚写的专论（1927）至今仍是形式分析的范本。弗莱的贡献在于把「形式」变成了可以逐笔追踪的东西：他不说「这画很有意味」，他指给你看轮廓如何在某处收紧、色块如何从冷转暖。他的局限在于，当他试图把这种分析上升为理论时，他也不得不借用贝尔的「审美情感」。

格林伯格（Clement Greenberg，1909—1994）把形式主义历史化。他在 1939 年的《先锋派与庸俗艺术》里把现代艺术放进政治与市场的对立中，在 1940 年的《走向更新的拉奥孔》里主张各门艺术应当守住自己的媒介，在 1960 年的《现代主义绘画》里把这一主张写成一部自我批判的历史。他的贡献在于让形式主义有了时间维度；局限在于这部历史带有明显的目的论色彩，仿佛绘画注定走向平面。

## 四、理论解析：一个定义，一个循环，一次改写

**第一步：语境。** 形式主义不是从书斋里长出来的，它是对一次趣味危机的回应。1910 年前后，欧洲绘画同时出现几种「画不像」的实践：塞尚把形体拆成色彩模块，马蒂斯用平涂的色块取消明暗，毕加索与布拉克把对象拆成多个视点。这些实践共同攻击了文艺复兴以来的两个前提：绘画应当再现对象，应当制造空间幻觉。为它们辩护，旧的美学词汇全部失效，因为「像」与「美」都不再适用。贝尔与弗莱要提供的，是一套不依赖「像」的评价语言。

**第二步：贝尔的论证结构。** 它可以分成三步。

1. 观察：某些作品（拜占庭镶嵌画、波斯陶器、塞尚）能唤起一种独特的、与日常生活情感不同的情绪。
2. 命名：这种情绪只能由「线条与色彩的组合关系」引起，因此称这种组合为「有意味的形式」。
3. 推论：既然只有形式引起审美情绪，那么题材、故事、再现的准确与否都与审美价值无关；一件作品越是依赖文学内容，审美价值越低。

第三步的结论很有杀伤力：它一举把十九世纪的叙事绘画、爱国主义历史画、插图式绘画判为低级。贝尔甚至说，欣赏艺术品时不必从生活中带来任何东西（大意）。这句话是形式主义最纯粹的表述，也是它最脆弱的地方。

**第三步：循环。** 问题出在第 2 步。贝尔怎么知道那种情绪「只能」由形式引起？他的回答是：因为它是一种特殊的审美情绪。那又怎么知道它是审美情绪？因为它是被有意味的形式引起的。这就形成了循环：形式由情感定义，情感由形式定义，两个词互相支撑，谁也没有独立的内容。

贝尔自己似乎意识到这一点，所以他把自己的主张称为「假说」，并求助于一个形而上学：有意味的形式让我们瞥见「物自体」，即现象背后的实在（大意）。这个补充把论证从循环里救了出来，代价是引入了一个更可疑的实体。批评者可以说，与其说「物自体」解释了形式的力量，不如说它只是给这种力量换了一个名字。

**第四步：弗莱的实践。** 弗莱的价值在于，他的批评比他的理论更聪明。他不满足于宣布「有意味」，他做三件事：第一，追溯轮廓的节奏，指出一条线如何在转折处加速或停顿；第二，分析体积的构成，看画家怎样用色温的推移代替明暗；第三，辨认「造型观念」，即画家如何处理画面与画布平面的关系。他对塞尚的解读正是这样：塞尚的「调整」（modulation）用冷色后退、暖色前进，造出一种既结实又开放的空间；他的笔触常常留白，让画面保持未完成的状态。

弗莱还用这套语言为后印象派辩护：这些画家不模仿形式，而在创造形式；不模仿生活，而在为生活寻找对等物（大意）。这句辩护的力量在于，它把「画不像」从失败改写成另一种成就。它的弱点在于，一旦「对等物」无法被检验，任何粗糙都可以被说成深刻。

**第五步：格林伯格的历史化。** 贝尔的形式是超时间的：拜占庭、非洲雕塑、塞尚共享同一种「有意味」。格林伯格把它放进历史：现代主义是各门艺术自我批判的过程，每门艺术要清除借自其他媒介的效果，剩下的才是它独有的。绘画独有的条件是平面，因此现代绘画的历史就是一部走向平面的历史：马奈最早承认画布的表面，立体派拆除空间，抽象表现主义把颜料变成事件本身。

这一步解决了贝尔的两个困难。第一，循环被历史叙事替代：不必再问「什么形式有意味」，只问「这种形式在媒介自我批判的进程中处于什么位置」。第二，评价有了方向：越接近媒介的纯粹条件，越现代。但代价同样明显：历史被写成了单行道。1960 年代之后，极简主义、波普艺术、观念艺术都不按这条单行道走，格林伯格的叙事就变成了一个需要被推翻的框架。

**第六步：最强反对。** 第一，概念无法独立界定。形式主义者只能在事后指认：先认定某件作品伟大，再从中找出「有意味的形式」。这把理论变成了趣味的追认，无法预测，也无法反驳。第二，内容与语境被抹掉。《阿维尼翁少女》里的面具来自非洲雕刻，这个事实涉及殖民地的收藏、人类学的展示与巴黎画坛的时尚，形式分析若把它们全部剔除，剩下的只是「构图」。第三，形式主义无法解释自己的情感。它预设了一种专门的「审美情感」，可我们从未在生理或心理上找到它；被形式打动，往往同时是被题材、记忆、联想打动。第四，标准随趣味漂移。贝尔把大量文艺复兴绘画判为「描述性」而贬低，这一判断今天很少有人接受，说明「有意味」的判准跟着批评家的口味走。

::: warn 「有意味的形式」等于「抽象艺术」
常见的误读是把贝尔当成抽象艺术的代言人。他确实欣赏非再现的作品，但他的定义并不要求抽象：一件再现性的作品，只要形式关系足够强，也可以是「有意味」的。反过来，一幅抽象画若只有装饰性的图案，在贝尔看来同样不合格。他排斥的是「文学性」，不是「对象」。
:::

## 五、经典原著：贝尔《艺术》（1914）

《艺术》全书不厚，前半部提出「审美假说」，后半部提出「形而上学假说」并重述艺术史。第一章是全书的核心，贝尔在那里区分了两种看画方式：一种是「生活的方式」，把画中人物当成真人，关心他们的命运；一种是「审美的方式」，只关心形式关系。他主张，只有后一种方式才触及艺术。

贝尔还提出一个历史判断：艺术在原始社会与拜占庭时期最纯粹，因为那时形式尚未被文学内容污染；文艺复兴之后，绘画越来越像文学，审美价值随之下降。这个判断的意识形态色彩很明显：它把「进步」与「倒退」的方向颠倒了，用「原始」为现代艺术背书。

::: quote 《艺术》第一章（大意，据通行英文本）
唤起审美情感的，是线条与色彩以某种方式组合起来的形式与形式关系；这些形式关系与关系中的形式，我称之为「有意味的形式」。
:::

这段话里有一个不易察觉的滑动：前半句是经验描述（某些形式唤起情感），后半句是定义（这类形式叫有意味的形式），而「意味」究竟指什么，始终没有被独立说明。贝尔的追随者把这个空缺填成了口号，反对者则把它当成了攻击的靶心。

## 六、艺术案例：《阿维尼翁少女》

1907 年，毕加索完成《阿维尼翁少女》，约 244 × 234 厘米，现藏纽约现代艺术博物馆。画面五个女性人物挤在一个浅窄的空间里：左侧三人面容接近伊比利亚雕塑，眼窝深、鼻梁直；右侧两人的脸被处理成面具，色块切成锐角，一只眼睛是漆黑的洞；下方中央摆着一堆水果，像把静物画塞进了人物画；背景的蓝色帷幔被拉成几道硬折，右上方的一块深蓝几乎是空的。

形式上有三处关键。第一，空间被压平：床沿与地面的角度错乱，人物仿佛贴在画布上，没有可以走进去的深度。第二，形体被切面化：身体的轮廓由直线与锐角构成，粉色与赭色的色块互相咬合，体积靠色块的明度对比而非明暗渐变。第三，视点被拆散：同一个头部上，正面与侧面并存。

按贝尔的框架，这幅画几乎是为「有意味的形式」量身定做的：它取消了叙事，拒绝了透视，把力量全部放在形与色的关系上。按弗莱的框架，也可以做很细的分析：右侧两张面具脸如何把画面的重心向右拉，下方的水果如何用一个稳定的三角把散乱的结构锚住。

但正是这幅画暴露了形式主义的限度。面具的来源是非洲雕刻，1907 年毕加索在特罗卡德罗博物馆看到它们；这个事实把作品接入了殖民贸易、人类学展示与巴黎先锋派的异域想象。画题中的「阿维尼翁」指向巴塞罗那的一条街，也影射妓院。这些都不是可以从画面上抹掉的「内容」，它们参与了形式的构成：面具之所以能那样切开脸，是因为它本来就不是一张欧洲人的脸。

形式主义能说的，是这幅画如何组织；它说不出的，是这种组织为什么在那一年、那个城市、那个人手里具有爆炸性。

## 七、思想联系

向前追溯，形式主义有两个源头。一个是康德：审美判断不涉及概念、不涉及利害，只关乎对象的表象形式（参见第 5 模块）。贝尔的「审美方式」几乎是「无利害」的通俗版。另一个是汉斯利克：他在 1854 年的《论音乐的美》里主张音乐的美在于乐音的运动形式，与情感内容无关。视觉形式主义把这个论点搬到了眼睛上。再往前，还有罗斯金的「对自然的忠实」，贝尔与弗莱正是通过对罗斯金的反叛来确立自己的立场。

向后看，格林伯格把形式主义变成了美国抽象表现主义的官方叙事，也把「媒介纯粹性」变成了批评标准。1960 年代，极简主义与波普艺术让这套标准失效，弗雷德（Michael Fried）在 1967 年的《艺术与物性》里用「剧场性」反击极简主义，仍然站在形式主义的延长线上。另一条线通向文学理论：俄国形式主义的「陌生化」经布拉格学派进入结构主义，再由结构主义进入符号学与文化研究。两条线在 1970 年代之后都被「语境」与「意识形态」的批评挤压，但形式分析作为技术从未消失，它只是退回到作品分析的内部。

## 八、本节总结

::: key 本讲要点
- 「有意味的形式」是对 1910 年前后趣味危机的回应，功能是为「画不像」的新艺术提供评价语言。
- 定义的核心是循环：形式由审美情感界定，审美情感由形式界定。
- 弗莱的批评实践比贝尔的理论更可靠：他追踪轮廓、体积与笔触，把形式变成可指认的东西。
- 格林伯格用媒介纯粹性把形式主义历史化，代价是写成了一部目的论的单行史。
- 最强反对有两路：概念只能事后指认；内容与语境被系统性抹除。
:::

把这一讲压成一句：形式主义教会了二十世纪如何看画，也教会了它如何不看画。

值得继续追问的问题：当一件作品的「意味」无法与它的题材、材质、流通方式分开时，我们还能不能把形式单独拿出来评价？今天的界面设计、字体排印与数据可视化，是否正在把「有意味的形式」变成一种日常技能？
