## 一、本节导入

《九章集》第一卷第六篇开头有一个看似朴素的观察：一块石头，本来粗糙、没有形状，被技艺打磨成神像或人像，它就美了。普洛丁说，美来自技艺带进来的形式，来自「理念」在石头上的在场。

同一篇里，他顺手拆掉了当时最流行的美学纲领。若美在于部分之间的对称与比例，那么一张左右完全对称的脸应当最美；可是活人的脸比死人的脸美，尽管两者的比例可以一样。若美在于比例，那么纯粹的光、纯净的颜色、单一的乐音都不该美，它们恰恰没有比例可言。这些反例看起来琐碎，指向的却是一个大问题：美究竟属于可测量的形式，还是属于某种在形式之中现身的、不可测量的东西？普洛丁选了后者，并由此搭出一个从质料到太一的宇宙阶梯。

## 二、核心知识

::: def 流溢（emanatio）
拉丁语 emanatio 意为「流出、散发」。普洛丁用它描述万物从太一生成的方式：太一像太阳发光、泉源涌水，自身不减少，却在其外产生了理智、灵魂与感性世界。流溢不经过计划，不消耗本源，也不等于创造：下层不是被「制造」出来的，它像光的边缘一样自然出现。例子：火把热传给周围的空气，火本身不因此变冷。
:::

::: def 太一（to hen, the One）
普洛丁体系的最高本原。它绝对单纯，没有部分、没有规定、没有形状，甚至不能说「存在」，因为「存在」已经是规定。它是一切的规定性的来源，本身却超出存在与思维。对这类的本原，只能采用否定神学的方式言说：不说它是什么，只说它不是什么。
:::

::: def 内在美（inner beauty）
指灵魂自身的美：德性、正义、节制、知识。普洛丁认为这类美比形体美更高，因为它离「一」更近，也因为它不依赖质料。认识内在美要求转向：把目光从外物收回，看向自己的灵魂，像雕刻家打磨自己的雕像一样去掉多余的部分。
:::

宇宙的层级可以先排成一张表：

| 层级 | 存在方式 | 与「一」的关系 | 美的形态 |
|---|---|---|---|
| 太一 | 超越存在与思维 | 绝对统一 | 美本身的源泉，超越美 |
| 理智（nous） | 思维与理念的总体 | 多中之一 | 理念之美，最纯粹的形式美 |
| 灵魂（psyche） | 既统一又分散，赋予形体生命 | 一与多的中介 | 德性、知识、秩序之美 |
| 质料（hyle） | 非存在、纯粹的匮乏 | 离「一」最远 | 无美可言，只能被形式照亮 |

表格里每一层都从上一层「流出」，同时转身回望上一层，才获得自己的规定。这个「回望」的动作很关键：流溢并非单向的倾倒，下层之所以成形，靠的是它对上的凝视。

## 三、代表人物

普洛丁（Plotinus，约 204—270）生于埃及的吕科波利斯，青年时在亚历山大港求学，听了多位老师的课都不满意，最后跟随阿摩尼乌斯十一年。为了解波斯与印度的智慧，他在 243 年加入戈尔迪安三世的远征军；皇帝被杀，远征失败，他辗转回到安条克，244 年前后到罗马讲学。

在罗马，他不开门派，只在家中聚徒讨论，学生里有元老、医生、诗人，也有后来整理他遗稿的波菲利。波菲利在 263 年入门，记录下他写作的次序，并把五十四篇论文编成六组、每组九篇，是为《九章集》。普洛丁晚年患重病，270 年病逝于坎帕尼亚。波菲利记载他曾数次达到与太一合一的体验；这类记载出自学生手笔，读时宜作传记材料，不宜当作教义。

他的思想位置可以这样理解：他把柏拉图的「美的阶梯」改写成宇宙论的循环，把「分有」改写成「流溢与回望」，把一个对话中的上升经验，变成一套关于万物如何存在的体系。

## 四、理论解析

### （一）流溢的图式

太一为何会产生万物？普洛丁的回答带着一种近乎自然的必然性：完善者必然给予，善的本性就是流布自身。太阳不为了照亮而照亮，它只是发光；泉源不为了河流而涌水，水只是溢出。太一的「创造」没有计算，没有目的，也没有疲劳。

流溢的次序是：太一首先流出理智。理智是太一的「看」，是理念的总体，在那里，一切事物都有其原型。理智再流出灵魂，灵魂是理念与感性世界的中介，它既保有多的一致性，又把自己分散到无数个体中，赋予身体以生命与形式。灵魂之下是质料，质料并非被创造出来的东西，它是流溢的尽头，是光无法再照透的边界。

质料在普洛丁那里位置很尴尬。他说质料是非存在，是匮乏本身，是恶与丑的根源；可是形体之美又必须借助质料才可见。于是形体美的地位被规定为「光在暗处的痕迹」：美属于照进来的形式，不属于被照的石头。这一规定同时解释了丑——丑是形式未能统摄质料，是杂多压倒了统一。

### （二）美在分有理念，不在对称比例

普洛丁对比例说的反驳，可以整理成五步。

第一步，活人与死人。一张脸的比例可以完全相同，活人的脸美，死人的脸不美。差别不在比例，在灵魂是否在场。第二步，单纯之物。光、金色、纯净的红色、一个单音，都没有部分之间的对称，却明显美。第三步，同一比例的效果不同。同样的对称放在不同的事物、不同的语境中，引起的感受大不相同；比例本身无法解释这种差别。第四步，无形之美。德性、知识、法律、制度没有几何比例，却是更高意义上的美。第五步，结论。比例只是形式在质料中呈现时伴随的结果；真正的美是理念的在场（parousia），是统一性对杂多的照亮。

这五步里，第一步最有力，因为它用一个日常经验击中了形式主义的要害：你可以测量一张脸，却测量不到那张脸上的「活」。第四步最彻底，它把美从感性领域扩展到伦理与认识领域，使美学与伦理学共用一套判据。

普洛丁还给出一个关于审美经验的描述：灵魂看见美时会感到亲切、战栗、似曾相识，因为它认出了自己的来源。美的经验因此带有回忆的结构，美的事物是故乡的痕迹。这个描述后来被浪漫主义接过去，变成了「乡愁」式的审美。

### （三）内在美与自我净化

既然美是分有，那么变美的方式就是「更多地分有」，而分有的障碍是附加物。普洛丁用了一个比喻：金子本身是亮的，沾上泥就不再闪亮；灵魂本来单纯，沾上身体的欲望、意见与恐惧就变丑。净化（katharsis）因此是去除，而非添加。

净化的步骤可以列为三层。第一层，切断与外物的纠缠：不把身体、财产、名声当作自己。第二层，转向内心：把目光从外面收回，观看自己的德性与秩序，像雕刻家打磨一座自己的像，凿掉多余的部分。第三层，超越形式之美：当灵魂在自身中看见秩序，它还要继续向上，直到看见那个给出秩序的东西。到了这一步，美与善合一，审美变成一种归返。

这里有一个容易被忽略的细节：普洛丁并不轻视艺术。他说艺术家观照的是理念，作品之所以美，因为艺术家把理念带进了材料；因此艺术可以比自然事物更美，因为自然事物常受质料的阻碍，而艺术家可以直接依照心中的形式工作。这个说法为后世的艺术辩护留了余地，也与柏拉图「艺术是影子的影子」的判决拉开了距离。

::: warn 「普洛丁只是把柏拉图重复了一遍」
这个印象忽略了他的改造。柏拉图的美本身是超越的理念，普洛丁把它并入流溢的层级，使美成为「一」在万物中的痕迹；柏拉图对艺术相当贬抑，普洛丁却承认艺术家可以依照心中的形式，造出比自然事物更美的东西。骨架取自柏拉图，光与动力则来自这套新体系。
:::

### （四）这套体系的困难

第一个困难是流溢的必然性。若太一是绝对自由的，它为何必然流出？若流出是必然的，它是否受制于某种更高的法则？普洛丁用「善必然给予」来回答，这个回答有力，也把「必然」放进了超越者内部。

第二个困难是质料的地位。质料既是恶，又是美的必要条件；若没有质料，形式之美无从显现。普洛丁只能说质料是「几乎不存在」，这个说法在逻辑上滑溜，在体验上却相当准确：丑的事物总像是「差一点就不存在」。

第三个困难是最高境界的不可言说。若合一体验无法用语词传达，那么以语词为载体的美学，到了最高处就只能沉默。这个沉默后来成了否定神学的起点，也成了所有神秘主义美学的共同难题。

两套纲领的差别可以并排比较：

| 比较项 | 美在形式（毕达哥拉斯、斯多亚一系） | 美在分有理念（普洛丁） |
|---|---|---|
| 美的根据 | 部分之间的比例、对称、和谐 | 理念的在场，统一对杂多的照亮 |
| 典型载体 | 建筑、音乐、人体 | 德性、知识、光、灵魂 |
| 判断标准 | 可测量、可计算 | 可辨认、可引起亲切与战栗 |
| 数学的角色 | 美的本质 | 美的伴随条件 |
| 经验描述 | 观者感到秩序与愉快 | 灵魂认出故乡，被提升 |
| 主要困难 | 无法解释无形之美与「活」 | 无法给出可操作的判据 |

## 五、经典原著

《九章集》第一卷第六篇《论美》是普洛丁美学的核心文本。结构大致为：开头提出美的多样性，随即反驳比例说；中段论证美在于分有理念，区分形体美与灵魂美；随后转向内在美与净化，描述灵魂如何从形体之美上升到德性之美；末尾描述最终的上升，以一句荷马诗句作结，召唤灵魂返回故乡。

同一主题在第五卷第八篇《论理智美》中得到补充，那里讨论艺术家心中的形式与作品的关系；第六卷第九篇讨论「一、善与美」的同一性。三篇合读，可以看出普洛丁的美学并非孤立的章节，它嵌在整套形而上学里。

::: quote 《九章集》I.6 末尾（引荷马）
让我们逃回亲爱的故乡吧。
:::

这句话原是荷马写归乡的诗句，普洛丁借它形容灵魂的归返。故乡不在任何地理位置上，它是灵魂来处的那种统一。用一句史诗的话结束一篇哲学论文，本身就说明他的美学最终指向一种经验，而非一套定义。

## 六、艺术案例：贝尼尼《圣特蕾莎的狂喜》

这件雕塑在罗马胜利圣母堂的科尔纳罗礼拜堂，1647 至 1652 年间完成。它被放在一个壁龛里，上方有一扇隐藏的窗，窗上装黄色玻璃，自然光从这里斜射下来；光沿着镀金的铜条继续往下，像一束被固定的射线。下方是大理石雕成的云，天使举箭，特蕾莎半卧，头向后仰，口微张，眼半闭，脚趾蜷曲。

形式上最值得注意的是光与材料的关系。大理石被处理得不像石头：云的边缘柔软，衣褶层层堆叠又彼此穿透，身体的重量被云托住，仿佛质料在服从一个更强的形状。铜条本是金属，却被镀成光的一部分，从窗口一直延伸到人物的上方。整个壁龛像一个舞台，两侧的包厢里雕着赞助人家族的成员，他们正在观看这场内在事件。

这套安排与普洛丁的图式有几处可以对应。光是太一最常用的比喻，普洛丁说太一像太阳，照亮而不被消耗；在这里，光从不可见的高处降下，人物被照亮，观看者也被要求抬头。特蕾莎的姿态是「出神」（ekstasis），灵魂被拉出自身，这与普洛丁所说的归返在现象上相似。质料被形式照透，正是「分有」的视觉版本。

也有不合的地方。普洛丁的归返是安静的、向内收的，最终的境界近乎无声；贝尼尼把内在经验做成了公共景观，用戏剧性的光、夸张的褶皱和剧场式的包厢，让观众站在外面观看别人的狂喜。巴洛克把神秘主义翻译成了可观看的图像，这个翻译扩大了它的传播，也改变了它的性质。

:::

## 七、思想联系

向前看，普洛丁承接了三条线索：毕达哥拉斯的比例说（他反对它，参见第 2 模块第 2 讲）、柏拉图的美的阶梯与分有说（他改写它，参见第 4、5 讲）、亚里士多德的形式概念（他把形式推向超越，参见第 6 讲）。他的贡献在于把零散的对话段落组织成一个可推导的体系。

向后看，影响几乎覆盖了整个中世纪与近代早期。奥古斯丁通过维克托里努斯的拉丁译本读到柏拉图派著作，在《忏悔录》卷七里记述这次阅读如何帮他摆脱摩尼教的物质主义；他的「秩序、尺度、形式」三要素带着明显的普洛丁痕迹。五、六世纪的伪狄奥尼修斯把流溢图式基督教化，在《神名论》里把美解释为「召唤」（kalos 与 kalein 的词源关联），并发展出光的神学与否定神学，这一支经由中世纪一直传到文艺复兴。费奇诺翻译普洛丁，文艺复兴的新柏拉图主义由此成形。近代方面，谢林与诺瓦利斯的「自然作为可见的精神」、浪漫主义对「乡愁」的偏爱，都可以追到这条线上。黑格尔把美定义为「理念的感性显现」，这个公式可以看作流溢图式的世俗版本：理念照亮感性材料，如同形式照亮质料。

## 八、本节总结

::: key 本讲要点
- 流溢的层级是太一、理智、灵魂、质料；下层通过回望上层而获得形式。
- 美在于分有理念，比例只是形式在质料中呈现时的伴随条件。
- 反驳比例说最有力的一步是活人脸与死人脸的对比：比例相同，美不同。
- 内在美高于形体美，净化是去除附加物、回到单纯，审美最终指向归返。
- 这套图式经由奥古斯丁、伪狄奥尼修斯与费奇诺，成为中世纪光的美学与浪漫主义的共同资源。
:::

值得继续追问的问题：如果美最终要被超越，那么「美学」是否只是通往沉默的一段阶梯？普洛丁留给后世的，是一套理论，还是一种练习？
