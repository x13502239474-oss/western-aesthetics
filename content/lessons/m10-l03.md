## 一、本节导入

把一幅风景画和它描绘的真实风景并排放，多数人会说：画更「艺术」，实景更「美」。这句寻常话里藏着一个哲学难题。如果说美是心灵的产品，那么未经人手触碰的雪山、原始森林、风暴中的海，凭什么也被称作美？如果说美在对象自身的形式，那么艺术家的加工似乎只是多余的中间层。美究竟更喜欢自然，还是更喜欢艺术？

这个问题在美学史上几经翻转。中世纪把自然美读作上帝的造物痕迹，浪漫主义把它读作无限者的象征，黑格尔却把它贬到艺术美之下，20 世纪的环境美学又把它请回中心。同一片风景，被赋予了四种不同的身份。本讲不打算替某一方宣布胜利，而是把每种立场的论证结构拆开，看它成立需要哪些条件。

## 二、核心知识：三种自然美观

自然美（c-natural-beauty）指非人造对象的审美价值，艺术美（c-artistic-beauty）指人造作品中的审美价值。两者之争的关键，在于它们被认定的「来源」不同。历史上大致有三种自然美观。

::: def 受造的自然美
把自然的美归于造物者的完善。中世纪神学美学认为，受造物的秩序、比例与光辉反映了上帝的完美，因此欣赏自然就是欣赏神迹。举例：托马斯·阿奎那（Thomas Aquinas）关于「美涉及形式」的论述，被纳入对上帝造物的赞颂。
:::

::: def 如画的自然美（picturesque）
把自然当作一幅画来欣赏，用构图、景深、明暗等绘画范畴去评价风景。18 世纪英国的「如画」趣味（吉尔平、普赖斯）推动了风景游览与园林改造。举例：游客站在观景点，寻找「像画一样」的角度，甚至按绘画原则改造地形。
:::

::: def 生态／环境的自然美
把自然的美与自然作为生态系统的健康、完整与可持续联系起来。当代环境美学主张，正确的欣赏需要理解对象是什么，而非只看它像什么画。举例：理解一片湿地的水文功能后，它的美不再只是「好看」，而与它的安康相连。
:::

三种美观的更替，不只是趣味的变化，背后是「美由什么担保」这一问题的答案在变：从神，到绘画成规，再到生态事实与人的身体经验。

::: key 本讲要点
- 自然美三种模式：受造（神学）、如画（绘画成规）、生态／环境（当代）。
- 黑格尔贬抑自然美的根据是「自然是自在的理念」，心灵的产品高于自然。
- 环境美学反驳：卡尔森的认知模式、伯林特的参与模式、卡罗尔的唤起模式。
- 当代争论落在气候、荒野保护与生态修复，自然美从趣味问题变成伦理问题。
:::

## 三、代表人物：贬抑者与反驳者

黑格尔（G. W. F. Hegel）在《美学》第一卷里明确贬抑自然美。他的立场来自整套形而上学：自然是「自在的理念」，心灵是「自为的理念」，只有后者能自我认识。美作为「理念的感性显现」，在自然中只能是不完全的显现。他的大意是（转述）：自然美只是为其他对象而美，即为我们、为审美的意识而美；心灵和它的产品比自然和它的现象高多少，艺术美就比自然美高多少。这段原文可在《美学》电子文本中核对。他的贡献是把贬抑理由说到了形而上学根上，代价是很难解释为什么许多人确实从自然中获得强烈的审美经验。

卡尔森（Allen Carlson，当代）是环境美学的认知模式代表。他面对的问题很具体：如果「如画」模式把自然当画看，那么理解生态科学后，我们的欣赏是否应当改变？他的回答是肯定，并主张科学知识是自然欣赏的必要条件。他的贡献在于把「对象是什么」与「如何欣赏对象」绑在一起。

伯林特（Arnold Berleant，当代）提出参与美学（aesthetics of engagement），反对认知模式把人立在自然之外当观察者。他主张审美经验是身体与环境之间的连续交融，欣赏者「置身其中」。他的贡献是把现象学与身体经验带进环境美学，代价是评价的标准变得模糊。

## 四、理论解析：贬抑的根据与三重反驳

### 黑格尔式贬抑：形而上学根据与代价

贬抑可以拆成三步：

1. 美是理念的感性显现，理念要达到自为存在才算完满。
2. 自然中的理念是「自在」的，它被物质包裹，不能自我认识，因此显现是不完全的。
3. 艺术是心灵的产品，心灵能认识自己，因此艺术美高于自然美。

这个论证的说服力完全系于第一步的前提。一旦接受「美＝理念的感性显现」且「心灵高于自然」，结论就顺理成章。代价也在这里：它把自然审美经验解释成「较低的」，这需要解释者无视大量经验事实——许多人在自然面前感到的震撼，并不比在博物馆里弱。

::: warn 常见误解
常说「黑格尔认为自然不美」。这不准确。黑格尔承认自然中有美，只是把它判为「不完善的美」——因为它依赖观察者的意识才成立，缺少自为的完满性。他的立场是等级性的，不是全盘否定。把他说成「自然不美」，会错过他论证里最精细的部分。这里关键词需要澄清：自然所缺的，是「自为的完满性」，也就是靠自己认识自己的那种能力。
:::

### 三重反驳：认知、参与、唤起

环境美学对贬抑的反驳，可以整理成三派：

| 立场 | 代表人物 | 核心主张 | 依据 |
|---|---|---|---|
| 认知模式 | 卡尔森 | 科学知识是正确欣赏自然的必要条件 | 对象是什么决定它如何被欣赏；如画模式错把自然当画 |
| 参与模式 | 伯林特 | 审美是身体与环境的交融，主客二分应当被取消 | 现象学经验；欣赏者置身景观之中 |
| 唤起模式 | 卡罗尔（Noël Carroll） | 自然引发特定情感与想象，欣赏的关键在恰当的情感反应 | 反对知识必要论；强调情绪与叙事的作用 |

卡尔森的论证锋利处在于一个类比：欣赏一幅立体主义画作却不知道立体主义，欣赏就会落空；同理，欣赏一片森林却不知道它是如何生长的，也落空。他由此主张，了解生态学、地质学能「揭示」自然的审美性质。卡罗尔则反驳：科学知识可以丰富欣赏，却非必要条件——一个不识地质的人照样能被峡谷震撼。

::: quote 黑格尔《美学》第一卷·全书序论（原文）
自然美只是为其他对象而美，这就是说，为我们，为审美的意识而美。
:::

这句原文点出了争论的焦点：如果自然美依赖「为我们」，它的地位就低于自足的艺术美吗？环境美学恰恰反过来用这一点——「为我们」意味着自然美与人的经验不可分割，这正值得美学研究。

## 五、经典原著：从《判断力批判》到《美学》

康德在《判断力批判》里给过一个与黑格尔相反的排序：自然美比艺术美更根本。他的大意是（转述）：无利害的愉悦在观赏自然时最纯粹，因为自然不像艺术品那样可能让我们想到它的目的与用途；自由美在自然中才有最纯粹的例证。这个立场被浪漫主义接过去，成为「自然高于人为」的重要根据。

黑格尔在《美学》全书序论里明确反对「美学」这个名称，主张改称「艺术哲学」，理由之一是自然美配不上与艺术美并列（参见第五模块第九、十讲）。两部文本的并置显示：自然美之争从来不只是趣味之争，它连着整个体系的建筑。

## 六、艺术案例：从「如画」到荒野

以风景欣赏的三个层次做一次观看练习。

第一层，如画式观看。站在观景点，找前景的树、中景的水、远景的山，判断明暗与层次是否「像画」。这是 18 世纪如画趣味的延续，风景被框成一个平面。它的美感来自熟悉的绘画成规，代价是把自然削薄成图像。

第二层，认知式观看。面对同一片山地，理解它的地质年代、冰川侵蚀留下的 U 形谷、植被的垂直分布。理解之后，眼前的形状不再是「构图元素」，而是一部写在岩石上的历史。卡尔森会说，这才是恰当的欣赏——你知道它是什么，才看得出它如何美。

第三层，参与式观看。放下「对象」与「观察者」的分界，注意风、湿度、脚下苔藓的质感、身体的位置。伯林特会说，审美经验发生在身体与环境的交界处，而不是一个主体面对一个客体。

::: note 补充
「如画」（picturesque）作为正式美学范畴，由 18 世纪英国的威廉·吉尔平（William Gilpin）等人确立，处在「优美」（beautiful）与「崇高」（sublime，参见第四模块第七讲）之间：如画美偏向粗糙、变化、不规则，适合入画。它一度支配了整个欧洲的风景游览方式，也塑造了今天旅游摄影的取景习惯。
:::

## 七、思想联系：从神创秩序到环境正义

向前追溯，自然美的地位随「美由谁担保」而变：中世纪归于上帝（受造模式），启蒙之后归于人的心意（康德的自然美优先），黑格尔归于理念的历史进程（艺术美优先），浪漫主义把自然当作无限者的象征（参见第六模块第一讲）。

向后看，20 世纪的环境美学把问题从「自然美是否低级」转成「如何恰当地欣赏自然」，再转成「自然美与生态伦理的关系」。卡尔森的认知模式背后是科学世界观，伯林特的参与模式背后是现象学与身体哲学（参见第七模块第八讲），两者都在黑格尔贬抑论失效后争夺新的担保者。

当代的转向尤其值得注意：气候危机、荒野保护与生态修复，把自然美从趣味问题变成伦理与政治问题。一片被修复的湿地是否「不自然」因而「不美」？荒野保护的审美理由与生态理由是否一致？这些问题已经越出黑格尔与康德的框架，需要环境美学与生态批评联手回应。

## 八、本节总结

- 自然美三种模式：受造（神学）、如画（绘画成规）、生态／环境（当代），担保者从神变成绘画成规，再变成生态事实与身体经验。
- 黑格尔贬抑自然美的根据是「自然是自在的理念」，属等级性判断，并非否认自然美存在。
- 康德把自然美看得比艺术美更根本，浪漫主义接过了这一立场。
- 环境美学的三重反驳：卡尔森的认知模式、伯林特的参与模式、卡罗尔的唤起模式，争论「科学知识是否必要」。
- 当代争论从「谁更美」转向「如何恰当欣赏」与自然美的伦理／政治维度。

值得继续追问的问题：如果一片被生态修复的湿地在科学上「健康」，却在观感上不如原始荒野「如画」，两种评价应当如何协调？这是否说明自然美始终在「像什么」与「是什么」之间摇摆？
