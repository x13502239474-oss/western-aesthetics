## 一、本节导入

一双穿了五年的皮鞋。后跟磨偏了大约三毫米，鞋面的折痕按脚背的形状定型，鞋头的皮被擦得发亮，鞋带换过一次，颜色比原装深一号。

这双鞋算不算审美对象？若说不算，理由通常是它没有作者、没有意图、不进美术馆。可它确实有形式：楦型决定脚背的弧度，缝线的密度决定鞋面能不能撑住，磨损的痕迹记录了一个人走路的姿势。它也确实被评价：合脚、体面、太旧、有味道。这些评价会被争论，会被推翻，会随场合改变。

18 世纪建立美学时，这类对象被系统地排除了。巴托把「美的艺术」从工艺中分离出来，康德把审美判断的纯粹性系于无利害，黑格尔把艺术定为精神的显现（参见第 2、3、5 模块）。这条线索走到 20 世纪的分析美学，美学几乎等于艺术哲学：定义、本体、解释、评价，全部围绕作品。

1990 年代之后，三条路同时把日常拉回来。韦尔施诊断世界正在审美化，美学必须处理这个事实；舒斯特曼主张身体是审美经验的场所，美学的范围应当扩到身体实践；斋藤百合子主张日常事物本身就有审美价值，无需借艺术的框架。三条路都扩张了地盘，也共同面对一个难题：地盘扩到哪里为止？

## 二、核心知识：三个概念

::: def 审美化（aestheticization）
指现实越来越多地以审美的方式被生产、包装与感知。韦尔施把它分成三层：表层的装饰、深层的材料与实在的重构、认识论上感知本身的审美性。**例**：同一杯咖啡，表层是杯套上的插画与店招字体，深层是可调色温的灯与吸音材料营造的「氛围」，认识论层面是你因为「这是一家讲究的店」而真的尝出了更多层次。
:::

::: def 身体美学（somaesthetics）
舒斯特曼的术语，指把身体当作审美感知的场所与自我塑造的媒介来研究。它分三支：分析性的（身体如何参与审美经验）、语用性的（各种身体实践的比较）、实践性的（具体的训练方法）。**例**：学琴的人调整坐姿与呼吸，音色随之改变；这里的美学问题不在曲子，而在身体如何被训练成能听出差别。
:::

::: def 日常美学（everyday aesthetics）
以日常事物与日常活动为对象的审美研究，主张其审美价值独立于艺术价值。**例**：擦干净的窗玻璃、切得整齐的菜、晾晒时按颜色排列的衣服；这些判断涉及秩序、合宜、手感，与「这幅画好不好」用的不是同一套词。
:::

三个概念的分工值得留意。审美化是一个诊断，描述世界发生了什么；身体美学是一个纲领，规定美学应当研究什么；日常美学是一个对象域的扩张，主张日常物值得被认真对待。它们常被混用，混用会让「泛化」的批评失去准头——被批评的究竟是世界的状态、学科的范围，还是判断的标准，需要分开说。

## 三、代表人物

**韦尔施**（Wolfgang Welsch，1946— ）是德国哲学家，长期任教于耶拿大学，研究后现代哲学、认识论与美学。他的问题意识来自一个观察：1980 年代以来，「美学」这个词在广告、城市政策、企业管理里被大量使用，含义却越来越空。他要做的是给这种通货膨胀分类，再判断哪一层值得保留。他的立场带有过程哲学与进化认识论的背景，因此对「感性认识」的评价比多数美学家高。

**舒斯特曼**（Richard Shusterman，1949— ）是美国哲学家，分析美学出身，后来转向杜威的实用主义。他早年研究艾略特与文学批评的客观性，1990 年代提出身体美学，并亲自实践费登奎斯方法一类的身体训练。他的写作有一个特点：把哲学论点与身体经验并置，用后者检验前者。这让他容易被学院派视为不够严格，也让他的主张有经验的分量。

**斋藤百合子**（Yuriko Saito）在日本受教育，长期任教于美国罗德岛设计学院，是日常美学与环境美学之间的桥梁。《日常美学》（2007）是她系统化的著作。她的方法接近现象学描述：从清洁、包装、修缮、季节感这些具体活动入手，指出其中的审美判断如何与伦理判断交织。她明确反对把日常美学做成艺术美学的应用分支。

**杜威**（John Dewey，1859—1952）在这一讲里是背景人物。《艺术即经验》（1934）主张审美经验并非另一类经验，它是日常经验被组织到完整、强烈、有节奏的程度时的形态。这条「连续性」论题是舒斯特曼与斋藤共同的起点，也是泛化难题的源头：若审美只是经验的强度，边界就只能靠程度来划。

## 四、理论解析

### （一）韦尔施：三层审美化与「麻醉」

韦尔施的分析分三步。第一步是观察：审美化的词义已经扩散到无法统称的程度。第二步是分层，把混杂的现象按深度排列。第三步是评价，指出哪一层是机会，哪一层是风险。

1. **表层审美化。** 装饰、包装、外观设计、城市立面。特征是给现有事物加一层皮，皮可以剥掉，事物本身不变。超市货架是典型：同一件商品靠包装区分，包装的成本有时超过内容。
2. **深层审美化。** 材料与实在本身被重构。可调色温的光源、可编程的表面、吸音与反射被精确计算的厅堂、屏幕包裹的建筑立面。这里没有「皮」可剥，审美参数已经写进物的构造。
3. **认识论审美化。** 这一层不描述对象，描述认知。韦尔施借助 aisthesis 的古义（感性知觉），主张一切认识都含有审美的成分：选择、凸显、构型。这一层带有先验色彩，也是最容易被误读的一层。

他的评价有一条对立轴：aesthetics 与 anaesthetics（麻醉）。审美刺激过度密集，结果是感官钝化；城市里灯光、屏幕、音乐同时工作，行人反而关闭感知。这个诊断很有力，也很容易被滥用：任何关于疲劳的抱怨都能套上去，缺少可检验的指标。

论证的弱点在层与层之间。第二层与第三层的关系没有交代清楚：如果认识本身是审美的，那么「深层审美化」凭什么被批评为过度？韦尔施的答案大概是「强度」与「反思性」的差别，但这个答案没有展开。

### （二）舒斯特曼：身体作为场所

舒斯特曼的出发点是一个批评：现代美学把审美经验说得太像「观看」。无利害、距离、静观，这些词都以眼睛为模型，把身体的其他部分排除在外。他的替代方案是把身体放回中心：感知是身体的活动，快感是身体的训练结果，自我塑造也通过身体进行。

论证可以拆成四步。其一，审美经验总带有身体维度，这一点在音乐、舞蹈、体育里明显。其二，身体状态可以被训练，因此可以被改善，这使美学带有规范性与实践性。其三，学院美学忽略了这一维度，因为它把对象锁定在文本与图像上。其四，因此美学应当包含身体实践的研究。

他的困难有两处。第一处是标准：身体训练的「好」由什么判定？健康、效率、快感、控制力，这些目标会互相冲突，舒斯特曼没有给出排序。第二处是范围：若美学研究身体训练，它与体育科学、医学、健身产业的界线在哪里？

### （三）斋藤：日常物的审美价值

斋藤的进路不同于前两人。她不从世界的审美化或身体的训练入手，而从对象的日常性入手。她给出的界定是：日常事物是熟悉的、习惯性的、不被注意的。正因为不被注意，它们塑造感知的方式才更深。

她的核心主张有两条。第一条是独立性：日常物的审美价值不能用艺术价值来衡量。一只碗的好，在于口沿的厚度、圈足的重心、釉面在使用中被磨出的光，这些属性在展柜里会退化。第二条是连续性：日常审美判断与伦理判断难以截然分开。关心一件物的保养、注意他人的劳动、对材料来源的敏感，都会进入「这东西好不好」的判断。

这两条都有争议。第一条被质问：若判准独立，它从哪来？斋藤的答案倾向于「合宜」——物在其用途、场合、文化中的适当性。这个答案有弹性，也有滑向相对主义的风险。第二条被质问：道德考量进入审美判断，会不会让美学变成伦理学的附庸？她的回应是，日常判断本来就是混合的，把它净化反而失真。

### （四）泛化难题：双方最强的理由

把三条路推到极端，就得到同一个问题。若审美经验遍布日常，若一切认识都含审美成分，美学作为学科就失去了可指认的对象。

支持扩张的一方有三条理由。第一，历史的：把美学绑定于「美的艺术」是 18 世纪的建构，巴托的体系、康德的无利害、黑格尔的艺术哲学共同完成了这次收窄；把这个收窄当作美学的本质，是把一段历史当成永恒。第二，经验的：日常判断确有可争论性。厨房的动线顺不顺、衣服的肩线合不合、街道的招牌是否刺眼，这些争论有理由可讲，不是纯偏好。第三，理论的：杜威的连续性论题指出，审美经验是日常经验的强化，另立一个种类会制造无法解释的断裂。

反对扩张的一方也有三条。第一，标准：没有对象边界就没有判准，评价退化为偏好，批评退化为表态。第二，区分力：若一切皆美，则无物特别美，「审美」这个词失去信息量。第三，社会学的：日常品味常是阶层标记。布迪厄的分析指出，对「清淡」「自然」「不张扬」的偏好与教育资本相关；把这些偏好当作审美判断，会把区隔误认成趣味。

双方最强的地方正好互相对准。支持者说标准是历史建构的，所以可以重建；反对者说重建需要新标准，而新标准至今没有出现。折中的路线有两条：一条把焦点从「审美态度」移到「审美属性」，列出一张属性清单（秩序、合宜、光洁、节奏、手感），用属性而非态度界定范围；一条区分「审美关注」与「泛审美化」，前者是注意力的方式，后者是世界的状态。两条路线都能缓解泛化，却都还没有给出可操作的判准。

::: warn 日常美学不等于「什么都说好」
常见的误读是把日常美学听成一种泛泛的赞美：既然日常物也有审美价值，那就什么都美。这个推论不成立。日常美学主张的是日常物具有可评价、可争论的审美属性，因此可以被说好，也可以被说坏；一只碗可以因为口沿过薄而烫手，一间厨房可以因为动线混乱而让人烦躁。泛化的风险在于放弃区分，日常美学的要点恰在于恢复区分，只不过换了一套词。
:::

| | 对象 | 判准 | 主要风险 |
| --- | --- | --- | --- |
| 艺术美学 | 作品，有作者与边界 | 艺术史与批评提供的范畴；独创性、统一性、深度 | 把非作品的经验排除在外 |
| 环境美学 | 自然物与环境整体 | 科学范畴引导的恰当性；生态关系 | 知识门槛过高，直接性受损 |
| 日常美学 | 日常物与日常活动 | 合宜、秩序、手感、与伦理的交织 | 判准弥散，易滑向相对主义 |

## 五、经典原著：《重构美学》的三层结构

《重构美学》由若干篇论文整合而成，英译本标题是 Undoing Aesthetics。这个标题值得停留一下：undoing 兼有拆解与取消两义，中译「重构」取了建设的一面，英译取了拆除的一面。两种译法各自抓住了一半，这本书的立场正好在两者之间——拆掉以艺术为中心的美学，重建为以 aisthesis 为核心的感性学。

::: quote 英译本标题
Undoing Aesthetics
:::

书的结构可以按三层审美化来读。前几章处理「美学」一词的通货膨胀，列出表层与深层的区别；中间几章转向认识论，论证感知本身具有建构性；最后几章讨论这种扩展的后果，包括伦理与教育。关键的一步在中间：若感知本身是建构的，美学就从「关于美与艺术的学科」变成「关于感性认识的学科」，这一步把美学的范围推到与认识论重叠。

这一步的代价，韦尔施自己看得很清楚。他在讨论「麻醉」时承认，感性认识的扩展会带来感官的钝化，因此美学同时需要一门「反麻醉」的理论。这个补充是全书最薄弱的地方：它提出了任务，没有给出方法。

## 六、艺术案例：一只茶杯的两套判准

取一只手工制的茶杯来看。口沿厚度约两毫米半，比机制杯厚，唇感偏软；圈足略小，重心偏低，放在桌上不易倾；釉面有细开片，茶汤渗进去之后颜色变深；杯壁内侧有一圈使用留下的茶痕。

这些都是形式属性，但它们的显现方式不同于画。口沿的厚度只在唇接触时被感知；重心只在端起来时被感知；开片的颜色只在长期使用后出现。把它们放在展柜里，灯光从上方打下来，能看见的只有釉色与轮廓，其余属性全部退场。

这正好支持斋藤的论点：日常物的审美属性是使用中的属性，脱离使用就会退化。它也解释了为什么同一只杯子进美术馆之后会被另一套判准接管——作者、造型、烧成难度、流派位置。判准的切换不改变物，改变的是它被当作什么。

衣着是另一个例子。合身是一种关系性属性：肩线的位置相对于肩宽，袖长相对于臂长，面料的垂坠相对于动作幅度。它无法在静态展示中被完整评价，只能在走动、坐下、伸手的过程中显现。日常美学若要认真处理衣着，就必须处理运动，这会把它推向身体美学，也会把它推向设计与工艺的知识。

## 七、思想联系

向前，这条线索接在杜威的连续性论题上（参见第 6 模块）。杜威把审美经验定义为日常经验的完整化，这一定义既为日常美学提供了合法性，也埋下了泛化的隐患。康德的无利害与 18 世纪的艺术体系则是被批评的对象：它们确立了「美学等于艺术哲学」的格局。布迪厄的趣味社会学从外部施加压力，提醒审美判断与社会位置难以分开。

向后，日常美学分化出几条路径。设计美学承接了物的一面，研究功能与形式的耦合；饮食美学研究味觉的判断如何被语言与文化塑造；城市美学处理步行尺度上的感官经验。与此并行的是对「审美资本主义」的批判：当审美化成为增值手段，日常美学就可能变成对这种增值的描述而非批判。这一张力至今没有解决。

## 八、本节总结

- 韦尔施把审美化分为表层装饰、深层材料重构、认识论三层，并用「美学／麻醉」的对立给出评价；层间关系是他论证的薄弱处。
- 舒斯特曼以身体为审美场所，把美学推向实践与训练；标准问题与学科界线问题没有解决。
- 斋藤主张日常物的审美价值独立于艺术价值，判准倾向于「合宜」；道德与审美的交织是她最有争议也最有说服力的部分。
- 泛化难题的双方各有强论证：一方指出艺术中心是历史建构，一方指出无边界则无判准。
- 折中路线目前只有两条草图：以审美属性替代审美态度，或区分审美关注与泛审美化。
- 三套判准的差异可以用一张表看清：艺术看独创与深度，环境看恰当性，日常看合宜与秩序。

值得继续追问的是：如果日常判断的判准是「合宜」，那么合宜相对于谁？相对于使用者、共同体，还是物本身的用途？这个问题的答案会决定日常美学究竟是一门批判的学科，还是一门描述的学科。

::: key 本讲要点
- 审美化是诊断，身体美学是纲领，日常美学是对象扩展，三者不可混用。
- 韦尔施的三层区分有解释力，层间的推导不够紧。
- 舒斯特曼把美学从观看转向训练，代价是标准悬空。
- 斋藤的「合宜」是一种判准，也是一种风险。
- 泛化之争的实质是：边界由对象划定，还是由注意力划定。
:::
