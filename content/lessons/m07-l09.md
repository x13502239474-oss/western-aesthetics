## 一、本节导入

先想一件小事：你做完一顿饭，从备菜、下锅、调味到装盘，最后一口吃下去，心里有一个「成了」的感觉；另一次，你心不在焉地翻手机、扒了几口冷饭，同样是吃饭，却什么感觉也没留下。差别不在食物，在经验是否「做完」。

杜威（John Dewey）就从这里切入美学。他认为，我们通常把「艺术」理解成挂在博物馆里、需要特殊鉴赏能力的稀有对象，这恰恰把事情弄反了。艺术并非少数对象的属性，它是经验达到「一个经验」那种完整状态时的强化形态。问题于是从「作品是什么」转到了「经验怎么才算完整」。这一转，既拆掉了艺术的围墙，也埋下了一个大争议：如果艺术只是圆满的经验，那它与一顿好饭、一场好球的界线还在哪里？

## 二、核心知识：一个经验及其两个支柱

::: def 一个经验（an experience）
杜威的关键区分：日常经验通常是零散的、被打断的、没有起讫的；只有当经验达到「完整、有起讫、有自身质量」的状态——各部分融合成一个整体，带着一种贯穿始终的独特性质——它才配叫「一个经验」。**例子**：一次专注的登山，从出发、攀爬、到登顶，中间每一步都指向终点又各具滋味，事后回想是一个不可分割的整体；而日常中浑浑噩噩的一小时，只是「经历」，不算「一个经验」。
:::

::: def 连续性（continuity）
杜威主张经验各环节、手段与目的之间是连续的，反对把二者割裂。真正的经验里，手段并非达到目的后就被丢弃的垫脚石，它融入目的、成为目的的一部分。**例子**：做菜时翻炒的动作不能只当「手段」看，它本身就带有香气的层次与节奏，装盘后的「完成」把这些环节统统收进自身。
:::

::: def 做与受（doing and undergoing）
经验是机体与环境交互的过程：机体主动地「做」，同时被动地「承受」环境反馈，二者交替推进。审美经验的质量取决于做与受之间平衡而有节律的往复。**例子**：画家落下一笔（做），随即承受这一笔在画面上的效果（受），再据以落下下一笔；若只做不受，就成了机械涂抹，若只受不做，就只是被动刺激。
:::

三个概念串成杜威的路线：经验在「做与受」的节律里推进，靠「连续性」把各环节收拢，最终达成「一个经验」；而艺术，就是这种经验的最强化形态。

::: warn 「艺术即经验」不等于「一切愉快都是艺术」
杜威的话常被简化成「任何令人满足的经验都是艺术」。他真正的意思是：艺术是经验的一种品质——完成的、有组织的、手段与目的连续的经验。一顿饭、一盘棋能否算艺术，取决于它是否达到这种品质，而非是否令人愉快。把「经验」读成「快感」，就把杜威退回到了他正在批评的享乐主义。
:::

## 三、代表人物：从黑格尔到经验自然主义

杜威（John Dewey，1859—1952）生于美国佛蒙特州，早年深受黑格尔影响，后逐渐转向实验主义与「经验自然主义」，成为实用主义（pragmatism）的代表人物之一，与詹姆斯、皮尔士并称。他在芝加哥大学与哥伦比亚大学长期任教，同时是著名的教育改革家。

他面对的问题是 20 世纪初美学的分裂：一边是形式主义把艺术封进「有意味的形式」的密室，一边是日常生活被排除在审美之外。他的思想转折点是把「经验」从认识论的工具升级为本体论的基础——经验并非心灵对世界的一层薄膜，它属于机体与环境的整个交互。1931 年他在哈佛作威廉·詹姆斯讲座，讲稿三年后修订出版，即为《艺术即经验》（1934）。这本书的雄心，是把美学从「美的哲学」改造成「经验的哲学」。

## 四、理论解析：把问题从作品挪到经验

### 为什么产生：拆「博物馆艺术」的墙

杜威的靶子很明确：他称之为「博物馆艺术观念」（museum conception of art）——艺术被当作与日常生活隔离的、稀有的、需专门场合才能接触的珍品。他的社会史依据是：18—19 世纪，随着民族国家的兴起与资本积累，艺术品被从原来的教堂、宫殿、仪式现场搬出来，集中到美术馆与私人收藏里，成为民族荣耀的战利品与财富的炫耀品。艺术从此脱离了它原先生长的土壤，被供上了隔离的祭坛。

这一步诊断支撑着他的正面主张：把艺术放回经验的连续性里。艺术并非「对象」的一个特殊类别，它是经验的一种特殊品质。

### 论证结构：四步

1. **经验的完整与否是程度之别**。经验有「完成」与「涣散」两端。涣散的经验是日常常态，完成的经验（「一个经验」）则有一个开端、一个发展、一个收束，各部分各司其职又融成整体。这一步靠的是对日常经验的现象式描述，几乎不用论证，只需唤起读者的亲身感受。

2. **艺术是经验的强化**。艺术不另起炉灶，它是「一个经验」被提炼、被澄清、被推到最饱满的形态。杜威的大意是：艺术使经验里的手段、材料、情感各得其所，达成一种别的经验达不到的完整与集中。所以艺术并非孤立对象，它就是「经验的强化」（intensification）。这一步是定义性的，把「艺术」从名词改造成一个形容词——「艺术的」首先描述经验的质量。

3. **媒介区别于质料**。为说明这种强化如何可能，杜威区分两个常被混用的词：质料（matter）是未经组织的原材料，颜料、声音、石块；媒介（medium）是已经进入表现、与作品整体融为一体的材料。媒介不可替换——梵高画里那一笔厚的、带方向的颜料就是表现本身，换成平涂就不再是同一件作品；而质料可以被随便更换。这一步支撑「艺术即经验」：只有当材料被组织成媒介、融入经验的完成，作品才成立。

4. **做与受的节律构成审美经验**。经验在机体「做」与环境「受」的往复中推进，节奏、张力与抵抗使它充实。杜威的大意是：美与丑的差别在于这一往复是否有节律、有组织。这一步把「一个经验」的动态机制讲清楚了，也解释了为什么「完成」的经验往往伴随一种情绪上的统一与满足。

### 问题与最强反对

杜威的主张有一个直接的代价：艺术的边界被大幅拓宽，以至于「坏艺术」也能钻空子——一次滥情的宣泄、一顿满足的晚餐，只要当事人觉得「完整」，就能自称提供了审美经验。

形式主义者克莱夫·贝尔（Clive Bell）一系的反对可以概括为：艺术在于对象本身的特殊性质（「有意味的形式」），与经验者是否「圆满」无关；把艺术等同于圆满经验，等于取消了艺术与非艺术的客观界限。阿瑟·丹托（Arthur Danto）式的反对则指向判断标准：如果「一个经验」是主观的完成感，那么对同一件作品，谁的经验算数？一件平庸之作也能让某人「完整」地被打动，杜威的标准无法把「伟大的艺术」与「仅仅是讨人喜欢的东西」分开。（以上对贝尔、丹托立场的概括为转述，非逐字引文。）

杜威的辩护方向是：艺术与非艺术本就没有形而上学的硬边界，只有程度与品质之别；「坏艺术」的问题应当用经验品质的持续检验来回答，而非用一套先验的分类。但这个辩护反过来坐实了批评——它承认边界是流动的，也就承认了「什么是艺术」这个问题在实用主义框架里注定得不到一个干净答案。

## 五、经典原著：《艺术即经验》的骨架

《艺术即经验》（Art as Experience，1934）源于 1931 年哈佛大学的威廉·詹姆斯讲座，全书十四章，从「活的生物」（the live creature）与环境的交互讲起，经「一个经验」「表现行为」「质料与媒介」，最后落到「艺术与文明」。开篇第一章的著名论断大意是：艺术作品的妙处不在于它自身，而在于它如何把经验里的零散重新组织成一个整体（此为转述）。

书的论证骨架与上一节四步一致：先建立「一个经验」，再证明艺术是它的强化，中间用「媒介／质料」「做与受」解释强化的机制，最后把美学带回生活与民主。值得注意的是它的政治落点：杜威认为，把艺术锁进博物馆，是特权社会的症状；把艺术还给经验，是一种民主的美学方案——人人都有能力拥有「一个经验」，审美因此成为可普遍实现的解放。

an experience 一个经验；doing and undergoing 做与受；medium 媒介
:::

## 六、艺术案例：从《印象·日出》到《百老汇爵士乐》

以莫奈《印象·日出》（Impression, soleil levant，1872，布面油画）为例。画面上，一轮橙红的太阳浮在灰蓝的晨雾里，水面碎成几道颤动的倒影，前景几笔深色小船与远景的吊机、烟囱都是简化的剪影。笔触快速、短促、未加修饰，颜色直接并置，光与水的界限被抹糊。这幅画当年被讥为「印象」派得名之作，恰因为它在传统眼光里是「没完成」的——没有打磨的轮廓、没有叙事、没有主题。

但按杜威的读法，「没完成」恰恰是误解。这幅画的经验是完成的：观者的目光在太阳、倒影、雾气、船影之间往复，做（追逐光斑）与受（承受雾气的后退）交替推进，最终把一整个海港清晨收拢成一个有自身质量的整体。它不是「画完的画」，却是一个「做完的经验」——这正是杜威要的区分：完成属于经验，不属于画面的抛光程度。

再看蒙德里安《百老汇爵士乐》（Broadway Boogie Woogie，1942—43，布面油画）。画面由黄、红、蓝的小色块在灰白底上排成跳动的网格，像被切碎的街道路灯与霓虹。这里没有再现对象，只有「做与受」的节律本身：色块的大小与间隔制造出强—弱、快—慢的节奏，观者的眼睛随着这些节拍跳动，如同爵士乐的切分。杜威会说，这幅画的媒介——那些精确排布的颜色——不是描绘音乐的手段，它就是节奏本身，是「一个经验」的视觉化。

::: fig a-impression-sunrise | 莫奈《印象·日出》：快速笔触与并置色彩把海港清晨收拢成一个完成的经验
:::

两件作品共同说明一点：杜威关心的并非作品「像什么」或「表达了什么」，他问的是它能否把观者卷入一场做与受的、有节律的交互，并最终抵达「一个经验」。

## 七、思想联系

向前，杜威有两个明确的对手。一是康德以来的「无利害」审美态度（参见前面模块），它把审美抽离成静观的、与实践无关的精神活动；杜威用「做与受」的实践交互把它拉回经验。二是黑格尔的绝对精神等级，杜威早年浸淫其中，后来用「经验自然主义」取而代之——艺术不再是理念的感性显现，而是经验自身的圆满。

向后，杜威的实用主义美学影响了晚近的两支。一是理查德·舒斯特曼（Richard Shusterman），他接过「经验」的身体维度，发展出「身体美学」（somaesthetics），把杜威没有充分展开的「做与受」落实为身体训练与日常实践。二是日常美学（everyday aesthetics）与参与式艺术（participatory aesthetics），它们沿着「打破博物馆围墙」的方向，把审美扩展到饮食、家居、行走等日常领域。杜威因此被看作 20 世纪美学里最早、也最彻底的「去精英化」方案之一。

## 八、本节总结

- 「一个经验」指达到完整、有起讫、有自身质量的经验，是杜威美学的起点。
- 艺术是经验的强化，而非孤立对象；问题从「作品是什么」转向「经验怎么完成」。
- 「博物馆艺术」是 18—19 世纪艺术体制的产物，切断了艺术与日常经验的连续性。
- 「做与受」的节律是审美经验的动态机制；媒介是进入表现的质料，不可替换。
- 最强反对：把艺术泛化为经验会消解艺术与非艺术的界限，使坏艺术也能自称经验（贝尔、丹托，转述）。
- 杜威的方案是一套民主美学，通向舒斯特曼的身体美学与日常美学。

值得继续追问的是：当杜威把审美的大门向一切「完成的经验」敞开时，他是否也同时取消了艺术区别于其他圆满经验的任何标准？这个问题，正是下一讲分析美学要正面接住的——「艺术能被定义吗」。

::: key 本讲要点
- 一个经验＝完整、有起讫、有自身质量；艺术是它的最强化形态。
- 博物馆艺术是 18—19 世纪体制产物，杜威要恢复艺术与日常的连续性。
- 做与受的节律、手段与目的的连续、媒介与质料的区分，构成强化的机制。
- 批评焦点：边界消解与判断标准失效（贝尔、丹托）。
:::
