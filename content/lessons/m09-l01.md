## 一、本节导入

站到卢浮宫《米洛斯的维纳斯》面前，多数人最先冒出的念头是「这就是美的标准」。但再问一句：它到底美在哪？是那根缺失的双臂留给我们的想象空间，还是身体里某种可以计算的比例？同一间博物馆外，梵蒂冈的《拉奥孔》却是另一副样子——肌肉绷到极限、蛇缠住父子三人，可那张脸却几乎不哀号。痛苦被压在表情之下，这又凭什么也被叫作「美」？

这两个问题指向同一件事：我们脑中「古典美」的印象，未必来自希腊人自己，而更多来自 18 世纪一批德国学者的重新讲述。本讲要做两件事：先回到作品本身，看「古典美」的三要素如何在石头上落实；再反过来拆掉这个神话，指出「高贵的单纯、静穆的伟大」是一套事后的历史建构，而希腊雕塑原本上彩的考古发现，则让「静穆纯白」的想象彻底动摇。理解了这一层，我们才算真正「看到」这两件作品，而只是对着一个被教科书塞进眼睛里的标签点头。

## 二、核心知识：古典美理想的三要素

所谓「古典美」（c-classical-beauty），在美学传统里大致可以拆成三根支柱：**比例、对称、克制（静穆）**。它们各有出处，也各有一个具体的观察入口。

::: def 比例（proportion）
指整体与部分、部分与部分之间的可量化数值关系。希腊传统相信，美并不等于随意的偏好，它更接近一种可以用「数」表达的和谐。比如多立克柱式的高度与柱径之比，或人体各段之间的倍数关系。波利克里托斯《法则》残篇讲人体比例，大意是：美来自许多小数目之间精确的对应，而非单个部分的美。
:::

比例回答「整体为什么协调」。在《米洛斯的维纳斯》上，一个常被引用的观察是头身比接近一比八，较古典盛期常见的七头身略修长。这种拉长不是偶然：它让女神显得更高挑、更脱离日常的肉体，向「理想」再迈一步。但请注意分寸——所谓「黄金比」「八头身」多是后人追加的读数，希腊工匠更多是凭一套代代相传的视觉修正去逼近理想，而不是拿尺子先算好再动手。

::: def 对称（symmetry）
指围绕一个中轴，左右部分的对应与均衡。希腊语的 symmetria 本义是「可共量」，最初指比例协调，后来才收窄为「左右相称」。在神庙立面、人像正面立姿里，它提供稳定的秩序感。
:::

第三根支柱「克制」，常常被压缩进温克尔曼那句名言，但它值得单独拎出来。克制意味着：即使在表现极端情感（痛苦、狂喜、死亡）时，形体也保持某种从容，表情不彻底失守。这一点在《拉奥孔》上体现得最尖锐。

::: key 本讲要点
- 古典美 = 比例 + 对称 + 克制（静穆）三者的组合，缺一不可。
- 三者都可落到作品形式：比例看头身比与柱式，对称看立姿中轴，克制看痛苦中的表情收束。
- 这套「古典美」很大程度上是 18 世纪的建构，需与希腊雕塑的历史实况分开处理。
:::

## 三、代表人物：温克尔曼与莱辛

温克尔曼（Johann Joachim Winckelmann，1717—1768）本是德国一个鞋匠之子，靠苦读与在罗马古董圈里的抄录、鉴别，成了近代艺术史与古典考古学的奠基人。他面对的问题很具体：在大量罗马复制品与希腊原作混杂的收藏里，如何判断什么是「真正的希腊」？他的答案是一条风格史线索——希腊艺术经历从「远古的力」到「崇高」，再到「美」的演进，顶峰是古典盛期那种「高贵的单纯，静穆的伟大」。这套叙述的局限也正在于此：它用一把「静穆」的尺子去量一切希腊艺术，把希腊化晚期那些更戏剧、更感官的作品要么贬低、要么强行收编。

莱辛（Gotthold Ephraim Lessing，1729—1781）则是以文学批评切入。1766 年他出版《拉奥孔》，副题是「论诗与画的界限」。他接住温克尔曼的论断，却往媒介的方向上推：拉奥孔不哀号，主要因为雕刻是空间艺术，它只能固定一个瞬间；选错了瞬间，丑就会永久定格。莱辛的贡献是把「为什么拉奥孔不叫」从一种趣味判断，转成一个关于艺术媒介的学理问题——这直接呼应本课程第二模块的模仿论，我们到理论解析里展开。

## 四、理论解析：诗画之别与「最富孕育性的顷刻」

这一讲的深层问题，是**模仿的对象与媒介的约束**。第二模块的模仿论（mimesis）讲艺术模仿自然或行动；但莱辛指出，不同媒介的「模仿」规则并不相同，不能拿诗的规则去要求画，反之亦然。这个「诗画之别」（ut pictura poesis 传统的反面）是理解《拉奥孔》争论的钥匙。

::: warn 常见误解
流行的说法是「拉奥孔不哀号，是因为希腊人追求静穆、鄙视激烈的表情」。这话只对了一半。温克尔曼确实这么解释，把它归因于希腊灵魂的克制；但莱辛指出，更根本的原因是媒介限制：雕塑一旦把张大的嘴固定下来，观者每看一眼都会重新撞上那张扭曲的脸，丑被永久化了。所以「克制」在雕塑里是一种技艺上的必然，叠加于精神理想之上，两套解释并不互相排斥。
:::

莱辛的论证可以拆成三步：

1. **媒介分野**：诗用时间中的语言符号，擅长叙述动作的先后；画与雕刻用空间中的形状与颜色，擅长呈现某一瞬间的物态。
2. **瞬间的选择**：造型艺术只能选一个瞬间，这个瞬间须是「最富孕育性的顷刻」（der fruchtbarste Augenblick，莱辛原词大意如此，转述）。它要让观者的想象可以向前、向后补全整个动作，而不是把高潮本身钉死。
3. **美的法则**：造型艺术的首要法则是美，因此激情的顶点——那种让面部彻底变形的时刻——应当回避，或者把表情收束在「叹息」而非「嚎叫」的临界状态。

这条推理在《拉奥孔》上完全可验证：胸腔转向左、骨盆朝右，躯干是螺旋扭紧的；颈部、胸部、腹部的肌肉绷到极限，蛇的曲线把三人连成一个受力系统。可面部只微微张口，痛苦停在「将发未发」的临界点。观者的想象被邀请去补全那声没有喊出的哀号——这正是莱辛要的效果：雕塑不给你高潮，给你的是高潮前最有张力的那一格。

这套理论的问题也明显。莱辛把「美」设为造型艺术的最高法则，是一种典型的古典主义趣味预设，他并未证明它普遍成立；后世浪漫主义恰恰以痛苦、丑、怪诞的造型艺术（如罗丹之后）反驳了他。此外，「诗画之别」虽犀利，却把两种艺术各自的经验结构说得过于干净，忽视了造型艺术同样可以靠系列构图、靠观者移动来叙述时间。

## 五、经典原著：两句关键表述的出处

两句话需要分别处理，因为它们常被混为一谈。

第一句，温克尔曼的原话。研究者通常指出，这句表述见于温克尔曼 1755 年的论文《关于在绘画与雕刻中摹仿希腊作品的一些见解》，此后在《古代艺术史》中反复回响。其大意是（转述）：希腊杰作普遍而突出的特征，是一种高贵的单纯和静穆的伟大，无论在姿态还是表情里；就像海的表面无论怎样翻腾，深处永远平静。请注意，这是对「希腊灵魂」的一种总体刻画，而非对某一件作品的尺寸测量。

::: quote 温克尔曼论希腊杰作（转述大意）
希腊杰作的一般特征，是高贵的单纯与静穆的伟大，既在姿态中，也在表情里。
:::

第二句是莱辛对温克尔曼的回应。莱辛在《拉奥孔》第一章里承认拉奥孔面部痛苦的程度「与诗里相仿」，但追问：为什么雕刻家不让他像维吉尔诗里那样「向天发出可怕的哀号」？莱辛的大意是（转述）：造型艺术家要让观众想象最大痛苦，却只能呈现痛苦的一个瞬间，因此不能选那个使表情完全走样的顶点。这里的关键词是「最富孕育性的顷刻」，它是整本书里最有生命力、被后世艺术批评反复借用的概念。

## 六、艺术案例：两件作品的形式细读

先看《米洛斯的维纳斯》。站到它正面，先看**重心**：她重心落在右腿，左膝微屈，髋部因此向一侧横移，肩线与髋线反向倾斜——这就是对立式平衡。

::: def 对立式平衡（contrapposto）
一种站姿的构图原则：人体重心偏于一条腿，另一条腿放松微屈，使骨盆与双肩形成相反的倾斜，脊柱随之呈柔和的 S 形。它让静止的人像获得内在的动势与生命感。对照《米洛斯的维纳斯》：右腿承重、左膝微屈、髋右移而肩左倾。
:::

再看**衣褶与螺旋**：下裳的深褶螺旋缠绕双腿，褶沟钻得很深，形成强烈的明暗对比；这不再是古典盛期那种紧贴身体的「湿衣」式轻褶，而更感官、更戏剧。头部略向左转，目光越过观者，暗示她并不为观看者而存在——这是神性的疏离。最后，她须绕行才能看完整，正面、侧面各自成立，属于希腊化的多视点造型。把这几点连起来，你会发现一个耐人寻味的错位：一件被 19 世纪奉为「希腊典范」的作品，其实是希腊化晚期（约前 130—前 100）的产物，它身上的螺旋、戏剧性扭转与感官肉体，早已溢出古典的节制。

再看《拉奥孔》。它被叫作「群像」，因为三人的身体靠蛇的曲线贯穿成一个受力系统：构图呈向右上倾斜的三角形，顶点落在拉奥孔向左倾的头部。看**张力分布**：胸腔向左、骨盆向右，躯干拧成麻花，双腿被蛇缠住无法迈出；深凿的阴影与打磨光洁的面部形成质感对比。关键在**面部**：与浑身绷紧的肌肉相反，那张脸只微张口。这个「不哀号」正是莱辛与温克尔曼争论的焦点，也是整件作品最能逼人思考的地方——痛苦被压在一个临界点上，反而比嚎叫更让人不安。

::: fig a-laocoon | 拉奥孔群像的螺旋构图：三人构成一个向右上倾斜的三角形，痛苦停在哀号前的临界点
:::

两件作品放在一起，恰好构成「古典美」的两个极端：维纳斯示范了比例与平衡如何抵达理想化的静穆；拉奥孔则检验，当题材是极端痛苦时，克制这条支柱还能不能立得住。

## 七、思想联系：从温克尔曼到「白石膏」神话的瓦解

向前追溯，温克尔曼的「静穆」理想继承的是文艺复兴以来对古典的崇敬，尤其是拉斐尔式的和谐趣味；他做的事，是把这种趣味上升到「历史分期」的高度——美有它的出生、巅峰与衰落。向后看，这套叙述直接喂养了 19 世纪的新古典主义：从卡诺瓦的雕刻到学院派的「高贵的单纯」，再到黑格尔把希腊艺术定为「艺术理想」的顶点（参见第四模块），温克尔曼的影子无处不在。

但有一个当代的冲击必须提。现代考古学与颜料分析发现，**希腊大理石雕塑原本是上彩的**：眼睛、头发、衣饰乃至皮肤，往往涂着鲜亮的矿物颜料，只是年代久远褪尽，才露出今天光裸的白色。研究者（如德国的布林克曼团队）用紫外光与复原模型证明，所谓「静穆纯白」的希腊，很大程度上是时间与审美趣味共同制造出来的错觉。这个发现不只是一条考古花絮：它动摇了温克尔曼以来「纯白 = 纯净 = 古典」的整个视觉前提。我们以为自己在膜拜希腊的「克制」，其实可能只是膜拜了几百年间被漂白过的石膏。

::: note 补充
「白石膏神话」还有一个传播学根源：18、19 世纪大量石膏复制品、版画把希腊雕塑渲染成白色，而「白」在启蒙美学里被附会为理性与纯粹。于是「古典美 = 白色大理石」的等式，被印刷术与石膏翻模大量复制，成了大众的常识。
:::

## 八、本节总结

- 古典美理想由三根支柱构成：比例、对称、克制（静穆），分别可在头身比、立姿中轴、痛苦中的表情收束上得到观察。
- 温克尔曼以「高贵的单纯、静穆的伟大」为希腊艺术定调，莱辛则以「诗画之别」把它修正为一个媒介论问题：造型艺术只能选「最富孕育性的顷刻」。
- 《米洛斯的维纳斯》示范了比例与平衡如何抵达理想化静穆，但它实为希腊化晚期之作，形式细节已溢出古典节制。
- 《拉奥孔》示范了克制如何在极端痛苦中成立：面部停在哀号前的临界点，把想象让给观者。
- 「静穆纯白」的希腊是一场历史建构，上彩考古发现揭示了其背后的审美漂白。

值得继续追问的问题：如果「古典美」是被 18 世纪建构出来的，那么它今天仍然有效吗——我们欣赏维纳斯时，欣赏的到底是希腊人的比例，还是我们自己愿意相信的那个「和谐而克制」的西方？
