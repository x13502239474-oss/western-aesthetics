## 一、本节导入

1955 年前后，巴特（Roland Barthes）在《神话学》末章分析过一张《巴黎竞赛画报》的封面：一名穿法国军服的年轻黑人士兵行举手礼，眼睛望向画面外的三色旗。巴特说，这张照片不止于「一名士兵在敬礼」，它同时说出另一句话——法国是一个伟大的帝国，她的儿子不分肤色都忠诚地为她服务（大意）。

这个分析让人不适：你无法反驳它，也无法证明它。照片的每个细节都真实，另一层意思却不在任何细节里。十三年后，巴特发表《作者之死》，把同样的逻辑推到文学上：既然意义来自符号的安排，「作者想说什么」这个提问本身就值得怀疑。

## 二、核心知识：四组区分与二级符号系统

::: def 能指与所指（signifiant / signifié）
能指是符号可感知的一面——声音形象、字形、笔画的排列；所指是它唤起的那个概念。**例**：中文「树」的发音和字形是能指，「树」这个概念是所指；英语 tree 的能指完全不同，所指却大致相同。两者的结合是任意的（arbitraire），理由来自约定，而约定靠差异维持。
:::

::: def 语言与言语（langue / parole）
语言是社会的、集体的符号系统，包括语法、词形与搭配规则；言语是个人的、一次性的使用行为。**例**：一个人说错一句话，这是言语层面的偶发事件；他之所以能「说错」，是因为有一套他不曾发明的规则在先。
:::

四组区分的分量并不相同，「差异」原则支撑整座大厦。| 区分 | 定义 | 一个例子 | 被文论挪用为 |
| --- | --- | --- | --- |
| 能指／所指 | 声音形象与概念 | 「树」的发音与树的概念 | 诗里能指自身的重量；字面义与引申义的分层 |
| 语言／言语 | 社会系统与个人使用 | 语法规则与某人说的一句话 | 文类是语言，单篇作品是言语 |
| 共时／历时 | 同一时刻的系统状态与历史演变 | 1960 年法语的状态与它的词源史 | 文学史被读成若干结构状态，而非传记的连续 |
| 组合／聚合 | 横向的连锁与纵向的可替换项 | 「猫在垫子上」；把「猫」换成「狗」 | 叙事句法与选择轴；雅各布森由此引出隐喻与转喻 |

索绪尔有一句常被引用的话，大意是：在语言里只有差异，没有正项。**例**：红灯意味着「停」，靠的是它与绿灯、黄灯的对立；单独拿出来，它只是一块红玻璃。意义因此成为系统内部位置的效果，不再是某个词「带着」的属性。

列维-斯特劳斯（Claude Lévi-Strauss）把这条原则搬到神话上。1955 年的《神话的结构》处理俄狄浦斯神话，做法分四步。

1. **切成最小单位。** 把叙述拆成短句，每句记一件事，他称之为「神话素」（mythème），相当于语言里的音位。
2. **横向读一遍。** 按叙述顺序得到流程：卡德摩斯寻找妹妹、俄狄浦斯弑父娶母、安提戈涅埋葬兄长。
3. **纵向重排。** 把内容相近的神话素叠成一列，得到四列：过度评价血缘、低估血缘、否认人由大地所生、肯定人由大地所生。
4. **读出矛盾。** 前两列与后两列的对立互相交叉，神话的工作是在「人从土里长出」与「人由男女所生」这两条冲突信念之间做中介。

它的说服力在于解释了为什么同一个故事有那么多版本却仍「是同一个神话」：变体更换表层叙述，深层关系不变。困难同样明显：结构分析压平了叙述的时间性。

巴特走的是另一条路，把符号系统分为两级：第一级是语言本身的系统，第二级是建立在它之上的「神话」。

::: def 二级符号系统（système sémiologique second）
在第一级里，能指与所指结合成一个完整符号。到了第二级，这个完整符号被整个降格为新的能指，再与一个新的所指结合。**例**：一束红玫瑰在第一级是「花」这个符号；在第二级，它成为「爱情」的能指，花的具体来历被抽空，只剩下一个可供填充的形式。
:::

巴特的关键一步是说：神话的功能在于把历史变成自然。**例**：那张照片的历史是殖民帝国的宣传与征兵；经过二级系统，这段历史变成了「理所当然的忠诚」。读者看到事实，看不到事实被生产的过程。他因此称神话为「去政治化的言说」（大意）。这套分析可以批量使用，风险也在这里：如果一切都能读成神话，批判者站在什么位置上说话？巴特在末章的回答大意是，把神话再神话化一次，用「人工的神话」暴露它的机制。

## 三、代表人物：方法的迁移

**索绪尔**（Ferdinand de Saussure，1857—1913）在日内瓦长大，先在莱比锡学历史比较语言学，1879 年以一部关于印欧语元音的著作成名。1907 至 1911 年在日内瓦大学三次讲授普通语言学，讲稿未成书；1916 年同事巴利与塞什哈耶据学生笔记编成《普通语言学教程》。今天读到的「索绪尔」经过编者整理，后来的手稿研究发现，某些二元对立被强化得比原讲更整齐。

**列维-斯特劳斯**（1908—2009）学哲学出身，1935 至 1939 年在巴西做田野，1941 年流亡纽约，与雅各布森相识，语言学模型从此进入他的方法。1958 年的《结构人类学》收有《神话的结构》。

**巴特**（1915—1980）长期受结核病困扰，学术路径偏离常规。1950 年代为报刊写文化短评，1960 年代转向符号学，1970 年的《S/Z》逐句拆解巴尔扎克的一个中篇，1976 年进入法兰西学院任文学符号学教席。他的轨迹很清楚：从揭露资产阶级神话，到放弃揭露的姿态，转而主张文本的复数。

**德里达**（Jacques Derrida，1930—2004）生于阿尔及利亚，1950 年代在巴黎高师求学。1967 年同时出版《书写与差异》《论文字学》《声音与现象》，1978 年的《绘画中的真理》把解构带进美学。

## 四、理论解析

### （一）结构主义要解决什么

19 世纪的文学研究以作者为中心：作品是生平与时代的表达。这套方法有两个困难。其一，证据不足，信件、日记、自述常常互相矛盾。其二，无穷后退：要理解作品先理解作者，要理解作者先理解时代，时代又由无数作品构成。

结构主义的回应是把对象从「谁在说」换成「说的规则是什么」。三条假设支撑它：系统先于项，意义来自差异，共时分析优先于历时叙述。合起来，作品从「表达」变成「实例」——某套文学规则的一次具体运用。这个转向在学理上清醒，在趣味上贫薄：它解释了文学的语法，解释不了为什么某一行诗让人停住。

### （二）作者之死的五步论证

《作者之死》篇幅很短，论证可以拆成五步。

1. **作者是历史的产物。** 巴特说，作者这个形象随资本主义、经验主义与个人主义兴起；中世纪以前的作品并不以「作者其人」为意义的归宿（大意）。
2. **作者是文本的神。** 作者被设想为文本的最终所指，就像神是世界的最终所指；他限制意义，给意义一个止步之处。
3. **写作销毁声音。** 现代抄写者与文本同时诞生，没有先于文本的存在；写作是一场「所有起源的销毁」（大意）。
4. **文本是引文的编织。** 一个文本由无数文化引文构成，来自四面八方；「内在的」原创性是一种错觉。
5. **读者的诞生。** 意义的统一性不在起源，而在目的地；这个目的地是读者。

第三步到第五步之间有一处跳跃：如果作者死了，读者凭什么不是另一个「神」？巴特在《从作品到文本》（1971）里做了补救，用七条命题区分「作品」与「文本」：

| 作品（œuvre） | 文本（texte） |
| --- | --- |
| 可计量的、有形的、摆在书店里的 | 一个生产的场所，一种方法上的场域 |
| 被「作者」担保 | 由引文与代码编织，作者只是其中之一 |
| 意义有终点，可以被「解释」 | 意义处于无限延宕的意指过程（signifiance）中 |
| 属于文类，可被分类 | 越过文类，甚至越过文学，指向「极乐」（jouissance）与断裂 |

关键在第三行。「文本」标的是一个过程，也可以读作一种要求：阅读应当生产，而非消费。这条要求把读者从接受者变成工作者，为后来的读者反应批评留了门（参见本模块第 3 讲）。

### （三）德里达：延异与「文本之外」

德里达的起点是对索绪尔半途而废的指认：索绪尔说意义来自差异，却仍把所指当作在场的概念。如果差异彻底，任何符号都不可能自我同一，它的意义永远要参照别的符号，而那些符号又参照别的符号。

::: def 延异（différance）
德里达自造的词，把法语 différer 的两个义项叠在一起：一是「相异」，二是「推迟」。它指差异的运动与意义的延宕同时发生。**例**：查一个词的意思，得到一串同义词；再查这些同义词，又得到新的词。意义在链条上被不断推迟，永远不会停在某个「本义」上。拼写里的 a 在法语中不发音，只看得见——这一点本身在提示：这个差异逃出了语音的秩序。
:::

延异不是一个概念，也不是一个词，德里达自己就这样说过（大意）。它是一个「非概念」：一旦把它当作某个东西来定义，它就又变成了在场。由此有那句被引用得最多、也被误读得最厉害的话：

::: quote 《论文字学》
il n'y a pas de hors-texte.
（文本之外别无他物。）
:::

::: warn 「文本之外无物」不等于「现实不存在」
流行的读法把这句话译成「一切都在语言之内」，于是变成一种唯心论：世界只是文本，火山与失业都是修辞。这个读法错在两处。

其一，hors-texte 的对手是「超验所指」（signifié transcendantal）——那个被认为可以终止符号链条、自身不再需要解释的最终意义：上帝、本质、作者的意图、直接给定的实在。德里达要说的倾向于：没有任何所指能跳出指涉的网络，成为不需要补充的在场。其二，他在 1988 年回应塞尔的《有限公司》里把这句话改述为「文本之外无物，即没有东西在语境之外」（大意），落点在语境，不在世界。

所以这句话并不否认石头与枪炮的存在。它否认的是：有一个脱离符号与语境的立足点，可以从那里一劳永逸地判定意义。把它读成「否认现实」，恰好把它变成了它要批判的绝对立场。
:::

### （四）三个后果与最强反对

解构对美学的冲击集中在三处。**作品的同一性**：如果意义在延异中不断推迟，「同一件作品」靠什么成立——物质载体、作者署名，还是一代代读者的构造？数字复制让这个问题变得具体：一次压缩、一次转发都参与构成「它是什么」。**作者意图**：意图不再是判据，成为可以被读出也可以被误读的痕迹。**审美判断的稳定性**：如果价值来自系统的位置，「经典」的构成就是系统运作的结果，美学史随之成为趣味史与制度史。

最强的反对来自两个方向。解释学：赫施（E. D. Hirsch）主张，若文本意义不由作者意图确定，解释的有效性就无从检验，批评将退化为各说各话（详见本模块第 2 讲）。政治批评：伊格尔顿曾指出，《作者之死》读起来像 1968 年那种把一切权威一起推倒的姿态，它取消了作者，却没有说明谁在印刷、谁在被审查（转述）。两者都不否认「意义是系统的效果」，质疑的是能否由此得出「怎么读都行」。

## 五、经典原著：三本书与一篇短文

《普通语言学教程》1916 年在日内瓦出版，按语音、共时语言学、历时语言学、地理语言学编排。它很快越出语言学：雅各布森把它带到布拉格，列维-斯特劳斯带到人类学，巴特带到文化批评。

《神话学》1957 年由瑟伊出版社出版，收 1954 至 1956 年为《新文学》杂志写的月度短评，末章《今日神话》是理论总结，对象是摔跤、玩具、洗衣粉广告这类日常。

《作者之死》1968 年发表在一份先锋派小杂志上，不足十页；《从作品到文本》1971 年刊于《美学杂志》。两篇合起来，是结构主义向「后结构」过渡的路标。巴特在结尾写下的那句话，语气近乎宣言：

::: quote 《作者之死》
la naissance du lecteur doit se payer de la mort de l'Auteur.
（读者的诞生必须以作者的死亡为代价。）
:::

「必须」这个词值得停留：它把理论推断说成一件代价明确的交换——要让阅读成为生产，就得放弃作者作为意义的担保人。读者是否因此变成新的权威，巴特没有回答。

## 六、艺术案例：毕加索《亚维农少女》的面孔

1907 年，毕加索完成《亚维农少女》（现藏纽约现代艺术博物馆，约 244 × 234 厘米）。画题里的「亚维农」是巴塞罗那的一条街，画中是五名妓院女子。右侧两张脸最引人注意：一张被压成红褐色的长条，鼻子与额头连成一道硬边，像伊比利亚石雕；另一张涂着粗重的绿色条纹，五官被简化为几道刻痕，与毕加索在民族志博物馆见到的非洲面具相似。

形式上，构图横向展开，五人几乎站在同一平面上，背景压成几块蓝与褐的平面，深度很浅。左下角有一堆水果与一块垂落的布，布的位置把视线引向画面中央；右侧女子抬起手臂抓住帷幔，斜线又把视线推向左侧。身体被处理成棱面：乳房与腹部由几道粗线勾出，明暗压缩成平面色块。整幅画没有统一的透视点，观者的位置被反复移动。

::: fig a-avignon | 《亚维农少女》：五个人物压在同一浅平面上，右侧两张面具式的脸与左侧的伊比利亚式侧脸形成对照
:::

从符号学角度看，这张画可以做三层读解。第一层，面具是一个能指，它指向 1907 年巴黎艺术界想象中的「原始」——生命力、直接性、对学院规范的反抗，与某个具体的非洲族群关系不大。按巴特的说法，这正是二级系统：面具的来历被抽空，只剩下「原始性」这个所指。第二层，画作是引文的编织：伊比利亚雕塑、非洲面具、塞尚的《浴女》、格列柯的拉长形体都留下痕迹，并置本身构成意义。第三层，面孔与装饰的对立被拆开：学院传统里脸是灵魂的所在，装饰是附加物；在这里脸变成图案，图案又承担了表情，观者找不到一张可以回望的脸。

以上三层是三种读法，并非画家的自述。

## 七、思想联系

向前，结构主义继承两条线。一条是历史比较语言学：索绪尔反对新语法学派把语言变化解释为个别音变，主张从系统看变化。另一条是俄国形式主义：什克洛夫斯基的「陌生化」与雅各布森的「文学性」都把注意力从作者转到手法，1930 年代经布拉格学派传入巴黎。

向后，福柯以「话语」替代「文本」，把符号系统接到权力与制度上，并在 1969 年的《什么是作者？》里用「作者功能」替代作者其人（大意）；克里斯蒂娃在 1960 年代后期提出「互文性」，把巴特的「引文编织」技术化；拉康把能指链接到无意识上；霍尔在文化研究中提出「编码／解码」，把读者的位置分成主导、协商、对抗三种。德里达 1978 年的《绘画中的真理》则讨论康德《判断力批判》里的「画框」（parergon）：框既属于作品又不属于作品，它区分作品与世界，自身悬在两者之间。

## 八、本节总结

- 索绪尔的四组区分共享一条原则：意义来自差异，系统先于个别项；列维-斯特劳斯用它找出神话的恒定对立，代价是压平了叙述的时间性。
- 巴特的二级系统说明神话如何把历史变成自然，也带来「批判者站在哪里」的困难。
- 《作者之死》把意义从起源移到目的地，《从作品到文本》把「文本」定义为生产的过程。
- 延异指差异与推迟的同体运作；「文本之外无物」针对超验所指，不否认现实存在。
- 解构让作品同一性、作者意图、审美判断的稳定性同时成为问题，最强的反对来自解释学与政治批评。

值得追问的是：如果意义在系统与语境中生成，我们说「这部作品被误读了」，依据的究竟是什么——文本的约束，还是某个共同体的共识？

- 索绪尔的核心是差异原则，四组区分是它的技术展开。
- 结构主义文论把作品变成系统的实例，解释了语法，损失了独特性。
- 神话是二级符号系统，功能是把历史自然化。
- 作者之死与文本的复数性，把阅读从消费变成生产。
- 延异不是「一切皆语言」，它针对的是超验所指与语境的缺席。
:::
