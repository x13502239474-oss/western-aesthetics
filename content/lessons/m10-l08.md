## 一、本节导入

一件作品把古典柱式、漫画线条和霓虹灯并置在一起，还配了一段戏仿的广告词。现代主义批评家会皱眉：这是拼凑，缺乏原创，没有媒介的自觉。后现代批评家会微笑：这正是时代的真实处境——所有风格都已归档，剩下的只能重新组合。

两种反应背后是对「我们身在何处」的不同诊断。现代主义把艺术史看成一条不断自我净化的道路：每个门类都应回到自己的媒介本质，剔除杂质，向前推进。后现代主义则怀疑这套「进步叙事」本身，认为它只是现代性为自身合法性编造的故事。本讲不打算站队，而是把双方最锋利的论述摆出来，看这场争论究竟争的是什么。

## 二、核心知识：现代主义的自我理解

::: def 现代主义（modernism）
一种以媒介自觉、形式实验与历史进步信念为核心的艺术取向。格林伯格的叙事是它的经典版本：现代主义绘画的历史，就是不断回到平面性这一媒介特性的自我批判过程（参见第九模块第七讲）。
:::

::: def 后现代主义（postmodernism）
一种以怀疑元叙事、混用风格、取消深度为核心的西方文化取向。它既是一个时期概念（约 1960 年代以后），也是一种态度——对宏大叙事、原创性与统一标准持怀疑态度（参见第八模块第四节）。
:::

现代主义的三个自我理解：

1. **媒介纯粹性**：每种艺术应回到自身独有的媒介，绘画回到平面，雕塑回到三维，音乐回到声音本身。
2. **自我批判**：艺术的发展是通过不断排除不属于自身的成分实现的，这是一条理性的道路。
3. **进步信念**：艺术史有方向，新作品因回应了前人的问题而更高级。

::: key 本讲要点
- 现代主义三信念：媒介纯粹、自我批判、历史进步。
- 后现代四特征：拼贴、戏仿、拟像、去深度，背后是对元叙事的怀疑。
- 利奥塔、詹姆逊、鲍德里亚给出三种不同的后现代诊断。
- 哈贝马斯以「未完成的方案」反驳，认为现代性仍可自我修正。
- 争论的强项是诊断时代处境，弱项是规范建设的缺席。
:::

## 三、代表人物：四种诊断

格林伯格（Clement Greenberg，1909—1994）是现代主义叙事的主要建构者。他把 19 世纪以来的绘画史读成一场走向平面性的运动，认为每一次自我批判都是净化的步骤。他面对的问题是「如何为抽象艺术辩护」，答案是一条历史必然性的叙事。代价是把艺术史写成目的论，且把非西方的、工艺性的艺术排除在外。

利奥塔（Jean-François Lyotard，1924—1998）在《后现代状况》（1979）里把后现代定义为「对元叙事的怀疑」。他面对的问题是「知识在后工业社会如何合法化」：宏大叙事（启蒙的解放故事、黑格尔式的精神史）不再可信，知识只能靠局部的、暂时的「小叙事」获得合法性。他的贡献是把「怀疑」从一种情绪变成知识论立场。

詹姆逊（Fredric Jameson，1934—2024）在《后现代主义，或晚期资本主义的文化逻辑》里把后现代当作一个历史阶段，与晚期资本主义的生产方式相连。他强调「拼贴」（pastiche）与「怀旧」：后现代作品大量引用过去的风格，却失去了讽刺的锋芒，只剩空洞的模仿。他的贡献是把文化现象接回经济基础，代价是被批评为经济决定论。

哈贝马斯（Jürgen Habermas，1929— ）在《现代性——一项未完成的方案》（1980）里反驳：现代性并不是一个已经破产的工程，它的问题在于理性被工具化了，出路是重建交往理性，而不是宣告终结。他与利奥塔的争论，是这场讨论里最有交锋的一幕。

## 四、理论解析：四个特征与一场反驳

### 后现代的四个特征

1. **拼贴（pastiche）**：把不同风格并置混用。詹姆逊强调它与「戏仿」（parody）的差别：戏仿带着讽刺，拼贴则是一种中性的引用，失去评判的力度。
2. **戏仿与拟像（simulacrum）**：鲍德里亚（Jean Baudrillard，1929—2007）描述符号脱离指涉对象、自我复制的状态。仿品不再指向原件，只指向其他仿品。
3. **去深度**：詹姆逊认为后现代作品取消了深度模式——表面与内里、本质与现象、真实与表象的区分被压平，剩下的只是平面的游戏。
4. **怀疑元叙事**：利奥塔的核心命题。任何声称能解释全部历史的宏大故事，都丧失了可信度。

### 哈贝马斯的反驳

哈贝马斯的论证可以拆成四步：

1. 现代性包含了理性、自由、批判的承诺，这些承诺尚未兑现。
2. 后现代对理性的全面怀疑，把这些承诺一起丢弃，代价过高。
3. 现代性的病症（工具理性膨胀、生活世界被殖民）可以被诊断和修正，不必整套放弃。
4. 因此，现代性依旧是一项「未完成的方案」。

::: warn 常见误解
「后现代主义就是什么都可以、怎么都行」。这是对怀疑元叙事的粗暴理解。利奥塔反对的是用一套宏大标准压制所有局部实践，他并未主张评价的消失；哈贝马斯正是抓住这一点反击：如果所有标准都被怀疑，那么「反对元叙事」本身也成了一种元叙事，后现代立场会陷入自我矛盾。
:::

### 双方如何攻击对方

后现代对现代主义的攻击：媒介纯粹性是一条人为设定的道路，所谓「进步」只是格林伯格叙事的产物，并非艺术本身的方向；把绘画压缩到平面性，恰恰是一种独断。

现代主义对后现代的回击：放弃标准等于放弃批评，作品的好坏无法再说，艺术沦为风格的超市；拼贴与拟像看似激进，实则最容易沦为市场的新包装。

要判断哪一种回击更有力，可以引入一个检验：看双方各自能否解释对方的产生。现代主义的叙事能解释后现代——把它当作进步链条走到尽头后的疲惫与反拨；后现代的叙事也能解释现代主义——把它当作一种特别宏大、特别自信的元叙事，其崩溃恰恰印证了对元叙事的怀疑。两边都自洽，这提示我们这场争论的分歧或许不在事实层面，而在评价层面：同一段历史，一方读到的是成就与未竟，另一方读到的是独断与终结。

哈贝马斯的价值正在于他承认了这种评价上的分歧，却拒绝接受它。他同意现代性带来了工具理性膨胀的病症，也同意这些病症是真实的危机；他反对的是从「有危机」直接跳到「该终结」。在他看来，现代性内部本来就同时存在着工具理性与交往理性两股力量，出路是让后者制约前者，而不是把整个工程拆毁。这一步区分——诊断病症与宣判死刑之间的区分——是这场争论里最有建设性的贡献。

## 五、经典原著：几处文本的坐标

利奥塔《后现代状况》1979 年受加拿大政府委托写成，原是一份关于知识状况的报告，意外成为后现代讨论的经典。它的名章是关于元叙事的怀疑与「小叙事」的合法性。

詹姆逊《后现代主义，或晚期资本主义的文化逻辑》1984 年发表于《新左派评论》，后扩展成书。它的分析把建筑、绘画、电影、文学放在同一框架里，体现了「总体性」的方法。

哈贝马斯《现代性——一项未完成的方案》1980 年是为法兰克福歌德奖所作的讲演，直接回应利奥塔与保守派对现代性的攻击。三者构成一场三方辩论：利奥塔主张怀疑、詹姆逊主张历史分期、哈贝马斯主张修正。

## 六、艺术案例：两种观看的对照

以一件包含古典柱式与工业材料混用的建筑作品类型为例（不指认具体作品名，以免编造）。

现代主义读法会追问：这座建筑是否忠实于材料与功能的真实？混凝土是否表现了自身的质感，结构是否清晰可辨？装饰是否被清除，形式是否从用途中自然生长？评价的语言是「诚实」「纯粹」「合乎逻辑」。

后现代读法会追问：这些古典柱式与工业材料的混用传达了什么态度？引用是否带着反讽，是否在调侃现代主义的严肃？它的意义是否恰恰在于拒绝纯粹、欢迎混杂？评价的语言是「策略」「引用」「反讽」。

::: note 补充
文丘里（Robert Venturi）在《建筑的复杂性与矛盾性》（1966）里以「少即是无聊」反驳密斯的「少即是多」（参见第九模块第九讲）。这句反转，是后现代对现代主义最凝练的一次挑衅，也说明两者在形式趣味上的分歧有具体的落点。
:::

## 七、思想联系：争论的来龙去脉

向前追溯，现代主义的根据在格林伯格的媒介纯粹性叙事与康德美学的自律传统（第五模块第三讲、第九模块第七讲）；后现代主义的根据在对启蒙理性的怀疑——霍克海默与阿多诺的《启蒙辩证法》已经揭示了理性如何反转为统治（第七模块第十一讲），利奥塔把这一步推到知识论。

向后看，这场争论进入 21 世纪后并未终结。艺术界的「当代艺术」概念、数字媒介与人工智能生成艺术（第八模块第九讲），都在重新提出「原创性」「作者性」「媒介」这些现代主义的核心范畴。有人宣告后现代已经过去，有人认为是它的深化。

评价这场争论要公平：它的强项是诊断——它准确描述了我们这个时代风格混杂、深度消失、宏大叙事失信的经验；它的弱项是规范——在指出旧标准失效之后，它没能给出新的评价标准。这也是为什么许多批评家感到后现代理论「善于拆解，拙于建设」。

## 八、本节总结

- 现代主义三信念：媒介纯粹、自我批判、历史进步，格林伯格叙事是经典版本。
- 后现代四特征：拼贴、戏仿、拟像、去深度，背后是对元叙事的怀疑。
- 利奥塔、詹姆逊、鲍德里亚给出知识论、历史分期、符号论三种诊断。
- 哈贝马斯以「未完成的方案」反驳，主张修正理性而非全面放弃。
- 两论的强弱分明：诊断时代处境有力，建设新规范不足。

值得继续追问的问题：如果「反对元叙事」本身也是一种元叙事，后现代主义如何避免自我矛盾？这是否说明任何批判都需要至少一个自己不愿放弃的承诺？
