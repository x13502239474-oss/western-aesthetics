## 一、本节导入

1929 年巴塞罗那世博会上，德国馆既不是展品陈列厅，也不是办公或居住的场所——它几乎没有实用功能，甚至没有多少门。参观者从一端走到另一端，脚下是打磨光滑的石灰华地面，头顶是一片悬挑的薄屋顶，两侧是错动的玻璃与大理石墙；两片水面，一片映着屋顶，一片被深色玻璃围起。整座建筑像一个被拆开的、又极其精确的几何练习。

这引出一个看起来矛盾的现象：一座「功能主义」的代表作，竟然几乎不服务任何具体功能。它恰恰是我们理解「功能主义」与「少即是多」的绝佳入口——因为正是这座「没用」的馆，把功能主义的美学原则从「实用」里剥离出来，晾成了一个纯粹的空间宣言。本讲要讲清这条思想脉络：从沙利文的「形式追随功能」、卢斯的「装饰即罪恶」，到包豪斯的「艺术与技术的新统一」，再到密斯的「少即是多」，最后看看后现代建筑如何把这套信条讽刺地解构。

## 二、核心知识：功能主义与「少即是多」

先厘清本讲的三个概念。

::: def 功能主义（functionalism）
在建筑与设计中，主张形式应当由功能决定、由用途与结构逻辑生成，而非由外在装饰或风格习惯决定的原则。例子：一座工厂的立面，应当诚实显示它的框架、门窗与结构，而不是套上古典柱式的外衣。
:::

::: def 少即是多（less is more）
密斯·凡·德·罗广为流传的设计格言，主张以极少的元素、极简的手法，通过精确的比例与材料本身，获得更丰富的空间与审美效果。例子：一面不施线脚的缟玛瑙墙，靠石纹本身与光影就成为「装饰」。
:::

::: def 现代主义（modernism）
在建筑中，指 20 世纪上半叶以功能、技术、新材料与工业化生产为出发点，反对历史风格折衷、追求简洁几何形式与普遍性语言的运动。例子：平屋顶、钢与玻璃幕墙、自由平面，都是它的典型语汇。
:::

这三个概念背后有一套共同的逻辑：建筑的价值，应当来自它的用途、结构与材料，而非来自附加的装饰与历史样式。为了看清这套逻辑如何一步步成形，可以先看一张「功能主义信条」与「后现代反驳」的对照表，后面各段再展开：

| 维度 | 功能主义信条 | 后现代反驳 |
|------|-------------|-----------|
| 形式来源 | 追随功能、由结构生成 | 形式也来自符号、记忆与趣味 |
| 装饰 | 装饰即罪恶，应当剥除 | 装饰可以是意义与情感的表达 |
| 语言 | 普遍的、放之四海皆准 | 应当是地方的、多样的 |
| 代表口号 | 少即是多（密斯） | 少即是无聊（文丘里） |

## 三、代表人物：卢斯、格罗皮乌斯、密斯与文丘里

阿道夫·卢斯（Adolf Loos，1870—1933）是维也纳的建筑师与论战者，以尖刻著称。1908 年他发表《装饰与罪恶》，把装饰与现代文明对立起来，认为过度装饰既是资源的浪费，也是文化的退化。他的论战姿态多于系统理论，却为功能主义清理出了一条「反装饰」的底线。

瓦尔特·格罗皮乌斯（Walter Gropius，1883—1969）则把这条底线变成了一套教育制度。1919 年他在魏玛创办包豪斯，宣言主张「艺术与技术的新统一」，把画家、工匠、建筑师聚到一个屋顶下，要让设计从手工艺走向工业化，为现代生活批量生产既实用又美观的器物。包豪斯的理想是「总体建筑」——一切造型活动都汇入建筑这一总目标。

密斯·凡·德·罗（Ludwig Mies van der Rohe，1886—1969）把包豪斯的理想推到了最纯粹的形式高度。他先后主持包豪斯（末任校长），后流亡美国。他关心的命题极其集中：如何用最少的元素——钢、玻璃、大理石——造出最精确、最宁静的空间。他的「少即是多」正是这一追求的口头浓缩。

罗伯特·文丘里（Robert Venturi，1925—2018）则是这套信条最著名的挑战者。1966 年他出版《建筑的复杂性与矛盾性》，主张建筑应当容纳复杂、暧昧与矛盾，而非追求纯粹。他对「少即是多」的反讽回应「少即是无聊」，成了后现代建筑的战斗口号之一。

## 四、理论解析：功能主义的思想史与「少即是多」

功能主义的思想史可以分三步看。

第一步，**「形式追随功能」的提出**。美国建筑师路易斯·沙利文（Louis Sullivan）在 1896 年前后的文章里提出这一口号，其大意是：建筑的形式应当由它的功能自然生成。这句话后来被简化为一句格言，也被大量误读——沙利文本人并不排斥装饰，他设计的建筑仍有繁复的植物纹样；他反对的是把历史风格当作遮羞布，而不是反对一切装饰。这一区分很重要，因为它提示我们：「功能主义」从来不等于「素面朝天」。

第二步，**卢斯的「装饰即罪恶」**。1908 年卢斯把论战推得更极端：他把装饰与文明发展的阶段挂钩，认为现代文明人应当剥除装饰。这里只作转述其大意：装饰的消失，是文化进化的标志，也是一种节约——节约劳动、材料与金钱。卢斯的立场更多是一种道德化的文化批判，而非严格的美学论证，但它为「简洁」赋予了正当性。

第三步，**包豪斯的综合**。格罗皮乌斯把「反对装饰」与「拥抱工业」合成一个正面纲领：不靠剥除，而靠「艺术与技术的新统一」——让工匠的手艺与机器的精确结合起来，让形式在功能与生产逻辑里自然长出来。包豪斯的课程体系把基础造型、材料、工坊实践串成一条从「形式感」到「可批量生产」的完整训练链。

密斯的「少即是多」则是这三步的最精炼结晶。要理解它，关键在「少」不等于「没有」，而在于用极少元素逼出极大精确：一根钢柱的十字形截面、一面缟玛瑙墙的石纹对位、一片悬挑屋顶的薄边，都靠「少」来凸显材料的本体与比例的精确。「少」在这里是一种纪律，它要求你把每一个剩下的元素都做到无可挑剔——因为已经没有装饰可以掩盖任何瑕疵。

::: warn 常见误解
「功能主义 = 房子只求实用、不要美观」是一种流行误读。功能主义者并不否认美，他们主张的是：美应当从用途、结构与材料的诚实表达中产生，而不是从外贴的装饰里购买。密斯的巴塞罗那馆几乎「无用」却极尽精美，正说明功能主义的美学与「实用主义」是两回事。
:::

## 五、经典原著：三份宣言式文本

本讲的三份文本都是「宣言」，均作转述。

卢斯《装饰与罪恶》（1908）的大意是：原始人靠纹身与装饰标记自己，现代文明人则把装饰视为一种落后；现代文化的进步，正在于它越来越少地依赖装饰，而让形式与材料本身说话。

格罗皮乌斯《包豪斯宣言》（1919）的大意是：一切造型艺术的最终目标是建筑，艺术家与工匠之间没有本质界限，包豪斯要把他们重新联合起来，为新的时代创造出统一的、与工业结合的作品。

文丘里《建筑的复杂性与矛盾性》（1966）的大意是：现代建筑追求纯粹的清晰，却牺牲了生活本身的复杂；建筑应当拥抱矛盾与暧昧，容纳多义，而不是把一切都简化成单一答案。

::: quote 文丘里《建筑的复杂性与矛盾性》（转述）
文丘里在此处的大意是：我拥护复杂而矛盾的建筑，它比「少即是多」更接近生活的丰富与暧昧；对现代建筑的纯粹性而言，「少」往往是「无聊」。
:::

这三份文本构成一条完整的弧线：卢斯为「少」立法，格罗皮乌斯为「少」建了学校，文丘里则宣布「少」可能走向乏味。功能主义由此从口号升为制度，再被制度所反噬。

## 六、艺术案例：巴塞罗那馆的形式细读

巴塞罗那德国馆（1929，钢框架、玻璃、大理石、缟玛瑙、洞石、镀铬钢柱；1930 年拆除，1986 年原址重建；密斯与莉莉·赖希合作）是「少即是多」最完整的实物。我们可以对照它逐项看。

看**结构与墙的分离**：八根镀铬的十字形钢柱承重，墙体完全脱开承重，成为独立的「空间屏」。这意味着墙不再是「围出房间」的结构，而成了「划分空间」的元素——这是「自由平面」的关键一步。

看**三套平面的错动**：墙、顶、地三套平面错动穿插，互相不严格对位，室内与室外互相渗透，形成连续流动的空间，而非一个个封闭的房间。你从一端走进去，说不清哪里是「室内」的结束、哪里是「室外」的开始。

看**材料本体**：石灰华地面、缟玛瑙与洞石的贴面按石纹对位拼缝，材料本身的纹理就是装饰，没有附加的线脚与柱式。缟玛瑙墙在光下近乎发光，成了整座建筑唯一的「奢侈品」。

看**两片水面**：大池映出悬挑的屋面，小池围以深色玻璃，水与墙体互相反射，把建筑的重感一再稀释。

看**屋顶的失重**：屋面是一块薄板出挑，柱与顶的接头尽量消隐，使屋顶近乎「无重量」，悬在半空。

::: fig a-barcelona-pavilion | 巴塞罗那馆：八根十字形钢柱承重，墙体脱开成空间屏，墙顶地三套平面错动，室内外互相渗透
:::

把这些形式特征合起来，就能理解本讲开头那个「矛盾」：这座馆几乎没有功能，却把功能主义的「诚实」原则——结构、材料、空间各自说话——贯彻到了极致。它证明「少即是多」的「少」，是一种把结构逻辑、材料本体与空间流动同时推向纯粹的美学纪律。

## 七、思想联系：从国际式到后现代的反驳

向前追溯，功能主义的根可以伸到沙利文与卢斯，再往前则是 19 世纪工业革命对「风格折衷」的反动：当钢铁、玻璃、混凝土取代了砖石，旧的样式语言失灵了，功能主义正是对这种失灵的正面回应。它也呼应了本模块反复处理的主题——形式自律：正如绘画走向平面、音乐走向纯形式，建筑也试图走向「结构与材料的自律」。

向后看，功能主义在战后被推广成「国际式」（International Style），钢与玻璃的方盒子在世界各地被复制。这套普遍性语言的代价随之暴露：它把地方性、气候、文脉与使用习惯一并悬置，造出了大量千篇一律的现代建筑。后现代建筑正是从这一不满里生长出来：文丘里主张回到符号、历史与趣味，雅各布斯（Jane Jacobs）在《美国大城市的死与生》（1961）里则从城市生活的角度，批评现代主义规划对街道、街区与人文尺度的漠视——这些多为研究者的转述与概括。用前面模块的术语说，这是「现代主义」的普遍性语言与「地方性、人文尺度」之间的一场正面冲突，而文丘里的「少即是无聊」就是这场冲突最俏皮的注脚。

## 八、本节总结

::: key 本讲要点
- 功能主义主张形式由用途、结构与材料生成，「形式追随功能」常被误读为「不要装饰」。
- 卢斯的「装饰即罪恶」为简洁立法，包豪斯以「艺术与技术的新统一」把它制度化。
- 密斯的「少即是多」以极少的元素逼出极致的精确，巴塞罗那馆是其最完整的空间示范。
- 巴塞罗那馆几乎无功能，却把结构、材料与空间的自律贯彻到底，暴露了「功能主义」与「实用主义」的错位。
- 后现代建筑（文丘里「少即是无聊」、雅各布斯）批评国际式的千篇一律与对人文尺度的漠视。
:::

- 功能主义主张形式由用途、结构与材料生成，但「形式追随功能」不应被简化为「不要装饰」。
- 卢斯以「装饰即罪恶」为简洁正名，包豪斯以「艺术与技术的新统一」把这一理念变成教育与生产制度。
- 密斯的「少即是多」用极少元素逼出极大精确，巴塞罗那馆是这一美学的完整空间示范。
- 功能主义在战后被推广为「国际式」，其普遍性语言付出了地方性、气候与人文尺度的代价。
- 文丘里「少即是无聊」、雅各布斯的城市批评，构成对功能主义纯粹性最有力的反驳。

值得继续追问的问题：如果一座建筑的美在于「结构与材料的诚实」，那么巴塞罗那馆那片几乎「没用」的缟玛瑙墙，究竟是在诚实展示材料，还是在用昂贵材料制造另一种「装饰」？这个追问，指向功能主义话语里「真实」与「修辞」之间最微妙的地带。
