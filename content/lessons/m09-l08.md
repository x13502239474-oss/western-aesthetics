## 一、本节导入

把《英雄交响曲》第一乐章的开头放出来，哪怕只放三十秒，一个熟悉古典音乐的人都会感到「不对劲」。按当时惯例，交响曲第一乐章通常由一个辉煌、完整的主题开场，乐队长驱直入；可《英雄》一上来只是两个 E♭ 大调的强力和弦，随即一片寂静，然后大提琴在低音区极其克制地、几乎是悄悄地把主题「托」了出来。它不宣布，它酝酿。

再放瓦格纳《特里斯坦与伊索尔德》的前奏曲：开头那个著名的「特里斯坦和弦」，由 F、B、D♯、G♯ 四个音叠成，它本身不解决，转了几个位置之后还是不解决，整段前奏曲就这样悬着，把「想解决而不得」的情绪拉长到几分钟。这两段声音，一个来自 1803—1804 年，一个来自 1857—1859 年，中间隔着半个世纪，却共享同一种冲动：音乐要表达某种超越技艺的东西——自我的理念、无尽的渴望。这正是本讲要讲清的浪漫主义转向。

## 二、核心知识：从绝对音乐到总体艺术

先厘清三个术语，它们构成理解这一讲的三角。

::: def 绝对音乐（absolute music）
不依赖文字、标题、剧情或图像，仅凭纯器乐形式自身成立的音乐。它的拥护者主张，器乐的意义就在乐音的组织之中，无须借助任何外部指涉。例子：一部无标题的交响曲、弦乐四重奏，被当作「纯粹」的绝对音乐。
:::

::: def 形式与内容（form-content）
美学中关于作品「怎样组织」与「表达了什么」之间关系的一对范畴。在音乐美学里，它表现为一个经典争论：音乐的内容究竟是一种可命名的情感或观念，还是仅仅等于乐音的运动形式本身。例子：同一段音乐，标题派会说它「表达了英雄的奋斗」，形式派会说它「就是这一串乐音的关系」。
:::

::: def 总体艺术作品（Gesamtkunstwerk）
瓦格纳提出的理想：把诗歌、音乐、戏剧、舞台视觉等多种艺术融合成一个不可分割的整体，各门艺术不再各自为政，而是共同服务于一个总的戏剧意图。例子：瓦格纳的乐剧里，管弦乐不只伴奏，舞台不只布景，诗歌不只唱词，它们互为注释、共同推进。
:::

第三个概念「渴望」（c-sehnsucht）可以看作浪漫主义的情感底色——一种指向无限、永不满足的渴慕，瓦格纳把它写进了《特里斯坦》那永不解决的半音里。下面这张表先把两派对峙的格局摆出来，再逐段展开：

| 维度 | 绝对音乐派（汉斯立克） | 总体艺术派（瓦格纳） |
|------|----------------------|---------------------|
| 音乐的内容 | 乐音的运动形式本身 | 与诗、剧合一的整体情感 |
| 音乐与语言 | 独立，无须歌词 | 与诗歌、戏剧不可分 |
| 价值标准 | 形式的自足 | 综合体的整体效果 |
| 代表立场 | 《论音乐的美》 | 《未来的艺术作品》 |

## 三、代表人物：贝多芬、瓦格纳、汉斯立克与尼采

路德维希·凡·贝多芬（Ludwig van Beethoven，1770—1827）是这场转向的关键人物。他早年在波恩与维也纳都曾以音乐家身份依附于贵族赞助，但他逐渐把自己从「受雇的乐师」转变为「独立创作的艺术家」——他不再只按委托写应景之作，而把交响曲、奏鸣曲当作表达自我理念的载体。他的耳聋加深了这种内向化：听不见世界的他，却把内心世界写进了音乐。他的局限与伟大一体两面：他开创了「为理念而作」的姿态，却仍以古典的奏鸣曲式、交响曲体裁为容器，尚未走到瓦格纳那种跨媒介的综合。

理查德·瓦格纳（Richard Wagner，1813—1883）则把浪漫主义推到了极致。他既是作曲家，又是脚本作者、剧院改革者与理论家，主张音乐必须与诗、剧、舞台合一，于是放弃传统歌剧的「分曲」结构，创造了持续不断的「乐剧」。他的理论抱负与政治、种族观念的牵连同样真实，后面会如实交代。

爱德华·汉斯立克（Eduard Hanslick，1825—1904）站在这股潮流的对面。他是音乐评论家，在《论音乐的美》（1854）里为「绝对音乐」辩护，反对把音乐当作情感的表达。他的著名命题「音乐的内容就是乐音的运动形式」，成了形式主义音乐美学的基石。

弗里德里希·尼采（Friedrich Nietzsche，1844—1900）与瓦格纳的关系则是一段著名的「先赞后弃」：他早年视瓦格纳为酒神精神在当代的复活，晚年却对其大加批判。这组关系是理解瓦格纳争议性的最好透镜。

## 四、理论解析：期待—延迟—解决，与「不解决」的美学

先讲清楚奏鸣曲式，因为《英雄》的形式越界要在这套惯例里才能看出来。奏鸣曲式的张力结构可以概括为三步：

1. **呈示**：呈示部给出两个对比的主题，通常一个刚健（第一主题）、一个抒情（第二主题），并把调性从主调移向属调。
2. **发展**：发展部把主题打碎、变形、推向远方，制造最大的不稳定与期待。
3. **解决**：再现部让主题回到主调，完成调性上的「回家」。

这套「期待—延迟—解决」的结构，正是古典音乐最核心的形式承诺。汉斯立克的美学就建立在这上面：他认为音乐的美不在它「表达」了什么情感，而在这些乐音关系的组织本身。他的大意是（转述）：音乐的内容，就是乐音的运动形式，除此之外它不「说」任何东西。

贝多芬《英雄》恰恰在这套形式里塞进了前所未有的越界。它的第一乐章规模被大幅扩张，发展部插入一个全新的 E 小调主题，圆号还在再现部「提前误入」，制造出结构断裂感。这些越界让当时的听众既困惑又激动：音乐似乎第一次显露出「形式本身被撑开」的挣扎，标题「英雄」以及那段题献又划掉的轶事，更让这种挣扎有了可指认的观念内容。

瓦格纳则从另一个方向动摇了这套体系。他不满足于让音乐自律，而要让它回到与诗、剧的综合。他在《未来的艺术作品》（1849）里主张（转述）：未来真正的艺术作品，应当是诗、乐、舞、建筑等一切艺术在戏剧中的重新统一，就像它们在古希腊悲剧里曾经统一过那样。为此他改造了歌剧结构：取消分曲，让旋律「无终」地流动（无限旋律），用「主导动机」把人物与情感贯穿全剧，让管弦乐承担起评论与推进的双重职责。

《特里斯坦与伊索尔德》把这一理想的「渴望」维度写到极致。前奏曲的「特里斯坦和弦」悬而未决，半音阶持续扩张，调性中心不断游移，整部剧的张力都在「想解决而不得」中积累，直到最后一幕「爱之死」才回到 B 大调，把前奏曲的悬置最终了结。这种「无限渴慕」，正是浪漫主义的 c-sehnsucht 在音乐里最彻底的形态。

::: warn 常见误解
「汉斯立克说音乐与情感无关」是一种流传很广的误读。他反对的是把音乐解释成对具体情感的再现或语言式的表达，他承认听音乐会引起情感。准确的说法是：他认为音乐的美学价值不在于「说出了一个情感」，而在于乐音形式自身的组织。
:::

## 五、经典原著：四份文本与一段公案

本讲涉及四份文本，均作转述。

瓦格纳《未来的艺术作品》（1849）的大意是：单门艺术已经走到尽头，唯有重新综合各门艺术、回到戏剧这一共同的母体，艺术才能恢复其公共的、整体的力量。这一理想后来以「总体艺术作品」之名成为瓦格纳主义的旗帜。

汉斯立克《论音乐的美》（1854）的大意是：音乐的美是一种纯音乐的美，它就在乐音及其艺术性的组合之中，与音乐之外的内容无关；说音乐「表达」情感，只是把它当成了某种心理状态的符号。

尼采《悲剧的诞生》（1872）曾把瓦格纳奉为酒神精神在现代的再生；而《瓦格纳事件》（1888）则调转枪口，斥之为「颓废」，认为瓦格纳的音乐靠过度刺激与戏剧化来掩饰生命力的衰竭。同一对象，支撑了相反的两份判断。

::: quote 汉斯立克《论音乐的美》（转述）
汉斯立克在此处的大意是：音乐的内容就是乐音的运动形式，音乐的美是一种不依赖外部指涉的纯音乐的美。
:::

此外有一桩必须如实交代的公案：瓦格纳的反犹主义。他 1850 年匿名发表《音乐中的犹太性》，攻击犹太音乐家，尤其针对门德尔松与迈耶贝尔，1869 年又以真名再版。这一立场与其「德意志艺术复兴」的民族主义话语纠缠在一起，也在后世与纳粹对瓦格纳的利用形成了令人不安的历史呼应。交代这一点，是为了说明：审美理想从来不是无菌的，瓦格纳的「总体艺术」与他关于民族、种族的观念来自同一个思想熔炉。

## 六、艺术案例：两段音乐的「听什么」

先听《英雄交响曲》（1803—1804 作曲，1805 年首演，E♭ 大调，双管编制加三支圆号）。听**第一乐章的破题**：两个 E♭ 大调强力和弦后，大提琴在低音区呈示主题——注意这个主题多么克制，它不从高处宣布，而从低处爬升，等于把「英雄」先写成一个正在生成的形象。听**发展部**：主题被撕碎、推向远关系调，并闯入一个新的 E 小调主题，音乐的张力依靠调性上的迷失，而非音量的堆叠。听**圆号的「误入」**：再现部来临前，圆号提前吹出主题，这一著名的「错误」在结构上制造了一次断裂，至今仍是演奏与分析的焦点。听**第二乐章**：c 小调葬礼进行曲，附点节奏与低沉的中提琴构成沉重的步伐——它呈现的是英雄之死，而非胜利的凯旋。

再听《特里斯坦与伊索尔德》（1857—1859 作曲，1865 年首演，三幕乐剧）。听**前奏曲**：那个 F—B—D♯—G♯ 叠成的「特里斯坦和弦」悬而未决，多次转位仍不落到主调，把「渴望」直接做成了音响事实。听**半音化的推进**：旋律沿着半音阶持续滑动，调性中心不断游移，你始终等不到一个安稳的落脚点——这就是「无限旋律」：旋律不再分句收束，而是无休止地向前流。听**第二幕爱情二重唱**：长时段的渐强与延迟解决堆叠张力，把「夜」写成唯一的真实，白昼则成了必须被否定的虚伪。听**第三幕「爱之死」**：全剧的悬置终于回到 B 大调，前奏曲的那个未解决和弦在此获得了解决——但解决的同时，正是死亡。

::: fig a-tristan | 《特里斯坦》前奏曲：特里斯坦和弦悬而未决，半音阶使调性中心不断游移，构成「无限渴慕」的音响
:::

两段音乐合起来看，正好是浪漫主义的两个时刻：贝多芬还在古典形式的容器里「撑开」形式，瓦格纳则干脆打破了分曲与调性的边界，让形式本身溶解在无尽的渴望里。

## 七、思想联系：从浪漫主义到无调性，与瓦格纳的遗产

向前追溯，这一讲直接承接第六模块第一讲的浪漫主义转向：从「为贵族服务」到「为自我与理念创作」，贝多芬是这条路上的枢纽人物。他之后的整个 19 世纪，音乐家们越来越把自己当作「艺术家」而非「匠人」，把作品当作自我与世界观的表达。

向后看，瓦格纳的半音化把调性推到了崩解边缘：既然「特里斯坦和弦」可以如此长久地不解决，那么「解决」这一古典音乐的根基性承诺就被动摇了。勋伯格后来正是从这条半音化的路走到了无调性与十二音体系。可以说，《特里斯坦》既是浪漫主义渴望的巅峰，也是古典调性瓦解的起点。

瓦格纳的「总体艺术作品」遗产同样双面。一方面，它启发了后世跨媒介的综合理想——电影、歌剧改革、乃至先锋戏剧都从中受益；另一方面，它与民族主义、反犹主义的纠缠，使它成为美学史上一面必须谨慎对待的镜子。尼采的先赞后弃，正是这面镜子最尖锐的反映：同一个人，既是「酒神复兴的象征」，也是「颓废的典型」。用前面模块的话说，审美判断从来无法脱离价值立场而纯然「无利害」，瓦格纳把这一点暴露得尤其彻底。

## 八、本节总结

::: key 本讲要点
- 贝多芬把音乐从「为贵族服务」转向「为自我与理念而作」，是浪漫主义转向的枢纽。
- 奏鸣曲式的「期待—延迟—解决」是古典形式的核心承诺，《英雄》以规模扩张与结构越界撑开了这套形式。
- 汉斯立克以「音乐的内容就是乐音的运动形式」为绝对音乐辩护，反对把音乐还原为情感表达。
- 瓦格纳以「总体艺术作品」主张诗、乐、剧、舞台的合一，《特里斯坦》的未解决和弦写尽了「无限渴慕」。
- 瓦格纳的遗产是双面的：半音化通向无调性，其民族主义与反犹主义则留下了必须直面的阴影。
:::

- 贝多芬《英雄》以形式越界与「为理念而作」的姿态，标志音乐从服务性技艺转向浪漫主义的自我表达。
- 奏鸣曲式的「期待—延迟—解决」是古典音乐的形式承诺，理解《英雄》的越界须以它为参照。
- 汉斯立克的「音乐的内容就是乐音的运动形式」，是形式主义音乐美学对「表达论」的最有力反驳。
- 瓦格纳的「总体艺术作品」主张各门艺术在戏剧中重新合一，《特里斯坦》以未解决和弦与无限旋律写尽渴望。
- 瓦格纳既是酒神复兴的象征（尼采早赞），也是颓废的典型（尼采晚弃），其反犹主义牵连不可回避。

值得继续追问的问题：当汉斯立克说音乐的美只在「乐音的运动形式」，他能否解释《英雄》第二乐章葬礼进行曲那种几乎人人都会感到的「悲伤」？或者说，那份「悲伤」究竟在乐音里，还是在听者的文化经验里？这个问题，正是形式与内容之争至今未歇的根源。
