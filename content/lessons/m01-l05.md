## 一、本节导入

爬到山顶，人会做两件事：先看，再拍。看的时候眼睛在找「好看的角度」，拍的时候手在调取景框。取景框这个动作很有意思，它把连绵的山脊切成一个矩形，把多余的天空裁掉，把前景的树枝安排到右上角。这个动作只有两百多年的历史：十八世纪末的英国旅行者带着一面凸面深色镜出门，把镜中的风景当作画来看，再按镜中构图写生。这面镜子叫克劳德镜，名字来自法国画家克劳德·洛兰。人需要镜子才能看见自然的美，说明自然美依赖观看技术。

与这套技术并行的是另一条思路。黑格尔在柏林讲美学时说，艺术美高于自然美，因为艺术美由心灵产生，心灵高于自然。他把自然美排除在美学之外。两条思路——把自然当画看，与把自然排在艺术之下——构成本讲要处理的问题。

## 二、核心知识：三个概念与四种范式

::: def 自然美（natural beauty）
自然对象作为审美对象时呈现的价值。这个定义看似自明，实际依赖「什么算自然」「谁在欣赏」「用什么标准」三个变量，历史上的自然美观念因此差异极大。
例子：同一片湿地，农夫看到待开垦的荒，鸟类学者看到栖息地，十八世纪的旅行者看到需要「如画」处理的野景。
:::

::: def 如画（picturesque）
十八世纪英国形成的审美范畴，介于优美与崇高之间，以粗糙、不规则、纹理丰富、明暗对比强烈为特征。它同时是一种观看方式：把自然置于取景框内，按绘画的构图要求加以取舍。
例子：一座荒废的哥特式小教堂，墙皮剥落、藤蔓攀爬、屋顶塌了一角，在「如画」的眼光里比修葺一新的教堂更美，因为残破提供了纹理与时间感。
:::

::: def 艺术美（artistic beauty）
在黑格尔体系中，指理念在感性形式中的完满显现，承担者是艺术作品。它的等级高于自然美，因为作品由心灵产生，而心灵是理念的自为存在。
例子：一座希腊神像的美不只在于比例，还在于它把「神性的静穆」表现在大理石里；石头没有这种内容，是雕刻家的心灵放进去的。
:::

自然美的观念史大致有四种范式：

| 范式 | 根据 | 判断标准 | 主体位置 | 主要风险 |
|---|---|---|---|---|
| 神创秩序 | 自然是受造物，映照造物主 | 完善、秩序、目的 | 受造者，读自然的书 | 世俗化之后失去根据 |
| 如画 | 自然按绘画的语法被观看 | 构图、纹理、明暗 | 旅行者、取景者 | 自然沦为风景图片 |
| 黑格尔式 | 心灵高于自然 | 理念显现的自由度 | 绝对精神 | 自然被剥夺独立价值 |
| 环境美学 | 自然有其自身的尺度 | 恰当性、认知正确 | 环境中的身体 | 知识门槛排斥感受 |

## 三、代表人物：黑格尔

黑格尔（Georg Wilhelm Friedrich Hegel，1770—1831）在图宾根神学院求学时与荷尔德林、谢林同住，早年做过家庭教师与报纸编辑，1801 年在耶拿任教，1807 年《精神现象学》出版，此后在纽伦堡任中学校长，1816 年赴海德堡，1818 年接任柏林大学哲学教授。美学讲演集中在柏林时期，1820 年代反复讲授，生前未及整理成书。

他面对的问题是如何把艺术纳入体系。在《精神现象学》里，艺术属于「绝对精神」的第一个形态，低于宗教与哲学；在《美学》里，他要说明艺术为何是真理的一种必要形式，又为何终将被哲学取代。这个双重任务决定了他对自然的态度：自然若也有美，艺术的必要性就被削弱，因此自然美必须被安置在较低的位置上。

他的贡献在于把美学从趣味理论提升为历史哲学：艺术类型对应精神自我认识的阶段，作品因此有了真理内容。他的局限也在这里：体系等级一旦成立，自然就只能作为「不完全的形态」出现。

## 四、理论解析：黑格尔凭什么颠倒等级

**先看自然美的历史构造。**第一种范式是神学的。奥古斯丁与阿奎那都承认自然的美，却把它放在受造物的秩序里：自然的美是完善的痕迹，最终指向造物主。这个框架里，自然美有确定位置，却没有独立价值，它的意义在于指向。第二种范式是趣味的。十八世纪，自然鉴赏变成可训练的技艺：吉尔平的《论如画美》教人如何在野景中寻找构图，普莱斯与奈特争论如画的本质是粗糙还是联想，克劳德镜与哈哈墙（用暗沟代替围墙，让园林与田野在视觉上连成一片）则把这种眼光物质化。自然在此被视觉化、框架化，成为「风景」。

**再看黑格尔的论证。**他的结论源于存在论等级的必然推论，与趣味偏好无关。推理分六步。

第一步，确定美的定义：美是理念的感性显现。理念指概念与其实在的统一，二者相合的程度决定美的程度。

第二步，确定理念在自然中的存在方式。自然是「理念的最浅近的客观存在」，在自然里，概念沉没于外在性，见不出主体的观念性的统一。一块石头、一条河的统一性由外部看出，无法由自身建立。

第三步，确定理念在心灵中的存在方式。心灵（Geist）是自为的存在，它知道自己，因此自由；自然的存在是自在的，它不知道自己，因此不自由。

第四步，由此推出等级：美的程度随理念在其实在中达到自由的程度而定。心灵高于自然，所以艺术美高于自然美。

第五步，补上两条具体论据。形式上，任何一个无聊的幻想，只要经过了人的头脑，就比任何自然产品高，因为它见出了心灵的活动和自由；内容上，太阳对自身无足轻重，它没有自由，也没有自意识，我们只从它与其他事物的必然关系看它。

第六步，得出方法论的结论：自然美的概念既不确定，又没有什么标准，无法构成系统的科学，美学应当把自然美排除在外。

这六步的关键在第三步。黑格尔的「心灵」指理念达到自我意识的存在方式，与心理活动无关。他之所以敢说艺术美高于自然美，是因为已经预设了「自意识高于无自意识」这一存在论等级。这个预设一旦被接受，结论就无可反驳；一旦被质疑，整个论证就悬空。

::: quote 《美学》第一卷，全书序论
就这个意义来说，自然美只是属于心灵的那种美的反映，它所反映的只是一种不完全不完善的形态，而按照它的实体，这种形态原已包含在心灵里。
:::

这段话把「反映」这个词用得很重。自然美在此没有自己的光源，它像月亮借太阳的光。代价是：自然从审美的主体降为审美的材料，它的价值由心灵授予。

**黑格尔的最强理由值得公平对待。**其一，任何欣赏都是心灵的活动，说「自然美独立于心灵」需要解释谁在欣赏，而答案总是心灵。其二，判断自然美所用的标准（生命、健康、对称、完整）本身来自心灵的概念，自然并不提供这些标准。其三，艺术能承载真理内容——历史的苦难、伦理的冲突、自由的理念——自然不能「说出」什么，它只能被赋予意义。三条理由合起来，构成了一个相当强的立场。

**代价同样明显。**第一，自然作为「应当被扬弃的外在性」，在实践中容易导向征服自然的姿态，生态批评对此有持续的指控。第二，自然审美经验的独立性被取消：热爱荒野的人所感到的东西，被解释成心灵自我观照的副产品。第三，艺术美的优先无法解释二十世纪的大量实践，从杜尚的反艺术到自然摄影，艺术与自然的边界早已混乱。第四，论证有循环之嫌：用心灵的标准证明心灵高于自然。

**环境美学的反驳。**卡尔森在 1970 年代末提出，自然审美欣赏有「恰当」与「不恰当」之分。把自然当画看，他称为「风景模式」，这种欣赏只取视觉表面，忽略了对象究竟是什么。他主张「认知模式」：用生态学、地质学、自然史的知识确定欣赏的范畴，就像艺术欣赏需要范畴一样。

他的类比很有力。看芭蕾舞，若当成体操，就会用「动作难度」去评价，错过编舞的意义；看《格尔尼卡》，若当成装饰画，就会用「配色是否悦目」去评价，错过它的控诉。自然同样：把冰川谷当成矿坑遗址，把苔原当成荒地，都是范畴错误导致的审美误判。鹿群啃食造成的树线，在不懂生态的人眼里是「病态」，在懂的人眼里是系统的正常节律。

::: warn 「自然美是原始的、未经中介的」
这个说法听起来像在抬举自然，实际站不住。未经中介的自然审美经验并不存在：我们要么用如画的构图看，要么用生态学的范畴看，要么用农业的有用性看。差别只在中介是否恰当。黑格尔把中介全归给心灵，某些环境美学家以为知识可以取代感受，两边都简化了事情。
:::

**对卡尔森的反驳。**柏林特主张「参与模式」：人始终在环境之中，脚步声、温度、湿度都是审美经验的一部分，视觉中心主义才是问题的根源。卡罗尔主张「情感唤起模式」：自然直接激起情感，知识可以辅助，却不构成必要条件。戈德洛维奇强调自然的神秘与不可知，认为把它变成知识对象恰恰取消了崇高感。这些反驳共享一个要点：认知主义把自然变成「被认识的东西」，审美经验的当下性与身体性被压缩了。

双方最强的理由可以这样摆。卡尔森一方：没有范畴就无法辨别对象，审美判断会退化为投射；「这朵花很美」若不知它是入侵物种，判断就可能是错的。反对方：审美感受先于知识，儿童与渔民对风暴的敬畏不需要生态学；把欣赏变成考试，等于把自然交给专家。

我倾向于认为，卡尔森在「恰当性」上较为吻合经验，在「科学认知是唯一恰当模式」上过强。自然审美可以是多价的：科学的、情感的、身体的、神秘的，各有各的恰当条件。

## 五、经典原著：黑格尔《美学》

《美学》不是黑格尔生前出版的书。他在柏林多次讲授美学，1831 年去世后，学生霍托根据听课笔记与部分手稿整理成书，1835 年起陆续出版。全书分三卷：第一卷讨论美的理念与自然美，第二卷讨论象征型、古典型、浪漫型三种艺术类型，第三卷讨论建筑、雕塑、绘画、音乐、诗各门艺术。第一卷的结构是：全书序论、第一章总论美的概念、第二章自然美、第三章艺术美或理想。

第二章「自然美」篇幅不长，处理的却是关键问题。黑格尔先区分自然中理念存在的几种方式：机械物、化学物、有机体，逐级上升，最后到达生命；再讨论自然美的抽象形式——整齐一律、平衡对称、符合规律、和谐。这些形式靠数量关系维持，尚未达到概念的自由。自然美因此可以被描述，却无法被组织成有内在必然性的科学。

::: quote 《美学》第一卷，全书序论
不过我们可以肯定地说，艺术美高于自然。因为艺术美是由心灵产生和再生的美，心灵和它的产品比自然和它的现象高多少，艺术美也就比自然美高多少。
:::

这段话的逻辑是一个比例式：艺术美与自然美之差，等于心灵与自然之差。它的力量来自那个「高多少」的比较——黑格尔承认这是量的说法，随即声明真正的「高于」无法用量衡量，因为只有心灵才是真实的，一切美只有在涉及心灵时才真正是美的。比较由此从量的层面转到存在论的层面：自然美属于「借来的美」，不能用「较少的美」来描述。

## 六、艺术案例：莫奈《日出·印象》

莫奈 1872 年在勒阿弗尔港画的这幅小画，宽约六十厘米，1874 年在巴黎展出时被评论家勒鲁瓦借题讥讽，「印象派」由此得名。画面是一片灰蓝的晨雾，左上角一轮橙红的太阳，水面上一道断续的橙色倒影，前景两只小舟的剪影，远处是吊车与桅杆的模糊轮廓。

形式上，三处处理值得注意。第一，轮廓被取消：船、水、天之间没有清晰边界，形体的边缘由笔触的断续构成。第二，色彩关系取代明暗关系：太阳的橙与天空的灰蓝形成冷暖对比，倒影用短促的水平笔触，把光在水面的碎裂直接画出来。第三，笔触可见：颜料没有被抹平，观者能看见手的位置，画面因此带有「未完成」的质感。

三种读法又出现了。如画的读法把它当作取景的成功：雾、逆光、剪影，都是十八世纪以来训练出来的构图套路。黑格尔式的读法把它当作心灵对自然的再造：港口本身只是货栈与吊车，是画家的心灵把它变成了光的结构。环境美学的读法会追问：画中的港口是真实的生态与劳动场所，把它读成「晨雾中的诗意」，会不会遮蔽其他维度？

::: fig a-impression-sunrise | 《日出·印象》：橙红的太阳与灰蓝雾气的冷暖对比，轮廓由断续笔触构成
:::

这个案例同时支持黑格尔与反驳黑格尔。支持的一面是，画中的美确实由心灵产生，港口不会自己呈现为这种光色结构；反驳的一面是，画家所做的工作是让自然自己说话，他放弃构图与叙事，把感受交给光线。

## 七、思想联系

向前追溯，黑格尔的颠倒针对的是康德。康德在第 42 节讨论「对美的智性兴趣」，认为对自然美的直接兴趣是善的心灵的标志，自然仿佛对我们有所安排。这个立场把自然美放在很高的位置，黑格尔把次序倒过来，等于宣布康德的「好意」是一种感伤。

向后看，阿多诺在《美学理论》中为自然美翻案（大意）：自然美是被艺术理性压抑的「非同一者」的痕迹，艺术的正当性恰恰在于替自然说话。这个论断把黑格尔的等级重新颠倒了一次。再往后，卡尔森、柏林特与生态美学把自然审美从艺术哲学的附庸变成独立领域。

## 八、本节总结

::: key 本讲要点
- 自然美依赖观看技术：神创秩序、如画取景、黑格尔式贬抑、环境美学的恰当性，四种范式各有根据。
- 黑格尔的颠倒建立在存在论等级上：理念在自然中沉没于外在性，在心灵中达到自为与自由，因此艺术美高于自然美。
- 六步论证中，第三步（心灵是自为存在）是关键预设，接受它则结论成立，质疑它则论证悬空。
- 自然美被规定为「心灵美的反映」，代价是自然失去独立审美价值，并可能导向征服自然的姿态。
- 卡尔森以「恰当性」与「认知模式」反驳，柏林特、卡罗尔、戈德洛维奇以参与、情感、神秘三种模式回应。
:::

这个颠倒的意义超出美学。它把一个审美判断与一套形而上学捆绑在一起：自然是否美，取决于心灵在宇宙中的位置。二十世纪对黑格尔的反弹，多半也是形而上学层面的反弹。

值得继续追问的问题：如果自然美需要知识来担保，那么没有生态学知识的古人是否就错失了自然美？反过来，如果感受先于知识，我们又如何避免把自然读成自己的投影？
