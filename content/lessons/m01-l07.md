## 一、本节导入

同一块卡拉拉大理石，在采石场是论吨卖的原料，在雕刻家的工作室里是「料」，凿成人体之后成了《大卫》。搬石头的工人关心它的重量与暗裂，修复师关心它的风化层，站在像前的观众关心「他在看什么」。三种人面对的是同一块物质，谈论的却是三种不同的东西。

再看音乐。贝多芬《英雄交响曲》的乐谱是几十页纸，某场演出是两个小时的声波，唱片是塑料片上的凹槽。三者都能被叫作「这部作品」，存在方式却相差很远：乐谱可装进抽屉，演出不能；唱片可复制，某一场演出不能。若作品就是声波，一场糟糕的演出也成了作品本身；若作品就是乐谱，从未被演奏的交响曲似乎从未真正存在。

这两个例子指向同一个问题：我们称为「审美对象」的东西，究竟是什么？它是物吗？是心里的观念吗？还是某种在观看与作品之间生成的东西？本讲处理其来历、困境与改造。

## 二、核心知识：三个层次的区分

先把三样东西分开，后面的一切讨论才有地基。

::: def 物理物（physical thing）
按自然科学的描述而存在的物：有质量、有化学成分、服从因果律。**例子**：一块大理石的密度、导热性、晶体结构，以及它在搬运中会不会裂；这些属性不因有没有人观看而改变。
:::

::: def 审美客体（aesthetic object）
在审美关系中构成的、作为感性意蕴整体而向我们呈现的对象。它依赖物理物，却不等于物理物。**例子**：雕像的「挣扎」不存在于大理石的密度里；把石头磨成粉，密度还在，雕像没了。
:::

::: def 审美主体（aesthetic subject）
在审美关系中以感知、想象、情感参与对象构成的一方。近代意义上的「趣味主体」是其特定历史形态：一个拥有内在感受、并要求他人同意自己判断的人。**例子**：面对同一片晚霞，气象学家计算云层高度，赶路的人嫌天要黑了，拍照的人在意色温——第三种位置接近审美主体。
:::

::: def 未定点（Unbestimmtheitsstelle / spot of indeterminacy）
英伽登的术语，指作品图式中未被确定、必须由读者在阅读中填补的空隙。**例子**：小说写「他走进房间」，没写大小、墙色、气味；读者总会补出某种房间，补法不同会影响整段气氛。
:::

三个层次的差别可以用下表定住：

| | 存在方式 | 同一性由什么保证 | 典型的错误 |
| --- | --- | --- | --- |
| 物理物 | 实在的、因果的 | 物质构成与时空位置 | 把雕像的意蕴还原为石头的物理属性 |
| 艺术产品 | 人造的、有意图的 | 作者的制作与文本/乐谱的记号 | 把作品等同于某一版印刷或某一场演出 |
| 审美客体 | 关系中被构成的 | 图式＋具体化＋传统的约束 | 把每一次读法都当成作品本身 |

这张表的关键在第三行：审美客体既受对象约束，也受接受者参与，两边都不能删。

## 三、代表人物：从意识到读者

埃德蒙·胡塞尔（Edmund Husserl，1859—1938），现象学创立者。他面对 19 世纪末的双重困境：心理主义把逻辑与真理还原为心理事实，实证主义把意义挤成物理事实。其「意向性」学说（意识总是关于某物的意识）要说明：「被意识到的对象」与「实在的物」并不等同。这为审美对象理论提供第三条路。

罗曼·英伽登（Roman Ingarden，1893—1970），波兰哲学家，胡塞尔的学生，却反叛老师的唯心论倾向。他在《文学的艺术作品》（1931）里追问：作品存在于何处？它既不在纸上，也不在作者心里，也不在读者体验里。答案是「纯粹意向对象」，并给出层次结构。贡献在于把存在方式变成可分析的问题，局限在于具体化的边界难以划清。

汉斯·罗伯特·姚斯（Hans Robert Jauss，1921—1997），康斯坦茨学派代表，1967 年以《文学史作为向文学理论的挑战》开启接受美学。他要反对两种文学史：只排作家年表，或只做文本内部析。方案是把读者放进历史，让意义在历代接受中累积。贡献在于使「关系」获得历史厚度，局限在于读者群的经验能否被重建始终存疑。

## 四、理论解析

### 第一步：主客二分是如何被造出来的

近代认识论把「我」设为表象的拥有者：笛卡尔的「我思」确立了思考者的优先地位，对象成了被表象、被审视的东西。这一框架在美学上的后果，是审美被安置在主体的判断里。18 世纪的英国趣味论者把「趣味」当作内在感官，康德进一步把它规定为反思判断力的运作：美由主体的愉悦来标识，却要求普遍同意。

这一步解决了什么？它把审美从宇宙论的秩序里解放出来。古典与中世纪把美看作事物本身的属性——比例、秩序、光辉；说某物美，等于说它符合某种客观的完善。近代之后，根据移到人的感受性上，人才成为审美的主人。代价是对象被降为刺激物。黑格尔对此有清醒的警觉，他坚持艺术兴趣让对象「自由独立存在」，正要把对象从单纯的刺激中救出来。

::: warn 常见误解：以为「主客二分」是永恒的结构
主体与客体的对置是近代认识论的产物，并非一切时代都有的常识。古希腊人谈「美」，讨论的是存在者的秩序与光亮；中世纪谈「美」，讨论的是受造物对神性的分有。把这些讨论直接翻译成「主体的感受」，会丢掉它们本来要回答的问题。
:::

### 第二步：胡塞尔的意向性提供了什么

胡塞尔的分析可分三步。第一，意识行为与意识对象在结构上相互关联：看总是看某物，想总是想某事。第二，对象的存在方式随行为方式而变：被知觉的树、被想象的树、被回忆的树，是同一棵树的三种呈现，而它们的「存在设定」不同。第三，由此可区分「实在对象」与「意向对象」：半人马没有实在性，却作为意向对象真实地被思考；方形的圆则连意向对象都构不成，因为内容自相矛盾。

这套分析给出了一个既不把对象化为主观幻觉、也不钉死在物理属性上的位置。审美对象既受意识行为构成，又有独立于某次体验的同一性：我今天看《拉奥孔》看出的东西明天可以修正，修正的对象仍是同一座像。

### 第三步：英伽登的层次论

英伽登把文学作品分析为四层，外加一类依附性的性质：

1. 语音层：字词的声音形式与节奏，提供感性基础，使作品可被朗读、被听见。
2. 意义层：词义、句义以及由句子构成的事态；单个词义指向对象，句义把对象组织成事态。
3. 图式化观相层：作品只提供对象呈现的「侧面」，如写一个人「脸色发白」，只给出一个视觉侧面，其余留空。
4. 再现客体层：由事态与观相共同构成的人物、事件、空间。
5. 形而上学质：悲剧性、崇高性、恐怖、神圣这类无法由前四层直接推导、却在具体化中显现的性质，英伽登视之为最高价值的承载者。

读者把未定点补实、把观相综合为完整对象，这一活动就是「具体化」（Konkretisation）：读「他走进房间」时补出房间的样子，看《拉奥孔》时把扭曲的躯干读成「极力忍耐」而非「嚎叫」。

这套结构要解释的悖论是：作品同一，读法多变。英伽登据此反对两个极端——把作品等同于某次阅读的心理内容，或等同于印刷符号的物理总和。最容易被追问的则是：具体化的自由有多大？他答以图式的「确定性轮廓」，具体化应与图式相容，却没给出判定相容性的程序。

### 第四步：一块大理石与一座雕像

落到造型艺术上，区别更清楚。大理石有重量、纹理、会风化；雕像有姿态、重心、表情。前者可测量，后者不能。同一块大理石可以被凿成完全不同的姿态，物理描述未变，作品却完全不同——这说明审美对象依赖形式组织，形式组织则依赖意图与观看。

更麻烦的是修复史。文艺复兴的修复者为这组像补过一条伸直的手臂，后来在原作残块上发现原臂是弯的，于是又换了回去。两次修复之间，物质载体几乎相同，审美对象却经历两次改写。雕像既不能还原为石头，也不能还原为观众的心理印象；它存在于材料、形式、意图、观看四者交织的关系里。

同样的结构见于音乐。乐谱给出指令，演奏是一次具体化：速度、音色、分句留有空间，而弹错音、改结构就不再是这部作品。古德曼在《艺术的语言》里称这类艺术为「多层记谱的」（allographic），认为同一性由记谱系统固定。这与英伽登不同：一个把同一性放在意向对象的图式上，一个放在记号系统的可识别性上；两者都拒绝把作品等同于某次物理事件。

### 第五步：姚斯与接受美学如何改造主客二分

姚斯的改造分三层。第一，概念工具：「期待视域」指读者进入作品时携带的、由先前阅读经验与文化知识构成的框架。第二，历史机制：新作与读者视域之间有三种关系——顺应（通俗作品）、打破（先锋作品）、颠覆（真正带来新经验者），作品价值部分取决于它如何改变视域。第三，审美经验的重新规定：创制（poiesis）、感受（aisthesis）、净化（catharsis），分别对应人把世界造成自己的作品、对感性显现的专注、被作品带出日常的震动。

要点在于，它把纵向的「主体—客体」换成横向的「作品—读者」，并让历史进入这个关系：意义在接受的链条上累积，后代读者能看见前代看不见的东西。这与伽达默尔的「视域融合」可以对应：理解发生在两个视域于事情本身上的交汇处；单方面投射与意图复原都不足以概括它。

代价同样明显。其一，约束从哪里来？伊瑟尔用「隐含读者」与「空白」给出较强约束：文本结构预设了某种阅读位置，空白引导填补的方向。其二，「视域」能否被客观重建？姚斯依赖对当时读者预期的史料重构，而这类重构往往只能近似。其三，接受史会不会把作品稀释为历代读法的总和？若是，作品就失去抵抗误读的力量。

### 第六步：主体间性：共识如何可能

若审美对象在关系中生成，普遍性就得另找根据。康德诉诸「共通感」：审美判断出自个人愉悦，却预设人人共有的感受能力，因此可以「要求」他人同意；这是先验假设，无法经验证实。哈贝马斯式方案把它移到交往层面：共识来自自由讨论中的相互理解。

两条路都有困难：共通感难解释系统性的趣味差异，交往共识难解释某些判断为何能跨越文化而稳定。社会学的解释（趣味是阶层区隔的标记）能说明差异来源，却难说明某些作品为何持续经受跨时代检验。**较为吻合**的处理是承认三层约束：对象的图式、传统的视域、共同体的争论程序。

## 五、经典原著

英伽登《文学的艺术作品》（1931）的核心问题是存在论的：文学作品存在于何处？回答分三步：其一，它既不属于物理事物，也不属于心理体验，只能被规定为「纯粹意向对象」，其存在依赖作者与读者的意向行为；其二，它由异质的多层结构组成，各层既有先后又有依存；其三，未定点是图式的本质特征，具体化是作品被现实化的必要环节，却不等于作品本身。

此处对全书论证只作转述，不引原文，因为中译本术语尚未统一（「图式化观相」另有译作「图式化外观」）。

黑格尔对艺术对象的独立性有一段说明，可用于对照近代主客框架的局限：

::: quote 《美学》第一卷，全书序论
艺术观照也不离开它所直接接触的对象，不去把对象作为普遍概念来理解，像科学那样
:::

这句话说的是：科学认识把个别事物转化为普遍概念，艺术观照则停留在对象的个体存在上。用本讲的话说，审美对象不能被概念替换，也不能被物理描述替换。黑格尔未必同意「对象由关系构成」，但他对「对象不能被还原」的坚持与英伽登方向一致。

## 六、艺术案例：《拉奥孔》与两种对象

《拉奥孔》群像 1506 年在罗马出土，高约两米，表现祭司拉奥孔与两个儿子被海蛇缠住的情形。三个人物构成上升的三角形：父亲体量最大、居于中轴，两个儿子分列两侧，身体向外倾斜，形成对抗中心的拉力；蛇身走出一条 S 形曲线，把三具身体串成螺旋；父亲头向后仰、胸部挺起、腹部收缩，紧张集中在躯干，四肢被蛇缚住。

当作「物理物」看，能得到的只是大理石的白度、晶粒与裂纹；当作「审美客体」看，得到的是极限痛苦中仍保持自持的形象。两种描述没有推导关系：从石的密度推不出「自持」，反之亦然。

更有意思的是表情的未定点。温克尔曼在 18 世纪的描述里，把这组像的表情读作「高贵的单纯与静穆的伟大」——痛苦被节制，呼喊被压回体内。莱辛在《拉奥孔》（1766）里反对把这个读法当作造型艺术的普遍法则，他认为雕刻之所以不表现张嘴嚎叫，与媒介的限制有关：造型艺术在空间中并列，一旦选定极端的瞬间就无法再推进，因此要选「最富于孕育性的顷刻」。同一件作品，两种读法，各自补出了不同的未定点。

这正是英伽登理论的经验对应：观相有限，具体化却必须发生，其方向受传统、媒介知识与时代趣味约束。把《拉奥孔》读成「嚎叫」并非不可能，只是与胸腔的挺起、口部的克制不相容，在争论中处于劣势。

:::

## 七、思想联系

向前看，它接在胡塞尔的意向性分析与狄尔泰的解释学之上；再往前，可以追到康德关于审美判断的普遍性要求。海德格尔把「对象」改写为「在世界之中的物」，梅洛-庞蒂把主体改写为「身体—主体」，两者都在拆解主客对置的硬壳。

向后看，它分化出三条路径：接受美学与读者反应批评（姚斯、伊瑟尔之后，费什把约束交给「阐释共同体」）；解释学美学（伽达默尔以「视域融合」取代主客对置）；关系美学（布尔里奥在 1990 年代把「关系」从观赏推展到社会交往）。三条路径共享一个赌注：关系比实体更基本。

## 八、本节总结

::: key 本讲要点
- 主客二分是近代认识论的产物，它把审美安置在主体判断里，代价是对象的存在被削弱。
- 审美客体依赖物理物却不等于物理物：换掉大理石的手臂角度，材料未变，作品已变。
- 英伽登以四层结构加未定点解释「同一作品、多种具体化」，古德曼则以记谱系统固定同一性。
- 姚斯把纵向的主客关系换成横向的作品—读者关系，并让意义在接受的链条中累积。
- 关系论的最大难题是约束：若对象由关系构成，误读与正确的界限从何而来。
:::

值得追问的问题：若审美对象在关系中被构成，一件从未被任何人观看的作品还算不算作品？这个问题把我们带到第 8 讲：艺术的存在是否依赖一个公共的艺术界。
