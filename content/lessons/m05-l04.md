## 一、本节导入

看两把椅子。第一把是餐椅：坐面高度、靠背角度、四条腿的落地方式，都为「坐」服务。你说它「设计得好」，这个判断有明确依据：坐久了不累，起身方便，结构稳。第二把是一把明式圈椅，摆在美术馆的展厅里，谁也不去坐它。你说它「美」，可你说不出它服务于什么：它的弧度不为舒适，它的比例不为承重，它的榫卯被藏在内部，看不见。

第一把椅子的好，可以用目的来解释。第二把椅子的美，似乎也有某种「合目的」的味道：每一处曲线都恰到好处，像是为某种眼光而存在。然而那个「目的」找不到。康德把这种状态称为「无目的的合目的性」：形式显得有安排，安排却不为任何确定的目的。

这个说法听起来像文字游戏，其实是第三契机的全部要点。它要回答：如果审美判断不依赖概念与利害，它凭什么还有规则性？完全没有规则，美退化为个人口味；规则太明确，美又变成认识。康德的答案是：规则性在形式里，目的却不在。

## 二、核心知识：合目的性、自由美、范例必然

::: def 目的（Zweck）
一个概念，它被视为对象之所以如此的原因。说某物有目的，等于说它的存在或形态可以由一个先行概念来解释。
例子：钟表的目的在钟表匠心里，齿轮的咬合由「报时」这个概念规定。
:::

::: def 无目的的合目的性（Zweckmäßigkeit ohne Zweck）
对象的形式显得仿佛为我们的认识能力而设，各部分互相支持、彼此呼应，但我们指不出任何确定的目的。这种「仿佛有目的、却无目的」的结构，就是审美判断的第三契机。
例子：一片枫叶的裂片与叶脉，看起来处处「合理」，你却不能说它为了什么；一块被海水磨圆的石头，形状像是被安排过，实际上只是偶然。
:::

::: def 自由美（pulchritudo vaga）
不以「对象应当是什么」的概念为前提的美。对象的形态不受任何目的概念的约束，鉴赏因此最纯粹。
例子：花、鹦鹉与蜂鸟的羽毛、贝壳、无标题的音乐、糊墙纸的花纹、arabesque 式的装饰线条。康德把这些列为自由美的典型。
:::

::: def 依附美（pulchritudo adhaerens）
以「对象应当是什么」的概念为前提的美。我们先把对象归入一个类，再评判它是否把这个类的理念表现得美。
例子：一座教堂、一座宫殿、一匹马、一个人。说「这是一座美的教堂」，先要有「教堂应当是什么」的概念，美依附于这个概念。
:::

还有第四个概念，留到理论解析一节展开。这里先给一个简短的定位：范例的必然性指审美判断所要求的那种必然性——它不像逻辑必然那样可以证明，也不像道德必然那样可以命令，它是一个「例子」所携带的应当。

## 三、代表人物：康德

康德（Immanuel Kant，1724—1804）处理第三、第四契机时，面对的是自己制造的难题。前两个契机已把审美判断规定为无利害、无概念却普遍；剩下的问题是：它有没有客观的「根据」？若无，如何区别于偏好？若有，这根据又不能是概念。

他的解决办法是双层的。在关系层面，他用「合目的性」给形式一个准客观的结构：形式仿佛有安排，因此可以讨论；但安排没有目的，因此不落入认识。在模态层面，他用「范例」给普遍性一个准规范的形态：判断是个别的，却作为例子要求同意；要求不能证明，因此不落入逻辑。

这两个动作都有一个共同点：把「客观性」换成「可传达性」。美不写在对象上，也不写在概念里，它写在人与人可以共享的感受里。这个转换是康德美学的核心操作，也是它最容易被批评的地方：可传达性究竟是一种弱化的客观性，还是一种被美化的共识？

康德对第三契机的表述比前两个谨慎。他承认「合目的性」只是「调节性的」说法，不能当作对象的属性。这使理论免于独断，也留下一个空洞：形式的「仿佛」由谁判定？答案只能是鉴赏者，而鉴赏者的资格又需要文化来保证。

## 四、理论解析：从形式到必然

**第三契机有两层，必须分开。**

第一层是「主观的形式合目的性」。对象的表象形式让想象力与知性进入自由游戏，这种和谐是自发的，不受概念强制。我们感到这形式「适合」认识能力，仿佛它是为这种和谐准备的。两个限定要抓住：主观，指它不涉及对象自身的目的；形式，指它只关乎诸要素的排列，不关乎质料的感觉。

第二层是那个著名表述：美是对象的合目的性形式，在它不具有目的的表象时被知觉到。逐词看：合目的性形式，说的是部分与整体的呼应；不具有目的的表象，说的是没有「它为了什么」的概念；被知觉到，说的是这层结构在直观中被感到，而非被推论出来。三个限定合起来，把美锁在「直观中的秩序感」这个狭窄地带。

这个表述为什么能避免相对主义？因为它把美的根据放在认识能力的和谐上，而认识能力人人都有。你觉得这朵花美，我觉得不美，我们争的是「这朵花是否让我们的能力进入和谐」，与「花有没有某种属性」无关。前者无法查证，只能通过反复观看、比较、讨论来调整。康德的乐观在于，他相信这种调整最终会趋同。

这个表述为什么又显得单薄？因为它把质料的部分排除了。颜色与声音的刺激被归入「魅力」，情感与意义的投入被归入「激动」，纯粹鉴赏只剩下形式关系。剥离在分析上很干净，在经验上很勉强：看一幅画时，很难把「这个红」从「这个形状」里剥出来。

**自由美与依附美。** 这个区分是康德的出路。他承认大部分现实的美都依附于概念：教堂、宫殿、人、马。对这些对象的判断，先要有「它应当是什么」的概念，再评判它是否把这个概念表现得美。只有少数对象能脱离概念，成为自由美：花、鸟羽、贝壳、无标题音乐、装饰花纹。

区分的后果有三。第一，美的分析论以自由美为范例，因为只有它能展示纯粹性；依附美是「应用」的部分。第二，依附美引入比较标准：同一概念下，哪个对象表现得更美。第三，最重要的后果是「美的理想」：理想需要一个「应当」的概念，而只有人自身是目的，因此只有人的形体可以承载美的理想。康德说，理想在于道德的表现（大意）。这句话把美学与伦理学接上线，也把人以外的存在排除在「理想」之外。

**第四契机：范例的必然性。** 鉴赏判断要求同意，这个要求带有必然性，但它既非逻辑的必然（无概念可推），也非道德的必然（无义务可循）。康德称之为「范例的必然性」：判断被看作一条无法陈述的普遍规则的一个例子。人们应当同意，因为这个判断本身就是「应当如何判断」的样本。

困难很明显。若规则无法陈述，我们凭什么说这个例子是规则的例子？康德的回答是共通感。于是第四契机的重量又压回第二契机，四个契机的论证有了循环的味道。

| 契机 | 着眼点 | 规定 | 关键词 |
|---|---|---|---|
| 质 | 愉悦的类型 | 无利害的愉悦 | 不关涉实存 |
| 量 | 普遍性的类型 | 无概念的普遍性 | 要求同意 |
| 关系 | 形式的结构 | 无目的的合目的性 | 仿佛有安排 |
| 模态 | 必然性的类型 | 范例的必然性 | 应当同意，无法证明 |

**四者能否拼成一个定义。** 把四个契机合起来，大致可以说：美是一个对象的无目的的合目的性形式，被普遍而必然地喜爱。四个契机的关键词都装了进去，代价是这定义几乎是否定式的：无利害、无概念、无目的、无法证明。四个「无」叠加，说明美被规定为一系列排除之后剩下的东西。

这不一定坏。否定式的定义有时比肯定式精确：它告诉我们美不在哪里，避免把美误当成属性、概念或道德。但它也留下一个问题：剩下的「剩余」究竟是什么？康德的回答是「自由游戏的和谐」，这个回答更像名字。

::: warn 自由美比依附美更高级
一种常见读法是：自由美是纯粹的美，依附美是次一等的美，所以抽象艺术高于具象艺术。康德没有这样说。他区分两者是为了分析的方便：自由美让纯粹性显露出来，依附美才是生活里更常见、内容更丰富的美。他举例时把人、马、教堂放在依附美里。把「纯粹」读成「高级」，是十九世纪形式主义的追加，算不得康德的原文。
:::

## 五、经典原著：第三契机与「美的理想」

《判断力批判》的「美的分析论」在讲完质与量之后，转入关系与模态。关系部分的篇幅最长，因为它要处理「合目的性」这个容易被误解的概念；其中还插入了「美的理想」一节，专门讨论人类形体为何是唯一能承载理想的对象。模态部分相对简短，却承担了把鉴赏判断与「应当」连接起来的工作。

原著的结构有一个特点：先给否定的规定（无目的），再给肯定的说明（形式的合目的性），最后用「理想」收拢两者。这个顺序说明康德知道「无目的」不足以支撑美：若只有无目的，美就成了偶然。

::: quote 《判断力批判》美的分析论第三契机（大意，据通行中译）
美是对象的合目的性形式，在它不具有目的的表象时被知觉到。
:::

每个限定都在防一种误读：「形式的」防质料的魅力，「不具有目的的表象」防功用与概念，「被知觉到」防推论与证明。三道防线围出一个小区域，康德把美放在里面。

模态部分的表述更简：美被认作一种必然愉悦的对象，而这必然性是范例性的。这句话几乎不可转述得更通俗，因为它说的正是「不可转述」：判断的力量来自例子本身，任何说明都会把它变成概念。

## 六、艺术案例：蒙德里安《百老汇布吉伍吉》

一九四二年至一九四三年，蒙德里安在纽约完成了这幅一百二十七厘米见方的画。画面由黄色、红色、蓝色、灰色与白色的矩形组成，色块之间用细窄的灰线分隔，黑线消失了。小色块像音符一样散布在大色块之间，眼睛从一个方块跳到另一个方块，停不下来。

形式上最值得注意的是「无中心」。画面没有透视焦点，没有主次，任何一块都可以是入口；但整体又不散，因为色块的大小、饱和度、位置互相制衡。这种结构常被形容为「动态的平衡」：静止的方格里有速度。

用第三契机看，这幅画近乎自由美的极限案例。它不描绘任何对象，没有「应当是什么」的概念，愉悦来自比例、节奏、色彩的重量。你可以说它「像」曼哈顿的街道网格，像爵士乐的切分；但「像」算不上它的目的。

麻烦出现在标题上。「百老汇」与「布吉伍吉」是两个概念：一个地名，一种音乐。标题把画拉回到依附美：它关于城市，关于节奏，关于一种听与看的通感。于是同一个对象，在两种描述下属于两个不同的类别。这说明自由美与依附美的界线，部分由我们如何描述作品决定，而不完全由对象决定。

::: fig a-broadway-boogie-woogie | 《百老汇布吉伍吉》：色块无中心地散布，灰线分隔，整体靠大小与饱和度的互相制衡维持平衡
:::


## 七、思想联系

向前追溯，「合目的性」来自亚里士多德的目的因，也与鲍姆嘉通的「完善」有亲缘。完善是一个目的论概念：事物实现了它应当是的样子，就是完善的。康德的「依附美」保留了这层意思，却把它降为美的一种，而非美的定义。美的理想更是直接继承了古典主义的「理想美」传统，只是把它的根据从宇宙秩序换成了人的道德使命。

向后看，席勒把「形式冲动」与「活的形体」接过来，让合目的性变成教养问题；谢林与黑格尔把合目的性重新本体化，美于是又有了客观内容；二十世纪的形式主义（贝尔的「有意味的形式」、弗莱的后印象派辩护）把「无目的的合目的性」推到极端，只看形式关系，不问内容。反形式主义则指出，这种纯粹化本身是一种历史态度。

## 八、本节总结

::: key 本讲要点
- 无目的的合目的性指形式显得有安排，却不服务于任何确定目的；它是第三契机的核心。
- 合目的性有两个层次：主观形式的合目的性，与「不具有目的的表象」这一限定。
- 自由美不以概念为前提，依附美以「应当是什么」为前提；美的理想只适用于人。
- 范例的必然性是一种「应当同意」的必然性，无法证明，只能以例子承担规则。
- 四个契机能否拼成一个定义仍有争议：它给出四个「无」，剩下的「剩余」难以正面说明。
:::

本讲留下的最大问题，是「纯粹」与「丰富」的张力。康德为了论证的干净，把质料、情感、概念一层层剥掉；剩下的形式关系可以被普遍传达，却已经很薄。后面的德国美学几乎都在想办法把它填厚：席勒填进生命，谢林填进自然，黑格尔填进历史。

值得继续追问的问题：如果「自由美」只是一小撮对象，那么康德的美学是否从根本上是一种例外状态的理论？当代艺术大量依赖概念与语境，它还能不能用「无目的的合目的性」来解释，还是说我们必须承认这套框架已经到期？
