## 一、本节导入

1913 年，康定斯基画出一幅近三米宽的大画，题名朴实得近乎冷漠：《构成第七号》。画面上没有可辨认的物象——没有人物、风景或静物，只有一道自左上到右下的对角线动势，中央一团浓黑的块面，四周环绕弧形色带与锐角三角形。三十年后，蒙德里安在纽约完成《百老汇爵士乐》，用黄、蓝、红的小矩形拼成一张跳动的网格。

普通观众面对这两幅画，最常见的疑问是：这到底「画了什么」？而本讲要处理的，正是这个疑问背后的美学问题：当绘画把一切再现对象都交出去之后，它还剩什么可以成为艺术？对这个问题的两种回答——康定斯基的「内在精神性」与蒙德里安的「普遍秩序」——构成了抽象艺术的两条路线；而格林伯格后来把它们一并收进一个「媒介纯粹性」的历史叙事里，说这是绘画走向自身逻辑的必然。这个叙事极具说服力，也遮蔽了大量历史偶然，本讲要一并讲清楚。

## 二、核心知识：抽象与媒介纯粹性

先定义本讲两个核心概念。

::: def 抽象（abstraction）
在视觉艺术中，指放弃对可见世界的再现，让形式（线、色、形）独立成为作品内容的做法。抽象可以是从对象中「提炼」（把一匹马简化为几条曲线），也可以是彻底的「无对象」（画面不指向任何外物）。例子：蒙德里安把一棵树逐年简化，最后只剩下横竖线组成的格子。
:::

::: def 媒介纯粹性（medium specificity）
指每一门艺术应当探索、并忠实于它自身媒介独有的性质，而非借用其他艺术的手段。格林伯格用它来主张：绘画的本质是平面性（flatness），所以现代绘画应拒绝文学的叙事与雕塑的立体幻觉，回到平面本身。例子：一幅画若追求戏剧式的情节，就被视为侵入了文学的地盘。
:::

这两个概念分别对应抽象艺术的两条路线：康定斯基走「精神性」一途，蒙德里安走「普遍秩序」一途，格林伯格则为它们补上一条共同的「历史必然」叙事。为看清三者的关系，先看一张对照表，后面再展开：

| 维度 | 康定斯基 | 蒙德里安 |
|------|---------|---------|
| 精神目标 | 内在必然性、精神的振动 | 普遍的宇宙秩序与均衡 |
| 形式手段 | 色彩与形式的通感、音乐类比、对角线动势 | 水平—垂直线、三原色加无彩色 |
| 类比艺术 | 音乐 | 数、建筑 |
| 关键词 | 内在音响（innere Klang） | 新造型主义 |

这张表先给出骨架，下面各段逐一填上血肉。

## 三、代表人物：康定斯基、蒙德里安与格林伯格

瓦西里·康定斯基（Wassily Kandinsky，1866—1944）生于莫斯科，三十岁前学的是法律与经济，后放弃教职改学绘画。他的转折点常被描述为一次「发现」：在自己的画室里，一幅倒放的作品让他认不出对象，却仍被其色彩打动。这一经历让他确信：去掉物象之后，色彩与形式仍能直接作用于灵魂。他后来到德国，与弗朗茨·马尔克等人发起「青骑士」团体，又在包豪斯任教，是把抽象理论化并系统教学的第一代人。

皮特·蒙德里安（Piet Mondrian，1872—1944）走的是另一条路。他早年画具象风景，经过多年「减法」，把一棵树、一片海逐渐简化为横线与竖线。他信奉一套近乎宗教式的信念：世界的表面充满偶然与个别，而艺术应当揭示底层的普遍秩序。为此他发展出「新造型主义」，主张只用水平—垂直线、三原色与无彩色。二战爆发后他移居纽约，晚年的《百老汇爵士乐》在这一严格语法里引入了节奏与都市经验。

克莱门特·格林伯格（Clement Greenberg，1909—1994）则是美国最重要的形式主义批评家。他不画画，只写批评，却给整个抽象运动配了一套最有影响力的历史解释。他的贡献与局限都在于：把塞尚、立体主义、抽象一路的发展，写成一条「绘画逐步纯化自身媒介」的单线必然史。这套叙事在 1940—1960 年代几乎垄断了美国的艺术评价标准，也在此后被反复挑战。

## 四、理论解析：两条路线与一套历史叙事

先看康定斯基的「内在精神性」。他在《论艺术中的精神》（1911—1912 年间完成并出版）里主张：艺术与物象的相似度无关，它应当表达「内在必然性」——一种来自艺术家灵魂深处、必须如此而非别样的冲动。他借音乐作类比：音乐从不模仿鸟叫，却能让听者直接感动，绘画也应当如此，让色彩与形式像音符一样直接振动心灵。他特别强调「通感」：黄色在他看来近乎刺耳的高音，蓝色则像向深处退去，不同的色与形各有其「内在音响」。

再看蒙德里安的「新造型主义」。他的逻辑更接近一种宇宙论：自然界的个别形状都是偶然的，唯有水平与垂直这两种最根本的方向、三原色这三种最根本的色彩、以及黑白灰这些无彩色，才配表达「普遍」。于是他的画面只保留这些元素，追求一种均衡的、无中心的结构——观者找不到一个焦点，也找不到一处情绪的高潮，只剩秩序本身。

::: def 内在音响（innere Klang）
康定斯基用来指称色彩与形式本身具有的、类似音乐音色的直接情感效果。例子：同一个三角形，涂成黄色与涂成深蓝，传达的「声响」不同——黄色明亮尖锐，深蓝沉静幽远。
:::

格林伯格则把这两条路线并进一个更宏大的叙事。他的论证大致分两步：第一步，《走向更新的拉奥孔》（1940）借莱辛的标题，主张各门艺术应当各守其媒介边界，绘画若依赖文学叙事或雕塑体积，就是在借用不属于它的力量；第二步，《现代主义绘画》（1960）把这一主张历史化，认为现代主义绘画的本质，就是不断发现并坦承绘画自身的「平面性」，从马奈开始，经塞尚、立体主义到抽象，是一条一步步抛弃再现、走向平面的必然之路。此处均为转述。

::: warn 常见误解
把格林伯格的「平面性」理解为「绘画只能画平的东西、不能有任何深度暗示」，是一种简化。格林伯格承认画面仍可有空间暗示，只是主张现代绘画应把「平面」这一根本条件当作自觉的主题来处理，而非假装画布不存在。
:::

这套叙事的反对意见同样有力，必须如实呈现。其一，罗森伯格（Harold Rosenberg）在《美国行动画家》（1952）里提出「行动绘画」，认为波洛克等人的价值不在画布上的形式结果，而在创作过程中的行动与姿态——这等于说格林伯格盯错了对象。其二，后来的后现代批评指出，格林伯格把现代主义写成「朝向平面性」的单线史，是一种目的论的历史观：它把大量并存的、非纯抽象的实验（达达、超现实主义、具象绘画）都贬为支流或倒退。其三，这套标准对非西方艺术传统缺乏解释力，也难以容纳那些不追求「纯化媒介」的实践。这些批评多为研究者与后起的理论家的转述与概括，非格林伯格本人的原话。

## 五、经典原著：三份文本的分寸

本讲涉及三份关键文本，均作转述处理。

康定斯基《论艺术中的精神》的核心命题是：艺术是精神性的，形式与色彩各自拥有直接打动人心的力量，画家应当服从「内在必然性」，物象只是可放弃的外壳。这里不逐字引原文，只转述其大意：一幅画的价值，不取决于它是否画得像某个东西，而取决于它的色彩与形式能否唤起观者内在的共振。

格林伯格《现代主义绘画》的大意是：现代主义绘画通过自我批判，逐步放弃与文学、雕塑共享的效果，退回到绘画独有的平面性之上；这种自我界定使绘画更纯粹，也使它的领域更明确。此处同样只作转述。

::: quote 康定斯基《论艺术中的精神》（转述）
康定斯基在此处的大意是：色彩与形式各自拥有内在的音响，能不经由物象而直接振动人的灵魂；画家的任务是服从这种内在必然性。
:::

三份文本合起来，回答了本讲开头的问题：没有物象之后，绘画靠什么成立？康定斯基的回答是「内在音响」，蒙德里安的回答是「普遍秩序」，格林伯格则补上一句「这是绘画的历史归宿」。

## 六、艺术案例：两件作品的对照细读

先看康定斯基《构成第七号》（1913，布面油画，200 × 300 厘米，藏莫斯科特列季亚科夫画廊）。看**动势**：一条自左上到右下的对角线贯穿全幅，视线被反复甩出画外，画面没有一个可以安放的焦点。看**重音**：中央一团浓黑块面压住全幅，像交响乐里的低音持续，周围环绕弧形色带与锐角三角形，形成对抗性的力的场。看**色彩**：红、黄、蓝与深紫黑并置，色块半透明叠加，边界时而渗化、时而硬切。看**线条**：细线、粗线、弧线与直线各自成层，与色块并不完全重合——这正对应康定斯基所谓「整体音响」：不同元素像不同乐器同时发声，彼此独立又互相激荡。

再看蒙德里安《百老汇爵士乐》（1942—1943，布面油画，127 × 127 厘米，藏纽约现代艺术博物馆）。看**网格**：近正方形的画幅由黄、蓝、红的小矩形与灰白、黑的细条交织成网格。看**线的变化**：黑线不再贯通全幅，而被切成短段，成为色块的边界而非框架——这与他早年整条黑线的做法判然有别。看**节奏**：色块大小不一、明度跳跃，形成类似切分音的节奏，故以「布吉伍吉」为名。看**纯粹性**：三原色与灰白并置，无渐变、无笔触，颜料平涂，密集的横竖短线使画面持续「振动」，视线无法停留于一点。

::: fig a-composition-vii | 《构成第七号》对角线动势、中央浓黑重音与环绕的弧形色带，形成对抗性的力的场
:::

两件作品对照，恰好显示两条路线的差异：康定斯基求的是「精神的振动」，画面充满动势与冲突；蒙德里安求的是「普遍的均衡」，画面冷静、克制、近乎数学。而它们共同支撑了格林伯格的一个观察：抽象绘画的价值，集中在画面自身的组织，而非任何外物。

## 七、思想联系：从莱辛到后现代的反驳

向前追溯，格林伯格《走向更新的拉奥孔》的标题本身就在回望莱辛 1766 年的《拉奥孔》（参见第九模块第一讲）：莱辛当年主张诗与画各守媒介边界，格林伯格把这套「媒介特殊论」从诗画之分推广到一切艺术，并给它装上「现代主义」的历史引擎。

向后看，格林伯格的叙事直接塑造了 1940—1960 年代美国抽象表现主义与色域绘画的评价标准，波洛克、纽曼、罗斯科都在这一框架下被阐释；它也经由形式主义，与更早的贝尔、弗莱一脉相承（参见第七模块第三讲）。但它的代价同样清晰：当「平面性」成为唯一合法的方向，那些不纯化媒介、不追求抽象的实践便被边缘化，后现代艺术（拼贴、装置、观念艺术）恰恰从这些被压制的支流里生长出来，反过来拆解了格林伯格的单线史。用前面模块的术语说，这是「宏大叙事」（metanarrative）在艺术史内部的一次自我暴露：一个讲得越通顺的故事，往往省略得越多。

## 八、本节总结

::: key 本讲要点
- 抽象放弃物象后，靠两条路线成立：康定斯基的「内在精神性」与蒙德里安的「普遍秩序」。
- 康定斯基借音乐与通感，主张色彩与形式拥有直接振动心灵的「内在音响」。
- 蒙德里安的新造型主义只用水平—垂直线、三原色与无彩色，追求均衡的普遍结构。
- 格林伯格以「媒介纯粹性」把抽象写成绘画回归平面性的历史必然，其叙事既有解释力，也带有目的论色彩。
- 罗森伯格、后现代批评对这套叙事提出反驳，指出它排斥了非纯抽象、非西方与反叙事的实践。
:::

- 抽象艺术有两条路线：康定斯基的「内在精神性」与蒙德里安的「普遍秩序」，前者求振动、后者求均衡。
- 康定斯基以音乐类比与通感，赋予色彩与形式独立的「内在音响」。
- 蒙德里安的新造型主义只用水平—垂直线、三原色与无彩色，追求无焦点的普遍结构。
- 格林伯格以「媒介纯粹性」把抽象解释为绘画回归平面性的历史必然，构成一套极具影响力的单线叙事。
- 这套叙事被批评为目的论的历史观，其对非西方、非纯抽象实践的排斥是其主要盲点。

值得继续追问的问题：如果抽象绘画的价值全在「形式自身」，那么面对《百老汇爵士乐》，一个完全不知道爵士乐为何物的人，与一个熟悉纽约都市节奏的人，看到的是不是同一幅画？这个追问，指向形式主义最薄弱的环节——它能否完全排除作品与历史经验的关系。
