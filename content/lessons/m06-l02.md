## 一、本节导入

1818 年底，一本厚书在莱比锡出版，扉页上印着 1819 年。1820 年他在柏林大学开课，特意把时间排在与黑格尔同一钟点，结果听众寥寥，课最后停开。这本书的第一句是「世界是我的表象」。二十五年后他加写了第二卷，三十多年后，一本随笔集让他突然出名。

这个失败与这个开头有关。「世界是我的表象」听起来像认识论的谦虚：我们只能认识呈现给我们的东西。但叔本华（Arthur Schopenhauer，1788—1860）要说的比这更狠：表象只是表面，表面之下是一种没有目的、没有尽头的欲求，他称之为意志。人以为自己在追求这个那个，其实是被一个自己看不见的东西推着走。若真如此，审美经验就成了唯一的例外：在听一首曲子或看一幅画的那几十分钟里，欲求停下了。

本讲要问的是，这个例外凭什么成立，又为什么只能维持那么短。

## 二、核心知识：四个概念

::: def 意志（Wille）
叔本华形而上学的核心：世界的物自体，一种盲目的、无尽的、无目的的欲求。它不在时间、空间与因果之中，因此不能被个体化，也不能被认识穷尽。
例子：饥饿不是「我想要食物」这个想法，身体本身就是意志的客体化；性欲是意志最直接的显现，因为个体在此为延续种类服务。
:::

::: def 表象（Vorstellung）
对某个主体而言的客体。它受根据律支配，形式是时空与因果，因此只能给出关系，不能给出本质。
例子：我看见窗外这棵树，树的位置、大小、颜色都由我的直观形式构成；树的「树性」不属于表象。
:::

::: def 理念（Idee）
意志客体化的各个级别，是意志与个别事物之间的中介。注意它取的是柏拉图义，而非黑格尔义：非历史的、非自我展开的、静止的模型。
例子：所有的马都分有「马」这个理念，个别马匹的生老病死不改变理念；画家要画的正是这个理念，而非这匹具体的马。
:::

::: def 审美观照（ästhetische Kontemplation）
认识摆脱为意志服务的状态，主体不再是个体，而成为「纯粹认识主体」；客体不再是被追问用途的东西，而成为理念。
例子：站在一幅画前忘记时间、忘记自己刚丢了钱包，出来时天已黑——这段时间里，认识不再替欲求办事。
:::

叔本华把各门艺术按「所呈现的理念层级」排成一个序列。这个序列很有意思，因为它把音乐单独拎了出来。

| 艺术 | 呈现的对象 | 在意志客体化中的位置 |
|---|---|---|
| 建筑 | 重力、支撑、材料抗力 | 最低：无机界的力 |
| 园林与风景画 | 植物的生长与自然景象 | 较低：植物界 |
| 动物画与雕塑 | 动物的生命与性格 | 中等：动物界 |
| 人物画与雕塑 | 人的形体与精神 | 较高：人 |
| 诗，尤其悲剧 | 人的欲求、冲突与命运 | 最高：人的意志的完整展开 |
| 音乐 | 意志本身 | 不在序列中：跳过理念 |

序列的前五项都遵循同一条规则：艺术呈现理念，观者通过理念摆脱个体性。音乐不遵守这条规则，它是意志的直接写照。这个例外既是全书最精彩的一页，也是体系最脆弱的地方。

## 三、代表人物

叔本华生于但泽一个商人家庭，父亲 1805 年去世，母亲约翰娜是当时颇受欢迎的小说家，家里常有歌德出入。他先学医，后转哲学，1813 年的博士论文《论充足理由律的四重根》已经确立了后来的问题框架：一切认识都按某种「为什么」的形式运作。1814 至 1818 年在德累斯顿写成《作为意志和表象的世界》，自称受了康德、柏拉图与印度《奥义书》三重影响。1820 年起在柏林任教，与黑格尔的竞争以失败告终；1831 年柏林霍乱流行，他迁往法兰克福，独居终老。1851 年的《附录与补遗》让他晚年成名。

他对美学的贡献在于把审美从「愉快的情感」改写成「认识的一种特殊状态」，并给了它一个救赎论的位置。代价是他必须说明这种状态如何可能——而这正是他体系中难以闭合的一环。

## 四、理论解析：从表象到意志，再回到表象

**先说它为什么要出现。** 康德留下一个缺口：物自体不可知。他的《判断力批判》又把审美愉悦规定为无利害而普遍，却不解释这种愉悦凭什么有如此地位。叔本华要补上物自体的内容，并给审美一个形而上学的理由。他还带着对抗性的目标——莱布尼茨说这是「最好的世界」，他反过来说，世界是一切可能世界中最坏的，因为它的本质是永不满足的欲求。

**补缺口的办法是身体。** 我有一个身体，它同时以两种方式被给予：从外面看，它是表象，受因果支配；从里面看，它就是我的意愿活动本身。叔本华强调，「意愿」与「身体的动作」并非两件事，它们是同一件事的两种给予方式。这是全书最关键的一步，因为它是唯一一条「从内部」把握物自体的通道。

**论证可以拆成六步。**

第一步，确立起点：世界是我的表象，受根据律支配。认识只能给出关系。

第二步，确立通道：身体的双重给予，使我能够从内部把握那个不是表象的东西。

第三步，类比推广：重力、磁力、结晶、植物的向光、动物的本能，都被解释为同一个意志的客体化。这一步靠类比，是最弱的一步——说重力「渴望」下落，已经把人的欲求投射到无生命物上。

第四步，意志客体化有级别，这些级别就是理念；个别事物只是理念的摹本，理念才是艺术的真正对象。

第五步，认识平时服务于意志：我们看东西总在问「这对我有什么用」。但在审美中，认识可以「脱轨」，不再服务，主体成为纯粹认识主体。

第六步，由此产生快感。这种快感源于欲求的暂停，其中没有满足的成分。美就是「意志在观照中暂息」的那种状态。

第六步是叔本华的独创，也是他最容易被误解的地方。审美的愉悦来自「不再被要求什么」，与「得到了什么」无关。

**审美观照有两个条件。** 主体侧要忘记自己的个体、利害与时间；客体侧要不从根据律看它，不问因果与用途。这两侧是同一事件的两面，没有先后：主体越纯粹，客体越呈现为理念。

**优美与崇高由此分化。** 优美是对象「邀请」我们进入观照，意志不抵抗，美自动呈现。崇高是对象威胁意志：风暴、荒漠、巨量。观照在此需要克服抵抗；克服成功时，愉悦带有提升感，因为人意识到自己作为纯粹认识主体可以不被意志支配。用一句话概括，崇高就是「意志的威胁被认识所克服」。

这与康德的结构相当接近，结论却相反。康德在崇高里看到的是理性对感性的优越，最终通向道德；叔本华看到的是认识对意志的摆脱，最终通向审美的禁欲。康德区分数学的崇高与力学的崇高，叔本华把它们改写成「量的压迫」与「力的威胁」。我倾向于认为，这种改写相当有解释力，但它悄悄换掉了康德的赌注：从「人是道德的存在」换成「人可以暂时不做欲求的存在」。

**音乐是体系的例外。** 叔本华说音乐不复制理念，而直接复制意志本身。其一，音乐不通过形象，因此不与任何确定的理念对应：它从不表达「这个或那个快乐」，只表达「快乐本身」。其二，音乐的结构与意志的层级有对应：和声的低音对应无机界，中间声部对应植物与动物，旋律对应人的欲求生活，旋律的进行就是欲求的起伏、延迟与满足。

这个论证很漂亮，代价也很大。如果一切艺术都通过理念起作用，音乐就成了唯一不通过理念的艺术，全书的总纲在此破例。他把音乐的地位抬到最高，却无法用同一套理论解释它为什么最高。

::: warn 「审美解脱」等于「摆脱了意志」
这个说法只对了一半。审美中止的是意志的「活动」，而非意志本身。出了音乐厅，饥饿、账单、野心照旧回来，而且往往更清楚。叔本华用「安息日」作比：一周里的一天，不等于取消了工作周。真正否定意志的是第四篇的禁欲，那是另一条路。
:::

**审美与禁欲的差别必须分清。** 审美是暂时的、被动的、依赖对象在场的：它需要一件作品、一段时间、一种禀赋。禁欲是永久的、主动的、不依赖对象的：通过绝食、独身、忍受痛苦，逐步熄灭欲求，最终达到他所谓的「清静无为」。前者是「忘记意志」，后者是「否定意志」。叔本华把前者当作后者的「预告」：审美让人看见不痛苦是可能的，禁欲则把这种可能变成生活方式。

这也解释了他为什么说审美只是「短暂的安息日」。观照一结束，个体立刻落回根据律，重新成为欲求的容器。而且观照本身需要「天才」——他把它定义为认识能力的过剩，一种可以暂时脱离服务关系的多余力量。于是审美的普遍性打了折扣：能进去的人不多，能久留的人没有。

**最强困难是一个循环。** 前提说，一切认识都由意志驱动，认识是意志的工具，为生存服务。结论说，审美认识是无意志的认识。那么，工具如何能脱离主人？

叔本华的答案是：认识可以反叛它的起源。他用「雇工逃跑」式的说法描述这种反转，又把希望寄托在天才的过剩与某种「恩典」上。这个答案的问题在于，它把一个结构性问题转成了特权问题：理论说明的落脚点落到了「少数人的禀赋」上，「认识的本性」反倒没被说明。

第二个困难更尖锐：纯粹认识主体是谁？个体性是表象的形式，而纯粹认识主体恰恰要摆脱个体性，它不能是「我」。于是审美主体成了一个无人的位置，这与他关于意志同一性的学说不协调。

第三个困难在价值论。审美被描述为「意志的寂静」，而寂静是否定性的，很难说明为什么某件作品比另一件更好。他实际给出的标准是「理念呈现的清晰度」，这又是认识论的：需要一个肯定性的尺度，手上只有一个否定性的形而上学。

**最强反对意见有三条。** 尼采说，审美应当理解为意志的增强与充盈，寂灭只是虚弱者的读法——这一条下一讲展开。逻辑经验主义者会说，「意志」作为物自体不可证实，把人的欲求放大成宇宙本原只是拟人化投射。阿多诺则会指出，「无利害的观照」把艺术描述成没有冲突的和谐，抹掉了艺术与社会之间的张力。

我的判断是：叔本华对审美经验的现象描述相当准确——被音乐带走、忘记自己，这类经验确实存在；但他把这种经验升格为「通往物自体的通道」，这一步缺乏独立支撑。音乐一章的力量，恰恰来自它溢出了体系。

## 五、经典原著：《作为意志和表象的世界》

此书 1818 年完成，1819 年出版，1844 年出第二版，增加了第二卷的补充章节。全书分四篇：第一篇讨论作为表象的世界与根据律，第二篇讨论作为意志的世界，第三篇讨论表象的第二种考察方式——独立于根据律的理念，第四篇讨论伦理与意志的否定。附录是对康德哲学的批评。

第三篇是全书写得最饱满的部分，也是本讲的主线。它的推进顺序很清楚：先规定一种不服从根据律的认识如何可能，再引出理念，再描述观照中的主体状态，再讨论天才，再按层级遍历各门艺术，最后以音乐收尾。这个顺序本身就是一个论证：审美的可能性依赖于认识可以从服务关系中松开，而各门艺术的差别只在于所呈现的理念层级。

::: quote 《作为意志和表象的世界》，开篇
世界是我的表象。
:::

这七个字是全书第一句，也是他唯一不加论证就提出的命题。它的作用是把哲学的地基从「事物」移到「关系」：一切被给予的东西都已经是「对某个主体而言」的东西。承认这一点，康德的物自体问题就不可避免；而叔本华的下一步，是把物自体填成意志。

::: note 「理念」的两个意思
读这一讲要小心术语撞车。黑格尔的「理念」是概念与实在的统一，是自我展开的历史过程；叔本华的「理念」取自柏拉图，是意志客体化的静止级别，没有历史。同一个中文词，两套形而上学。
:::

## 六、艺术案例：《特里斯坦与伊索尔德》

瓦格纳这部乐剧 1857 至 1859 年作曲，1865 年首演。叔本华 1860 年去世，没有听过它——这一点很重要，理论在这里先于作品。据记载，瓦格纳 1854 年读到这本书，此后创作深受影响。

形式上有三处值得看。前奏曲以「特里斯坦和弦」开场：F、B、D♯、G♯ 四音叠置，悬而未决，多次转位后仍不落到主调。半音阶持续扩张，调性中心不断游移，形成所谓「无限旋律」——旋律不再分句收束，永远指向下一音。第二幕的爱情二重唱用长时段的渐强与延迟解决堆叠张力，把「夜」写成唯一的真实。第三幕的「爱之死」终于回到 B 大调，前奏曲的悬置在此获得解决。

用叔本华的框架读，这些手法几乎是意志的音响图解：未解决的和弦就是欲求本身的结构，永远指向下一个音；解决就是满足，而满足一出现就消失，所以音乐必须继续。「夜」对应个体化原理的取消，白昼的姓名、身份、婚约都是表象的形式。爱之死则是意志寂灭的审美预演。

但这个对应有一处裂缝。叔本华的寂灭是「无」，瓦格纳的寂灭是「高潮」：乐队在这里达到全曲最饱满的音响，感官被推到极点。用叔本华的语汇说，这更像意志的强化，而非意志的否定。同一件作品，可以被读成「解脱的预演」，也可以被读成「解脱的感官化伪造」。这正是理论的边界。

::: fig a-tristan | 《特里斯坦》：特里斯坦和弦的悬置与第三幕的解决，把「欲求—满足—再欲求」写成和声结构
:::

## 七、思想联系

向前追溯，叔本华把康德的物自体、无利害与崇高论接了过来，把柏拉图的理念当作中介，又借《奥义书》的「那就是你」给「个体即意志的显现」一个东方根据。他反对的是黑格尔的历史理性：在他那里，历史没有意义，只有意志的重复。

向后看，瓦格纳把「意志的音乐」变成实践，尼采把「意志」改写成「权力意志」并反转其价值（第 6 模块第 3、4 讲），弗洛伊德把「盲目的欲求」改写成无意识本能，托马斯·曼则把叔本华的形而上学写进小说的反讽结构。二十世纪对「无利害」的批评——阿多诺、布尔迪厄——也都可以追溯到这个把审美规定为「意志暂停」的版本。

## 八、本节总结

::: key 本讲要点
- 世界是意志与表象：表象受根据律支配，意志是盲目的欲求，身体是两者的交汇点。
- 第三篇的推进：从独立于根据律的认识，到理念，到纯粹认识主体，到各门艺术的层级，最后到音乐。
- 审美快感来自意志的暂停，与满足不同；优美是意志不抵抗，崇高是意志受威胁而认识克服之。
- 音乐跳过理念，直接写照意志，因而是体系的例外，也是体系最脆弱处。
- 审美只是暂时的、被动的、依赖禀赋的解脱；禁欲才是永久的否定。循环困难在于：为意志服务的认识如何可能无意志。
:::

叔本华留下的问题比他的答案更持久：如果人主要由自己看不见的欲求驱动，那么「自由」还能在什么地方出现？他把答案放在审美与禁欲两处，前者太短，后者太难。

值得继续追问的问题：如果审美只是欲求的暂停，它凭什么被称为「解脱」而不是「麻醉」？这两者在经验上如何区分——靠事后是否更清醒，还是靠别的什么？
