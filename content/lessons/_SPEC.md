# 讲义写作规范（所有讲次必须严格遵守）

## 一、文件与命名
- 路径：`content/lessons/mNN-lNN.md`，编号必须与 `content/modules/mNN.json` 中的讲次顺序一致（`m01-l01` 即第 1 模块第 1 讲）。
- 一个讲次一个文件，UTF-8，无 BOM，换行用 `\n`。

## 二、front-matter（YAML，必须齐全）
```
---
id: m01-l01
title: 与 modules 文件完全一致的标题
lead: 80–150 字的导读，点出本讲要解决的问题和为什么值得读
quote: 一句 20–40 字的凝练短语（显示在课程卡片上，可用自己的话，不必是原典引文）
concepts: [c-aesthetica, c-baumgarten]
people: [p-baumgarten]
artworks: []
readings: []
---
```
- `concepts` / `people` 只能填 `tools/_idlist.json` 里已存在的 id，**不得自造 id**。通常填 2–5 个与本讲关系最紧的。
- `artworks` 只允许：`a-venus-de-milo a-laocoon a-parthenon a-school-of-athens a-santa-teresa a-impression-sunrise a-avignon a-guernica a-composition-vii a-broadway-boogie-woogie a-heroica a-tristan a-barcelona-pavilion a-battleship-potemkin`
- `readings` 只允许：`r-hippias r-symposium r-poetics r-hume-taste r-burke-sublime r-kant-judgment r-schiller-letters r-hegel-aesthetics r-nietzsche-tragedy r-heidegger-origin r-dewey-art`

## 三、正文结构：八段，缺一不可
二级标题必须包含下列关键词（检查脚本按关键词匹配），推荐写法：

```
## 一、本节导入
## 二、核心知识：xxx
## 三、代表人物：xxx
## 四、理论解析：xxx
## 五、经典原著：xxx
## 六、艺术案例：xxx
## 七、思想联系：xxx
## 八、本节总结
```

各段要求：

1. **本节导入**：从一个具体问题、一件作品或一个日常困惑切入，交代这个问题为何在思想史上重要。不要用「自古以来」开篇。
2. **核心知识**：把本讲的概念讲清楚。术语第一次出现必须给出定义 + 一个具体例子。可用列表或表格组织，但必须有连贯的说明文字，不能只有条目。
3. **代表人物**：生平只写与思想形成有关的部分（通常 100–200 字），重点写他面对的问题、思想转折、以及他的理论贡献与局限。
4. **理论解析**：本讲主体，占全文 30% 以上。必须写清：理论为什么产生、要解决什么问题、论证结构（分几步、每步靠什么支撑）、以及它的问题或反对意见。
5. **经典原著**：介绍相关著作的成书背景、结构、关键章节，给出经过核实的原文（见第五节规则），并解释这段原文在说什么。
6. **艺术案例**：结合具体作品分析，必须落到形式层面（构图、比例、笔触、材料、光线、结构、镜头），不能只讲背景故事。可用 `::: fig 作品id | 图注` 插入构图示意图。
7. **思想联系**：向前追溯它继承/反对了什么，向后说明它如何影响了谁，至少各提到一个有名字的理论或人物。
8. **本节总结**：用 4–6 条归纳关键概念与理论关系，并给出一个「值得继续追问的问题」。

## 四、长度与密度
- 单讲正文 **3000–4500 字**（中文字符计）。低于 2800 字视为不合格。
- 不允许用重复表述、空话、目录式罗列凑字数。每一段都要有信息量。
- 每讲至少出现 1 个表格（Markdown 表格）或 1 组编号步骤，用于承载可比较的结构化信息。
- 语言：口语化但不轻浮；避免学术黑话堆砌；不要用「不是……而是……」句式；判断用「倾向于／较为吻合／可以对应」这类分寸词，不作独断。

## 五、引文规则（最重要，违反即报废）
- **只允许引用你确有把握的原文**。有把握的常见引文可引用，但必须标注篇目/章节（如「《诗学》第 6 章」），**严禁编造页码、卷次、版次**。
- 没有把握逐字复现的，就写转述：「亚里士多德在此处的大意是……」，并说明这是转述。
- 黑格尔《美学》的原文可直接查 `content/refs/_hegel-quelle.txt`（汉译世界学术名著电子文本，可全文检索）。凡引用黑格尔原文，**必须先在该文件中检索确认逐字一致**，并标注「《美学》第一卷，全书序论」之类的位置。
- 其它原典（柏拉图、亚里士多德、康德、尼采、海德格尔等）如无把握逐字，一律转述。宁可少引，不可造假。
- 二手观点（研究者对某人的解释）必须写明是「研究者通常认为／朱光潜指出／朱立元主编本强调」，不得把解释写成原典原话。

## 六、可用排版容器
```
::: def 概念名
定义与解释，可含 **粗体**、列表、表格。
:::

::: key 本讲要点
- 要点一
- 要点二
:::

::: warn 常见误解
指出一个流行但错误的说法，并说明错在哪。
:::

::: note 补充
边缘性但有用的信息。
:::

::: quote 《诗学》第 6 章
被引用的原文（逐字核实过才放这里）
:::

::: fig a-laocoon | 拉奥孔群像的螺旋构图：三人构成一个上升的三角形
:::
```
- `def` 每讲 2–4 个，`key` 每讲 1 个（放在总结前或总结内），`warn` 每讲 1–2 个，`quote` 每讲 1–2 个。
- 容器内可以有空行和列表，必须以单独一行 `:::` 结束。

## 七、跨讲一致性
- 「美是理念的感性显现」「卡塔西斯」「无利害」「视域融合」等核心译名，全课程统一用这些写法，不要在同一讲里混用两套译名。
- 讲到某讲已讲过的内容，写「参见第 X 模块第 Y 讲」，不要重复展开。
- 年份用「前 427—前 347」这种格式；外国人名首次出现给原文（Plato）。
