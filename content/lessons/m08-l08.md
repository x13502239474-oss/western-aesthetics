## 一、本节导入

一张监控截图。便利店门口，凌晨两点十七分，画面右上角有蓝色的时间戳，人物被压成低分辨率的色块，货架的边缘出现锯齿，地上的反光过曝成一片白。

这张图也有形式：固定的高位视点、广角带来的边缘畸变、红外模式下的灰度反转、压缩算法留下的块状纹理。它也有构图：出入口被放在画面偏左，收银台在右后方，中间留出一条通道。它甚至有一种观看关系：没有人是给这张图拍的，图里的人不知道自己在被看。

艺术史的训练对这张图几乎无用。它没有作者，没有风格，没有意图，谈不上杰作。可它确实在组织我们的视觉经验，而且这种组织方式已经蔓延到广告、新闻、社交平台与家庭相册。

视觉文化研究就是从这类对象出发的。它主张：看是一种社会实践，被制度、技术与权力关系组织；研究的任务在于揭示这些组织方式。媒介美学走的是另一条路，它追问媒介的形式特性如何改变感知的尺度与节奏。两条路都离开了「杰作」，也都在离开之后遇到同一个麻烦：批判的锋利与形式的细致，很难同时保住。

## 二、核心知识：三个概念

::: def 视觉性（visuality）
指看的社会组织方式：谁被允许看、看什么、从哪里看、看到的东西如何被解释。它与「视觉」（vision）不同，后者是生理能力，前者是历史地形成的观看体制。**例**：同一座城市，游客的视线沿天际线移动，外卖骑手的视线沿门牌与路口移动，监控的视线从高处俯视；三种视觉性对应三种身体位置与制度角色。
:::

::: def 媒介（medium）
在美学里有两义。一义指材料与手段（油彩、胶片、像素）；一义指传递信息的技术装置（印刷、广播、平台）。媒介美学的重点是第二义：装置的形式特性如何塑造可被感知的东西。**例**：竖屏与横屏对构图的要求不同，竖屏偏好中心对称与近距离，横屏容纳横向叙事与并置。
:::

::: def 注意力经济（attention economy）
一种解释框架：当信息供给远超注意能力，注意力成为稀缺资源，媒介形式围绕争夺注意力而优化。**例**：短视频前三秒必须给出钩子，因此剪辑点前移、字幕居中、配乐先入；这些选择由争夺注意力的机制塑造。
:::

三个概念串起来是一条链：媒介提供装置，装置生产视觉性，视觉性在注意力经济中被定价。链条上的每一环都可以单独研究，混在一起谈则容易把技术问题说成政治问题。

## 三、代表人物

**伯格**（John Berger，1926—2017）是英国作家、画家与批评家。他早年画画，后来写小说与艺术评论，1972 年的电视系列与同名小书《观看之道》让他获得广泛读者。他的方法接近马克思主义的文化批评，但表达方式极为具体：从一张画里的手势、镜子的位置、油彩的光泽讲起。这种写法使他的论点容易被记住，也容易被简化。

**米切尔**（W. J. T. Mitchell，1942— ）是美国学者，长期任教于芝加哥大学，主编《批评探索》多年。他研究浪漫主义诗歌与图像理论，1990 年代提出「图像转向」，主张人文学科需要一套不依赖语言模型的图像理论。他的「元图像」概念影响很大，因为它把图像的理论能力放回了图像内部。

**克拉里**（Jonathan Crary，1951— ）是美国艺术史与理论学者，任教于哥伦比亚大学。《观察者的技术》（1990）研究 19 世纪视觉观念的变化，把「观察者」当作被技术与管理塑造的角色。他的写法结合了艺术史、科学史与福柯式的话语分析，影响远超艺术史领域。

**麦克卢汉**（Marshall McLuhan，1911—1980）是加拿大文学学者与媒介理论家，1960 年代因「媒介即讯息」等提法成为公共知识分子。他的写作风格是格言式的，论断密集而论证稀疏，这使他的观点易传播、难检验。

**弗卢塞尔**（Vilém Flusser，1920—1991）生于布拉格，战后移居巴西，后回欧洲任教，用德语与葡萄牙语写作。《摄影哲学的思考》（1983）把摄影当作「装置」生产的「技术图像」来分析，是媒介美学里最接近本体论的一支。

## 四、理论解析

### （一）视觉文化与艺术史的分工

两者的差别可以用四个变量看清。对象：艺术史以作品为单位，视觉文化以图像为单位，图像包括广告、医学影像、地图、监控、表情包。方法：艺术史以风格学、鉴定、作者研究、图像学为主，视觉文化以符号学、意识形态批判、话语分析为主。证据：艺术史依赖原作、档案、师承，视觉文化依赖流通、使用、接受。价值预设：艺术史默认作品值得保存与研究，视觉文化默认图像需要被揭露。

| | 艺术史 | 视觉文化研究 |
| --- | --- | --- |
| 对象 | 作品，有作者与边界 | 图像，含广告、监控、界面 |
| 方法 | 风格学、鉴定、图像学 | 符号学、意识形态批判、话语分析 |
| 证据 | 原作、档案、师承 | 流通、使用、接受、装置 |
| 风险 | 把非作品排除在外 | 把形式还原为症候 |

这次转向的动机不只是学术的。1960 年代之后，图像的生产与流通量急遽增加，艺术史的对象在整个视觉环境里变成少数；女性主义、后殖民研究与文化研究则提供了批判的工具，使「谁被看、谁在看」成为可研究的问题。伯格的《观看之道》在这条线上位置特殊：它把批判的语言带给了普通读者。

### （二）伯格的两个命题

第一个命题是「观看先于言语」。伯格的用法属于结构性的层面（与发生学的「婴儿先会看」不同）：看发生在语言之前，语言随后试图解释看，却无法完全接管看。这个命题的作用是给图像留出一个不可被语言穷尽的余地。

第二个命题关于女性。伯格的分析是：在传统的观看体制里，男人行动，女人出现；男人看女人，女人看自己被看。女性因此把自己分裂成两个部分——观看者与被观看者，并用观看者的眼光监视自己。这个分析的关键在于内化：监视不需要外部强制，它被安装在被看者身上。

他的论证靠两类证据。一类是图像证据：欧洲油画中的斜卧裸体，身体横向铺展以便观看，镜子被放在手边，视线或回避或迎向画外的观者。另一类是制度证据：收藏、赞助、市场，使这类图像的生产有稳定的需求方。两类证据合起来说明，裸体画是一种惯例，而非对身体的自然记录。

伯格的分析有力，也有粗糙处。他把「男性观者」预设得过于统一，忽略了女性观者、同性观者的位置；他也把图像的效果说得过于直接，仿佛构图必然产生对应的心理。后来的女性主义研究修正了这两点，但保留了核心洞见：观看位置是被安排的。

### （三）米切尔：图像转向与元图像

「图像转向」常被误读为「图像取代了语言」。米切尔的意思更窄：人文学科开始把图像当作不可还原为语言的对象来研究，而不再把它当作语言的附属。这与「语言转向」并不矛盾——语言转向教会我们一切都被语言中介，图像转向则指出图像有一种不服从语言的存在方式。

「元图像」是图像用来说明图像自身的图像。它可以是一幅画里挂着另一幅画，可以是漫画人物举起一张画，也可以是一张广告里出现另一张广告。元图像的价值在于：它证明图像具有理论能力，不必等文字来赋予。

这个概念的困难是范围过宽。几乎所有图像都包含某种自我指涉，若「元图像」什么都能收，它就失去区分力。米切尔自己也承认这一点，他的处理方式是分层：有些元图像只是嵌套，有些则真正对「什么是图像」提出主张。

### （四）克拉里：观察者被建构

《观察者的技术》讲了一个转变。19 世纪之前，主流模型是暗箱：观察者站在暗箱之外，看投射在内部的像，观察者与对象保持分离，像是客观的。19 世纪二三十年代之后，生理学研究发现视觉依赖身体：后像、视差、视觉暂留，这些现象说明眼睛有自己的运作，会出错、会被欺骗。

转变的后果有三层。认识论上，视觉从 «客观的窗口» 变成身体的功能，可靠性下降。技术上，立体镜、频闪玩具、早期电影利用身体的缺陷制造效果，视觉开始被仪器操纵。制度上，观察者成为可测量、可训练、可管理的对象，与工厂、监狱、医院的管理技术同步。

克拉里的论题因此不只是历史描述，它是一个强的哲学主张：不存在「自然的观看者」，每个时代都生产自己的观察者。这个主张与福柯的规训分析同源，也带来同样的困难：若观察者完全被建构，研究者凭什么站在建构之外做批判？克拉里没有正面回答。

### （五）媒介美学：麦克卢汉与弗卢塞尔

麦克卢汉的核心提法是「媒介即讯息」。它的意思是：媒介的形式特性——速度、尺度、参与程度——对社会与感知的改变，大于它传递的具体内容。同一则新闻，印在报纸上、播在广播里、刷在信息流中，产生的效果不同，因为接受的节奏与注意的结构不同。

这个提法在美学上的意义是把「形式」从作品内部移到技术条件：构图、剪辑、界面，都是媒介形式的显影。它的限度也很明显。技术决定论的倾向使他难以解释同一媒介上的不同使用；「冷媒介」「热媒介」的区分缺乏稳定标准；格言式的写作让论断无法被反驳。

弗卢塞尔的贡献更细。他把摄影分析为「装置」的运作：装置是一台按程序运作的自动机器，摄影师在程序允许的范围内穷尽可能性。技术图像看似客观记录，其实是把概念翻译成图像——先有理论（光学、化学、构图规范），再有图像。他的担忧是：当技术图像取代文字成为主要信息载体，人就被装置的程序支配，想象力退化为对程序的组合。

「自由」在他那里因此有了特殊含义：自由存在于与程序对抗的行动中，即拍摄程序未曾预期的图像。这个说法有力量，也有浪漫化的嫌疑：把反抗定位在个体的巧思上，回避了装置的所有权与制度。

### （六）共同的困难：批判替代形式分析

两条路径都容易滑向同一种失误：把图像直接读成意识形态的症候，跳过形式的分析。看到一幅广告，直接说它物化女性；看到一张新闻照片，直接说它服务于某种叙事。结论可能对，但论证跳过了最关键的一步——这幅图是通过什么具体手段产生这个效果的？

这一步的缺失有两个后果。其一，批评无法区分好图与坏图：若所有广告都物化女性，那么拍得精妙的与拍得拙劣的就没有差别。其二，批评无法反驳：既然结论先于分析，任何反例都可以被解释为「更深层的症候」。

与形式主义的张力也在这里。格林伯格一系主张形式自身具有价值，批判语言学则主张形式总是意识形态的。较有希望的路线是「批判性的形式分析」：把形式看作意识形态的载体，同时承认形式有自身的逻辑与技术约束。这条路线要求研究者既能读构图，也能读制度，工作量远大于任选其一。

## 五、经典原著：《观看之道》的写法

《观看之道》1972 年出版，源自同年的电视系列。全书由文字章与纯图片章交替构成，纯图片章没有解说，靠并置产生论点。这种编排本身就是论证：它让读者先经验到「复制改变意义」，再读到解释。

第一章处理复制技术。画被拍成照片、印在书上、放大在屏幕上之后，它进入新的语境，意义随之改变。原作的神圣性依赖于地点与仪式，复制把这些条件拆掉。这一章与本雅明的论述同源，但伯格的写法更具体：他展示同一幅画在不同版面中的效果差异。

第三章处理裸体画与观看关系。伯格区分「裸体」（naked）与「裸体画」（nude）：前者是一个人的状态，后者是一种被观看的惯例。

::: quote 《观看之道》第一章开篇（英文原文）
Seeing comes before words.
:::

这句话的位置很关键：它出现在全书第一句的位置，为一个以图像为对象的论证划出起点。它要强调的是看有其自身的运作，语言只是对它的追加解释，「语言不重要」并非它的主张。伯格随后用大量图像证明，这个「看」从来不是纯粹的：它被知识、信仰、阶级与性别塑形。

书的局限与优点同源。优点是具体、可感、易传播；局限是缺少对反例的处理，也缺少方法上的自省。它把批判的语言交给了公众，代价是把论证的细节留在了别处。

## 六、艺术案例：两种形式，两种观看

先看广告图像。一张化妆品广告的常规做法是：面部被裁切到只剩五官，颈部以下不出现；光源从斜上方打来，皮肤的高光被修到没有毛孔；视线或直视镜头，或略微下垂；背景是纯色或虚化。这套形式的效果是把人还原为表面，把注意力集中在可替换的部分。

再看短视频。竖屏、九比十六，主体必须居中偏上；前三秒要有动作或声音的突变；剪辑点密集，平均镜头长度以秒计；字幕固定在画面中部，因为拇指会遮住下方；配乐先入，语言后置。这套形式的效果是把叙事压成脉冲，把理解改成反应。

两种形式共享一个前提：观看的时间被压缩。广告假设你有两秒，短视频假设你有半秒。形式的所有选择都围绕这个假设展开。把它与一幅十九世纪的油画对比，差异立刻显现：油画的观看时间以分钟计，因此可以承载层次、典故与细节的回报；被压缩的观看只能承载即时的识别。

这也解释了为什么批判容易停在结论上。当形式的作用是「瞬间生效」，分析它的机制就需要放慢速度，而放慢速度恰好是这种形式所不允许的。

## 七、思想联系

向前，这条线索接在本雅明的复制理论（参见第 6 模块）：机械复制改变了作品的此地此时性，也改变了大众与作品的关系。潘诺夫斯基的图像学提供了「意义分层」的方法，视觉文化研究把它政治化。格林伯格的形式主义则是被反对的对手，它主张形式自律，批判语言学主张形式总在意识形态之中。

向后，视觉文化研究影响了平台研究、算法批判与界面研究；媒介美学则延伸为对基础设施、压缩算法、推荐系统的研究。两者在人工智能图像出现之后再次交汇：生成图像的「风格」变成了可计算的分布，观看的体制也随之一变（下一讲展开）。

## 八、本节总结

- 视觉文化研究与艺术史的分工在对象、方法、证据与价值预设四处；前者以图像为单位，后者以作品为单位。
- 伯格的「观看先于言语」为图像留出不可被语言穷尽的余地；「女性自我监视」说明观看位置如何被内化。
- 米切尔的图像转向要求一套不依赖语言的图像理论；元图像把理论能力放回图像内部，但范围过宽。
- 克拉里主张观察者被技术与管理建构，这一主张强，也带来「批判者站在何处」的困难。
- 麦克卢汉把形式移到技术条件，弗卢塞尔把图像分析为装置的产物；两人的论断有力，论证都偏松。
- 两条路径的共同弱点是批判替代形式分析，补救的方向是批判性的形式分析。

值得继续追问的是：如果观看位置总被安排，那么「批判性的观看」是否也是一种被安排的位置？它与它所批判的位置，差别在哪里？

::: key 本讲要点
- 从杰作到图像，从风格学到意识形态批判，是视觉文化的两个转向。
- 伯格的贡献在于把观看关系讲成可感的图像事实。
- 图像转向针对的是语言的霸权，不是图像的泛滥。
- 克拉里的观察者是技术—制度的产物，不是天生的感官主体。
- 媒介即讯息提示形式的所在，也暴露技术决定论的短板。
:::
