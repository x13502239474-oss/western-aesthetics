## 一、本节导入

1674 年，巴黎出版了两部书，译者都是布瓦洛（Nicolas Boileau，1636—1711）。一部是他自己的《诗的艺术》，一千余行的韵文，教人怎样写诗：情节要整一，人物要合礼，语言要清楚，判断要交给常识。另一部是朗吉弩斯《论崇高》的法译本，书里反复称颂一种状态——读者被言辞猛地抬离自身，像被雷击。

同一个人在同一年做这两件事，并非偶然的兼职：规则能保证作品不荒谬、不散乱、不失礼，却无法保证它动人。朗吉弩斯处理的是后一半。

这一讲要说明的就是这套纲领的内部构造，以及它在哪里绷不住。新古典主义常被当作僵硬教条，实际上它有论证、有分工，也有内在冲突。

## 二、核心知识

::: def 新古典主义（classicisme）
17 世纪法国以古代作品为典范、以理性为根据、以规则为技术保障的文艺纲领。三个信条：模仿普遍人性而非个别事实；遵守得体；追求明晰与整一。
例子：拉辛的悲剧把希腊题材收进法国宫廷的语言与礼仪，人物不着希腊长袍，说的是亚历山大体法语。
:::

::: def 可信性（vraisemblance）
剧场内被认为可能发生的东西。依据是公众对「事情会怎样」的共识，与事实记录无关。它排除偶然与荒诞，使观众愿意进入剧情。
例子：一个暴君在一场戏里忽然变成仁君，历史上或许发生过，舞台上不可信，因为观众不认这条心理路径。
:::

::: def 合礼（bienséance）
人物言行须与其身份、年龄、性别、处境相符，且不触犯观众的道德与宗教禁忌。它维护舞台的体面，也维护观众的身份秩序。
例子：国王在舞台上被刺死不合礼，须由人物出场叙述；圣礼不宜搬上舞台，因为教义不容轻慢。
:::

::: def 三一律（trois unités）
情节整一、时间约一日、地点同一这三条舞台规则的合称。前一条出自亚里士多德，后两条出自文艺复兴的注释与法国学院的实践。
例子：《费德尔》全部发生在特罗埃曾的王宫，从希波吕托斯宣告出走演到费德尔服毒自尽，中间不换景、不跳日。
:::

可信性与合礼常被混为一谈，其实分工不同：

| 比较项 | 可信性 | 合礼 |
|---|---|---|
| 管什么 | 是否可能（认知层面） | 是否合宜（伦理与社会层面） |
| 依据 | 公众对因果与人性的共识 | 观众的道德感与身份秩序 |
| 违反的后果 | 观众不信，情节失效 | 观众反感，作品失礼 |
| 典型违例 | 一场之内由恶转善 | 舞台上处死国王 |
| 冲突时 | 常让位于合礼 | 常压过可信 |

这张表也解释了法国古典悲剧为何把暴力移到台后：那既是合礼的要求，也是可信性的手段——由目击者叙述更容易被接受为「真发生过」。

## 三、代表人物：布瓦洛与拉辛

布瓦洛 1636 年生于巴黎，出身最高法院推事家庭，学法律后转向文学，与莫里哀、拉辛、拉封丹结成小圈子，1684 年进入法兰西学术院。他在古今之争中站在古人一边，晚年与佩罗和解时承认现代人在自然科学上胜出，同时坚持古人在刻画情感上无可比拟（此为转述）。

拉辛（Jean Racine，1639—1699）在波尔—罗亚尔的冉森派学校受教育，这段经历给他的人性观留下印记：人受激情支配，理性看见了陷阱也绕不开。1667 年《安德洛玛克》成功，1677 年《费德尔》遭遇对手组织的捧杀式竞争，他一度退出戏剧，后来继布瓦洛之后任史官。他的悲剧是三一律最精密的实现。

布瓦洛为拉辛提供理论语言与论战支援，拉辛为布瓦洛提供「规则能产生什么」的样本。新古典主义的力量，一半来自这种配合。

## 四、理论解析

### （一）理性、自然、规则：三角怎样立起来

**理性。** 在布瓦洛那里，理性指常识与明辨，即 le bon sens 与 discernement，不指推演能力。它的功能主要是否定性的：识别荒谬、删去多余、指出哪一句不成立。它不生产诗，只裁判诗。《诗的艺术》第一章大半篇幅在说「不要做什么」，原因就在这里。第一章以「爱理性」的祈使句开场，接着要求作品从理性取得光彩与价值——注意这个次序：先立法庭，再谈技艺。

**自然。** 这个词有两重含义。一重是普遍人性：宫廷与城市是观察人性的场所，那里的人被最多双眼睛看过，言行最有公共性。另一重是事物的一般秩序，即「真」：事情按常理该怎样发生。自然因此既是被模仿的对象，也是判断的尺度。

**规则。** 规则包括情节整一、得体、明晰这几条。关键在于它的地位：规则由理性从经验中抽出，因此它的合法性来自功能，不来自古人的权威。古人只是先行者，真正的立法者是理性。这句辩护让新古典主义在古今之争中有了退路：即使古人不完美，规则仍然成立。

三角的运作方式可以这样描述：理性给出判准，自然给出对象，规则给出技术。规则处在最下游，却最先被教授。这个颠倒造成了一个持久的误解：人们以为新古典主义从规则出发，其实规则是它的结论。

### （二）可信性与合礼：两种「应当」的冲突

可信性管的是认知：这件事在观众看来会不会发生。它的标准取公众的共识，与事实记录无关。所以可信性天然带历史性——同一件事在 1660 年可信，在 1760 年未必。布瓦洛只要求作家「研究宫廷，认识城市」，即从当代意见里取得可信性的样本。

合礼管的是伦理与社会秩序：这个人这样说话合不合他的身份，这个场面让观众看见会不会失礼。它的标准是等级与体面。

两者会冲突，而冲突的处理方式很有启发。一件真实发生过的事若不合礼（例如国王被臣下刺杀），就删掉或改写；一件合礼却不太可信的事（例如人人高尚、处处克制），则用语言的技巧补救。总的原则是让可信服从合礼——礼是硬约束，可信是可以调整的软约束。

后果有三重：题材被压缩到历史中体面的段落，乱伦与弑亲须过滤；暴力与死亡移到台后，由目击者叙述；语言被统一到宫廷法语的水准。这三重后果既是技术选择，也是伦理选择。18 世纪的攻击正落在这里：狄德罗要求舞台上出现市民的客厅与真实的职业，莱辛则说合礼不过是宫廷的偏见，把观众教成了只认一种人。

### （三）三一律：来源、论证与反对

三一律的三条并不同龄。情节整一有亚里士多德作依据，《诗学》第 8 章要求情节成为有机整体，各部分按可然律连接。时间与地点两条，在《诗学》里找不到对应的规定。

来源在文艺复兴的意大利。16 世纪中叶，吉拉尔迪（Giraldi Cinthio）在讨论悲剧时提出把剧情时间压缩到很短；1570 年，卡斯特尔维特罗（Lodovico Castelvetro）在《诗学》的意大利文译注里明确给出二十四小时与地点整一，理由取自舞台经验：观众坐在一处不动，剧情也不该换地方。斯卡利杰（Julius Caesar Scaliger）1561 年的《诗学七卷》强调逼真，为同一方向提供了理论支持。

在法国落地有两个标志。1634 年，迈雷（Jean Mairet）的《索福尼斯贝》被视为第一部严格遵守三一律的法国悲剧；1637 年，法兰西学术院就高乃依《熙德》发表《意见》，由夏普兰（Jean Chapelain）起草，批评该剧情节过载、不合三一律、也有失合礼。这份文件把三一律从一派主张变成了半官方标准。

它的论证结构可以还原为五步。

1. 戏剧是让人「看见」在此地此刻发生的事，效果依赖在场感。
2. 观众坐在剧场里的时间约三四小时，期间不离场。
3. 若剧情时间远长于演出时间，观众会察觉不对，在场感破裂。
4. 所以剧情时间须接近演出时间，二十四小时是宽松的上限。
5. 同理，地点若频繁变换，观众无法维持「同一处发生」的印象，故地点须同一。

这是经验论证，依据观众心理而非古人语录；也正因如此，它可以被经验反驳。

::: warn 「三一律出自亚里士多德」
流行说法称亚里士多德规定了三一律。核对文本：《诗学》第 8 章只要求情节整一，第 7 章说长度以能被一览为限，第 24 章讨论史诗与悲剧的长短，都没有二十四小时与单一地点。把三条并称并归到亚里士多德名下，是文艺复兴注释与法国学院实践的产物。17 世纪的论战里，古人派之所以能占上风，部分原因就是这条误认——反对三一律被说成反对亚里士多德，而实际上反对的是一套 16 世纪的舞台技术。
:::

最强的反对来自莱辛 1767 至 1769 年的《汉堡剧评》。他的论据有三层。第一，舞台幻觉本身不成立：观众从不忘记自己在剧场，否则不会为演员的嗓子担心、不会在中场起身。第二，法国悲剧自己就不守这套逻辑：大量的独白、旁白、当着人背过身说的密谈，没有一样合乎日常，若以逼真为标准，先该删的是这些。第三，若观众不需要幻觉，那么时间与地点的限制就失去理由，剩下的只有一条真正的原则——情节的整一。三层合起来，指责的要点因此落在自相矛盾上。

### （四）规则派与天才派的张力

反规则的论证有三条，都很硬。

其一，规则总在杰作之后被抽出。先有索福克勒斯，后有《诗学》。规则是对既有作品的描述，把它倒过来当作生产的条件，等于让描述去生产对象。

其二，最好的作品常常违规而成功。这条论据的力量来自它无法被规则派吸收：每一次成功都可以被解释为「他其实守了更深层的规则」，而这个「更深层」永远在事后追加。

其三，规则无法解释趣味的时代差异。同一部作品在一个世纪是典范，在下一个世纪是笑料，规则若普遍有效，就不该出现这种情况。

布瓦洛自己并非不知道这些。他的体系里留了两个出口。一个是「我说不清的什么」（je ne sais quoi），用来指那种说不出理由却确实动人的品质；一个是他对朗吉弩斯的译介，用来安置规则管不到的崇高。这两个出口在 18 世纪被放大：趣味论接管了第一个，崇高论接管了第二个。

规则派的回应也值得听。他们会说：规则的功能在于排除明显的失败，并不能保证成功。医学不能保证健康，却能减少死亡；语法不能保证好文章，却能减少歧义。这个回应把规则从「充分条件」降为「排除故障的工具」，其实已经向天才派让步了。

## 五、经典原著：《诗的艺术》

《诗的艺术》1674 年出版，四章，约一千一百行，亚历山大体重韵双行，模仿贺拉斯《诗艺》的书信体。第一章总论理性、自然、真；第二章论次要诗体（田园诗、哀歌、颂歌、十四行、讽刺诗）；第三章论主要诗体（悲剧、史诗、喜剧）；第四章论诗人的品格。

第一章的核心是一句祈使：

::: quote 《诗的艺术》第一章
Aimez donc la raison: que toujours vos écrits / Empruntent d'elle seule et leur lustre et leur prix.
（爱理性吧：让你的作品只从她那里取得光彩与价值。）
:::

这句话的语法值得注意。它用了「爱」，一个情感动词，来命令人服从理性。这个混用暴露了纲领的底细：理性在这套体系里不只是一条标准，它是一种被培养的倾向，靠教养与习惯养成。谁能「爱理性」，谁就自然避开荒谬；谁需要查规则才知道该删什么，谁就还没入门。

这也是这部书用韵文写成的理由：它在示范思想如何被纳入格律而不失力量。

## 六、艺术案例：《费德尔》

拉辛的《费德尔》1677 年首演，取材欧里庇得斯。剧情可以压成一句话：王后费德尔爱上继子希波吕托斯，告白被拒后任由乳母诬告，希波吕托斯死于海神之手，费德尔服毒后向丈夫忒修斯坦白。

三一律在这里充当压强。地点固定在特罗埃曾王宫，全剧不换景；时间压在同一天内，从希波吕托斯宣告出走演到费德尔自尽；情节只有一条线——谁向谁说了什么。人物无处可去，只能说话；说话即行动。

形式上有三处值得细看。

第一，格律承担情感。亚历山大体的十二音节在第六音节后有固定停顿，形成 6+6 的对称。拉辛大量使用跨行（enjambement）打破这个对称，让句子溢到下一行。情感越失控，句法越越界——规矩还在，裂缝出现在规矩内部。

第二，告白的位置。费德尔对俄侬娜说出对希波吕托斯的爱，是全剧的支点。这场戏之后，所有行动都是这句话的后果。三一律的整一性在这里得到验证：一个动作（告白）足以生成全部情节。

第三，暴力在台后。希波吕托斯的死由泰拉曼叙述：海神掀起的浪、惊马、缠住身体的缰绳。观众听见一段报告，看见的是听报告者的脸。合礼的要求与可信性的技术在此重合，想象补足了舞台给不出的部分。

假如允许换景，让观众跟着希波吕托斯去海边看马惊人亡，费德尔的独白就会被一场动作戏挤到边上。三一律的真正功能，是把戏剧的重量压在语言上。

## 七、思想联系

向前追溯，这套纲领有三处源头。贺拉斯《诗艺》提供了「寓教于乐」与得体的最初表述；亚里士多德《诗学》经文艺复兴注释者加工，提供了情节整一与可信性的框架；17 世纪初马莱伯的语言纯化清除了方言与拉丁化句法，为宫廷法语的标准扫了地。

向后看，影响沿两条路走。一条是英固化：蒲柏 1711 年的《批评论》用英雄双行体复述布瓦洛的纲领，约翰逊的批评继续沿用「自然」与「常识」的判准。另一条是反驳：莱辛以《汉堡剧评》拆掉三一律的论证，狄德罗以市民剧换掉宫廷题材，19 世纪初的浪漫主义则以天才与个性取代规则，把布瓦洛变成了一个反面符号。

## 八、本节总结

::: key 本讲要点
- 三角的次序是：理性给判准，自然给对象，规则给技术。规则处在结论的位置，合法性来自功能。
- 可信性管认知（观众信不信），合礼管伦理与身份（观众受不受得了）。两者冲突时，可信常让位于合礼。
- 三一律只有情节整一出自亚里士多德，时间与地点两条出自文艺复兴注释与法国学院实践，其论证是经验性的舞台幻觉论证。
- 莱辛的反对落在自相矛盾上：若以逼真为标准，独白与旁白先该删。
- 规则派与天才派的张力在布瓦洛体系内部已有出口：「我说不清的什么」与崇高。18 世纪的趣味论与崇高论分别接管了这两个出口。
:::

一句话收束：新古典主义用理性造了一间结实的屋子，窗户很小；朗吉弩斯是那扇窗，浪漫主义后来把整面墙拆了。

值得继续追问的问题：如果规则的真正功能是「排除明显的失败」，那么一套从不失败的创作是否必然平庸？安全与力量之间，是否存在可计算的比例？
