## 一、本节导入

翻开 1752 年《百科全书》第二卷，找到「美」（Beau）这一条。条目开头不急着下定义，先把古今说法排成一列：美在秩序、比例、和谐、适宜、多样统一、唤醒情感。排完之后，作者说了一句不客气的话，大意是：这些定义各抓住一部分，却都把某一种特殊的关系当成了美的全部。

写这条目的是狄德罗（Denis Diderot，1713—1784）。他当时正主编这部书，每天与检查、删改、匿名、查禁打交道。他的写法也带着这种处境：不给一个高高在上的定义，先把对手的观点摆清楚，再指出它们的共同毛病。

「美在关系」这句话听起来温和，其实是两面开战。对理性主义，它说美没有天赋的模型；对怀疑主义，它说关系在对象里，不由人随便定。中间这条路能不能走通，是本讲要检查的。

## 二、核心知识：关系、绝对与相对

::: def 美在关系（le beau de rapport）
狄德罗的定义：对象之所以美，因为其中含有能被知性觉察的关系；美感的产生，就是这些关系被知觉。关系包括部分与部分、部分与整体、对象与环境、对象与人的用途之间的种种联结。
例子：一座桥的美，在于拱的跨度与桥墩的间距彼此呼应，也在于它横跨的河面宽度；把同一座桥搬到一条窄沟上，关系变了，美也变了。
:::

::: def 实在关系与知觉关系
实在关系（rapports réels）指对象自身具有的、独立于是否被察看的联结；知觉关系（rapports aperçus）指主体实际察觉到的那部分。前者提供客观基础，后者提供美感的发生条件。
例子：钟表内部的齿轮咬合是实在关系，即使无人观看也在运作；只有当修表匠看出这组咬合如何传动，关系才被知觉，他才说「这机芯做得美」。
:::

::: def 绝对美与相对美
绝对美指不以与他物比较为条件而成立的美；相对美指依比较、环境、用途而成立的美。狄德罗承认严格意义的绝对美极难遇到，多数被称为绝对美的东西，只是关系较稳定、较少依赖外部条件。
例子：一朵花的结构常被当作绝对美；一旦放进花束与别的花比较，判断立刻变成相对的。
:::

三个区分可以并成一张表：

| 分类轴 | 类型 | 成立条件 | 例子 |
|---|---|---|---|
| 关系是否依赖观者 | 实在关系 | 对象自身具有 | 齿轮的咬合、叶脉的分叉 |
| | 知觉关系 | 被主体实际察觉 | 修表匠看出传动，观者看出构图 |
| 是否依赖比较 | 绝对美 | 不与他物比较 | 单株花的结构、单独的旋律 |
| | 相对美 | 依比较与环境 | 柱式之于建筑整体、礼服之于场合 |
| 关系是否实存 | 虚构关系 | 由艺术家设立 | 寓言中的狮身人面、悲剧人物的处境 |

第三行是狄德罗留给艺术的余地。艺术家可以设立现实中不存在的关系，只要这些关系在作品内部自洽，就能产生美。这一点使他的理论不至于把艺术降为模仿。

## 三、代表人物：狄德罗

狄德罗生于朗格勒，父亲是制刀匠，家境殷实。他少年入耶稣会学校，后来到巴黎读法律，却混迹于书店与沙龙，靠翻译与写作谋生。1746 年《哲学思想录》被巴黎高等法院下令焚毁，1749 年《论盲人书简》因唯物论与无神论倾向使他入狱 Vincennes 数月。出狱后，他与达朗贝尔共同主编《百科全书》，从 1751 年第一卷到 1772 年最后一批图版，前后二十余年，其间不断被查禁、被删条目、被合作者抛弃。

他的写作面貌很杂：哲学对话、小说、戏剧、艺术评论、书信。1759 年起，他为格里姆的《文学通讯》撰写两年一度的沙龙评论，稿本只在少数订阅者间传抄，却开创了艺术批评这一文体。思想底色是唯物论与感觉论：一切观念来自感官。美学上他既反对天赋观念，也反对美纯由主观决定——若一切皆主观，感官与对象之间的因果就断了。

## 四、理论解析：在两难之间找一条窄路

### （一）问题：天赋观念与相对主义

十八世纪中叶的法国美学有两条现成的路。一条是古典主义的：美有客观规则，规则来自理性，因此判断可以统一。另一条是怀疑论的：美在观者的感受里，感受各不相同，因此无可争辩。

两条路各有硬伤。第一条无法解释趣味的历史变化：哥特建筑曾被当作野蛮，后来又被视为伟大。第二条无法解释为何有些作品能跨时代站住：若一切随人，经典的形成就成了偶然。

狄德罗要在两者之间找位置：美有客观基础（关系），美的实现需要知觉（人）。这个结构使他既能承认历史变化，又能保留判断的可靠性。

### （二）第一步：拆掉「秩序、比例、和谐」

他的批评分三层。

第一层是逻辑的。秩序、比例、和谐本身都是关系的一种；若说美在比例，等于说美在某类关系，可关系有许多种，为何单挑这一类？把种差当作属，定义就不完整。

第二层是反例的。同一对象在不同关系中既美且丑：一条鱼在池塘里算大，在海洋里算小；一座宫殿在乡野显得宏伟，在宫城中显得局促。若美固定于某类属性，这种随关系变化的现象就无法解释。

第三层是经验的。人常在算出比例之前就觉得美，也在算出比例之后仍觉得不美。比例可以事后被指认，却难以充当美感的原因；这一点与博克的方向一致（参见第 7 讲），只是狄德罗给出了另一种替代方案。

他并未把秩序与比例判为无效，只判为「局部有效」。这个处理很像他的政治立场——不推倒，先限定。

### （三）第二步：定义的两半

定义被拆成两句话。第一句关于「在我之外的美」：凡是自身含有能在知性中唤起关系观念的东西，就客观地是美的。第二句关于「对我而言的美」：凡是实际唤起了这一关系观念的，就对我而言是美的。

两半分工清楚：前半给客观条件，后半给主观条件。美既不在对象里单独成立，也不在观者心里单独成立，它发生在两者相接处。这个结构比「美是主观的」精细，也比「美是客观的」松软。

一个好处是它能解释错误。若某人看不出关系，判断就失准，而他可以被指正——指正的方式在于让他看见关系，而非说服他的感受。批评因此有了位置：它的工作是揭示关系，而非宣布结论。

### （四）第三步：关系如何避免相对主义

三种关系（实在、知觉、虚构）之上，狄德罗还加了两条限制，用来防止理论滑向「怎么说都行」。

第一条是关系的等级。并非所有关系都同等重要，构成对象本质的那些关系优先。一座教堂的美主要取决于结构与比例，而不取决于它与旁边一棵树的关系；判断的顺序应先内后外。

第二条是知觉的条件。看错、看漏、看得太急都会导致误判，利益与激情也会扭曲知觉。分歧因此可以被归因：有的来自对象本身的多义，有的来自观者的位置。这一区分让讨论成为可能。

::: warn 「美在关系」等于「美是相对的」
关系论常被读成相对主义，理由似乎是：关系随情境变，美也就随情境变。这个推论跳了一步。狄德罗的关系是对象自身具有的联结，情境改变的是「哪一组关系被知觉到」，而非「关系是否存在」。他的立场更接近「关系实在论」：关系客观，知觉有条件。真正相对的是判断的准确性，不是美的基础。
:::

### （五）第四步：从条目到剧场

这套想法在 1757 至 1758 年间被搬上舞台。狄德罗写了两个剧本《私生子》与《家长》，各附一篇长论：《关于〈私生子〉的谈话》与《论戏剧诗》。主张可以归为三条。

第一，建立「严肃剧」（genre sérieux，后世通称市民剧 drame bourgeois）。它介于悲剧与喜剧之间，人物是律师、商人、一家之主，而非王侯与小丑；悲剧处理灾难，喜剧处理可笑，中间地带处理「职业与家庭中的困境」。

第二，用「身份」（condition）代替「性格」（caractère）。古典戏剧以性格为核心：吝啬、伪善、嫉妒；狄德罗认为严肃题材应以身份为核心：法官的职责、父亲的权威、商人的信用。身份带来关系网，性格带来个人癖性。这一步与「美在关系」直接同构：戏剧的对象就是人与人的关系。

第三，用「画面」（tableau）代替情节的机巧。他要求某些场面像一幅画那样被安排：人物站位、姿态、光线、彼此的视线，共同构成一个可看的整体，让观众在一瞬间把握全部关系。他著名的说法大意是：在舞台前沿立一堵大墙，把你与观众隔开，演的时候当作观众不存在。这就是后来被称为「第四堵墙」的主张。

《演员奇谈》写于 1770 年代，发表已在 1830 年。它的主张与第四堵墙看似相反：伟大的演员靠观察与计算，感受力强的演员往往只能演好一种角色，冷静的演员能演一切。论据是：若演员真被情绪占据，就无法控制声量、节奏与站位，也就无法每晚复现同一效果。

两个主张可以调和，但需要一步说明。第四堵墙要求观众忘记自己被看，演员却在墙内精确计算每一个动作的分寸——自然的效果是计算的结果。用关系论的话说：演员计算的是「关系的可见性」，观众感受到的是「关系好像自然发生」。这正是虚构关系在艺术中的运作方式。

### （六）问题与三条反对

第一条，关系无限，定义有落空的危险。任何对象都与无数他物有关系，若美在于关系，则一切皆美。狄德罗用「本质关系优先」来补救，可哪些算本质，仍要靠判断，标准又回到直觉。

第二条，理论偏认知，丢掉了强度。用「知觉关系」解释美，适合说明绘画、建筑、戏剧的构图，却难以说明崇高的压迫、音乐的沉醉、悲剧的撕裂——这些经验的强度往往与「看不清关系」相关。

第三条，第四堵墙与《演员奇谈》的张力没有真正解决。若演员在墙内计算，观众看到的「自然」就是设计出的自然；可狄德罗同时要求戏剧具有道德感染力，让观众「进入」场景。计算与感染如何并存，他给的说明并不充分。

## 五、经典原著：《百科全书》「美」条目与《论戏剧诗》

「美」条目收入《百科全书》第二卷（1752），署名带星号，出自狄德罗之手。写法是论战式的：先陈列定义，再指出共同错误，然后给出两半定义，最后讨论关系的种类与判断条件。篇幅不长，却是十八世纪对「美」最系统的清理之一。

《论戏剧诗》1758 年出版，作为《家长》的附录。全文分章讨论戏剧的目的、体裁、人物、场面、表演、布景，语气不像论文，更像一位剧作家在排练场上的笔记。它与《关于〈私生子〉的谈话》合起来，构成市民剧的理论纲领。

::: quote 《百科全书》「美」条目（中文转述）
我把在我之外的一切含有能在我的知性中唤起关系观念的东西称为美；把在我身上实际唤起了这一观念的东西称为对我而言的美。
:::

这段是转述，非逐字译文。它的结构值得注意：两句话共用「唤起关系观念」这个谓语，区别只在「含有」与「唤起」。前者是潜能，后者是现实。美因此被安放在潜能与现实的接缝上，这个位置既不属于物理，也不属于心理。

## 六、艺术案例：格勒兹《乡村新娘》

1761 年的沙龙上，狄德罗看到格勒兹的《乡村新娘》（又译《订婚》），写下长段评论，逐个人物点评，甚至对着画中人说话。这幅画正是他理论的样板。

构图上，人物沿一条浅浅的弧线横向排开，几乎占满前景，背景是谷仓的阴影与一扇半开的门。光源从左上方来，落在父亲与新娘的脸上，其余人物退入半明半暗；这个布光把视觉重心固定在父亲抬起的手上。

动作上，每个人都在对另一个人做事。父亲右手抬起指向新郎，左手搭在女儿臂上；新娘低头，手指绞在一起；新郎身体前倾，一只手伸向公证人手中的契约；公证人侧身记录；后排邻人低声交谈，孩子在角落玩耍。整幅画像一张关系网，没有一个人物是孤立的。

狄德罗称这类作品为「道德画」。在他的读法里，画的价值不在单个人体的比例，而在这些姿态之间被安排出的伦理关系：父权、婚约、财产、羞怯、祝福。这正是「美在关系」的落地版本——美由关系构成，关系由构图呈现。

这个案例同时暴露了理论的隐含条件。要看出这些关系，观者得知道这是订婚、那位是公证人、契约意味着什么。若不具备这些风俗知识，画面只剩一群穿旧式服装的人。换言之，「知觉关系」需要文化准备；关系论因此暗含语境依赖，而狄德罗本人并未把这一点讲透。

对照的是布歇。狄德罗屡次批评布歇只会画讨喜的肉体与装饰性的色彩，画面漂亮却无关系可看。这个对比说明他的标准落在「关系是否被组织起来」，而非「画得美」；也说明他的批评有明确的道德倾向，美学判断与社会判断难以分开。

## 七、思想联系

向前追溯，关系论接的是洛克的感觉论：一切观念来自经验，包括「关系」——人比较两个对象时，心智产生了新的观念。这使他能反对天赋观念。他也接过古典主义的真问题：布瓦洛要求判断有公共标准（参见第 3 讲），狄德罗把标准从规则改成关系。

向后看，三条线从这里分岔。莱辛在《拉奥孔》里处理诗与画的界限，用的正是「关系如何在媒介中呈现」的思路；他与狄德罗通信，共享同一批问题。黑格尔把美定义为理念的感性显现，其中「显现」一词承接了关系论的遗产：美在关系中呈现，而非在实体中固定。十九世纪的现实主义——库尔贝、巴尔扎克、易卜生式的社会剧——则把「身份与关系」当成题材的核心，这条路可以直接追溯到市民剧的主张。

## 八、本节总结

::: key 本讲要点
- 「美在关系」把美放在对象的关系结构与主体的知觉之间，两头都不单独成立。
- 实在关系与知觉关系的区分给出客观基础与发生条件；绝对美与相对美的区分则标明比较的作用。
- 对秩序、比例、和谐的批评是限定而非废弃：它们只是关系的一种。
- 市民剧以「身份」代替「性格」，以「画面」代替情节机巧，第四堵墙要求舞台自成世界。
- 主要困难：关系无限导致定义空转、理论偏认知而弱于强度、第四堵墙与《演员奇谈》的张力未解。
:::

狄德罗的贡献是把美学从「美是什么」拉向「关系如何被看见」。批评因此有了具体工作：指出作品组织了哪些关系，漏掉了哪些。代价是理论难以收束——关系可以无穷列举，判断最终仍靠眼光。

值得继续追问的问题：如果美的知觉依赖文化准备，那么「揭示关系」的批评是否只是在向已经懂的人解释他们已经看到的东西？
