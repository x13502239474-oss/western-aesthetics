## 一、本节导入

1857 年 1 月，福楼拜的《包法利夫人》开始在《巴黎评论》连载，不久被以「伤风败俗」的罪名起诉。检察官逐段朗读他认定的淫秽段落，控诉小说「没有理想」；福楼拜胜诉，小说同年成书。一个世纪之后，同一部书进入文学教科书，被当作现实主义叙事的典范。

这中间发生了什么？小说一个字没改，评价却翻转了。常见的解释有两种：一是文学观念进步了，读者终于「看懂」；二是时代宽容了，道德尺度放松了。两种解释都把评价的变化归给文本之外的某种进步，文本本身仍是一个固定的对象。

接受美学（Rezeptionsästhetik）提出的说法不同：意义在阅读中生成，而阅读总带着特定的期待。文学史如果只记录作品与作者，就漏掉了使作品成为作品的那一半。

## 二、核心知识：期待、空白与具体化

::: def 期待视野（Erwartungshorizont）
读者在进入一部作品之前所带的整套预期，包括对文类的知识、对已读作品的记忆、对虚构与现实的界线的理解。**例**：拿起一本侦探小说，你预期有案件、有嫌疑人、有揭晓；读到第三章还没有尸体，你就会不安。
:::

姚斯（Hans Robert Jauss）把期待视野拆成三个层次，这三层是同一套预期的不同来源。

1. **先前作品的规范。** 文类的成规、母题、格律、叙事惯例。读十四行诗，你预期十四行与特定的押韵格局。
2. **读者熟悉的文学史经验。** 他知道这部作品在文学传统中处于什么位置，此前有哪些同类作品。**例**：1857 年的读者读过巴尔扎克与乔治·桑，会用那套现实主义标准衡量福楼拜。
3. **虚构与现实的对照。** 作品许诺一个世界，读者带着对现实的认知去比对。**例**：小说写外省医生的妻子如何花钱、如何偷情，读者会问「这样的人可能存在吗」。

::: def 空白（Leerstellen）
文本中没有被明确填充、需要读者自行补足的地方。**例**：小说写「他推开门」，没有写门后有什么；读者的想象必须补上一个房间，否则读不下去。
:::

::: def 隐含读者（implizierter Leser）
文本结构所预设的读者角色，既非真实的个人，也非理想的完人，而是文本为完成自身而要求的那个位置。**例**：一份使用说明预设读者会按步骤操作；一首写给「你」的情诗预设读者接受这个称呼。
:::

伊瑟尔（Wolfgang Iser）的模型可以这样概括：文本由「图式化方面」构成，方面之间留有空白与未定点；读者在阅读中不断填补，形成「具体化」（Konkretisation）。这个词来自英伽登（Roman Ingarden），他早已指出文学作品含有「未定点」，需要读者完成。

| 比较项 | 姚斯 | 伊瑟尔 |
| --- | --- | --- |
| 核心问题 | 文学史如何可能 | 阅读如何发生 |
| 关键概念 | 期待视野、审美距离、视野变化 | 空白、否定、隐含读者、召唤结构 |
| 文本的地位 | 在历史序列中起作用的事件 | 一套等待具体化的图式 |
| 读者的角色 | 带着历史预期的公众 | 被文本结构引导的参与者 |
| 方法 | 接受史、效果史 | 现象学的阅读过程分析 |
| 弱点 | 预设公众同质，难以处理差异 | 读者仍是文本的角色，缺少社会规定 |

## 三、代表人物：康斯坦茨的两个人

**姚斯**（1921—1997）战后在海德堡学习，师从罗特哈克（Erich Rothacker），1950 年代研究中世纪与法国文学。1966 年到新成立的康斯坦茨大学任教，1967 年发表就职讲演《文学史作为文学理论的挑战》，这篇讲演成为接受美学的宣言。他要把文学史从「作者与作品的编年」改写成「接受与效果的历史」，晚年的《审美经验与文学解释学》（1982）把兴趣转向审美经验的三种态度：创造、感受、净化。

**伊瑟尔**（1926—2007）同样在康斯坦茨任教，方法资源来自英伽登的现象学与英国小说理论。1970 年的《文本的召唤结构》提出空白与否定，1972 年的《隐含读者》建立读者角色的模型，1976 年的《阅读活动》把阅读描述为一种「被动综合」。他与姚斯共事多年，关心的问题却不同：姚斯问历史，伊瑟尔问过程。

**费什**（Stanley Fish，1938—）代表另一条路。他在 1970 年的《文学在读者中》提出「情感文体学」，主张分析的对象是读者逐字阅读时的反应；1980 年的《这堂课里有文本吗？》进一步提出「阐释共同体」：意义来自一个共同体共享的阐释策略，文本不提供独立的约束。

**英伽登**（1893—1970）是胡塞尔的学生，1931 年的《文学的艺术作品》区分了作品的四个层次（语音、意义、图式化方面、再现的客体），并提出「具体化」概念。伊瑟尔的空白说可以看作对这一步的激进化。

## 四、理论解析

### （一）姚斯要解决什么

1960 年代的德国文学研究有两股强势方法。马克思主义文学史把作品还原为社会经济关系的反映，作品成了证据；形式主义（以及后来的「作品内在解释」）把文本封闭起来，历史被排除在外。两者共享一个盲点：读者不在场。

姚斯的判断是，文学史之所以危机，因为它把作品当成「已完成的事实」，只在作者与作品之间建立因果。他要引入第三个项：读者。他的讲演以七条论纲展开，前三条最关键。

1. **文学史是接受史。** 作品的意义在读者的接受中实现，离开接受，作品只是一堆印刷符号。
2. **接受有历史条件。** 每一代读者的期待不同，因此同一部作品在不同时代显现不同面貌。
3. **期待视野可以重构。** 研究者可以通过文类知识、同期作品与时代语言，重建某一代读者的预期。

### （二）审美距离与视野变化

姚斯用「审美距离」描述作品与期待之间的距离。距离为零，作品完全满足期待，读起来顺畅，也容易被遗忘；距离过大，作品难以被接受，可能被斥为胡闹；介于两者之间，作品「否定」了期待，又仍可被理解，这类作品最可能进入经典。

**例**：《包法利夫人》的叙事冷静到近乎冷酷，不提供道德评判，也不给读者可同情的中心人物。1857 年的读者习惯了巴尔扎克式的全知叙述与热情评论，福楼拜的「无个性」让他们愤怒。这就是一次视野的否定。

由此，文学史可以重写为「视野变化」的历史：它记录的是期待被打破、重组、再固化的过程；这并非一部作品越来越好的进步史。姚斯说，后来的读者会带着新的期待重读旧作，旧作因此获得新的位置。

这个方案有一处循环。若「突破期待」既是作品价值的标准，又是它进入经典的原因，那么评价就依赖事后结果：经典之所以经典，因为它突破了期待；它突破了期待，因为它是经典。姚斯后来用「视野融合」来缓解这个循环，效果有限。

### （三）伊瑟尔：文本如何召唤读者

伊瑟尔的出发点是：文学文本不提供完整的信息，它只提供「图式」。读者必须把图式连成意象，这个过程他称为「被动综合」：被动，因为读者受文本引导；综合，因为读者在意识中构造了连贯。

「空白」是这套模型的枢纽。空白指文本有意留下的不连接处：对话的中断、描写的省略、视角的切换。空白迫使读者停下来，调动自己的经验去填补。填补不是任意的：文本的上下文限制了可接受的补法。

「否定」是另一侧。文本可以否定读者已有的规范，把熟悉的观念悬置起来，使读者在阅读中修正自己。**例**：一部小说让叙述者不断自我拆台，读者对「叙述可信」的预期被否定，于是开始怀疑所有叙述。

「召唤结构」（Appellstruktur）把两者合起来：文本的结构在召唤读者参与，文本的意义是这次参与的产物。伊瑟尔强调，这并不意味着读者可以随心所欲；文本的图式像乐谱，演奏可以不同，跑调却听得出来。

### （四）姚斯与伊瑟尔的差别

两人常被并称，问题却分属两个层面。姚斯处理的是历史：一代代读者的期待如何变化，文学史如何据此重写。伊瑟尔处理的是现象学：一个读者在一次阅读中如何构造意义。

这个差别带来不同的困难。姚斯的「期待视野」需要一个可辨认的公众，但历史上的读者并不均质：1857 年读《包法利夫人》的人里，有外省医生，有巴黎文人，有审查官，他们的期待并不相同。伊瑟尔的「隐含读者」是一个结构位置，它解释了文本如何要求读者，却说不清真实读者的性别、阶级与教育如何改变阅读。

费什的方案是对两者的回应：把「读者」换成「阐释共同体」，意义来自一群共享策略的人。这个方案在社会性上更强，代价是文本的约束几乎消失：如果共同体决定一切，那么文本还剩下什么？

::: warn 「隐含读者」不是真实读者
伊瑟尔的隐含读者是一个文本结构，指文本为完成自身所要求的位置；它不指某位具体的先生或女士，也不指统计意义上的平均读者。把它等同于真实读者，会带来两个误判：以为文本已经规定了阅读的结果，以为读者的差异可以被文本吸收。姚斯的期待视野有同样的困难：它描述的是一代人的文类预期，不能代替对具体读者的调查。
:::

### （五）最强反对：抽象的读者

康斯坦茨学派受到的最有力的批评，是指它把「读者」抽象化了。

第一，社会史的批评。姚斯的期待视野建立在文类史与观念史上，读者被设想为一个共享同一套文学习惯的群体；实际阅读却受阶级、教育、地域、性别的分割。1970 年代后期，社会史取向的研究者主张，接受史应当接入书籍史、读者史与教育史，而非只处理文类规范（转述）。

第二，经验研究的批评。美国学者拉德威（Janice Radway）1984 年的《阅读言情小说》访谈了真实的女性读者，发现她们的阅读快感与「逃避」「确认自我」等具体需求相关，无法从文本结构中推出（转述）。这类研究把「读者」从结构位置还原为有生活处境的人。

第三，理论的批评。伊瑟尔的隐含读者仍是文本的产物，它解释了「文本要求什么样的阅读」，没有解释「谁在阅读」。批评者因此说，接受美学完成了从作者到读者的转移，却把读者变成了另一个功能性的构造。

姚斯晚年的回应是把「审美经验」引入，强调阅读中的享受、认同与反思；这条路线承认读者的多样性，却没有给出处理差异的方法。

## 五、经典原著：一篇就职讲演

1967 年，姚斯在康斯坦茨大学发表就职讲演，题为《文学史作为文学理论的挑战》。讲演针对的是当时文学史写作的困境：一是实证主义史学把作品埋进史料，二是形式主义把历史排除在外。姚斯说，两者都让文学史失去了读者。

讲演的骨架是七条论纲，加上对马克思主义与形式主义两派的批评，最后提出文学史的三种考察方式：历时、共时、以及两者与接受史的结合。全文不长，却是 20 世纪文学理论被引用最多的文本之一。

标题里的「挑战」有两个方向：文学史向文学理论挑战（理论不能回避历史），文学理论也向文学史挑战（史学不能回避读者）。

::: quote 姚斯就职讲演标题
Literaturgeschichte als Provokation der Literaturwissenschaft.
（文学史作为文学理论的挑战。）
:::

这个标题把「文学史」放在主语位置，意味深长：被挑战的是文学理论，被要求改变的是史学写法。

## 六、艺术案例：康定斯基《第七号构成》

1913 年，康定斯基完成《第七号构成》（现藏莫斯科特列季亚科夫画廊，约 200 × 300 厘米）。画面没有可辨认的对象：黑线像裂纹与藤蔓，横穿整幅；色块在线的两侧聚散，红、蓝、黄与灰绿互相挤压；中央偏左有一块浓重的暗色，四周被亮色包围。视点在画面上不断被牵引，找不到稳定的落点。

::: fig a-composition-vii | 《第七号构成》：黑线贯通画面，色块在线的分割中聚散，没有可供定位的中心
:::

用姚斯的框架看，这幅画 1913 年在慕尼黑展出时，面对的是一批以再现为默认预期的观众。他们的期待视野由印象派、象征主义与学院绘画构成：画应当画某个东西。康定斯基的作品否定了这条预期，观众的第一反应是「这是什么」。距离极大，接受因此延迟；等到抽象成为一套可辨认的语汇，后来的观众带着新的期待重看，作品的位置才稳定下来。

用伊瑟尔的框架看，这幅画把「空白」推到极限：没有对象可供辨认，图式化的方面几乎全靠色彩与线条的关系提供。观者必须自己构造连贯：某块红色是「火」还是「重量」，某条黑线是「边界」还是「运动」，取决于观看者的经验。这种构造受画面约束——线条的走向、色块的重量关系会驳回某些读法。

需要一点限定。康定斯基自己在 1911 年的《论艺术中的精神》里有一套相当强的纲领：色彩有内在的音响，绘画应当像音乐一样作用于灵魂。这套纲领说明，抽象并不等于让观者随意投射；它要求一种特定的、近乎通感的观看。伊瑟尔的模型适合描述这种「被引导的构造」，却不足以解释纲领本身的历史来源。

## 七、思想联系

向前，伊瑟尔的空白说直接来自英伽登的「未定点」与「具体化」，而英伽登的现象学来自胡塞尔；姚斯的「视野」借自伽达默尔的「视域融合」，他把融合改造成文学史的工具（参见本模块第 2 讲）。另一条线是俄国形式主义的「陌生化」：什克洛夫斯基说艺术使石头重新成为石头，姚斯的「审美距离」与这一思路较为吻合。

向后，费什的「阐释共同体」把读者社会化；拉德威与女性主义阅读研究把读者具体化；霍尔在文化研究中提出「编码／解码」，把接受分成主导、协商、对抗三种位置，这条线索通向本模块第 8 讲的视觉文化。数字时代的「参与式文化」把读者变成生产者，问题又以新的形式回来。

## 八、本节总结

- 接受美学把文学史改写成接受史，读者从背景变成方法的核心。
- 期待视野有三个来源：文类规范、文学史经验、虚构与现实的对照。
- 审美距离描述作品与期待的关系；距离过大或过小都影响接受。
- 伊瑟尔以空白、否定与召唤结构描述阅读过程，隐含读者是文本预设的位置。
- 姚斯处理历史，伊瑟尔处理过程；两人的读者都不是真实的个人。
- 最强的批评是「抽象的读者」：社会史与经验研究指出，实际读者被阶级、性别与教育分割。

值得追问的是：如果读者的期待决定了作品的面貌，那么教育在做什么——是在培养更敏锐的读者，还是在生产某一种期待？

::: key 本讲要点
- 姚斯：期待视野、审美距离、视野变化，三者构成接受史的方法。
- 伊瑟尔：空白与否定构成召唤结构，阅读是具体化的过程。
- 隐含读者是文本的角色，不能等同于真实读者。
- 费什以阐释共同体替代读者，强化社会性，弱化文本约束。
- 康斯坦茨学派的核心弱点，是把读者抽象化。
:::
