## 一、本节导入

1907 年，二十六岁的毕加索关起画室门，完成了一幅近两米半见方的大画。画里五个女性彼此不对视，右侧两张脸长着非洲面具般的条状刻痕，左侧一张脸像被斧子劈过的伊比利亚石雕；整幅画的空间被压成一块浅浮雕，几乎没有一个稳定的地面。这幅《亚维农少女》当时几乎无人能接受，连毕加索的朋友们都觉得它糟糕。它长期被卷在画室里，直到多年后才首次公开展出。

今天它挂在纽约现代艺术博物馆最显眼的位置，被当作现代艺术的分水岭。这中间发生了什么？本讲要处理的是一个具体的美学问题：当绘画不再服从「从一个固定位置看出去」的透视制度，当同一张脸可以同时出现正面和侧面，画家究竟放弃了什么，又换来了什么。要回答它，必须先回到一个几乎不出现在巴黎画坛中心的人——塞尚。

## 二、核心知识：空间的解体与重组

先厘清几个术语，它们都围绕一个共同的动作：把文艺复兴以来那套「单点透视」的空间契约拆开。

::: def 多视点（multiple viewpoint）
把从不同观看位置、不同时刻看到的面，并置到同一幅画面里的做法。传统单点透视假设一只固定的眼睛，所有物象都朝同一个灭点收缩；多视点取消了这只固定眼睛，让桌面的俯视、杯子的侧视、脸的正面与侧面同时在场。例子：毕加索画一只杯子，杯口画成从上方看到的圆形，杯身画成从侧面看到的轮廓，两套信息拼在同一只杯子上。
:::

::: def 立体主义（cubism）
约 1907 至 1914 年间，由毕加索与布拉克先后发展出的绘画方法：把对象拆解为几何化的切面，再从多个角度同时呈现，放弃单一视点与统一光源。它的名称来自批评家沃塞勒对布拉克作品的讥讽——大意是「一堆小立方体」。它通常分为分析立体主义（1909—1912，拆解对象、近乎单色）与综合立体主义（1912 年以后，引入拼贴与更整块的色面）。
:::

这两个术语背后，是塞尚留下的一条提示。塞尚晚年反复表达：印象派抓住了光在视网膜上的一瞬，却让形体「塌」了下去——苹果的圆、山的重量、桌面的稳定，都在闪烁的笔触里溶解。他想做的，是既保留印象派的明亮色彩，又恢复古典绘画的坚实结构。他的办法可以概括为「调制」（modulation）：不用单一光源的明暗去塑造体积，而用相邻色块之间的冷暖与明暗过渡来暗示形体转折。

::: def 调制（modulation）
用色块之间连续的色彩关系塑造体积的方法，用以替代传统的明暗晕染与单一光源。例子：塞尚的静物里，一只苹果向阳面偏暖黄、背光面偏冷蓝，中间由若干过渡色块衔接，体积感来自色块序列，而非一条清晰的明暗分界线。
:::

把这一方法推向极端，就自然触及透视：既然体积不再靠灭点和阴影来保证，那么维系「像」的那套单点透视也可以被松动。塞尚的画面里，桌布边缘会微微翘起、桌面朝观者倾斜、一只罐子的口和底可能各取不同的视点。观者不再被安置在画外的一个固定位置，而是被迫绕着物象「走」了一圈。这就是「空间的解体与重组」：解体的是文艺复兴以来的单点透视制度，重组的是由色块与多视点拼接起来的、属于画面自身的空间。可以放进一张对照表里看清楚：

| 维度 | 单点透视传统 | 塞尚与立体主义 |
|------|-------------|---------------|
| 眼睛 | 一只固定的眼睛 | 多只眼睛、多个位置 |
| 空间 | 朝一个灭点收缩的纵深 | 被压平、由切面拼合 |
| 体积 | 靠明暗与阴影 | 靠色块的调制与冷暖 |
| 光源 | 统一光源 | 取消统一光源 |
| 观者位置 | 画外一个固定点 | 被迫绕行、无处立足 |

## 三、代表人物：塞尚、毕加索与布拉克

塞尚（Paul Cézanne，1839—1906）生于普罗旺斯的艾克斯，家境优裕，性格孤僻，常年往返于巴黎与故乡。他早年参加印象派展览，却始终与印象派保持距离。对他影响最深的转折在于：他认定印象派的「瞬间」牺牲了形体的永恒性，于是把后半生都押在「用色彩重建结构」上。他几乎不出席沙龙，独自在故乡反复画同一座圣维克多山，晚年说他的目标是从自然里「实现」（réaliser）出某种坚实的东西——大意是，把自然的混沌组织进一个自足的画面结构。研究者通常认为，正是这份孤独的固执使他成为「现代绘画之父」：马蒂斯、毕加索都称他为「我们所有人的父亲」。

毕加索（Pablo Picasso，1881—1973）与布拉克（Georges Braque，1882—1963）都在这条路上受了塞尚的直接影响。1907 年，巴黎举办塞尚大型回顾展，毕加索深受震动；同一年他画出《亚维农少女》，被普遍视为立体主义的起点。1908 年起，布拉克与毕加索几乎形影不离地合作，发展出分析立体主义。布拉克的贡献长期被毕加索的巨大名声遮蔽：分析立体主义的许多关键手法——取消景深、引入字母与质感、进而走向拼贴——布拉克都走在前面。把两人并置，是为了说明立体主义并非单一天才的爆发，它是一场持续数年的、可相互印证的形式实验。

## 四、理论解析：形式主义如何为塞尚辩护

立体主义在公众眼里是「画得不像」，在理论界则需要一套能自圆其说的辩护。这套辩护来自形式主义批评，它与本课程第七模块第三讲（贝尔与弗莱的形式主义）直接相关。

罗杰·弗莱（Roger Fry）1910 年在伦敦格拉夫顿画廊举办「马奈与后印象派」展览，把塞尚、梵高、高更带到英国公众面前，遭到猛烈嘲讽。弗莱辩护的核心是：绘画的价值不在于它再现了什么对象，而在于它的形式组织——线条、色彩、块面的安排本身就能唤起一种特殊的审美情感。克莱夫·贝尔（Clive Bell）随后在《艺术》（1914）里把这一点提炼成「有意味的形式」。

::: def 有意味的形式（significant form）
贝尔在《艺术》中提出，视觉艺术中唤起审美情感的，是线条与色彩以特定方式组织起来的「形式」，这种形式与它再现的现实内容无关。例子：同一座山，风景明信片式的写实画与塞尚的《圣维克多山》，差别不在山的「像不像」，而在色块与笔触组织的「意味」。
:::

按这套逻辑，塞尚笔下歪斜的桌布、错位的罐口都获得了解释：它们并非画错，其目的在于服从画面的形式需要。弗莱为塞尚辩护时的大意是，塞尚把「逼真」从绘画的最高目标降为可取舍的手段之一，从而让绘画第一次真正为自己的形式负责。这套辩护把塞尚、毕加索的探索解释成一场纯形式的自律演进，很有力，也有盲点：它较少回答，为什么是 1900 年前后的欧洲、而非别的时间地点发生了这件事；非洲雕刻进入《亚维农少女》时，那种借用里裹着的殖民式观看又该怎么算。这些盲点，本模块第七讲还会在格林伯格那里再次出现。

::: warn 常见误解
有人认为「有意味的形式」意味着内容完全不重要、艺术与生活无关。贝尔与弗莱的表述更准确的读法是：他们主张审美判断的根据在形式，而非主张绘画必须放弃一切主题。把「形式优先」读成「内容无用」，是一种过度简化。
:::

## 五、经典原著：塞尚的信与贝尔的《艺术》

立体主义与形式主义各自有一份关键文本。

塞尚的文本主要是书信。1904 年他致年轻画家贝尔纳的信里，留下那段被反复引用的话。这里不作逐字引用，只转述其大意：塞尚建议贝尔纳把自然当作圆柱、球体和圆锥来处理，让一切物体都纳入透视之中；他又说，素描与色彩不可分离，颜色越和谐，素描就越精确。这段话的价值在于，它把「几何体块」与「色彩调制」绑在一起：体积的建立依靠色彩的秩序，线条的作用退居其次。

贝尔的《艺术》（1914）则系统化了形式主义的命题。他在书中提出「有意味的形式」，并把它当作一切视觉艺术共同的性质：一幅画、一件雕塑、一件瓷器，只要能唤起那种特殊的审美情感，就拥有它。贝尔进而把这种情感与日常生活的情感区分开，认为前者与利害、联想、宗教、性都无关。此处均为转述，不引原文。

::: quote 塞尚致贝尔纳的信（转述）
塞尚在此处的大意是：把自然当作圆柱、球体与圆锥来处理，让一切物体都服从透视；色彩与素描不可分，颜色越是和谐，素描便越是准确。
:::

这两份文本一个来自画家、一个来自批评家，却指向同一个方向：绘画的合法性，从「再现得对不对」转向「形式组织得好不好」。这一转向正是立体主义被接受的理论前提。

## 六、艺术案例：《亚维农少女》与《格尔尼卡》

先看《亚维农少女》（1907，布面油画，243.9 × 233.7 厘米，藏纽约现代艺术博物馆）。这是立体主义的起点，可以对照作品逐项看。

第一，构图近乎对称，五个女性站在被压扁的空间里，背景像一块浅浮雕，没有纵深。第二，脸的处理分裂成两套语汇：左侧一张近伊比利亚石雕的抽象轮廓，右侧两张直接取非洲面具的条状刻痕与尖长鼻梁——这是毕加索在特罗卡德罗人种学博物馆看到非洲雕刻后的挪用。第三，形体被分解为棱角分明的切面，肩、肘、膝以锐角转折，连续的肉体轮廓被打断。第四，蓝、赭、粉三组色块平涂并置，阴影不再统一于一个光源，明暗失去了方向。第五，背景由横向与斜向色带切分，帷幔与身体的分界被故意含混。

把这些形式特征串起来看，「多视点」就具体化了：同一张脸可以同时呈现正面与侧面，观者不再有一个固定的站立位置。这正是塞尚「用几何体块处理自然」的彻底化——毕加索把塞尚温和的调制推成了断裂的切面。

::: fig a-avignon | 《亚维农少女》五个女性：左侧伊比利亚式轮廓，右侧非洲面具式刻痕，空间被压成浅浮雕
:::

三十年后的《格尔尼卡》（1937，布面油画，349.3 × 776.6 厘米，藏马德里索菲亚王后国家艺术中心博物馆）把这套语言用于一场真实的政治暴力。1937 年 4 月 26 日，德国秃鹰军团与意大利空军对西班牙巴斯克小镇格尔尼卡实施轰炸，正值西班牙内战。毕加索受托为巴黎世博会西班牙馆作画，以这次轰炸为题材。

看形式：第一，全画只用黑、白、灰三色，色彩被抽掉，只剩明度对比，近于新闻照片与报纸的质地。第二，横向长幅可分三段——左侧公牛与怀抱死婴的母亲，中央垂死的马与一颗灯泡状的「眼睛」，右侧坠楼者与火焰。第三，中央的灯泡像一只眼，放射状短线构成光晕，把光源与注视合成一体，照亮这场屠杀却不指明敌我。第四，形体被切成几何块面并错位：人脸同时有正侧两面，肢体被拉长、翻转、拼接。第五，画面表层有报纸网点般的颗粒与条纹，近于拼贴的质感。

这里最值得注意的，是「形式的解体」与「内容的重组」同时成立：立体主义的切面法原本用于静物与肖像，是一种形式实验；在《格尔尼卡》里，它被用来拆解一场轰炸的视觉秩序——没有国旗、没有军装、没有英雄，只有被撕开的身体。毕加索拒绝把画做成宣传海报，却让分解的形式本身成为一种对暴力的表达。用本课程前面的话说，这与本雅明所谈「政治化的艺术」、阿多诺对介入式艺术既重视又保留的态度，构成一场三方对话（参见第七模块）。

:::

## 七、思想联系：从透视制度到形式主义批评

向前追溯，立体主义推翻的是阿尔伯蒂以来的单点透视制度——那套制度曾在拉斐尔《雅典学院》里被实现为理性的舞台（参见第九模块第三讲）。透视把观者锁在一个固定视点上，也把「真实」定义为这只固定眼睛所见的投影；立体主义用多视点打破了这把锁，等于宣告「真实」可以是观看方式的综合，而不必是单一视点的忠实记录。

向后看，立体主义的分解法直接通向两处：其一是抽象艺术——当切面进一步脱离对象，剩下的就是纯粹的形式与色彩，这正是康定斯基与蒙德里安的方向（参见第九模块第七讲）；其二是拼贴与达达——布拉克、毕加索 1912 年前后把报纸、壁纸直接贴上画布，打破了「绘画是画笔与颜料」的媒介边界，为后来更激进的媒介实验开了头。

理论层面，立体主义与形式主义批评互相成就：弗莱、贝尔需要塞尚这样一位「为形式负责」的画家来支撑自己的命题，而塞尚、毕加索也需要形式主义这套话语，才能把「画得不像」转译为一种正面的美学立场。这场互相成就，本身就是本模块反复处理的主题：理论与作品并无固定的先后，它们总是在具体的历史时刻互相证成。

## 八、本节总结

::: key 本讲要点
- 塞尚用「调制」以色彩构造体积，并松动单点透视，为立体主义铺路。
- 立体主义以多视点把不同角度的面并置到同一画面，拆解了固定视点与统一光源。
- 《亚维农少女》借非洲雕刻与伊比利亚石雕，把塞尚的几何化推向断裂的切面。
- 《格尔尼卡》用黑白灰与切面语言回应政治暴力，形式解体与内容重组同时成立。
- 形式主义（弗莱、贝尔）为「画得不像」提供了理论辩护，其解释也留下了历史与殖民视角的盲点。
:::

- 塞尚的「调制」以色彩关系塑造体积，松动单点透视，为立体主义提供方法起点。
- 立体主义通过多视点并置，拆解固定视点、统一光源与连续轮廓，重新定义了绘画的空间合同。
- 《亚维农少女》把塞尚的几何化推向断裂切面，并借用非洲雕刻与伊比利亚石雕。
- 《格尔尼卡》用黑白灰与切面语言回应西班牙内战中的轰炸，形式解体与内容重组同时成立。
- 形式主义批评（弗莱、贝尔）为「画得不像」正名，其「形式优先」的解释也留下了历史与殖民视角的盲点。

值得继续追问的问题：当形式主义说「审美与再现内容无关」，《格尔尼卡》那种能唤起强烈道德反应的题材，它的力量究竟来自形式，还是来自形式之外的现实指涉？这个追问，正是本模块最后一讲（电影与蒙太奇）要再次面对的「建构 vs 再现」之争的前奏。
