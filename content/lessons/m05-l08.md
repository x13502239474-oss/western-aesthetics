## 一、本节导入

1802 年冬，耶拿。谢林二十七岁，已经在大学教授职位上待了四年。他在讲一门叫「艺术哲学」的课，听课的人不多，讲义当时没有出版。同一座城里，施莱格尔兄弟在讲浪漫诗，诺瓦利斯刚去世一年，费希特刚离开，黑格尔还在默默写他的第一本书。

谢林在讲义开头提出一个命题：艺术是哲学唯一真实而永恒的工具，同时是哲学的证书。这句话听上去像一句颂词，其实是一个技术性的解决方案。它要解决的是这样一个困局：哲学的任务是认识「绝对」，也就是主体与客体尚未分裂的那个整体；可是哲学的表达必须用概念，概念的本性就是区分——主词与宾词、普遍与特殊、一与多。用概念去说不可分的东西，话一出口就已经分开了。

如果这个困局成立，哲学就面临一个尴尬：它最想说的东西，恰恰是它说不出的。谢林的方案是把这项任务转交给艺术。艺术作品也是一个「东西」，它有物质、有形式、有确定的边界；可是它又不像概念那样切割对象，它在感性形象里让对立的两面同时在场。于是艺术成了哲学的出口，哲学家成了艺术的解释者。

## 二、核心知识：四个关键词

::: def 同一哲学（Identitätsphilosophie）
谢林 1801 年前后形成的体系主张：主体与客体、观念与实在、自由与必然在「绝对」中同一，这种同一超出了 A＝A 的抽象同一，堪称「同一的同一」——绝对本身既非主体也非客体，它是二者的无差别（Indifferenz）。**例子**：磁石的南北极在同一块石头里互相对立又互相依赖；有机物里目的与机械互为条件，你无法说哪一方是本源。同一哲学要求从这种「对立中的统一」出发，而不从任何一方出发。
:::

::: def 理智直观（intellektuelle Anschauung）
一种非感性的直观：主体在思想中直接把自己提升到绝对，并在这一行动中与对象合一。它区别于感性直观（看见一个对象）与概念思维（规定一个对象）。**例子**：当一个人不再把自己当作「观察世界的我」，而意识到「世界与我是同一个生产活动的两面」，谢林说这就是理智直观。它的麻烦在于无法向他人证明，只能要求他人自己去做。
:::

::: def 审美直观（ästhetische Anschauung）
理智直观的客观化。同一个直观，在哲学家那里是内在的、私人的，在艺术家那里外化为作品，成为人人可看的对象。**例子**：哲学家用概念描述「自由与必然的合一」，悲剧诗人让俄狄浦斯在不知情中完成自己的命运，观众在舞台上看见了这种合一。前者需要论证，后者只需要看。
:::

::: def 艺术中的无意识
谢林用来指创作中超出艺术家清醒意图的那一层。艺术家按技艺工作，作品却带出他没有预先想到、也无法完全说明的东西；作品完成后比作者所意识到的更多。这个概念把康德的「天才为艺术立法却不能说明规则」本体论化了：无意识不再是心理学的边缘现象，而被看作绝对在主体中的活动。
:::

四个词连成一条链：绝对需要直观 → 直观分两种 → 审美直观是理智直观的客观化 → 客观化之所以可能，因为创作本身带有无意识。谢林的美学就架在这条链上。

## 三、代表人物：早熟的体系家

谢林（Friedrich Wilhelm Joseph Schelling，1775—1854）生于莱昂贝格，父亲是牧师。他十五岁进入图宾根神学院，与荷尔德林、黑格尔同住一间宿舍，三人一起读康德、读希腊悲剧、讨论法国大革命。1798 年经歌德与席勒推荐，二十三岁成为耶拿大学教授，此后与费希特、施莱格尔兄弟、诺瓦利斯往来密切，被视为浪漫派的哲学代言人。

他的思想有一条陡峭的曲线。1794—97 年的「自然哲学」时期，他把自然界说为「看得见的精神」，拒绝把它当作死物；1800 年的《先验唯心论体系》从自我出发推演到自然；1801 年起进入「同一哲学」，写作《我的体系的阐述》《布鲁诺》；1802—03 年在耶拿讲《艺术哲学》；1804 年《哲学与宗教》；1809 年《对人类自由本质的哲学探讨》出现转折，「根据」与「黑暗意志」进入体系；晚年转向「启示哲学」，与黑格尔的理性主义分道扬镳。

1841 年他在柏林开讲，目的是清除黑格尔死后弥漫的泛逻辑主义。听众里有青年恩格斯、克尔凯郭尔、巴枯宁。这场讲座标志他的第二次登场：从浪漫派的形而上学，变成存在主义与「后黑格尔」思想的源头之一。

## 四、理论解析：一条链与它的断点

### 第一步：问题的设定

康德的批判哲学留下一个「彼岸」：物自体不可知，自由只在本体界。费希特试图用「自我设定非我」把彼岸收回此岸，代价是自然沦为自我设定的产物，失去了独立性。谢林两边都不满意：自然如果有独立性，它就不能只是自我的影子；自我如果有实在性，它就不能从虚无中生出自然。

他的入手处是「生产性」（Produktivität）。自然在谢林那里首先是无限的生产活动，其次才是它生产出来的固定产物。**例子**：一条河流是流动本身，河床、三角洲、河道只是它某一刻的沉积。用产物去解释自然，就像用一张快照去解释奔跑。这个区分让他可以说：自然与精神是同一种生产活动的两个方向，一个向外造出物质，一个向内造出意识。

### 第二步：两极结构

同一哲学把体系排成两极。

| 维度 | 自然哲学 | 先验唯心论 |
| --- | --- | --- |
| 出发点 | 客体（自然） | 主体（自我） |
| 方向 | 从客观到主观 | 从主观到客观 |
| 方法 | 从产物回溯到生产 | 从生产推演到产物 |
| 终点 | 自然产生出精神 | 自我产生出自然 |
| 代表著作 | 《自然哲学观念》（1797） | 《先验唯心论体系》（1800） |
| 危险 | 陷入物活论 | 陷入主观唯心论 |

两极在「绝对」处汇合：从哪一头走，走到尽头都是同一个无差别的点。这个结构有一个明显的好处：它给了自然与精神同等的地位，避免了费希特式的唯我论。它也有一个明显的坏处：两条路既然都通向同一点，那么「走」本身还有什么意义？谢林的回答是，走的过程就是绝对自我展开的过程，哲学的任务是重演这个过程。

### 第三步：为什么需要艺术

《先验唯心论体系》最后一章是全书的转折。谢林在那里说，先验哲学从自我出发，一路推演到客观世界，最后停在两个东西面前：自由与必然的合一，以及「无意识的」活动。这两样东西哲学无法再往前推，因为它们正是哲学的前提。哲学能证明它们存在，却无法展示它们。

展示的任务交给艺术。论证可以拆成四步：

1. 绝对只能被直观，不能被概念穷尽；
2. 哲学家的理智直观是内在的，无法普遍传达，因此哲学永远有「私人性」的残余；
3. 艺术作品是唯一客观化的直观：它把创作者的自由（技艺、意图、构思）与被给予的必然（天才、素材、传统）统一在一个感性个体里；
4. 因此，艺术作品对哲学是工具（Organon，用来抵达绝对），对哲学史是文件（Dokument，证明绝对曾经被看见）。

第 3 步是全篇的枢纽，也是最难的一步。为什么艺术品能统一自由与必然？谢林的答案是：创作中有两个层次同时工作。艺术家清醒地安排材料、遵循规则，这是自由；可作品的成败往往取决于某种他无法完全控制的东西——灵感的到来、形式的自我生长、某个意外造成的恰好。作品完成后，艺术家常说自己「被某种东西推着走」。这一层在谢林看来并非心理偶然，它就是绝对在有限主体中的活动。

::: quote 《艺术哲学》开篇的命题（转述，非逐字）
艺术是哲学唯一的、真实的、永恒的工具，同时是哲学的证书。
:::

这句话里的「唯一」需要留意。它并不否认哲学能认识绝对，它否认哲学能独自完成这件事。哲学需要艺术作为它的客观证据，否则它永远只是少数人的内在经验。这个说法把艺术抬得很高，也把哲学降得很低：哲学成了艺术的注释。

### 第四步：艺术与有机自然的类比

谢林反复用有机体来类比艺术品。康德在《判断力批判》里指出，有机体的特点是「各部分互为因果」：叶子为整棵树存在，整棵树也为叶子存在，没有一方是单纯的手段。谢林接过这个结构，说艺术品同样如此：一句诗为整首诗存在，整首诗也为这一句存在；你无法把形式与内容拆开，拆开之后两样都不见了。

类比还有第二层。有机体是无意识的产物，它不知道自己为什么长成这样；艺术品是有意识的产物，艺术家知道自己在做什么。艺术品因此比有机体高一层：它同时是无意识的自然与有意识的精神。谢林用这个双重性解释为什么艺术能成为哲学的器官——它站在自然与精神的接缝上。

### 第五步：体系的反噬

这套论证有一个自我指涉的麻烦。如果艺术是绝对的唯一客观展示，那么谢林用来陈述这一点的《艺术哲学》讲义是什么？它用概念说「概念不够用」，用论证证明「论证无法抵达」。这个矛盾在谢林那里被一个等级序列暂时压住：艺术高于哲学，但关于艺术的哲学仍是最高的哲学。这个补丁并不牢固，它让哲学处在「低于艺术却有权给艺术排座次」的尴尬位置。

第二个麻烦是无意识概念的不可检验性。如果作品的意义可以超出作者意图，那么什么样的解释算是错的？谢林没有给出标准。这个缺口后来被解释学（伽达默尔）与精神分析（弗洛伊德）分别填补，但填法完全不同。

第三个麻烦是贵族主义。理智直观需要天才，审美直观需要天才的作品，那么没有天才的人在这一体系里处于什么位置？谢林没有回答。这个沉默在 20 世纪被阿多诺抓住：把真理寄托在少数天才的直观上，等于放弃了真理的公共性。

::: warn 「艺术高于哲学」不等于反理性
谢林把艺术放在哲学之上，常被读成他主张直觉高于理性。他要求的是同一种直观的两种形态：哲学家在内心里做的，艺术家在外在中做成了作品。理性并未被取消，它被要求承认自己的限度。把谢林读成非理性主义的先驱，会漏掉他全部体系性的工作。
:::

## 五、经典原著：一门没出版的课

《艺术哲学》是 1802—03 年冬季在耶拿的讲演，谢林生前没有出版，全文收在 1859 年的全集里。全书分两部分：一般部分讨论艺术的理念、艺术与哲学的关系、美与崇高的地位；特殊部分按门类讨论音乐、绘画、雕塑、诗（抒情诗、史诗、戏剧），并以悲剧收尾。

这本书的写法很有特点：它大量使用「构造」（Konstruktion）这个词，意思是把某个艺术门类从它在绝对中的位置推演出来，而不从历史经验归纳。例如音乐之所以排在造型艺术之前，因为在谢林看来声音比形体更接近纯粹的时间性。这种推演方式气势很大，可核对性很低：你很难说它错了，也很难说它对。

::: note 讲演与出版的距离
我们今天读到的《艺术哲学》来自讲稿与笔记，并非谢林亲手定稿的著作。这一点在引用时要留意：讲稿里的表述常有重复与松动，同一命题在不同段落的分量并不一致。把它当作一部完成的体系书来读，会高估它的严密程度。
:::

## 六、艺术案例：《俄狄浦斯王》与无意识的舞台

谢林在讨论悲剧时反复回到索福克勒斯的《俄狄浦斯王》。这出戏约作于公元前 429 年前后，雅典观众早就知道结局：俄狄浦斯会杀父娶母，会在真相大白后刺瞎自己。戏剧的张力因此不在「会发生什么」，而在「他何时知道」。

形式上有三处值得看。第一是「发现」（anagnorisis）的推迟。报信人、牧人、歌队轮番上场，每一场都把真相推近一步，俄狄浦斯却每次都用新的推理把它推开。他不是不聪明，他恰恰因为聪明而一步步走进陷阱：他追问、他比较、他排除，最后自己给自己定了罪。第二是歌队的位置。歌队在台上，却不参与行动；它唱的是普遍的道理，眼看着具体的人走向毁灭。第三是时间结构。戏从瘟疫开始，到放逐结束，前后不过一天，可这一天里被翻出来的是三代人的命运。

在谢林的读法里，这出戏演示了自由与必然的合一：俄狄浦斯每一步都在自由地行动，每一步又都在完成神谕。他越是自由，命运越紧。观众看见的正是这个「越挣扎越贴合」的结构——而这正是概念无法陈述的东西。用概念说「自由即必然」，只是一句悖论；用舞台演它，观众就信了。

这个例子也暴露了谢林论证的弱点。悲剧之所以能展示合一，靠的是一整套戏剧机制（推迟、反讽、歌队），而这些机制是技艺，是人有意识的设计。谢林要把它们归给无意识，可观众看到的恰恰是极其清醒的匠心。无意识在这里是一个解释性的剩余概念：凡是技艺解释不了的，就归给它。

## 七、思想联系

向前，谢林的直接来源有三个：斯宾诺莎的「实体」给了他「绝对」的模型；康德的第三批判给了他有机体与天才两个概念；费希特的「自我」给了他推演的方法。他把三者拧在一起，造出一个既有实体又有主体性的绝对。

向后，影响分两支。一支是黑格尔。黑格尔继承了谢林的「艺术是绝对精神的形式」这一框架，却把等级倒过来：艺术低于宗教，宗教低于哲学，因为艺术受感性形式的限制。黑格尔在《精神现象学》序言里还嘲笑过谢林式的「绝对」像一个「黑夜，其中一切牛都是黑的」——这是转述，不是原话，但意思是清楚的：没有中介的同一，等于什么都没说。

另一支是 20 世纪对谢林的重新发现。海德格尔在 1936 年与 1941 年两次讲《对人类自由本质的哲学探讨》，看中的是谢林把「根据」与「实存」分开的做法：绝对若要有根据，根据就不能完全在绝对之内，于是「黑暗」进入了神性。阿多诺在《否定辩证法》里批评同一哲学抹掉了非同一性，却承认谢林晚期对「不能概念化的东西」的敏感比黑格尔更早。两条线索合起来解释了谢林为何在战后走红：他是一个体系家，却给体系留了一个洞。

## 八、本节总结

- 同一哲学用「绝对中的无差别」解决康德留下的彼岸，代价是两条推演路线都通向同一点。
- 理智直观是哲学家的私人经验，审美直观是它的客观化，艺术作品因此成为哲学的器官。
- 「艺术是哲学的工具和文件」依赖一个前提：创作中有意识与无意识同时工作。
- 艺术与有机自然的类比提供了一座桥，也让艺术带上了自然目的论的包袱。
- 体系的反噬在于自我指涉：用概念证明概念不够用，用论证证明论证无效。
- 20 世纪对谢林的兴趣集中在「根据」与「无意识」两处，它们都是体系内的裂缝。

值得继续追问的是：如果作品的意义确实超出作者意图，那么解释的边界由什么划定？是由作品的形式，由作者所属的传统，还是由读者共同体的共识？谢林把这个位置留给了「绝对」，而绝对不说话。

::: key 本讲要点
- 谢林的美学是同一哲学的出口，不是一个独立的美学部门。
- 「艺术高于哲学」的确切含义是：艺术提供了哲学无法提供的公共证据。
- 无意识概念把康德的天才说本体论化，也因此不可检验。
- 黑格尔接受框架、颠倒等级，把艺术放在宗教与哲学之下。
- 20 世纪重新发现谢林，看中的是同一哲学内部的裂缝。
:::
