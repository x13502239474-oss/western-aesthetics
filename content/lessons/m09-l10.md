## 一、本节导入

先看《战舰波将金号》（1925）里那段六分钟左右的「敖德萨阶梯」。画面里，人群沿着阶梯自上而下奔逃，士兵的队列却沿着另一条对角线自上而下推进，两条逆向的线在同一个画面里相撞；镜头在极短的时间里频繁切换，一会儿是全景里密密麻麻的人，一会儿是近景里一张惊叫的脸，一会儿又突然插进一只「靴子踏下」的特写。最令人难忘的，是三只石狮的雕像被依次剪接——沉睡、惊醒、跃起——于是静止的石狮仿佛真的站了起来。

这段影像并不「写实」：真实的敖德萨阶梯没有这么长，屠杀也不是这样被一格格拼出来的。可它的情绪冲击，远超过一段连续的记录。这里藏着电影美学最核心的问题：意义究竟是「拍」出来的，还是「剪」出来的？围绕这个问题，20 世纪电影理论分成了两大阵营——爱森斯坦的蒙太奇与巴赞的长镜头，本讲要讲清这场争论的实质。

## 二、核心知识：蒙太奇与长镜头

先定义本讲的两个核心概念。

::: def 蒙太奇（montage）
来自法语「装配、组接」，指把不同镜头按照一定次序剪接起来，使它们在碰撞中产生单个镜头所没有的新意义。例子：一个面无表情的人脸，接一碗热汤，观众读出「饥饿」；接一具尸体，读出「悲伤」——意义来自并置，而非来自那张脸。
:::

::: def 长镜头（long take）
与蒙太奇相对，指用一个连续不断、时间较长的镜头完整记录一个动作或一个场景，尽量不做切割，以保持时空的连续与完整。例子：一个镜头跟随人物走过整个房间、开门、上楼，中途不切换，让观众在同一段连续时空里自行观察。
:::

这两个概念背后，是对「现实」的两套理解：蒙太奇认为电影的意义要靠镜头之间的碰撞去「建构」，长镜头则认为电影应当尊重现实本身的时空连续，让意义「自行呈现」。可以先用一张对照表把两派的立场摆出来：

| 维度 | 爱森斯坦（蒙太奇） | 巴赞（长镜头） |
|------|-------------------|---------------|
| 意义来源 | 镜头之间的碰撞与冲突 | 画面内部的时空连续 |
| 对现实 | 现实是被组接、被建构的 | 现实应被尊重其完整性 |
| 手法 | 短镜头、快节奏、理性剪辑 | 长镜头、景深镜头、场面调度 |
| 美学归属 | 建构论 | 再现论 |

## 三、代表人物：库里肖夫、爱森斯坦与巴赞

列夫·库里肖夫（Lev Kuleshov，1899—1970）是苏联蒙太奇学派的先行者，他的「库里肖夫效应」实验几乎是所有电影美学的起点：他把同一张演员面无表情的脸，分别与一碗汤、一具尸体、一个孩子组接，观众却分别读出了饥饿、悲伤与慈爱。这一实验指向一个结论：单个镜头的意义是不确定的，意义由镜头的组接产生。

谢尔盖·爱森斯坦（Sergei Eisenstein，1898—1948）把库里肖夫的「连接」推进为「冲突」。他不仅是导演，更是理论家，主张蒙太奇的本质是镜头的碰撞，而非镜头的相加——两个镜头像正题与反题，碰撞出一个合题，一个全新的概念。他的《战舰波将金号》正是这套理论的教科书。

安德烈·巴赞（André Bazin，1918—1958）则是另一极的代表。他是法国《电影手册》的精神导师，也是后来「法国新浪潮」的理论源头。他反对过度剪辑对现实的操纵，主张电影的本体在于摄影对现实的忠实记录，因而推崇长镜头与景深镜头，让现实在银幕上保持其时间与空间的完整。

## 四、理论解析：蒙太奇的「建构」与长镜头的「再现」

先讲爱森斯坦的蒙太奇理论。它的核心可以概括为「冲突剪辑」：蒙太奇的力量不在于把镜头「顺滑地接起来」，而在于让它们「相撞」。爱森斯坦把蒙太奇分为若干类型，按「冲突」的层次由低到高排列，可以这样理解：

1. **度量蒙太奇**：按镜头的物理长度剪辑，靠「长—短」的机械节拍制造节奏。
2. **节奏蒙太奇**：在长度之外加入画面内运动的节奏，让镜头切换呼应画面里的动势。
3. **调性蒙太奇**：按画面的情绪调性（明暗、冷暖、氛围）组织，追求整体情绪的统一。
4. **泛音蒙太奇**：让多种「声部」（运动、光线、构图）同时作用，产生类似泛音的复合效果。
5. **理性蒙太奇**：最高层次，用两个看似无关的镜头碰撞出一个抽象概念，比如用「克伦斯基」与「孔雀开屏」的并置去生产「虚荣」这一概念。

这五层的共同信念是「一加一大于二」：两个镜头并置，产生的第三个意义不来自任何一个单镜头，而来自它们的碰撞。敖德萨阶梯里的「石狮三连」就是理性蒙太奇的绝佳例子：沉睡、惊醒、跃起三只石狮本无时间关系，剪在一起却「制造」了石狮起身怒吼这一并不存在的动作——意义是被建构出来的。

再讲巴赞的长镜头本体论。他在《摄影影像的本体论》（1945）里提出：摄影不同于绘画之处，在于它第一次实现了「机械地、自动地」把现实记录下来的可能，影像是现实经由镜头直接「留下」的痕迹，因而具有一种本体论上的真实。基于此，他主张电影应当尊重现实的「时间的完整性与空间的不分割性」，反对用蒙太奇把现实切成碎片再按导演意图重组。他推崇长镜头与景深镜头（深焦），因为它们让观众在一段连续的时空里自行选择看什么，而不是被剪辑牵着鼻子走。此处均为转述。

::: def 景深镜头（deep focus）
让前景与后景同时保持清晰的镜头，观众可以在一个画面里自由地在前后景之间分配注意力。巴赞认为它比蒙太奇更尊重现实的含混性，因为它不替观众规定「此刻该看什么」。例子：一个前景人物与后景事件同时清晰可见，两者的关系由观众自己读出。
:::

两人之争的实质，可以归结为一句话：剪辑究竟是在「创造意义」，还是在「还原现实」。爱森斯坦站在建构一边：现实是素材，意义是导演用剪辑「造」出来的；巴赞站在再现一边：现实本身就有意义，导演的任务是尽量少地干预，让它自己显现。这正是本课程反复出现的「建构 vs 再现」之争，在电影这门最年轻的艺术里重演了一遍。

::: warn 常见误解
把巴赞理解为「反对一切剪辑」是一种简化。巴赞并不主张完全不剪，他反对的是「过度剪辑」——那种把现实的连续时空打碎、再按单一意图强制重组的手法。长镜头与景深是他的偏好，而非绝对的禁令。
:::

## 五、经典原著：从「第七艺术」到《摄影影像的本体论》

电影美学的文本史，可以先从「第七艺术」讲起。意大利人里乔托·卡努杜（Ricciotto Canudo）在 1911 年前后提出「第七艺术宣言」，其大意是：电影既是艺术又是工业，它综合了建筑、音乐、绘画、雕塑、诗歌与舞蹈这六种艺术，是全新的「第七艺术」。这一说法为电影争取「艺术」身份提供了最初的合法化话语——在那之前，电影常被当作马戏团式的杂耍。

爱森斯坦的蒙太奇理论散见于他的多篇文章与讲稿（后辑为《蒙太奇论》等），核心命题是：蒙太奇是冲突，是镜头之间的碰撞，它产生的是概念与思想，而非仅仅是叙事。这里只作转述。

巴赞的《摄影影像的本体论》（1945，后收入《电影是什么？》）则提出：摄影的本质是忠实记录，影像与被摄物之间存在一种「转移」关系，仿佛现实本身被复印到了胶片上；电影因此天然倾向于现实主义。此处均为转述。

::: quote 巴赞《摄影影像的本体论》（转述）
巴赞在此处的大意是：摄影影像第一次让现实不再经人手干预地被记录下来，它在本体论上区别于绘画；电影的美学因此应当建立在对现实连续性的尊重之上。
:::

这三份文本串成一条线索：卡努杜为电影争「艺术」名分，爱森斯坦为电影争「思想」能力，巴赞则为电影争「现实」品格。三者各自回答了「电影凭什么成为艺术」的不同侧面。

## 六、艺术案例：《战舰波将金号》的敖德萨阶梯

回到开头那段影像，逐项看它的形式处理。

看**节奏**：约六分钟的段落有逾一百五十个镜头，平均镜长远短于常规，节奏完全由剪辑而非场面调度产生。镜头越来越短，情绪越来越紧，观众的心跳被剪辑的节拍牵引。

看**逆向对角线**：人群自右上向左下奔逃，士兵队列自左上向右下推进，两条逆向的对角线在画面中相撞。这种构图把「冲突」先做在了每一个画面内部，再通过剪辑把它放大为整体结构。

看**局部替代整体**：反复插入「靴子踏下」的短特写，用一只靴子代表整支军队，把暴力抽象为机械的动作。观众看到的并非具体的士兵，却读出了「镇压」这一概念的视觉符号。

看**石狮三连**：沉睡、惊醒、跃起三个石狮雕像的镜头并置，产生石狮起身的错觉——这是理性蒙太奇的典范，一个并不存在的动作被剪辑「制造」了出来，用以隐喻「人民的觉醒」。

看**时间的拉长**：婴儿车沿台阶滑落的段落，交替使用全景、中景与主观视点，把真实时间拉长。真实的滑落或许只有几秒，剪辑却把它延展成一段漫长的、令人窒息的心理时间。

::: fig a-battleship-potemkin | 敖德萨阶梯：人群与士兵的逆向对角线相撞，石狮三连把静止雕像剪成「跃起」的错觉
:::

把这些手法合起来，就能理解爱森斯坦的信念：这段影像的力量不在「真实记录了一场屠杀」，而在「用剪辑精确计算了一场情绪」。时空在此并不写实，情绪却极其真实——这正是蒙太奇美学的核心悖论，也是巴赞日后要反对的东西。

## 七、思想联系：建构与再现之争的当代回响

向前追溯，电影为争取「艺术」身份的努力，承接的是整个现代主义对「媒介自律」的追求：正如绘画走向平面、音乐走向纯形式，电影也在追问「什么只有电影能做」。库里肖夫效应、蒙太奇与长镜头之争，本质上是「电影媒介的本性是什么」这一问题的不同回答。

向后看，这场争论的实质——建构还是再现——在 20 世纪后半叶继续发酵。巴赞的「现实本体论」受到结构主义与符号学的挑战：研究者通常认为，克里斯蒂安·麦茨（Christian Metz）等人的电影符号学指出，电影影像并非现实的透明复制，它同样是一套被选择、被编码、被组织的符号系统——镜头怎么摆、取哪个景别、何时起止，都是建构。这一反驳（此处为转述）等于把爱森斯坦的「建构论」以更精密的理论形态重新提了出来：即便是一个长镜头，也仍然是导演的一次选择。于是问题从「剪不剪」深化为「一切影像是否都已是建构」。

用本模块的术语说，这场争论呼应了形式主义与现实主义在绘画、文学里的老对手戏：形式主义相信意义来自形式的组织，现实主义相信意义来自对现实的尊重。电影只是把这场老争论，放到了一个「时间与运动」的新媒介里重演，并因此获得了新的尖锐度——因为在电影里，「形式」第一次能够直接操纵观众的时间经验。

## 八、本节总结

::: key 本讲要点
- 库里肖夫效应证明：单个镜头的意义不确定，意义由镜头组接产生。
- 爱森斯坦的蒙太奇是「冲突剪辑」，五种类型层层递进，最高形态是用镜头碰撞生产概念。
- 敖德萨阶梯以逆向对角线、局部特写、石狮三连与时间拉长，示范了「一加一大于二」的建构。
- 巴赞以摄影的「本体论真实」为据，主张长镜头与景深尊重现实的时空完整，反对过度剪辑。
- 两人之争的实质是「建构 vs 再现」：意义是剪出来的，还是现实自己显现的。
:::

- 库里肖夫效应揭示：电影镜头的意义由组接产生，而非单个镜头自身。
- 爱森斯坦以「冲突剪辑」为蒙太奇立法，五种类型由机械节拍递进到理性概念的碰撞。
- 《战舰波将金号》的敖德萨阶梯，用逆向对角线、局部特写、石狮三连与时间拉长示范了意义的建构。
- 巴赞以摄影的「本体论真实」为据，主张长镜头与景深镜头尊重现实的时空完整，反对过度剪辑。
- 两人之争的实质是「建构 vs 再现」；麦茨等人的电影符号学又指出，即使长镜头也仍是选择与建构。

值得继续追问的问题：如果连长镜头都是一种「选择」，那么「还原现实」是否只是一个不可能兑现的理想？但反过来，如果一切影像都是建构，我们又如何解释纪录片式的镜头与虚构镜头在观感上的真实差异？这个追问，正是电影美学至今仍在「建构」与「再现」之间摇摆的原因。
