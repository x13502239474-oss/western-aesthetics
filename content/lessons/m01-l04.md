## 一、本节导入

玻璃观景台伸出崖壁几米，脚下是透明的板，板下是数百米的空谷。多数人走上去的第一步是抓栏杆，第二步才敢往下看。心跳加快，手心出汗，膝盖发软，这些是身体在说「退回去」。可十几秒之后，几乎所有人都会再往下看一眼，甚至掏出手机拍照。恐惧没有消失，它和一种奇特的兴奋混在一起。

把这个经验与另一种对照：春日的湖面，风把水纹推成一格一格的光，人坐在岸边，呼吸放慢，不想动，也不想走。两种经验都叫「审美」，结构却相反。前者先拒绝后吸引，后者从头到尾顺畅；前者让人感到自己的渺小，后者让人感到世界的可亲。

美学史上把这两种形态分别叫做崇高与优美。它们的差别不只是强度，还是结构。本讲要说明这个结构差在哪里，以及为什么它值得用一整套哲学去处理。

## 二、核心知识：形式、边界与愉悦的类型

::: def 优美（grace）
审美形态之一，指形式的和谐、边界的清晰、运动的自如，其愉悦是直接而流畅的。拉丁语 gratia 兼有优雅、恩惠、魅力之义，中文「优美」「优雅」都落在这一族。
例子：猫从桌面跳下，落地几乎没有声音，四肢的屈伸在过程中完成，看不出用力的瞬间；同一个动作若由人笨拙地模仿，重心提前暴露，优美立刻消失。
:::

::: def 崇高（sublime）
审美形态之一，指对象在数量上绝对巨大或在力量上压倒一切，想象力无法把它统摄为完整直观，先引起痛感与压迫感，随后由理性能力或道德使命感的优越感转为愉悦。
例子：观景台上的空谷、雷雨中的海面、仰望没有光污染的星空；对象没有给出任何「合适的形式」，人却在失措之后感到自己被提升。
:::

::: def 消极愉悦（negative pleasure）
康德用来描述崇高感的术语：它经由不快而达到愉悦，因此是间接的、否定的。优美感是肯定的愉悦，崇高感则先经历想象的失败，再由理性的胜利补偿。
例子：恐怖片里，观众在安全座位上经历惊吓，散场后说「真过瘾」；这个「过瘾」建立在「我其实没事」的前提上。
:::

两种形态的差别可以列成一张表：

| 维度 | 优美 | 崇高 |
|---|---|---|
| 形式 | 有边界、有轮廓、比例可把握 | 无形式、无边界、超出尺度 |
| 想象力的状态 | 与知性自由游戏，顺畅 | 在度量或威力面前受挫 |
| 情感基调 | 直接的愉悦、爱、亲近 | 先痛后快、敬惧、距离 |
| 愉悦类型 | 肯定的 | 否定的（经由不快） |
| 主体根据 | 共通感的普遍可传达性 | 理性理念与道德使命的优越性 |
| 典型对象 | 花、湖、人体、室内乐 | 峡谷、风暴、星空、废墟 |

表中最容易被忽略的是第三行。优美拉近距离，崇高保持距离。观景台上的人之所以能享受恐惧，前提是玻璃不会碎；一旦玻璃出现裂纹，崇高一秒变成灾难。这个前提本身就是崇高经验的构成条件。

::: warn 「崇高就是很大的美」
把崇高当成「美」的加强版，会得出一个错误推论：越大的东西越崇高。实际经验恰好相反。一间巨大的仓库不崇高，因为它虽然大，却仍可被一眼丈量；一片雾中的山脊尺度并不惊人，却能让人失去方位感。崇高依赖的是想象力的失败，而非尺寸的纪录。康德的表述更彻底：崇高不能存在于自然对象之中，只能存在于我们的心灵里。
:::

## 三、代表人物：康德

康德（Immanuel Kant，1724—1804）一生几乎未离开柯尼斯堡，早年在大学任编外讲师，讲授逻辑、形而上学、自然地理与人类学，1770 年才获得教授职位。他的哲学转向发生在前批判期之后：1764 年出版的《论优美感和崇高感》还是一部人类学观察之作，把崇高与气质、性别、民族性格联系起来，笔调接近随笔；1781 年《纯粹理性批判》确立先验方法；1790 年《判断力批判》才把审美判断纳入批判体系。

这个转变的关键在于提问方式的改变。早期他问「哪些人容易感到崇高」，后期他问「崇高判断凭什么要求普遍赞同」。前者可以靠观察回答，后者只能靠先验论证。他的贡献是把崇高从生理反应与个人气质中解救出来，变成主体能力之间的关系；他的局限在于，这套论证要求鉴赏者具备文化修养，因此难以说明崇高经验的普遍性究竟覆盖多少人。

## 四、理论解析：从修辞术到主体性哲学

**第一阶段：朗吉弩斯与修辞学。**《论崇高》大约成于公元一世纪，作者身份不明，后世常称伪朗吉弩斯。这本书要解决的问题很实际：罗马帝国的演说术趋于精巧而失去力量，青年人写得出漂亮的句子，却说不出伟大的话。作者要找出那种「使人惊心动魄」的效果从何而来。

他的回答是技术性的。崇高有五个来源：庄严的思想、强烈的情感、辞格的使用、高雅的措辞、以及把词句组合成庄严整体的结构。这五项的前两项靠天赋，后三项可靠训练。全书大量举例，比较德摩斯梯尼与西塞罗，分析《创世记》「神说，要有光，就有了光」这样的句式为何有力。这是一部修辞学手册，它关心的是如何写出崇高，尚未关心崇高在自然中是什么。

**第二阶段：博克的生理学。**十七世纪末，布瓦洛把《论崇高》译成法文，这本书进入欧洲文人的视野。十八世纪，问题从文本转到心灵：崇高文体为何有效？因为人心中有一种能被巨大与危险激起的机制。博克 1757 年的《关于我们崇高与美观念之根源的哲学探讨》给出了生理学的答案。

他的论证分三步。第一步，把人的基本情欲分为两类：指向自我保存的，与指向社会交往的。第二步，把崇高归于前者，把美归于后者：凡危及生命、让人联想到痛苦与危险的对象，都激起崇高的感受；凡引起爱、亲近、绵延之感的对象，都激起美的感受。第三步，用神经的紧张解释两者：崇高的对象使神经处于紧张状态，紧张解除时产生的快感，他称为 delight，与正面的 pleasure 不同。

博克列举的崇高原因包括：巨大的尺度、晦暗、力量、空虚、无限、突然性、以及声响的宏大。这些描述非常准确，后来的经验研究大体沿用了他的清单。他的困难在于普遍性：如果崇高只是神经的紧张与松弛，那么「你应该觉得这崇高」就没有根据，只能说「你的神经如此反应」。

**第三阶段：康德的先验论。**康德保留了博克的观察，换掉了根据。他要证明的是「崇高判断凭什么具有必然性」，而非「人通常如何反应」。

数学的崇高处理「绝对大」。设想你站在金字塔前，或仰望星空：想象力试图把对象一次把握为整体，但它只能一寸一寸地度量，永远无法给出最后的总体；与此同时，理性却要求一个绝对的总体。想象力在这里失败，这个失败带来痛感。但理性的要求本身显示了理性超越一切感官尺度的能力，于是痛感转为愉悦——人意识到自己身上有一种不受感性限制的能力。

力学的崇高处理「绝对强」。面对风暴、火山、冰川，人感到自己肉体上的渺小与无力；但只要身处安全之地，理性就意识到自己有一种独立于自然的道德人格，这种人格的价值不被自然的威力所动摇。恐惧因此转为敬重，敬重的对象其实是自己身上的理性。

**反对意见。**康德的方案至少面临三种质疑。其一，精英主义：崇高判断以文化修养为条件，这意味着未受教养的人被排除在崇高经验之外，而经验事实恰好相反，面对风暴的渔民未必比教授少受震撼。其二，性别政治：二十世纪后期的一些研究者指出，崇高话语把「理性对感性的胜利」写成男性主体的自我确证，把优美与感性分配给女性，这套分配本身就是权力。其三，生态批评：把自然当作唤起主体崇高的舞台，自然只承担道具功能，它的独立价值被抹掉。此外，利奥塔与詹姆逊讨论的「技术崇高」提示，当代的无限性已由技术系统而非自然提供，康德的框架需要重新校准。

::: quote 《美学》第一卷，全书序论
因此，内容意蕴不能完全体现于表现方式，而且不管怎样希求和努力，理念与形象的互不符合仍然无法克服。这就是第一种艺术类型，即象征型艺术，以及它的希求，它的骚动不宁，它的神秘色彩和崇高风格。
:::

这段引文出自黑格尔对艺术类型的划分，位置在全书序论。它显示了崇高概念的第三次位移：在朗吉弩斯那里，崇高是文体效果；在康德那里，崇高是主体能力的关系；在黑格尔这里，崇高成了「理念与形象不相称」的类型学标记，专指象征型艺术——理念太抽象，形象太确定，两者无法彼此吻合，于是产生那种骚动、夸张、神秘的风格。三次位移共用一词，所指的对象已经换了三次。

## 五、经典原著：康德《判断力批判》

《判断力批判》1790 年出版，是三大批判的最后一部。全书分「审美判断力批判」与「目的论判断力批判」两部分，前者又分「美的分析论」与「崇高的分析论」。崇高的分析论从第 23 节开始，第 24 节划分数学的崇高与力学的崇高，第 25 至 27 节讨论数学的崇高，第 28 节讨论力学的崇高，第 29 节讨论自然崇高判断的模态。

这一部分篇幅只有美的分析论的三分之一，理论重量却相当。美证明想象力与知性可以和谐，崇高证明这种和谐被打破之后主体仍然完整；两个结论合起来，才是康德人类学的全貌。也正因如此，崇高在《判断力批判》里承担了额外任务：它把审美判断与道德哲学连接起来，为「美是道德的象征」提供支点。

这一部分的论证结构值得注意。康德先做否定的工作：崇高不属于任何一种形式，因此不能像美那样从「形式的合目的性」去解释；崇高感涉及想象力与理性的冲突，而美涉及想象力与知性的和谐。再做肯定的工作：冲突的结果是理性占优，愉悦由此产生。最后做限定的工作：这一切以「安全」与「文化修养」为条件，因此崇高判断的普遍性带有前提。

用一句话概括这一节的意思：崇高感是理性对想象力的一次胜利的见证，而胜利的代价是先承认失败。

## 六、艺术案例：贝尔尼尼《圣特雷莎的狂喜》

罗马胜利圣母堂的科纳罗礼拜堂，贝尔尼尼在 1647 至 1652 年间完成的组雕，表现阿维拉的特雷莎在异象中被天使的金箭刺入心脏。整组作品嵌在礼拜堂侧壁的壁龛里，上方是镀金的金属光线，从隐蔽的窗口射入自然光，下方是剧场式的台阶与包厢。

形式上有几处关键处理。第一，两个人体重心不稳：特雷莎的身体向后倾倒，落在云上，云本身像一块柔软的垫子，没有支撑点；天使一脚踏云，一手的箭指向她的心口，动作停在刺入前的瞬间。第二，衣褶被处理成深槽与高峰，凹处极深，凸处极薄，光线穿过时产生近乎透明的效果，大理石因此失去了石头的重量。第三，镀金光线从上方倾泻，把整个壁龛变成舞台，观者站在台阶下仰视，被安排在观众席的位置。

这组作品同时含两种形态。优美的部分在衣褶的流动、云朵的轻盈、天使年轻身体的曲线；崇高的部分在光线的暴力、身体的失重、以及那种把肉体经验写成神性事件的力量。若只按优美去读，会漏掉它的震撼；若只按崇高去读，会漏掉它的甜。

::: fig a-santa-teresa | 《圣特雷莎的狂喜》：身体后倾于云上，镀金光线自上方射入，壁龛把观者安排在仰视的位置
:::

这个案例对康德的框架构成一个温和的反例。康德的崇高要求「无形式」，而贝尔尼尼的崇高恰恰由极度精巧的形式（深槽、金光、舞台装置）制造出来。一种可能的回应是：这里的形式服务于「压倒」，形式越精巧，压倒感越强，崇高的结构仍在，只是媒介不同。另一种回应是：巴洛克的崇高属于另一个谱系，它靠感官的过量而非感官的失败。两种回应都成立，选择哪一种，取决于你更看重结构还是更看重媒介。

## 七、思想联系

向前追溯，崇高概念从修辞学中生长出来，带着「如何打动人」的技术基因；布瓦洛的翻译把它送入古典主义的论争，博克把它变成经验科学的问题，康德把它变成先验哲学的问题。

向后看，席勒在《论崇高》中把崇高与人的道德自由连接，认为崇高感证明了人能够超越感性；利奥塔在二十世纪讨论先锋派艺术时重新启用崇高，把它理解为「不可表现之物的呈现」；环境美学则批评崇高话语把自然当作人类自我确证的舞台，忽略了自然自身的价值。三条线都从康德出发，走向不同方向。

## 八、本节总结

::: key 本讲要点
- 优美是形式的和谐与愉悦的流畅，崇高是想象力受挫后由理性补偿的间接愉悦。
- 朗吉弩斯把崇高定为修辞效果，博克用自我保存与神经紧张解释它，康德用先验论证说明它的必然性。
- 康德的数学的崇高与力学的崇高，分别处理「绝对大」与「绝对强」，共同结构是挫败之后的提升。
- 崇高依赖安全与距离，这个条件使它在灾难现场立即失效。
- 黑格尔把崇高转为「理念与形象不相称」的类型学标记，概念从此承担了第三种含义。
:::

两种形态的不可通约性，最终落在愉悦的类型上：优美的愉悦可以直接给出，崇高的愉悦必须绕道不快。凡是把崇高说成「更高级的美」的理论，都会在解释这个绕道时失效。

值得继续追问的问题：技术时代的「技术崇高」——核爆、航天、气候危机——是否还保留了康德式的安全距离？当我们观看一场远处的灾难直播时，那种震颤属于崇高，还是属于消费？
