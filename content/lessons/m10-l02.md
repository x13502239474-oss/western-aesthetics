## 一、本节导入

假设两位批评家站在同一幅画前。甲说：我喜欢它，而且我有理由要求你也喜欢——因为它在我们每个人心里唤起同一种自由游戏，这种愉悦不靠概念、不靠利害，谁都一样。乙说：你喜欢它，是因为这件作品把一个时代所能达到的真理，用感性形状呈现了出来；你感到的愉悦，其实是精神在作品里认出了自己。

这两句话听着都能自圆其说，指向的却是两套完全不同的美学。甲的背后是康德（Immanuel Kant，1724—1804），《判断力批判》的作者；乙的背后是黑格尔（G. W. F. Hegel，1770—1831），《美学》讲演的作者。他们的年代只隔了一代，问题也同源，结论却把美学带向两条不同的路：一条通向审美自律、形式主义与「为艺术而艺术」；另一条通向艺术史哲学、真理内容与「艺术终结」论。

理解这次分岔，不能停在「一个讲主观、一个讲客观」的粗线条上。真正的问题是：审美判断的有效性，究竟从哪里取得担保？本讲就从这个担保问题切入。

## 二、核心知识：担保有效性的两种装置

两人都要回答「为什么我能要求别人同意我的审美判断」，但各自搬来的装置不同。

::: def 共通感（sensus communis，康德）
在《判断力批判》里，指一种诸认识能力自由协调的「主观原则」，它使人在判断美时能把他人「在思想中」一并考虑进去。它是审美判断得以要求普遍赞同的先验条件，与经验调查得出的多数意见分属两层。举例：你说一朵花美，并不需要统计别人的喜好，只默认那种愉悦对任何具同样心意能力的人都成立。
:::

::: def 绝对精神（absoluter Geist，黑格尔）
精神发展的最高阶段，涵盖艺术、宗教与哲学三种形态。三者都以绝对者为对象，只是把握方式不同：艺术用感性直观，宗教用表象，哲学用概念。举例：同一真理，希腊雕像用身体呈现，基督教用故事表象，哲学用概念论证。
:::

两者的差别可以这样看：康德的担保装置是「主体间的心意结构」，属于先验人类学；黑格尔的担保装置是「精神在历史中认识自己的进程」，属于历史形而上学。前者是共时性的——任何时代的任何人原则上都有同样的心意能力；后者是历时性的——不同时代的艺术承载不同程度的真理。

::: key 本讲要点
- 康德以共通感为审美判断的先验担保，艺术自律由此成立。
- 黑格尔以绝对精神的自我认识为艺术的担保，艺术因此承载真理。
- 体系位置不同：判断力是两大批判的桥梁，艺术是绝对精神的第一个环节。
- 两种遗产：形式主义与「为艺术而艺术」 vs 艺术史哲学与「艺术终结」论。
:::

## 三、代表人物：两个体系的位置

康德终身未离开东普鲁士的柯尼斯堡，生活刻板到市民们按他散步的时间对表。他的哲学工程是「三大批判」：《纯粹理性批判》为知识划界，《实践理性批判》为道德奠基，而《判断力批判》（1790）要填上前两者之间那道「自然与自由」的鸿沟。判断力在体系里扮演桥梁角色，审美判断只是这座桥的一部分。这个位置决定了康德对艺术的态度：他关心的是「审美判断如何可能」，艺术之所以重要，是因为它最纯粹地展示了这种判断的自由。

黑格尔的生涯更具公共性，做过家庭教师、报馆编辑、大学教授，讲演风趣，吸引大批听众。《美学》并非他亲手定本的著作，而是 1820 年代海德堡与柏林讲演的听众笔记，身后由学生整理成书（参见第五模块第九讲）。在体系里，艺术处在绝对精神的第一站：精神先从艺术出发，经过宗教，最终在哲学中完成自我认识。这个位置同样决定了他看艺术的眼光——他关心的是「艺术如何承载并推进真理」，而非「判断者心里发生了什么」。

把两人的体系位置并排看，分歧几乎是被位置决定的：桥梁需要普遍可传递的形式条件，精神的第一站需要可显示的历史内容。

## 四、理论解析：三场对撞

### 第一撞：判断的有效性来源

康德的最强理由，来自对「无利害」的分析。他的大意是（转述）：当我说某物美，我并不关心它是否存在、是否对我有用，我只关心它的表象在我的诸认识能力（想象力与知性）之间激起的自由游戏；正因这份愉悦不夹带个人利害，我才有资格把它推荐给所有人。这是一个极其精巧的论证：普遍性的根据，恰恰来自主观性的彻底净化——把私人的东西排除干净，剩下的就是人人都有的。

黑格尔的攻击直指要害：这样的「普遍」是空的。他的大意是（转述）：审美判断若只依据主观心意状态，就永远停留在趣味的偶然性里，它所要求的普遍赞同是一种没有内容的「应当」，无法说明为什么这个时代产生这样的艺术、那个时代产生那样的艺术。要给出真正的普遍性，必须让艺术隶属于一个客观的精神进程。

康德一方可以反击：把艺术交给历史进程，个体的审美经验就被吞没了——难道我看一幅画时的真切愉悦，要等哲学史给出解释才算数？

### 第二撞：艺术与真理的关系

这是最根本的分歧，可以用一张表看清：

| 比较项 | 康德 | 黑格尔 |
|---|---|---|
| 艺术的核心功能 | 展示心意能力的自由游戏 | 让理念获得感性显现 |
| 与真理的关系 | 审美判断不提供关于对象的知识 | 艺术是真理的一种发生方式 |
| 判断的根据 | 主体的无利害愉悦 | 理念与感性形式的适合程度 |
| 艺术的类型等级 | 无系统等级，只有自由美与依附美之分 | 象征型、古典型、浪漫型的等级序列 |
| 艺术的终点 | 无终局问题 | 浪漫型之后有「艺术终结」命题 |

康德那句「美是对象的合目的性形式，在它不具有目的的表象时被知觉到」（通行中译，大意如此），把美彻底放在判断者的反思活动里。黑格尔那句「美就是理念的感性显现」（原文见《美学》第一卷全书序论），把美放在理念自身的显现里。同一讲里并置这两句，争论的轮廓一目了然。

::: warn 常见误解
有一种流行说法：康德认为美是主观的，黑格尔认为美是客观的，两人各执一端。这话有误导性。康德的「主观」指判断的根据在主体心意，但他同时坚持这种判断要求普遍赞同，绝非「我觉得美就美」的相对主义；黑格尔的「客观」指理念，而理念并非外部物质，恰是精神性的。两人争论的并非「主观／客观」这个粗糙标签，而是「普遍性以何种方式成立」。
:::

### 第三撞：体系位置带来的后果

康德把判断力设为桥梁，桥梁的性质是「过渡」——它不生产知识，也不立法，只提供调节性的原则。因此审美在康德体系里是自律的：它有自己的领地，不必向知识或道德缴税。这正是「审美无利害」的深层含义——美不从真或善那里借来的尊严。

黑格尔把艺术设为环节，环节的性质是「被扬弃」——艺术完成它的使命后，会被更高的形态（宗教、哲学）接手。这就埋下了「艺术终结」命题的种子：在「我们现时代的一般情况不利于艺术」这一判断里（原文见《美学》第一卷全书序论），艺术的有限性被明确说出来。这句话说的并非创作的停止；艺术当然还有人创作，只是它不再承担最高的真理职能。

## 五、经典原著：两部书的成书与关键段落

《判断力批判》写成于 1790 年，正值康德「三大批判」工程的收尾。全书分「审美判断力批判」与「目的论判断力批判」两部分，前者又按质、量、关系、模态四个契机分析美的判断。第一节「无利害」与「主观普遍性」两契机，是全部争论的源头。

《美学》来自讲演，结构分为全书序论与三部分：艺术美的普遍概念、艺术美的特殊化（三种艺术类型）、各门艺术的体系。全书序论里，黑格尔专门处理了「美学」这个名称是否恰当，主张改称「艺术哲学」，理由正是自然美在他看来只是不完善的形态。这一段可以直接对照第五模块第十讲。

::: quote 黑格尔《美学》第一卷·全书序论（原文）
美因此可以下这样的定义：美就是理念的感性显现。
:::

这句原文在《美学》电子文本中可逐字核对。它把「理念」（内容）与「感性显现」（形式）两环节绑在一起，既反对把美降到纯形式，也反对脱离形式的抽象理念。

## 六、艺术案例：同一座哥特教堂，两种读法

拿一座中世纪哥特教堂（可对照第二模块关于哥特的内容）来做思想实验。

康德式读法会把注意力放在形式在观者心里激起的反应：尖拱的上升线条、彩色玻璃的光、巨大空间带来的想象力扩张，这些形式让想象力与知性进入自由游戏，产生一种既愉悦又超出任何概念的感受。人会感到「崇高」，因为想象力在巨大的尺度前受挫，理性却因此意识到自身的优越（参见第五模块第五讲）。这里，教堂的意义取决于观看者的心意状态。

黑格尔式读法会把同一座建筑读成精神自我认识的一个阶段：哥特建筑属于浪漫型艺术，它的尖拱与高度指向一种内在性的超越，内容是基督教的灵魂深度，形式却仍受石头重量的束缚。建筑的意义，在于它把一个时代的宗教精神呈现为可见的形状，并因其形式与内容的不完全适合，预示了向绘画、音乐、诗的过渡（参见第五模块第十一讲）。

::: note 补充
席勒（Friedrich Schiller，1759—1805）站在两人之间。他接受康德把审美与利害切开，却不满这种自由停留在主观心意里，于是用「游戏冲动」把审美改造成弥合感性与理性的教育力量（参见第五模块第七讲）。说他「站在两人之间」只在提示一种思想史位置，他和黑格尔的体系并无承继关系。
:::

## 七、思想联系：两条遗产如何支配两百年

康德的遗产，走的是「守住审美领地」这条路。席勒把审美变成教育，浪漫派把反讽与断片当成主体自由的表演（参见第六模块第一讲），唯美主义把它推到「为艺术而艺术」（参见第六模块第七讲），格林伯格的媒介纯粹性叙事是其 20 世纪的后裔（参见第七模块第三讲、第九模块第七讲）。分析美学关于「审美无利害是否可能」的长期争论，也以它为靶子。

黑格尔的遗产，走的是「让艺术承担意义」这条路。丹托的艺术界理论与「艺术终结」论直接改写黑格尔命题（参见第七模块第十讲），阿多诺的「真理内容」把真理从观念改成作品形式中解决的矛盾（参见第七模块第十二讲），艺术史叙事、风格分期与「时代精神」这类分析工具，都在他的影子下。

要公平地看，两条路各有代价。自律论守住审美经验的特性，代价是把艺术与生活、历史的关联削薄，容易滑向「形式游戏」；真理论让艺术重新进入历史，代价是艺术可能被哲学收编，失去了它不可被概念穷尽的那部分。此后的美学史，很大程度上就是在这两种代价之间来回摆动。

## 八、本节总结

- 两人都以「审美判断如何要求普遍赞同」为出发点，担保装置不同：康德用共通感，黑格尔用绝对精神的自我认识。
- 共通感是先验的主观原则，绝对精神是历史性的客观进程；一个共时，一个历时。
- 体系位置决定结论：判断力是桥梁，艺术保持自律；艺术是绝对精神的第一环节，因而承载真理并终将被扬弃。
- 「主观看法／客观真理」的标签过于粗糙，真正的分歧在「普遍性以何种方式成立」。
- 两种遗产支配此后两百年：形式主义与为艺术而艺术 vs 艺术史哲学与艺术终结论。

值得继续追问的问题：阿多诺既坚持艺术自律，又坚持艺术承担真理内容（参见第七模块第十二讲）。他是不是在试图调和康德与黑格尔？如果调和成功，代价又是什么？
