## 一、本节导入

1960 年，六十岁的伽达默尔（Hans-Georg Gadamer）出版《真理与方法》，副标题是「哲学解释学纲要」。书的编排有点奇怪：标题里写着「方法」，第一部分讲的却是艺术经验，而且主张艺术经验里有真理——一种不能用自然科学方法检验、也不能用「主观感受」打发的真理。

这个主张的困难可以用一个日常场景说明。你在一座教堂里看一幅十六世纪的祭坛画，画的是圣母升天。你不信教，也不熟悉图像志，却觉得这幅画「说对了什么」。这句话既不是趣味判断（「我喜欢」），也不是事实判断（「它是油画」）。它要求你承认：一件过去的作品可以对你发生作用，而这种作用有真假可言。

伽达默尔要解释的正是这种作用。他的问题可以分成三问：理解如何可能？理解是否总是历史地有限的？如果有限，理解的有效性靠什么？

## 二、核心知识：四个概念

::: def 解释学（Hermeneutik）
关于理解与解释的理论。在伽达默尔之前，它主要指文本解释的技艺（神学的、法律的、语文学的）；在他之后，它指人作为历史存在者理解世界的方式。**例**：读一封三十年前的家书，你既要懂字面，也要懂写信人当时的处境，还要懂你自己为什么此刻被某句话打动。
:::

::: def 前见（Vorurteil）
理解之前已经存在的判断结构，包括预设、习惯、立场。日常汉语把它译成「偏见」，带有贬义；伽达默尔要恢复它的中性含义。**例**：翻开《红楼梦》之前，你已知它是「古典小说」「爱情悲剧」，这些预设让你读得进去，也可能让你读不出别的东西。
:::

::: def 视域融合（Horizontverschmelzung）
视域指从一个位置所能看见的范围。理解发生时，解释者的视域与文本的视域合成一个更大的视域，双方都在其中被重新规定。**例**：你带着「心理创伤」这套当代词汇读古希腊悲剧，文本会纠正你：它的「灾祸」概念包含神意与污染，与临床心理学并不重合。纠正之后的读法，属于融合后的视域。
:::

::: def 游戏与构成物（Spiel / Gebilde）
伽达默尔用来说明艺术作品存在方式的一对概念。游戏的主体是游戏本身，参与者被规则与节奏牵着走；游戏一旦被表现，就形成「构成物」——可反复表现又不被任何一次表现耗尽的结构。**例**：一场球赛的走向不由某个球员决定；《英雄交响曲》每次演奏都不同，你仍说「这是同一部作品」。
:::

这四个概念不是并列的清单，它们构成一条线索：理解总是从前见出发，在前见与文本的碰撞中形成融合的视域，而艺术作品是这种发生的典型场所。

| 议题 | 启蒙解释学的立场 | 伽达默尔的修正 |
| --- | --- | --- |
| 前见的来源 | 来自权威、轻信与习俗，应当清除 | 一部分来自流传物，是理解得以开始的条件 |
| 权威 | 与理性对立，是未成年的标志 | 权威可以基于承认与判断，不等于盲从 |
| 传统 | 沉淀的偏见，须由理性批判 | 传统是持续进行的传递，可以被检验与修正 |
| 时间距离 | 需要跨越的障碍 | 区分真假前见的生产性条件 |

## 三、代表人物：从方法之争到存在论

**伽达默尔**（1900—2002）生于马堡，1922 年获博士学位，1923 年赴弗莱堡随海德格尔学习，此后终身以海德格尔为对话者。1939 年在莱比锡任教授，1946 年任该校校长，1949 年转任海德堡。1960 年出版《真理与方法》时他已六十岁，此书让他成为战后德国最有影响的人文学者。他要对抗的是两种东西：一是把精神科学方法化的实证主义，二是把理解心理化的浪漫解释学。

**海德格尔**（1889—1976）提供了关键的一步。他在 1920 年代的讲课里指出，理解总带着「前结构」：我们先有一个大致的方向、一种预期，才可能把某物当作某物来理解。伽达默尔把这一步历史化：前结构来自传统，传统又在理解中被改变。

**贝蒂**（Emilio Betti，1890—1968）与**赫施**（E. D. Hirsch，1928—）代表另一条路线。贝蒂 1962 年出版《作为精神科学普遍方法论的解释学》，主张解释的对象是作者对象化在作品中的意义，解释者应遵守「对象的自主性」等规则。赫施 1967 年出版《解释的有效性》，坚持作者意图是文本意义的确定者。两人都把伽达默尔视为相对主义的入口。

**哈贝马斯**（Jürgen Habermas，1929—）从批判理论一侧发难。他在 1960 年代末的讨论中指出，解释学把传统当作理解的唯一媒介，忽略了系统性扭曲的交往：当权力结构渗入语言本身，理解与误解的界限就不能只靠传统来划定（大意）。

## 四、理论解析

### （一）问题：精神科学有没有自己的真理

19 世纪后半叶，人文研究面临合法性危机：如果科学的方法是观察、实验与量化，研究荷马与研究昆虫有何不同？狄尔泰以「理解」与「说明」的区分作答：自然需要说明，心灵需要理解。施莱尔马赫则把解释学建立为「重构作者心理」的技艺。

伽达默尔认为两条路都走偏了。狄尔泰仍在模仿科学模型，只是把方法换成移情；施莱尔马赫把理解变成对另一个心灵的复制，理解的对象于是成了一个死去的过去。他要问：理解是否本来就是一种「发生」，在其中过去与现在同时被牵动？

### （二）审美区分的批判

《真理与方法》第一部分从康德讲起。伽达默尔承认康德把审美判断从概念认识中解放出来，但认为这一步被席勒与后继者推成了「审美区分」（ästhetische Unterscheidung）：抽出作品的形式，剥离它的世界、功能与真理要求。后果是双重的：作品成了纯粹形式，观赏者成了纯粹意识，两者都失去历史。他要恢复的是作品的世界——祭坛画在教堂里被朝拜，奏鸣曲在沙龙里被演奏，这些关系属于作品的存在。

### （三）游戏、转化与构成物

「游戏」这个概念承担了论证的关键一步。伽达默尔说，游戏的主体是游戏本身，游戏者只是被卷入其中的人。这个说法有三个支撑。

1. **游戏有自身的严肃性。** 儿童游戏时全神贯注，规则的约束力不亚于工作。
2. **游戏先于游戏者。** 游戏的规则、节奏与可能性构成一个场，个人进入这个场才成为游戏者。
3. **游戏需要被表现。** 游戏总要「演出来」；戏剧与音乐把这一点推到极致，表现（Darstellung）成为作品的存在方式。

由此引出「转化」（Verwandlung）。转化指游戏者与游戏一同进入另一种存在：演奏者成为作品的执行者，观众成为参与者。转化的结果是「构成物」（Gebilde）：一个在每次表现中重新在场、又不被任何一次表现耗尽的结构。

### （四）前见、权威与效果历史

启蒙运动的纲领可以概括为「摆脱前见」。伽达默尔指出，这个纲领本身依赖一个前见：反对前见的前见。他把前见分成两类：一类来自轻信与仓促概括，应当被纠正；一类来自传统与权威，是理解的条件。

权威在这里需要辨析。伽达默尔说的权威与权力压迫无关，它指基于承认的服从：你承认某位医生在诊断上比你有判断力，于是接受他的意见；这种接受包含判断，不包含盲从。传统同样如此：它是持续进行的传递，可以被检验、被修正，也会在传递中被改变。

「效果历史意识」（wirkungsgeschichtliches Bewusstsein）指解释者对自己始终被历史影响的意识。我们无法站到历史之外去清点自己的前见，因为清点所用的工具也是历史给的。这个限制听起来像缺陷，伽达默尔把它当作理解的条件。

「时间距离」在这个框架里获得生产性。启蒙解释学把时间距离看作需要跨越的鸿沟；伽达默尔认为，正是距离让作品的真意与其当下的喧嚣分开，也让解释者能够区分哪些前见在起作用、哪些已经失效。

### （五）视域融合与应用

视域融合不是两个视域的相加。伽达默尔说，融合产生的是「更高的普遍性」：双方都在其中被重新理解。**例**：读亚里士多德的「德性」，你先用现代伦理学的「品格」去对应，读下去发现他的「德性」包含城邦与习惯，于是你调整了「品格」的含义；调整之后，两边都变了。

与此相连的是「应用」（Anwendung）。伽达默尔主张，应用是理解的内在要素，并非理解之后的附加步骤。**例**：法官解释一条法律，必须把它用到眼前的案子上；脱离案子的「纯解释」在法学里没有意义。审美理解同样如此：作品的意义总在某个具体处境里被兑现。

::: warn 「视域融合」不是把文本读成自己的样子
一种流行理解是：融合即「用我的框架解释你」，最后一切都变成我的。这与原意相反。融合要求解释者的视域被文本改变，改变的方向由「事情本身」约束；若文本只是被塞进原有框架，发生的是一次误用，并非融合。判据在事后：解释者能否说出自己原来错在哪里。
:::

### （六）三场争论

**与贝蒂、赫施的争论**围绕作者原意。贝蒂主张解释必须尊重「对象的自主性」，即作者对象化在作品中的意义；赫施区分「含义」（meaning，作者确定的）与「意味」（significance，随语境变化的），认为前者是解释有效性的锚。伽达默尔的回应大意是：作者的意思只是理解的一个环节，理解总在流传中继续；把意义钉死在作者心里，等于要求解释者放弃自己的处境。

**与哈贝马斯的争论**围绕权威与传统。哈贝马斯认为，伽达默尔把传统视为理解的普遍媒介，就取消了意识形态批判的位置：当交往被权力系统扭曲，解释学只能复述扭曲后的共识。伽达默尔的回应大意是：解释学并不否认批判，它指出批判也必须从某种前见开始；反思本身依赖语言与传统，没有「无传统的立场」。

**与德里达的争论**发生在 1981 年的巴黎。德里达提出三个问题，大意是：理解是否预设了一种「善良意志」的伦理学？解释学如何处理文本中的无意识与不可读之处？意义的多元是否会被解释学收编为一种「更好理解」？伽达默尔答以对话伦理学：理解的善意是实践的前提，并非形而上学的预设。争论没有结论，它暴露的是两套语言哲学的距离。

### （七）最强反对：相对主义

最有力的批评可以这样表述：如果意义总在融合中生成，那么任何解释都同等有效，「更好的理解」就失去了标准。

伽达默尔的回应有三层。第一，「理解总是以不同的方式发生」说的是理解的结构，并非一切解释都同样好；他区分「不同的理解」与「随意的曲解」。第二，理解受「事情本身」（die Sache）的约束：读者可以带着前见进入文本，文本会抵抗、纠正、驳回某些读法；这种抵抗是可经验的。第三，融合指向「更高的普遍性」，它要求解释者扩大自己的视域，而非把文本塞进原有框架。

这三层回应是否足够，仍有争议。反对者可以说，「事情本身」的约束只有在事后才能辨认：当两派都声称自己被文本纠正时，谁来判定？伽达默尔晚年更多依靠「对话」与「共同的事情」来回答，这使他的立场倾向于一种实践哲学，而非可操作的解释规则。

## 五、经典原著：《真理与方法》的结构

《真理与方法》1960 年由图宾根莫尔出版社出版，全书分三部分。第一部分「艺术经验里真理问题的展现」讨论人文主义概念（教化、共通感、判断力、趣味）、康德与席勒的审美主体化、游戏与作品的存在论。第二部分「真理问题扩大到精神科学的理解」处理历史主义、前见、视域与效果历史。第三部分「以语言为主线的解释学存在论转向」提出语言是理解得以进行的视域。

1965 年第二版加了序言，回应贝蒂等人的批评；1972 年第三版后记继续申辩。全书的核心命题在结尾：

::: quote 《真理与方法》
Sein, das verstanden werden kann, ist Sprache.
（能被理解的存在就是语言。）
:::

这句话常被读成「一切都是语言」，那是误解。它说的是：存在只有在被理解时才向我们显现，而理解总以语言的方式发生。语言在这里是媒介，也是界限。

## 六、艺术案例：《英雄交响曲》的一次演奏

贝多芬《第三交响曲》作于 1803 至 1804 年，1805 年 4 月在维也纳首演，原标题是「英雄交响曲，为纪念一位伟人而作」。据里斯（Ferdinand Ries）后来的回忆，贝多芬曾划掉题献给拿破仑的字样。这个轶事常被引用，证据却只有里斯的转述。

第一乐章的几个形式细节，正好可以说明「构成物」与「表现」的关系。开头两小节是全奏的两个强和弦，像一次拍门；第七小节大提琴声部出现一个升 C，与当时和弦的降 E 大调相冲，这个音在 1805 年听起来相当刺耳。展开部引入一个新的主题，材料被切成碎片，反复转调。再现部之前，圆号提前两小节奏出主题，弦乐还停在属和弦上，两者撞在一起；据里斯说，当时有乐手以为出了错。

::: fig a-heroica | 《英雄交响曲》第一乐章：圆号在再现部提前进入，主题的降 E 大调与弦乐的属和声短暂错位
:::

用伽达默尔的术语看，这部作品是「构成物」：它不能被任何一次演奏穷尽，也不存在于乐谱的符号里。乐谱只是指令，作品在每一次「表现」中重新在场。演奏者被作品的要求牵着走，这正是「游戏」的结构：主体是作品与演奏共同构成的那个事件，演奏者只是其中的参与者。

「节庆」的时间性在这里也用得上。节庆的特征是重复：它每年回来，每次都是同一个节庆，又每次不同。交响音乐会同样如此，同一部作品被反复演奏，重复本身就是它的存在方式。

需要一点限定。伽达默尔并不认为演奏可以任意：构成物要求「正当的表现」，一次糟糕的演奏仍然是演奏，却让作品「没有真的在场」。这个标准如何判定，他交给实践判断，没有给出规则。

## 七、思想联系

向前，伽达默尔继承三条线。施莱尔马赫与狄尔泰提供了解释学的学科框架，海德格尔提供了理解的前结构与存在论转向，黑格尔提供了「真理是过程」的模型：真理在展开中，而非在某个命题里。

向后，姚斯把「视域融合」改造成「期待视野」，用于文学史（参见本模块第 3 讲）；伊瑟尔把「具体化」用于阅读过程。利科（Paul Ricœur）从另一侧发展了解释学，强调文本的「间距」与自我理解。反对者一侧，赫施坚持作者意图，哈贝马斯坚持意识形态批判，德里达坚持文本的不可闭合。中国的接受美学在 1980 年代引入，姚斯与伊瑟尔的影响大于伽达默尔本人，这一点常被忽略。

## 八、本节总结

- 伽达默尔要回答的是：精神科学有没有不模仿自然科学的真理。
- 「审美区分」把作品抽成纯粹形式，抽掉了作品的世界。
- 游戏的主体是游戏本身；转化产生构成物，作品在表现中存在。
- 前见有合法与非法之分；效果历史意识承认解释者始终被历史规定。
- 时间距离具有生产性，它让真前见与假前见分开。
- 视域融合产生更高的普遍性，应用是理解的内在要素。
- 相对主义的质疑指向「标准」，伽达默尔以「事情本身」与对话回应，回应仍有争议。

值得追问的是：如果理解总在融合中发生，那么我们还能不能说某人是「错的」？如果不能，批评还剩什么？

::: key 本讲要点
- 解释学从文本技艺变成存在论：理解是人的存在方式。
- 游戏—转化—构成物，是作品存在论的三步。
- 前见与效果历史意识，把解释者的历史性变成条件。
- 视域融合要求双方都被改变，应用是理解的内在环节。
- 三场争论（贝蒂/赫施、哈贝马斯、德里达）指向同一个问题：有效性靠什么担保。
:::
