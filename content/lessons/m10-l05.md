## 一、本节导入

假设有人站在一幅画前说：我不在乎它画的是战争还是婚礼，我只看这些线条、色块、结构怎样彼此撑住。另一个人反驳：你抽掉画的题材，等于抽掉它的灵魂，那些线条正因为服务着某个具体的苦难才有分量。前者是形式主义者，后者是内容论者。

这场争论在艺术批评里几乎每天重演，却很少被认真清理。原因之一是「形式」「内容」这两个词各有好几副面孔，双方常常在用不同的意思说话。本讲先拆开这两个词的歧义，再摆出强纲领与反纲领，最后用毕加索的《格尔尼卡》做一次检验——这幅作品之所以是好试纸，恰恰因为它既是极强的形式构造，又背负着极重的历史内容。

## 二、核心知识：形式的三重歧义

::: def 形式（form）
在美学讨论里至少有三副面孔：其一，与「质料」相对的形式，指事物的组织结构（亚里士多德意义上的形式）；其二，与「内容」相对的形式，指作品的表达方式，如构图、笔触、色彩关系；其三，与「媒介」相连的形式，指艺术门类自身的物质特性，如绘画的平面性。三种意思常被混用，是争论空转的主因。
:::

::: def 内容（content）
作品所传达的意义、题材、情感或思想。内容论者内部也有分歧：有的把内容理解为「所画的物」，有的理解为「社会历史的真实」，有的理解为「作者要说的道理」。
:::

把三副面孔分开，争论会立刻变得清楚一些。形式主义峰会主张「有意味的形式」（significant form）：线条与色彩以某种方式组合，唤起一种特殊的审美情感，这与画的是什么无关（参见第七模块第三讲）。格林伯格的媒介纯粹性叙事是它的历史化版本：现代主义绘画的使命，是不断回到平面性这一媒介特性，清除文学性、雕塑性的杂质（参见第九模块第七讲）。

::: key 本讲要点
- 形式有三义：与质料相对、与内容相对、与媒介相连，混用导致争论空转。
- 形式主义强纲领：审美价值在形式关系；弱纲领：形式关系是价值的重要条件。
- 内容论的社会历史版本（卢卡奇的典型论）与道德版本（对作品立场的评判）。
- 「形式即内容」的折中能否成立，取决于对形式的理解是否足够厚。
- 《格尔尼卡》检验：抽出内容，形式仍在；解释形式，却逃不开内容。
:::

## 三、代表人物：四个立场的坐标

克莱夫·贝尔（Clive Bell，1881—1964）在《艺术》（1914）里提出「有意味的形式」，为后印象派辩护。他的立场是强纲领：能唤起审美情感的，只有形式关系，题材无关紧要。这个理论有一个著名循环——有意味的形式引起审美情感，而审美情感只能由有意味的形式引起——它既是理论的力量所在（自足），也是它的软肋（无法独立界定）。

格林伯格（Clement Greenberg，1909—1994）把这个立场改造为历史叙事：艺术门类应不断「自我批判」，回到自身媒介的独特性。他的影响支配了 20 世纪中期英美批评，也招致目的论历史观与排斥非西方艺术的反批评（参见第九模块第七讲）。

卢卡奇（György Lukács，1885—1971）代表内容论的社会历史版本。他强调「典型」：现实主义作品要通过对具体人物与环境的描写，揭示社会关系的总体性。在他看来，形式主义把艺术抽成纯形式，恰好掩盖了艺术的意识形态功能。他的立场提醒我们，「形式」的选择本身也是历史性的。

阿多诺（Theodor W. Adorno，1903—1969）试图越过对立。他的「形式即内容的沉淀」主张：作品的形式是内容在材料中反复冲突、被解决后留下的结构，而非一层漂亮的包装；因此形式本身就携带着真理内容（参见第七模块第十二讲）。

## 四、理论解析：强纲领、反纲领与折中

### 形式主义的强纲领与弱纲领

强纲领的论证分三步：

1. 审美经验有独特性，它不是认识，也不是道德感动。
2. 这种独特经验只能由形式关系引起，因为题材会引起实用、认知或道德兴趣，超出审美本身。
3. 因此，作品的审美价值只取决于形式。

这个论证最有力的地方，是它解释了为什么一件作品换个题材、甚至认不出题材，仍可能打动我们。它的困难在于「审美情感」无法被独立识别：我们总是带着题材、语境、记忆去感受形式，纯粹的「只看形式」更像一种批评训练，而非自然的观看状态。

弱纲领则退一步：形式关系是审美价值的必要条件或核心条件，内容的作用是辅助性的、可被转化的。多数严肃的形式主义者其实持弱纲领。

### 内容论的两种版本

社会历史版本（卢卡奇）的论证：艺术是对社会现实的反映，真正的作品通过典型人物与典型环境揭示历史的总体性；形式主义把形式抽离出来，会遮蔽这一点。它的强项是解释现实主义作品的社会深度，弱项是容易把艺术价值等同于认识论的正确性。

道德版本则主张：作品的立场与价值判断构成其价值的一部分，对苦难的冷漠处理会损害作品，无论形式多完美。它的强项是指出「为艺术而艺术」的盲点，弱项是可能滑向宣传口径与道德审查。

### 折中方案：「形式即内容」

阿多诺的折中说能否成立，取决于「形式」被理解得多厚。若形式只是线条与色块的排列，那么「形式即内容」只是一句漂亮话；若形式被理解为「内容在材料中被解决的痕迹」，那么它就有分量了。

::: warn 常见误解
「形式即内容」常被当成一句取消争论的万能话。实际上它有两种截然不同的意思。浅的版本是「内容要借形式呈现」，这只是老生常谈；深的版本是「形式是内容在材料中斗争并沉淀的结果」，这才有理论重量。区分二者，是判断这类折中说是否有用的关键。
:::

## 五、经典原著：几处理论文本的坐标

贝尔《艺术》1914 年出版，正值后印象派引发争议之际。它的写作动机是一次具体的批评实践：为塞尚、马蒂斯那些「看不懂」的新画辩护。理解这个动机，才能理解「有意味的形式」为何强调题材无关——那是一种批评策略。

格林伯格《走向更新的拉奥孔》（1940）、《现代主义绘画》（1960）把形式主义历史化，提出「媒介纯粹性」与「自我批判」。这组文本影响巨大，也最常被后现代理论当作靶子（参见第八模块第四节）。

《格尔尼卡》相关的批评文献中，研究者常引用两种对立的读法：一种强调其立体主义语言与黑白灰的形式力量，一种强调其反战内容与政治语境。本讲采用的方法，是让两种读法在同一件作品上竞争。

## 六、艺术案例：《格尔尼卡》的形式与内容

::: fig a-guernica | 《格尔尼卡》：几何化的形体、叠压的平面与黑白灰的克制色域，构成极强的形式结构，同时承载反战的具体内容
:::

先做形式细读。整幅画是横长的构图，近似一个舞台，光源被画成灯泡般的太阳，光线从上方投下。人物与动物被拆解成几何化的块面：公牛、马、举灯的人、倒地的士兵，都被拉成尖锐的三角形与折线。色彩被压到黑白灰，去掉了色彩的感官诱惑，强化了摄影报道般的冷峻。叠压的平面取消了传统透视的深度，所有事件被挤到同一层——这是立体主义的空间处理。这些形式特征，完全可以用「线条、色块、结构如何彼此撑住」来描述。

再做内容细读。作品画的是 1937 年西班牙内战期间格尔尼卡城遭轰炸的事件，公牛、马、母亲与孩子构成受难的群像。黑白灰的选择，让画面接近当时报纸图片的效果，把新闻的即时性带进了绘画。如果抽掉题材，只谈几何块面，这些块面的力量从何而来？若说来自纯粹的视觉张力，那么为何换成一组同样几何化的静物，效果会完全不同？

这次检验给出一个判断：内容论在这幅作品上有解释优势。形式主义能精确描述「怎么画的」，却难以解释为何这些形状如此紧迫；而一旦引入轰炸、无辜者受难、反战的立场，形式的紧迫感就获得了来源。这个结果不等于形式主义全面失败——它说明了在历史负载极重的作品上，内容提供了解释的框架。反过来，面对一首无标题的抽象画，形式主义又会重新占据上风。

## 七、思想联系：争论的来龙去脉

向前追溯，形式主义可以追溯到康德的「自由美」与无利害（参见第五模块第三讲），经李格尔、沃尔夫林的艺术科学，到贝尔与格林伯格（参见第七模块第三讲）；内容论则可以追溯到亚里士多德的模仿论、黑格尔的艺术真理（参见第十模块第一、二讲），以及 19 世纪现实主义与马克思主义文论（参见第六模块第六、八讲）。

向后看，两论在当代都发生了变形。后现代主义质疑「纯形式」的神话，强调任何形式选择都携带意识形态（参见第八模块第四节）；女性主义美学追问「有意味的形式」中的「意味」由谁定义（参见第八模块第五节）；分析美学则试图重新定义艺术概念，把形式与制度、历史语境一起纳入（参见第七模块第十讲）。

阿多诺的折中方案在当代得到最多呼应，也承受最多质疑：它保存了形式分析的精细，又让艺术重新连上社会，代价是「真理内容」这一概念本身难以被经验地验证。

## 八、本节总结

- 形式有三义：与质料相对、与内容相对、与媒介相连；混用是争论空转的主因。
- 形式主义强纲领主张审美价值只在形式关系，弱纲领视形式为价值的核心条件。
- 内容论有社会历史版本（卢卡奇的典型论）与道德版本（作品立场的评判），各有强弱项。
- 「形式即内容」有深浅两解，深解指形式是内容在材料中沉淀的结果，才有理论重量。
- 《格尔尼卡》检验显示：在历史负载极重的作品上，内容论解释力更强；面对抽象作品，形式主义重新占优。

值得继续追问的问题：如果形式与内容的解释力随作品类型而变化，那么「形式主义 vs 内容论」也许根本不该被当成一场要决出胜负的争论，而是一种随对象切换的批评工具。这种工具论看法，会不会让美学失去对艺术价值的稳定判断？
