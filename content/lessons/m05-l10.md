## 一、本节导入

假设有两个提案摆在预算委员会面前。第一个：修缮一座十九世纪的画廊，让市民免费看画。第二个：保护一片湿地，禁止开发。两个提案都说自己关乎「美」，都要求公共资金。委员们大概会觉得这是两种不同的东西，没法比较。黑格尔会说，它们不但能比较，而且高下立判——画廊里的画高于湿地，因为画是心灵的产品，湿地只是自然。

这个答案今天听来不合时宜。生态意识让我们觉得，湿地比一幅画更不可替代，黑格尔的立场因此像一个必须被驳倒的旧偏见。但驳倒它之前，得先弄清它说了什么。他说自然美「只是为其他对象而美」，这句话常被读成轻蔑之词，其实是一个存在论命题：自然物不知道自己美，它的美需要外部意识来点亮；作品则知道自己在说什么。

本讲先把这条论证拆到骨头，再看它今天还剩多少。剩下的比反对者以为的多，失去的也比辩护者愿意承认的多。

## 二、核心知识：三组区分

::: def 自在（an sich）与自为（für sich）
黑格尔的一对基本范畴。「自在」指某物按其概念已经是它所是，却没有意识到自己；「自为」指它不仅如此，而且知道自己如此。**例子**：一块石头有重量，它「自在」地受重力支配，却不知道重力；一个人知道自己有重量，他在这一点上「自为」。这个区分不涉及大小强弱，只涉及自我关系。
:::

::: def 自然美
指自然物作为「理念的直接感性存在」而呈现的美。条件是：一个自然个体的各部分互相依存，形成受「生气灌注」的整体，且符合我们关于该类事物的概念。**例子**：一匹结构匀称的马、一块纹理自由生长的水晶、一片有层次的山谷。自然美的最高形态是动物的生命，因为只有生命才有内在的统一。
:::

::: def 艺术美
指由心灵产生并再生的美，即「理念的感性显现」在作品中的实现。它与自然美的差别在存在方式：艺术美是「为意识并且为自身」的美，作品把真理设置在外形里，因此要求观者理解。**例子**：一尊神像让人看见「神是什么」；一幅肖像让一张脸成为性格。
:::

三个概念组成一条推论：自在／自为的区分 → 自然美是自在的 → 艺术美是自为的 → 艺术美高于自然美。推论是否成立，取决于第一步能否承担后面的重量。

## 三、代表人物：一位体系家与两位反叛者

黑格尔的生平上一讲已交代，这里只补一点：他在《美学》第一卷第二章用整整一章处理自然美，作用却是「清场」。把自然美排除出美学，理由并非自然不美——自然美无法构成一门科学，它的概念不确定，也没有标准。

卡尔森（Allen Carlson，1936— ）长期任教于阿尔伯塔大学，是分析传统里环境美学的奠基者之一。1980 年代起他提出「科学认知主义」：对自然的恰当欣赏必须由自然科学（地质学、生态学、生物学）的范畴引导，如同欣赏艺术品需要艺术史与批评的范畴。代表作《美学与环境》（2000）。

伯林特（Arnold Berleant，1932— ）走另一条路。他在《环境美学》（1992）里主张，自然欣赏是「身体在环境中参与」，而非「主体看对象」：你听见风、感到湿度、闻到土腥味，欣赏者成了环境的一部分，没有画框隔开二者。他因此批评「无利害观照」模型过于视觉化、过于有距离。

## 四、理论解析：一条等级论及其对手

### 第一步：文本位置与力度

第二章的结构是：先给自然美一个最低限度的定义（理念作为生命），再按层级往上走（无机物、植物、动物），最后指出根本缺陷，由此过渡到第三章「艺术美」。这个结构本身就是论证：自然美被允许存在，却被安排在必然后退的位置上。

序论里的判断更直接：

::: quote 《美学》第一卷，全书序论，1. 自然美和艺术美
心灵和它的产品比自然和它的现象高多少，艺术美也就比自然美高多少。
:::

比较用的是「多少」，带着量的口吻；黑格尔马上补充，这种「高于」并非量的分别。心灵与自然之间有存在方式的差异，艺术美与自然美的差异只是它的显影。

### 第二步：形而上根据

为什么心灵高于自然？答案在「自我关系」。只有心灵能「知道自己」，能在它的他者中认出自己。石头与他物发生关系，它不知道；植物朝向阳光，它不知道自己朝向；动物感到饥饿，却不知道自己在感到。只有人能返身观照：我知道我在看，我知道我在说。

美的定义要求「理念的感性显现」，而理念的标志是「在它的他者中与自己同在」。自然物做不到：它在感性外形里，却不在外形里认出自己。所以自然美只是理念的「自在」形态，要有人站在它面前说「这很美」，那个「显现」才算完成。

::: warn 这不等于「自然不美」
黑格尔的结论比通常引用的要窄。他承认自然美存在，甚至承认它有层级；他否认的是自然美能作为美学的科学对象，以及自然美能承担「真理的感性形式」这一职能。把他说成「否认自然美」的人，多半只读了序论里的半句话。真正的问题在于：他把「美」与「自我意识」绑得太紧，于是所有非人的美都成了二等公民。
:::

### 第三步：自然美「为我们」而美

自然美章里有一句关键的话，位置在「自然生命作为美」一节的开头：

::: quote 《美学》第一卷，第二章「自然美」，2. 自然生命作为美
自然美只是为其他对象而美，这就是说，为我们，为审美的意识而美。
:::

这句话有三层含义，逐层加重。

第一层是因果的：自然物没有为自己「打扮」的意图。花开不为谁看，羽毛不为谁亮；它们的美是我们读出来的。

第二层是依赖的：自然美依赖观者的心境。黑格尔举的例子是寂静的月夜、平静的山谷、汹涌的海洋；这些对象的意蕴「并不属于对象本身，而是在于所唤醒的心情」。同一片海，在渔民眼里是生计，在诗人眼里是崇高。

第三层是认识论的：自然美没有标准。概念既不确定，也没有标准，所以「这种比较研究就不会有什么意思」。这句判断否认的是自然美能被系统化为一门学问，并非自然美的存在。

### 第四步：三个层级的评价

黑格尔并非一视同仁地谈论自然。他给了一个上升的序列：

| 层级 | 形态 | 黑格尔的判词 | 理由 |
| --- | --- | --- | --- |
| 无机自然 | 结晶体的规则形状、对称、整齐一律 | 只是「抽象形式的外在美」 | 统一来自外部（外力、数目），不在物自身中活动 |
| 植物 | 生长、分枝、开花 | 有生命，但生命还是「外在的」 | 各部分互相依存，却没有感觉的中心 |
| 动物 | 有感觉、有灵魂、有运动 | 「自然美的顶峰」 | 内在统一在身体中显现，且表现为运动与情绪 |

这个序列的逻辑是「内在性的递增」：从外部赋予的统一，到生命体内的统一，再到有感觉的统一。但序列在动物这里停住，并且立刻转向否定。黑格尔说，「这就是自然美的基本缺陷，就连它的最高的形式也在所不免」；正是这种缺陷，使人有必要进一步认识理想，即艺术美。

缺陷在于：动物的灵魂是「自在的」统一，它不能「看到自己的灵魂」，只能让人从外形上「猜想到」它有灵魂。人不同，人能把内在显现出来，因为人知道自己。自然美的顶峰因此同时是它的终点，再往上只有心灵。

### 第五步：环境美学的三重反攻

20 世纪后期，环境美学从三个方向质疑这条等级论。

**其一，卡尔森的认知主义。** 把自然美说成只为我们心情而美，正是环境欣赏里最常见的错误：把自然当作情绪的投影幕。恰当的欣赏应由正确的范畴引导——知道这片苔原是冰川退却的产物，知道这棵树的形态来自风与水，你的欣赏才是「对它的」欣赏。这个论点把「不确定性」指控反转了：自然美显得不确定，因为欣赏者无知，并非因为对象贫乏。

**其二，伯林特的参与美学。** 他质疑「观照」模型本身。看画时你站在画框外，看自然时你站在其中：风打在皮肤上，地面在脚下起伏，声音从四面来。审美经验因此是多感官的、身体性的、没有边界的。黑格尔的框架以视觉为原型、以距离为条件，从一开始就漏掉了环境经验的主要部分。

**其三，环境伦理的独立价值论。** 利奥波德（Aldo Leopold，1887—1948）在《沙乡年鉴》（1949）里提出大地伦理：一件事物倾向于保护生物共同体的完整、稳定与美时，就是对的。这里的「美」不为给人看，它是共同体自身的属性。问题于是从「自然美不美」推到「自然有没有超出人类趣味的价值」。

### 第六步：黑格尔式立场还能守住什么

辩护可以从三处入手，每一处都要付出代价。

**第一，区分「美」与「审美价值」。** 黑格尔不否认自然令人愉悦，他否认自然能承担「真理的感性形式」这一职能。湿地能让我们感到生命的丰盈，却不能让我们看见「自由」「罪」「和解」这些只有心灵才有的规定。这个区分守得住，代价是把自然美降为较弱的审美价值。

**第二，不确定性论证仍然有效。** 没有中介的自然欣赏很容易落入「如画」（picturesque）的框架：找一个像画的取景框，把自然剪成风景。这恰恰证明自然美是「为我们」的。科学范畴可以纠正它，但科学范畴本身也是中介。论点因此可改写为：自然欣赏总已带着中介，问题在于用哪一种。

**第三，艺术的反身性不可替代。** 艺术能表现自然无法表现的东西：一个人对过去的选择、一个民族对神的关系、一场失败的意义。这类内容要求形象与意义的自觉统一，而自然没有意义，只有形态。这条辩护最强，也最有限：它只证明艺术在某一类内容上不可替代。

| 争点 | 黑格尔一方的最强理由 | 环境美学一方的最强理由 |
| --- | --- | --- |
| 美的根据 | 只有自我意识能让理念在外形中「回到自身」 | 自然是自在的价值源，不依赖人的确认 |
| 不确定性 | 没有标准的自然欣赏易沦为情绪投射与「如画」取景 | 不确定性来自欣赏者的无知，可由科学范畴修正 |
| 感性模型 | 「显现」要求距离与观照，这是审美自律的条件 | 环境经验是多感官参与，观照模型漏掉了身体 |
| 不可替代性 | 艺术能表现自由、历史、和解，自然不能 | 自然的野生性、尺度、非人造性同样不可替代 |
| 政治含义 | 审美教育需要作品作为公共的真理载体 | 把美绑在人的意识上，为自然的工具化开了口子 |

表格里没有一方全胜。较为均衡的判断是：黑格尔在「艺术能表现什么」上仍然有力，在「自然的美是什么」上已经很难维持。

## 五、经典原著：一章「清场」的文字

第二章分三节：A. 自然美，单就它本身来看（1. 理念作为生命；2. 自然生命作为美；3. 对自然生命的观察方式）；B. 抽象形式的外在美与感性材料的抽象统一的外在美（整齐一律、平衡对称、和谐、尺度）；C. 自然美的缺陷。

B 节常被忽略，其实有意思。黑格尔讨论整齐、对称、和谐，结论是：这些形式之所以美，只因为它们暗示了某种内在统一，本身停留在「量」的层面。他举结晶体的例子：规则形状并非外力压出，它由矿物按自身本质自由形成。即使在无机界，他也要找到「内在性」的痕迹才肯承认美。

C 节是过渡。三重缺陷：内在因素仍是内在的（灵魂不显现）、个别存在带有偶然（这一朵花、这一片云）、物种定型限制了精神。三者指向同一结论：自然美需要艺术美来补足。

文风上，这一章比序论松弛，大量举例（水晶、苔藓、懒虫、鸭嘴兽、月夜、海），语气接近博物学随笔。这种松弛暴露了他的趣味：自然是一个有等级、充满暗示的系统，并非生态学意义上的网络。

## 六、艺术案例：莫奈《日出·印象》

1872 年，莫奈在勒阿弗尔港画了一幅 48×63 厘米的油画，1874 年在巴黎的「无名艺术家协会」展览上展出，被评论家勒鲁瓦借题嘲讽，印象派由此得名。

看形式。画面左上是一轮橙红的太阳，很低，光晕模糊；天空是灰蓝与淡紫的混合，向下过渡到更冷的水面。港口在背景里：吊车、桅杆、烟囱的剪影，几笔深蓝灰扫出，几乎不成形。前景两只小艇，笔触短促，颜色直接从管里挤出，没有罩染。太阳在水面的倒影是几道断开的橙色横笔，与冷色并置，没有过渡。

这幅画在黑格尔的框架里处于一个尴尬位置。它画的正是自然美的「不确定」：晨雾、光的瞬间、形状的消融。按黑格尔，艺术的任务是把理念显现在感性里，可这幅画几乎放弃了「理念」——它没有叙事、没有性格、没有伦理力量，只有光与空气。它把艺术交给了自然，让画布变成一块敏感的视网膜。

但它同时证明了黑格尔的另一面。这幅画之所以是艺术而非风景，因为笔触是选择的结果：哪几笔留下，太阳偏高还是偏低，都是心灵的决断。印象派把「自然的瞬间」提升为「可见的形式」，正是「心灵从自身产生出作品」的例证。

冲突可以这样表述：黑格尔要求艺术让理念可见，印象派让光可见。这场冲突至今没有仲裁者。它提示我们，等级论有一个未被审查的前提——艺术的价值在于表现「心灵性的内容」；这个前提本身属于德国古典时期对「严肃艺术」的期待。

## 七、思想联系

向前，这条等级论的直接前身是康德的目的论判断。康德在《判断力批判》里把自然看作一个「仿佛有目的」的系统，自然美因此成为「自然对我们示好」的迹象；黑格尔把这个「仿佛」去掉，把自然规定为「自在的理念」，于是自然美成了理念的初级形态。另一个前身是席勒的「素朴」，古代人与自然的合一被现代人失去，自然因此带上怀旧的色彩。

向后，影响分两支。一支是批判：阿多诺在《美学理论》里说，自然美在黑格尔之后成了「艺术的伤疤」——艺术越是自足，越把自然美排除在外，而自然美恰恰是「非同一性」的庇护所，是那些不能被概念收编的东西。这个论点把黑格尔的等级论彻底翻转：自然美之所以重要，正因为它不服从意义。另一支是建设：环境美学在 1970 年代之后成为独立学科，卡尔森、伯林特、罗尔斯顿（Holmes Rolston III）各自建立了自然欣赏的规范理论，黑格尔则成了他们共同的「反面起点」。

中国的实践美学接过这个问题。李泽厚一系强调「自然的人化」，认为自然美产生于实践对自然的改造；这条思路与「心灵高于自然」同构，只把主体从「意识」换成了「劳动」。生态美学则更接近阿多诺，主张自然有超出人的尺度的价值。

## 八、本节总结

- 自然美是「自在的」理念，艺术美是「自为的」理念；差别在存在方式，不在强度。
- 「自然美只是为我们而美」有三层含义：不为自身、依赖心境、没有标准。
- 自然美按「内在性递增」排列（无机物、植物、动物），动物是顶峰也是终点；灵魂不显现的缺陷使艺术美成为必需。
- 环境美学从认知、身体、伦理三方面反攻，最有力的一击是「不确定性来自无知」。
- 黑格尔式辩护只能守住「艺术能表现什么」，守不住「自然的美是什么」。

值得追问的是：如果自然美依赖人的意识，那么在一片无人到访的荒野里，美还存在吗？说它存在，需要什么样的存在论？说它不存在，我们又凭什么为保护它付出代价？

::: key 本讲要点
- 「自在／自为」是全部论证的支点，也是全部争议的起点。
- 黑格尔不否认自然美，他否认自然美能成为科学对象、能承担真理。
- 三形态的层级逻辑是内在性递增，动物生命是自然美的顶峰与终点。
- 环境美学的反攻迫使黑格尔派把「美」与「审美价值」分开。
- 这场争论的实质是：美是否必须与自我意识绑定。
:::
