## 一、本节导入

1798 年，耶拿，一份名叫《雅典娜神庙》的小杂志开始刊登编号的短句。有的只有两三行，说完就断。同一批人却在别处宣称，真正的诗应当是「总汇」的，要把一切体裁、一切知识、一切生活都吸收进来。一边把话说得极短，一边要求把世界说尽，两个动作看起来相反。

这个矛盾就是本讲要处理的问题。施莱格尔兄弟、诺瓦利斯、蒂克、施莱尔马赫同时放弃了两种最体面的写作方式：体系的哲学论文与古典的完整作品，转而选择断片、未完成的长篇小说，以及把批评与诗混在一起。这套理论后来被黑格尔当作最危险的敌人。

「浪漫主义」是个被用坏的词，常被当作风格标签——月光、废墟、激情、中世纪。它在耶拿最初是一套关于「有限者如何面对无限」的立场。

## 二、核心知识：四个概念与四股潮流

::: def 浪漫主义（作为立场）
一种主张：有限物（作品、个体、制度）只有在指向无限时才有意义，而任何有限物都不足以承载无限，因此必须自己标出这个不足。它天然带有反思性与形式实验。
例子：一首情诗写完了，浪漫派的要求是让它承认自己没说完——靠叙述者自嘲，或结尾故意不解决。
:::

::: def 断片（Fragment）
有意为之的未完成短章。它与残篇不同：残篇是散佚的结果，断片是写作的决定。它与格言也不同：格言自足且带教谕，断片以开口本身为目的。
例子：施莱格尔把断片比作刺猬——自成一体，浑身是刺，谁想整体抓住它就会被扎手。
:::

::: def 浪漫反讽（romantische Ironie）
艺术家对自己作品保持的超越自由：他在作品内部现身，把作品作为作品揭示出来，从而悬置它的绝对性。它指向作品的界限，而非嘲笑内容。
例子：霍夫曼《公猫摩尔》把猫的成长回忆与乐队指挥的传记交替编排，猫在稿纸上涂改主人的文字，读者无法忘记这是「写出来的」。
:::

::: def 无限渴慕（Sehnsucht）与蓝花
渴望的对象是缺失本身：越接近越确知不可达，于是「未达」成为价值。蓝花是它的图像。
例子：诺瓦利斯《亨利希·冯·奥夫特丁根》开头，主人公梦见一朵蓝花，花心露出一张脸；小说结束时他仍未采到它。
:::

「浪漫主义」在 1800 年前后至少指四股潮流。混为一谈，就会得出「逃避现实」或「革命」两种错误结论。

| 潮流 | 时间地点 | 要解决的问题 | 关键词 | 代表 | 政治位置 |
|---|---|---|---|---|---|
| 耶拿派 | 1796—1801，耶拿 | 主体无限而作品有限 | 反讽、断片、总汇诗 | 弗·施莱格尔、诺瓦利斯、蒂克 | 早期倾向共和，晚期多人转向保守 |
| 英国湖畔派 | 1798—1815，湖区 | 自然与道德感如何互相支撑 | 情感的自然流露、想象 | 华兹华斯、柯勒律治 | 由激进转向保守 |
| 法国浪漫派 | 1820—1848，巴黎 | 古典规则与「丑」的地位 | 怪诞、激情、色彩、现代性 | 斯塔尔夫人、雨果、波德莱尔 | 多与共和派结盟 |
| 德国晚期浪漫派 | 1800—1820，柏林 | 内在性的深渊与艺术宗教 | 夜、无意识、双影、器乐 | 霍夫曼、艾兴多夫 | 文化复古，政治复辟 |

四者都反对规则、看重情感、以无限为尺度；分歧只在「无限」被安放的位置：自我、自然、历史社会、夜与死后。

诺瓦利斯给这套立场写过一个操作公式，大意分四步：

1. 给平凡的事物一个崇高的意义；
2. 给日常的景物一个神秘的外观；
3. 给已知的东西以未知者的尊严；
4. 给有限的东西以无限的假象。

第四条里的「假象」值得停留。他没有说有限物真的变成了无限，只说它获得了无限的外观。这个保留使浪漫化免于变成泛神论的狂喜。

## 三、代表人物

弗·施莱格尔（Friedrich Schlegel，1772—1829）生于汉诺威，在哥廷根学语文学，1796 年赴耶拿，与兄长奥古斯特·威廉合办《雅典娜神庙》，在上面以断片把「反讽」与「总汇诗」写成纲领，1799 年的《露辛德》是它的实践。1808 年在科隆皈依天主教，此后进入外交与邦联政治，晚年立场与耶拿时期几乎相反。这个转折本身是论据：反讽的倡导者可以变成复辟的官员，这套理论并不自带政治方向。

诺瓦利斯（Novalis，本名哈登贝格，1772—1801）在耶拿听过费希特与席勒的课，1797 年未婚妻索菲病故，《夜颂》由此写成。他在弗赖贝格学矿业，把数学、地质与诗放进同一个「浪漫化」纲领。《亨利希·冯·奥夫特丁根》未完成，蓝花因此永远停在途中。

海涅（Heinrich Heine，1797—1856）1831 年移居巴黎，1835 年的《论浪漫派》是他应法国读者之请写的清算之作。

## 四、理论解析：反讽为什么是哲学问题

**先看它为什么在此时出现。** 三个条件叠在一起。其一是康德：审美判断无概念而普遍，崇高论又把「无限」引入审美经验，艺术从此以表现主体的自由为任务（参见第 1 模块第 4 讲、第 5 模块第 5 讲）。其二是费希特：自我设定非我，一切存在都是自我设定的产物，因而也可被自我扬弃。其三是斯宾诺莎主义的复兴：1785 年围绕莱辛的泛神论争论把「一切限定都是否定」变成公共话题，有限物只是无限实体的样式。再加上施莱尔马赫 1799 年的《论宗教》，宗教被放在「对无限者的直观与感受」上，艺术与宗教成了邻居。

**要解决的困难很具体。** 如果主体无限，作品有限，那么每件完成的作品都在撒谎：它把有限物摆在了无限的位置上。四种解法由此产生——断片让作品不冒充整体，反讽让作品标出自己的界限，浪漫化让有限物携带无限的意义却不占据无限，渴慕把「不可达」本身设为对象。

**施莱格尔的论证可以拆成六步。**

第一步，给纲领：浪漫诗是「渐进的总汇诗」（progressive Universalpoesie，通译如此）。这是定义，不是论证。

第二步，「总汇」意味着取消体裁界限：小说、童话、断片、批评、翻译都可入诗，依据是「总汇」的字面要求。

第三步，既要总汇一切，任何单件作品都无法完成它，诗必须永远在途中，依据是无限不可穷尽。

第四步，诗因此必须包含对自己的反思，在描绘之中描绘描绘者。依据是费希特式的反思：意识总能再上一层，把刚才的活动当作对象。

第五步，反思的形式就是反讽：作者在作品内部保持自由，可提升它，也可悬置它。依据是康德式的天才自由。

第六步，结论：诗的对象从「作品」转为「诗化活动」本身。

接缝在第四步与第五步之间：从「诗要包含批评」到「诗要悬置自身」，还需一条隐含理由——只有悬置才能防止有限物冒充绝对，而施莱格尔从未系统论证它。

**反讽有三层，混用会失去各自的问题。** 修辞层是说反话：明明下着雨，却说「好天气」。苏格拉底层是装作无知，用提问引出对方定义里的矛盾——《大希庇阿斯篇》里苏格拉底追问「美是什么」，把希庇阿斯的答案逐个拆掉，自己始终不给定义。先验层是施莱格尔的：艺术家对作品的自由，作品因此不被当作绝对。

三层共享「双重立场」：同时在内、在外。说反话的人同时占据字面与真意；苏格拉底同时是无知者与提问的支配者；浪漫反讽的作者同时在作品里与作品之上。塞万提斯让堂吉诃德在第二部里读到第一部，人物知道自己是被写的，是它的近亲。

::: warn 反讽就是讽刺或嘲弄
这个等式是最大的误读。施莱格尔的反讽带有严肃目的：防止作品偶像化。它的动作是「标出界限」，不是「取消内容」。中译本把 Ironie 译作「滑稽」，朱光潜在注释里说明理由——它指「艺术家对现实世界形象的自由玩弄的心情」。译名一旦落地，「玩弄」就容易被读成「开玩笑」，原意里的克制反而消失。
:::

**黑格尔的批评是这套理论遇到的最强反对。** 他在《美学》第一卷全书序论里专设一节处理「滑稽」说，把它追溯到费希特式的抽象自我。

::: quote 《美学》第一卷，全书序论
如果按照滑稽说，艺术家就是自由建立一切又自由消灭一切的“我”，对于这个“我”没有什么意识内容是绝对的和自为自在的，而只显现为由我自己创造并且可以由我自己消灭的显现（外形）……
:::

他的推理是一条链：自我设定一切，所以一切内容对我只是外形；既然只是外形，我就无法对它持严肃态度；没有严肃态度，就没有实体性的意蕴；没有意蕴，艺术只剩自我欣赏。他给这种状态起名「精神上的饥渴病」：主体渴望客观性，又怕沾染有限事物。

**双方最强的理由可以摆在一起。** 黑格尔一方：艺术要承载真理，就需要有实体性的内容，而反讽解除了「事情本身」的约束，作品因此无法被认真对待。浪漫派一方：悬置不等于消灭，标出界限恰恰是另一种严肃；黑格尔自己的浪漫型艺术也要求主体性的自由，他反对的是「把反讽当最高原则」；「精神饥渴病」则是心理学化的处理，把理论命题读成了气质缺陷。

我倾向于认为，黑格尔对「反讽制度化之后的任意」诊断得相当准，对反讽的原意则读得过窄。两家共享一个前提：艺术必须与真理相关。分歧在于真理是否必须既成：黑格尔要一个已经在那里的意义，浪漫派要一个永远在途中的意义。

**「理想」之争也该放在这里。** 温克尔曼的理想美从个别形体中提炼普遍形式，形态完整、静穆、现在时；浪漫的理想以未完成、以未来、以缺失为形态。差别在有限与无限的关系：古典让无限安居在有限里，浪漫让有限永远追赶无限。形状上一个圆，一个箭头。

**海涅的政治解读提供了另一种反对。** 《论浪漫派》的论点是：德国浪漫主义为中世纪招魂，根底是宗教的，政治上与复辟同谋。有力处在史实：晚期施莱格尔、根茨与梅特涅时代的检查制度确实共处一个屋檐下。弱点在于抹平了耶拿派早期的共和倾向；而且海涅本人正是用反讽写作的，那句「浪漫派已经终结」的宣告本身就是浪漫式姿态。由此下一个分寸有限的判断：浪漫主义没有统一的政治，决定其位置的，是它把哪个共同体当作无限的载体——民族、教会、人类，或者个体。

## 五、经典原著：《雅典娜神庙断片》与《论宗教》

《雅典娜神庙》1798 年创刊，1800 年停刊，由施莱格尔兄弟主编，作者包括诺瓦利斯、蒂克、施莱尔马赫。它的形式本身就是纲领：断片、对话、短评混排，最后一期以《论不理解》收尾——一篇为「被误读」辩护的文章，给整份杂志的开放形式做了注脚。

其中被引用最多的一条给浪漫诗下了定义：它是「渐进的总汇诗」，要把诗与散文、天才与批评、艺术诗与自然诗、生命与诗统一起来，永远在生成中，永不完结。这一条把三件事绑在一起：体裁的取消、批评的入诗、无限的不可完成。

同一时期的《论宗教》是施莱尔马赫向「有教养的蔑视宗教者」所作的五篇讲演。他把宗教从形而上学与道德中分离出来，规定为对无限者的直观与感受。如果宗教的核心是感受而非教义，艺术就有了与宗教同级的功能。

::: note 一个译名的问题
黑格尔《美学》中译本把 Ironie 译作「滑稽」，并在注释中说明：德文此字不指一般讽刺，而指艺术家对现实世界形象的自由玩弄的心情，故译「滑稽」较妥。这个选择照顾了黑格尔的贬义语境，却让中文读者很难把「滑稽」与「反讽」这套现代批评术语接上。
:::

黑格尔的《美学》是最佳的反面材料。他把「滑稽」说放在全书序论里处理——在他那里，浪漫反讽是一个必须被排除的起点，而非可以吸收的环节。这也解释了他后来为什么坚持「理想」必须有实体性的意蕴。

## 六、艺术案例：贝多芬《第三交响曲「英雄」》

这部作品 1805 年首演，双管编制加三支圆号。

第一乐章以两个 E♭ 大调强力和弦开场，像两声宣告；随后主题没有交给小提琴，而由大提琴在低音区唱出。把「英雄」的主体从高音区的辉煌挪到低声的吟唱，推翻了听众对「主角在哪里」的预期。发展部大幅扩张，插入新的 E 小调主题，结构出现一段不属于原计划的阴影。最著名的是圆号在再现部之前「提前误入」：主调还没回来，它已吹出主题，弦乐还停在属和弦上——接缝被暴露了一瞬。

第二乐章是 c 小调葬礼进行曲，附点节奏构成沉重步伐。第三乐章用谐谑曲取代小步舞曲，社交性的体裁被换成突变的动能。第四乐章是变奏曲，主题取自舞剧《普罗米修斯的造物》，先给低音骨架，再逐层重建。

用反讽的框架读，能对上三件事：圆号的误入是形式自我暴露，作品在关键时刻指出自己是构造；谐谑曲取代小步舞曲是体裁界限的取消；终曲把主题拆成骨架再重组，统一来自断裂的接合，与断片的逻辑相近。还有一层：据学生里斯后来回忆，贝多芬原将题献写为「献给波拿巴」，1804 年拿破仑称帝后涂去，改题「为纪念一位伟人而作」。标题的撤回是作品对自身的二次操作。

::: fig a-heroica | 《英雄交响曲》：两个和弦的宣告、低音区的主题、圆号提前误入再现，构成「暴露接缝」的结构
:::

这个读法有明确限度：贝多芬没有读过施莱格尔，把他说成浪漫反讽者是回溯投射。较为吻合的说法是，这部作品在形式上做了反讽所做的工作——暴露构造、取消体裁界限、让整体由断裂构成——但它的动力来自革命时代的英雄伦理。

## 七、思想联系

向前追溯，这套理论承接康德的审美自由与崇高论、费希特的反思结构、斯宾诺莎主义的泛神论，以及赫尔德对民歌的收集。它反对的是法国新古典主义的规则体系与温克尔曼式的静的古典理想（参见第 4 模块第 3 讲）。

向后看，黑格尔把反讽判为非艺术，由此确立「理想须有实体性意蕴」这条标准（第 5 模块第 9 讲）。克尔凯郭尔 1841 年的《论反讽概念》是更锋利的内在批评：苏格拉底的反讽是「无限的绝对否定」，若不被他所谓的「幽默」接续，会把主体自身也掏空。瓦格纳与叔本华把「无限渴慕」接到音乐上，下一讲处理。二十世纪还有两次清算：本雅明 1919 年的《德国浪漫主义的批评概念》把早期浪漫派的「反思」读成无限媒介，认为批评的功能是完成作品；卡尔·施米特同年的《政治的浪漫主义》指控浪漫主体把一切都当作「机缘」，因此在政治上是非决断的。

## 八、本节总结

::: key 本讲要点
- 浪漫主义作为立场：有限物只有指向无限才有意义，而任何有限物都不足以承载无限，故必须自标不足。
- 四股潮流的分歧在于「无限」被安放在哪里，同一套语汇有四种政治后果。
- 反讽有三层：修辞的说反话、苏格拉底的装无知、施莱格尔的先验悬置。要的是第三层，目的是防止作品偶像化。
- 断片是对体系的形式抵抗：刺猬式地自成一体，又浑身是刺。
- 黑格尔的批评击中「制度化的反讽」导致的任意，未击中「防御性的反讽」的原意；两家共享「艺术须与真理相关」的前提。
:::

这套理论的历史效果超出了文学。它把「作品必须承认自己是作品」变成现代艺术的一条基本自觉，从塞万提斯式的人物自我指涉，到二十世纪的元小说，都能看到它的变形。

值得继续追问的问题：如果完成的作品必然把有限当成绝对，那么一切经典是否都带有意识形态的性质？反过来，如果每件作品都必须当场声明自己不够，艺术还能不能承担它想承担的那些重量？
