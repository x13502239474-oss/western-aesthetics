## 一、本节导入

1855 年，彼得堡大学的学位答辩厅里，一个二十六岁的中学教师提交了一篇题为《艺术对现实的审美关系》的论文。题目温和，内容却在拆一座大厦。当时俄国读书人接触的美学，大多来自黑格尔一系的讲义：美是理念在感性中的显现，艺术因为是精神的产物，地位高于自然。这篇论文的结论正相反——现实中的美高于艺术中的美，艺术最多是现实的代用品。

一个日常的困惑可以把这场争论拉近。假设要在两幅画之间判高下：一幅是学院里反复练习的圣母像，一幅是乡间一个正在喝水的农妇。判据是什么？学院的答案是理想化的程度——形体要修正，表情要升华；这篇论文的答案是生活的含量——那个农妇的脸色、手臂、姿态里有多少真实的生活。两种答案都能自圆其说，但对「艺术应该让人看见什么」的回答完全不同。

这场争论值得细读，因为它是美学史上第一次把一个明确的社会标准放进美的定义里。此后一百多年，凡想让艺术回答生活的人都会回到它，担心艺术被社会任务压扁的人也会回到它。它在中国的命运尤其特殊：1950 至 60 年代那场美学大讨论，很大程度上是在它的概念框架里进行的。

## 二、核心知识：一个定义与三个推论

这篇论文的力量来自一个定义，两个分句各有分工。

::: def 美是生活
车尔尼雪夫斯基的核心命题。第一个分句处理「事物本身美」：我们在事物中看见依照我们的理解应当如此的生活，它就美。第二个分句处理「事物唤起美」：事物显示出生活，或使我们想起生活，它就美。**例**：一个健康的农家少女属于前者，她的红润面色与有力手足本身就是生活的充实；一片秋天的白桦林属于后者，它本身没有生活，却让人想起生活的季节。两个分句把美的根据从理念搬到生活，也把判断权交给「我们的理解」。
:::

三个推论可以逐条展开。

::: def 代用品（суррогат）
车尔尼雪夫斯基用来给艺术定位的词：艺术是现实的代替品，只在无法直接拥有现实时才被需要。他以纸币与黄金的关系作比（大意）：纸币的价值来自它能兑换的黄金，一旦这层关系断了，它只是一张纸。后果很重：艺术的价值被设定为派生的、可兑换的。
:::

::: def 生活的教科书
车尔尼雪夫斯基给艺术功能的名字。艺术在再现生活之后，还要说明生活、对生活作出判断，使读者知道什么样的生活值得过。**例**：一幅描绘纤夫的画不只要让人看清劳动的姿势，还要让人判断这种劳动是否正当。它把认识与规范捆在一起，艺术因此同时是镜子与判词。
:::

三个推论可以排成一张表，与黑格尔一系逐条对照。

| 争点 | 黑格尔一系 | 车尔尼雪夫斯基 |
| --- | --- | --- |
| 美的根据 | 理念在感性中的显现，根据在理念 | 生活在感性中的充实，根据在生活 |
| 现实与艺术的等级 | 艺术美高于自然美，因为艺术由自觉的精神产生 | 现实美高于艺术美，艺术只是代用品 |
| 艺术的任务 | 使真理显现，完成精神的自我认识 | 再现生活，说明并判断生活 |
| 判断的尺度 | 理念显现的完满程度 | 生活的充实与正当 |

四行里最要紧的是第二行。等级一旦颠倒，后三行都跟着改写：艺术降为传递手段，艺术家从「精神的器官」变成「生活的解释者」。

## 三、代表人物：一个平民知识分子的选择

车尔尼雪夫斯基（Nikolay Chernyshevsky，1828—1889）生于萨拉托夫一个神父家庭，1846 年入彼得堡大学历史语文系。大学几年里，他读费尔巴哈，也读傅立叶的空想社会主义；1848 年欧洲革命的消息与俄国随后收紧的书报检查，一起构成了他的政治启蒙。1853 年写完学位论文，1855 年答辩并发表；1856 年起主持《同时代人》的文学批评栏，1862 年被捕，此后是苦役与流放，1883 年才获准移居阿斯特拉罕。长篇小说《怎么办？》写于狱中。

他面对的问题很具体。平民知识分子想用文学推动社会改革，当时的美学却教他们：艺术比现实更高，因为艺术是精神的领域。这套说法在书斋里成立，在政治上有另一种效果——它劝人把最好的注意力投向远离现实的地方。论文要拆的就是这道台阶。

贡献在于把阶级的生活条件写进审美判断，让「美」这个最普遍的字眼显出社会内容。局限有两处：他的黑格尔是二手的，主要经由俄国 1840 年代的转述与费肖尔一类的体系著作；他笔下的「黑格尔美学」因此比原著更整齐，也更容易被推翻。

## 四、理论解析：五步论证与它的裂缝

### （一）理论为什么出现在这里

三个条件叠在一起。第一是农奴制危机：1850 年代俄国关于改革的讨论已把「生活应该如何」变成公共问题，美学若要介入，需要一个能把美与生活接起来的定义。第二是平民知识分子入场：别林斯基在 1840 年代已把艺术定义为「形象的思维」，车尔尼雪夫斯基接过这个要求，把它从批评原则推到本体论。第三是黑格尔美学的支配地位：1830 至 40 年代的黑格尔热使「美是理念的感性显现」成为常识，而反驳常识最有效的办法是给它一个同样简短的对案。

### （二）论证的五个步骤

1. **立定义。** 美是生活，即凡显出或使我们想起「应当如此的生活」者皆美。这一步靠的是定义的简明，不靠推理。
2. **用阶级经验检验定义。** 他对比农家少女与贵族妇女：前者美在鲜润的面色、有力的手足、饱满的精力，因为劳动生活需要这些；后者美在苍白、纤弱、小手小脚，因为不劳动的生活使手足萎缩。同一个人体，两套标准。说服力全来自具体观察。
3. **比较现实与艺术。** 他给出三条理由：现实中的美是完整的、活的、当下在场的；艺术受媒介限制，只能片面地再现；我们看画，往往是因为看不到原物。三条理由合起来，得出艺术是代用品的结论。
4. **重定艺术的两个目的。** 第一目的是再现生活，包括人的情感与理想；第二目的是说明生活与判断生活。前者是认识，后者是规范。
5. **给艺术一个新位置。** 艺术低于现实，却不被取消：现实的美分散、易逝，艺术可以集中它、保存它、传播它。这是他留出的余地。

第 2 步最有创造性，也是后世引用最多的地方。它把审美判断从「趣味」拖到「生活条件」：一个人觉得什么美，取决于他过什么样的生活、想要什么样的生活。这个洞见在 20 世纪被社会学取向的美学反复重述。

### （三）与黑格尔的对立，以及对立中的误读

黑格尔的命题有两面。一面是「美是理念的感性显现」，根据在理念；另一面是理念必须显现于感性，艺术的价值恰在两者的统一。他还承认自然有美，只是认为自然美要由精神来照亮，因而不如艺术美。车尔尼雪夫斯基抓住第一面，对第二面几乎没有回应。

这一反在效果上有力，在文本上不完全准确。把黑格尔读成「美在概念」，等于把一个以调和为宗旨的体系读成了柏拉图式的体系。研究者通常认为，这篇论文的批判对象更多是俄国 1840 年代被通俗化的黑格尔主义，与《美学》讲义的全部论证尚有距离。

真正的分歧在艺术的地位。黑格尔认为艺术是精神认识自身的一个阶段，因此带有真理的分量；车尔尼雪夫斯基认为真理已经在生活里，艺术只负责传递。前者把艺术放在认识的前沿，后者把它放在传播的中段。这一分歧比「美在哪里」更难调和。

### （四）困难与最强的反对意见

第一，「应当如此的生活」是一个规范词。定义本想说「美即生活」，可生活并不都美，于是加了限定：符合我们理解中应当如此的生活才美。这个限定把标准交给了「理解」，而理解随阶级、时代而变。定义因此有循环之嫌：美的事物显出应当如此的生活，而应当如此的生活又由我们认为美的那种生活来规定。

第二，它难以解释形式的差异。同一题材的两幅画，一幅令人信服，一幅呆板，差别往往在构图、笔触、明暗的处理。「更完整地再现」解释不了这件事，因为两幅画的再现完整度可以完全相同。

第三，比较的对象不对等。把艺术与「现实本身」相比，等于用一个无限的、流动的整体去比一个有限的、固定的制品。艺术创造的许多东西在现实中并不存在——虚构的情节、结构的节奏、被压缩的时间。

第四，一个当时就能提出的反例：摄影。1839 年照相术公布，1855 年论文发表时，摄影已经在俄国传播。若艺术的功能是再现可见现实，摄影在忠实度上远胜绘画。后来的历史恰好相反：摄影迫使绘画放弃记录的任务，转向印象派与抽象。这条反驳不证明他错了，但它证明「再现」无法穷尽艺术的功能。

::: warn 美的自律性如何消失
「应当如此的生活」这个限定，把美学变成了社会理想的表达式。后果有三。其一，形式与技艺失去独立的评价标准：一笔为什么这样落，只能由它是否更有助于说明生活来回答。其二，审美分歧变成政治分歧，讨论无法在美学内部解决。其三，艺术的批判功能反而被削弱——如果美只属于已被认定为正当的生活，艺术就难以肯定尚未被承认的生活方式。

这一结构在 1950 至 60 年代中国的美学讨论中留下明显痕迹。1956 年朱光潜发表自我批判，讨论随之展开；蔡仪主张美是典型，李泽厚主张美是客观性与社会性的统一，高尔泰主张美是主观的。车尔尼雪夫斯基的「美是生活」被反复引用：它提供了唯物主义的起点，也把争论锁进「美在物还是在心」的框架。研究者通常认为，李泽厚一方面批评它用生活代替了美，另一方面又接过「生活」这一落点，发展为实践美学。
:::

## 五、经典原著：一篇论战文字

论文 1853 年写成，1855 年答辩并发表。结构大致三段：先立定义并反驳「美在理念」说，再比较现实美与艺术美，最后重定艺术的使命。文体属论战文字，语气尖锐，例子多取日常生活，与黑格尔《美学》讲义式的从容形成对照。

核心定义值得逐字读：

::: quote 《艺术对现实的审美关系》
任何事物，凡是我们在那里面看得见依照我们的理解应当如此的生活，那就是美的；任何东西，凡是显示出生活或使我们想起生活的，那就是美的。
:::

两个分句的语法值得注意。第一句的主语是「任何事物」，条件是「我们在那里面看得见……生活」；第二句的条件是「显示出生活或使我们想起生活」。两句话都把美放在事物与我们的关系里，没有放在事物的属性里。这是全文最接近现代美学的地方——美成为一种关系项，在事物与人的生活理解之间成立。

枢纽在「依照我们的理解」这一从句。它承认了判断的相对性，也埋下了理论的隐患：既然标准随理解而变，那么美的讨论最终要回到「谁的理解」这个问题上。车尔尼雪夫斯基的回答是阶级与时代，这个回答在社会学上很有力，在美学上却把定义的第一项交给了定义之外的东西。

::: note 版本与译名
此段依通行中译引录。周扬的节译本以《生活与美学》为名流传，是中文世界影响最大的读本。论文原有说明写作目的的自述，大意是这篇文字要对当时占支配地位的美学体系作批判，与建立新体系尚有距离——这解释了全文为何以驳论为主。
:::

## 六、艺术案例：《伏尔加河上的纤夫》

列宾的《伏尔加河上的纤夫》作于 1870 至 1873 年，比论文晚十五年。它几乎逐条对应了「教科书」的三项功能，也暴露了这套框架的缺口。

先看形式。十一个纤夫沿河岸排成一条从右下向左上延伸的斜线，纤绳把人与远处的船连成一体，重力全压在这条线上。领队的老纤夫正面朝向观者，身旁的壮年侧着身，两人构成第一组对比；前景的少年挺直身体，一只手试图松开勒住肩膀的纤绳——这是全画唯一的反向姿态。背景的桅杆在逆光里几乎成了剪影，天空占的比例很小，土黄与灰蓝构成基本色调。视线无法逃向远景，只能落在人的身体上。

三项功能与论文的要求较为吻合。再现：衣服的补丁、绑腿的布条、纤绳勒进肩膀的角度，具体到可以核对。说明：队形与纤绳显示的是一种被组织起来的劳动。判断：少年的挺直身体是一个含蓄的抗议，画家没有画标语，判断从姿态里透出来。

缺口也在同一幅画里。这幅画的力量有很大一部分来自构图——斜线的压力、少年的反向姿态、色彩的压抑。用「更完整地再现」解释不了为什么这样排列比那样排列更有力；若只以再现的完整度为标准，一张清晰的纪实照片本该更好。这套框架能说明这幅画为什么重要，却说不清它为什么好。

## 七、思想联系

向前，别林斯基在 1840 年代已把艺术定义为「形象的思维」，要求理念化为典型、文学承担时代的精神；车尔尼雪夫斯基接过这个要求，把它从批评原则推到本体论——美本身就落在生活里。费尔巴哈的人本学提供了语言：人是感性的存在，美也必须是感性的、此岸的。黑格尔的体系是他的反面，参见第 5 模块第 9、10 讲。

向后，杜勃罗留波夫的「现实的批评」把这套标准变成方法：从作品出发，检验它是否忠实于生活。普列汉诺夫在评述车尔尼雪夫斯基美学的文章里既肯定这一现实立场，又指出它忽略了阶级性与形式的相对独立，把俄国民主主义美学推进到马克思主义框架。苏联 1934 年的社会主义现实主义把「教科书」论制度化，使它从批判的武器变成规范的教条。中国一线，周扬的译本、1950 年代的讨论、李泽厚以后的实践美学，都是这个命题的延长线。

## 八、本节总结

- 「美是生活」以两个分句界定美：显出「应当如此的生活」者美，显示或唤起生活者亦美。根据从理念移到生活，判断权交给「我们的理解」。
- 三个推论：现实美高于艺术美，艺术是代用品；艺术的第一目的是再现生活；第二目的是说明与判断生活，故艺术是教科书。
- 创造性在第 2 步：农家少女与贵族妇女的对比，把审美判断接到阶级的生活条件上。
- 与黑格尔的对立集中在艺术的地位，而它对黑格尔的读法经过简化，靶子更接近俄国通俗化的黑格尔主义。
- 代价是美的自律性消失：形式无法被独立评价，审美分歧化为政治分歧。这一结构在 1950 至 60 年代中国的讨论中留下了痕迹。

值得继续追问的是：如果美的判断必须依赖「应当如此的生活」，那么一件挑战我们生活理想的作品，还能不能是美的？这个问题至今没有公认的答案。

::: key 本讲要点
- 定义的两个分句分别覆盖「事物本身美」与「事物唤起生活记忆而美」。
- 现实高于艺术、艺术是代用品、艺术是教科书，三个推论同出一个定义。
- 与黑格尔的冲突在艺术是否承担真理，不只在「美在哪里」。
- 「应当如此」是规范词，它使美学成为社会理想的表达式，这是理论的力量所在，也是它最受攻击之处。
:::
