## 一、本节导入

拿一根弦绷紧，在正中间按下，再拨一半的长度，声音升高八度。把手指移到三分之二处，得到五度；移到四分之三处，得到四度。三次试验，三个简单分数。做实验的人不需要知道任何数学，他的耳朵已经先做出了判断：这三个音在一起听起来是「合」的，其余位置听起来是「散」的。

把这个日常经验翻过来看，就是一个形而上学命题：使声音听起来合的东西，是弦长之间的整数比。公元前 6 世纪的毕达哥拉斯学派做了这个翻转。他们由此得出一个在本模块里反复出现的结论——美有客观根据，这个根据可以计算。

这个纲领的吸引力在于它同时满足两种渴望：它让美成为公共可检验的（任何人量一量弦长就能复核），又让美保持神圣（数是宇宙的骨架，能懂数就是接近神）。它的困难也在这里：一旦美被换算成比率，那些无法换算的美——一首曲子的走向、一张脸的生动、一个姿态的分寸——就无处安放。

::: note 铁匠铺的传说
古代传记说，毕达哥拉斯走过铁匠铺，听出不同重量的锤子敲出协和音程，由此发现比率。这个故事几乎可以确定是后人编的：锤子的音高取决于材质、形状与悬挂方式，并不与重量成简单整数比。传说本身仍有价值：它说明学派希望把「发现」写成一次听觉事件，与计算无关。引用这条材料时必须标明它是传说，晚出数百年。
:::

## 二、核心知识：比率、和谐与四数

先要拆开一个常被混用的区别：数字（arithmos）与比率（logos、analogia）。毕达哥拉斯学派并没有说万物由数字构成，那是后世的通俗化。他们的主张更精确：事物的规定性由数之间的关系给出。12 这个数字本身不美，6 也不美；2:1 这个关系才美。所以「万物皆数」的准确读法是「万物的结构皆可表示为比率」。

::: def harmonia（ἁρμονία）
原义是「接合」「榫接」，用于木工与造船，指不同部件被调适成一个能承力的整体。在音乐里它指音与音之间的调适关系，后来才引申为「和谐」这种感受性质。这个原义很要紧：harmonia 首先是一个结构词，指部分如何被装到一起，其次才是一个听觉评价词。
:::

音程是这个理论的核心证据，因为它是古代世界少数可以被精确测量的美。请看这张表。

| 音程 | 比率 | 弦长关系 | 在四数中的位置 |
|---|---|---|---|
| 八度 | 2:1 | 全弦与半弦 | 4 与 2 |
| 五度 | 3:2 | 全弦与三分之二 | 3 与 2 |
| 四度 | 4:3 | 全弦与四分之三 | 4 与 3 |
| 全音（五度减四度） | 9:8 | 由 3:2 除以 4:3 得出 | 派生，不在四数内 |

表中 1、2、3、4 四个数之和为 10，学派称之为 tetraktys（四数），并把它当作誓词的对象。四数之所以神圣，理由在结构上：1:2 给八度，2:3 给五度，3:4 给四度，三个协和音程恰好被前四个整数穷尽。这跟数字崇拜无关；震动人的是「用最少的元素生成最多的秩序」这件事本身。

::: def tetraktys（τετρακτύς）
意为「四数组」，指 1、2、3、4 构成的序列。它的功能是把协和音程的全部比率压缩进一个可视的图形（通常画成十点的三角形），从而使「宇宙有秩序」变成一个可以指着看的命题。它是毕达哥拉斯学派的核心象征。
:::

第二步的推广是灵魂。学派主张灵魂也是一种 harmonia：身体各部分的调和产生生命，正如弦的调和产生音。这个类比有一个直接后果：灵魂可以被「调音」，失调就是疾病，重新调好就是治疗。第三步的推广是宇宙：天体按距离构成音程，运行发出声音，这就是「天体音乐」。

::: def katharsis（κάθαρσις）
早期含义偏医学与宗教：指把体内多余或有害的东西排出，也指通过仪式洗去污染。毕达哥拉斯学派把它用于灵魂，指用音乐、舞蹈、饮食与静默把失调的灵魂重新调回秩序。它与后来亚里士多德在《诗学》里讲的悲剧效果有词源关系，内容并不相同，参见第 2 模块第 6 讲。
:::

## 三、代表人物：毕达哥拉斯与菲洛劳斯

毕达哥拉斯（Pythagoras，约前 570—前 495）生于萨摩斯，据说因不满僭主政治迁往南意大利的克罗顿，在那里建立了一个兼具宗教团体、政治同盟与学术学派性质的共同体。他不留著作，团体内部流行「他本人说过」（autos epha）的权威句式，这使后人极难区分哪些主张属于他本人，哪些属于两百年间的学派积累。所有关于他的传记——扬布里柯、波菲利的作品——都晚出七百年以上，作为史料需大幅打折。

菲洛劳斯（Philolaus，约前 470—前 390）是学派史上的关键人物。他可能是第一个把学说写成书的人，后世哲学家正是通过他的残篇接触到毕达哥拉斯派的宇宙论。他提出的框架是「有限者与无限者」由 harmonia 结合：世界由两类原则构成，二者本身对立，靠比率被调适为可理解的整体。这个框架把「美在于比率」从一个音乐事实提升为一条宇宙论原则。

两人的差别值得注意。毕达哥拉斯更像一位教派领袖，其权威建立在生活方式与神启上；菲洛劳斯更像一位理论家，其权威建立在论证与文本上。美学史上真正起作用的是后者的框架：它第一次给出了「秩序如何从无秩序中产生」的形式化描述，而这个描述后来被柏拉图《蒂迈欧》整段接收。

## 四、理论解析：四步论证与它松动的三处

这个学说的力量来自一个环环相扣的推理链。把它拆成四步，每一步的支撑与裂缝都会显出来。

1. 现象层的归纳。可测量的协和音程对应简单整数比。支撑：实验可重复，任何人用单弦琴都能验证。裂缝：这只覆盖了「协和」这一种听觉性质，尚不涉及旋律、节奏与表现。
2. 概念层的定义。把「和谐」定义为部分之间的比率关系，于是美成为关系属性，不再附着于个别对象。支撑：它解释了一个事实——同样的音在不同音区仍然协和，说明起作用的确实是比例而非绝对音高。裂缝：关系属性需要一个承载者，纯粹的比率自身并不显现，必须落在材料上。
3. 存在层的推广。灵魂是和谐，天体是和谐，德性也是和谐。支撑：类比的一致性——凡有秩序处皆有比率。裂缝：这一步靠类比串联，而类比本身不构成证明。亚里士多德后来在《形而上学》里批评的正是这一点：把数当作事物本身，而数本应是事物的属性。
4. 本原层的收束。数为本原，所以美有客观根据，且这根据可知。支撑：它给美学提供了一个可检验的标准，这是西方第一次。裂缝：它无法说明为什么某些同样有秩序的东西并不美——秩序是美的必要条件，未必是充分条件。

::: warn 黄金分割是后世的归纳
流行的说法是：毕达哥拉斯学派发现了黄金分割，并把它当作美的法则。这个说法站不住。第一，欧几里得《几何原本》第六卷确实讨论了「中末比」的作图，但那已是公元前 3 世纪，距离毕达哥拉斯两百年以上。第二，没有任何公元前 5 世纪以前的材料把中末比与「美」联系起来；学派关心的是可听的比例，而中末比在听觉上没有对应物。第三，「φ」这个符号由工程师马克·巴尔在 20 世纪初采用，据说取名于菲狄亚斯；「黄金分割」这个名称要到 19 世纪才通行。把它读回毕达哥拉斯学派，是把后世的归纳当成了原初的教义。
:::

第四步的困难还可以换一个方向说。毕达哥拉斯学派最有力的证据全部来自听觉，而他们最想解释的对象却包括视觉形式。听觉的比率可以由弦长直接测量，视觉的比率要靠什么测量？建筑与雕塑的「和谐」是否也服从同一套整数比？古代材料对这一点说得含糊。后世把这套方法移用到视觉艺术时，实际上加入了一个新假设：眼睛与耳朵服从同一套数学。这个假设在文艺复兴被当成公理，在近代被实验心理学检验，结论比想象中复杂。参见本讲第六节。

## 五、经典原著：一个没有书的学派

毕达哥拉斯学派没有留下可读的原典，我们面对的是三条性质不同的史料链。第一条是亚里士多德在《形而上学》第一卷中对前苏格拉底诸家的评述，可靠但经过他的问题框架过滤——他关心的是「本原」问题，因此把毕达哥拉斯派读成一批主张「数是本原」的宇宙论者。第二条是亚里士多德《论天》与一些医学、音乐著作中对「天体音乐」的转述，其中提到我们听不见天体的声音，理由是从出生起就一直在听，如同铁匠习惯了打铁声。第三条是晚出的传记与汇编，包括扬布里柯《毕达哥拉斯传》与塞克斯都·恩披里柯的记述，材料丰富但需要逐条辨伪。

这种史料状况决定了一件事：谈「毕达哥拉斯的美学」时，严格说来谈的是一个学派的长期沉积，而非一个人的学说。任何把某句话钉死在毕达哥拉斯名下的做法都需要额外的证据。

::: quote 《美学》第一卷，「艺术美，或理想」一章论外在形式的部分
这种质的差异不再保持彼此之间的单纯的对立，而是转化到协调一致，才有和谐
:::

这段话出自黑格尔对「抽象形式的美」的分析，不是毕达哥拉斯派的原文，需要明确区分。它的价值在于点出了本讲理论的一个隐含困难：如果和谐只是量的关系，那么它永远停留在「整齐」的层面；真正的和谐要求差异者各自保持其质，又被调成一个整体。黑格尔把「质」引进来，等于替毕达哥拉斯学派补上了他们缺的那一环——比率解释了秩序，却解释不了为什么秩序令人愉悦。

## 六、艺术案例：米洛的维纳斯与测量出来的美

米洛的维纳斯（约前 2 世纪末，卢浮宫藏）是「比例美学」最常被援引的标本。先看形式本身。雕像的重心落在右腿，左膝微屈前移，骨盆因此倾斜，肩线朝相反方向偏转，整个身体沿一条缓慢的螺旋轴上升。衣褶从髋部滑落，堆在脚边，把下坠的重量变成了向上的支撑。头部转向左侧，视线不与身体同向——这个细微的错位让静止的石像有了「将要动作」的余地。这些效果靠的是重心、轴线与体块的关系，确实是一种比例，但它是可调节的动态比例，不是一组固定分数。

再看常被引用的数据。流传的说法是：以肚脐为分割点，雕像上下两部分之比接近 0.618；或说身高与某段长度之比符合黄金比。这类测量在方法上有两个漏洞。其一，测量点可以自由选择——肚脐、髋骨、膝、发际线都能当分割点，只要换一个点，比值就会落到 0.6 附近或远离它。其二，样本只有一个，无法排除巧合。更要紧的是，古希腊雕塑家的工作方式依赖模件与经验校正，而非一套统一的比例公式；维特鲁威记载的人体比例是整数分数，与黄金比无关。

于是这座雕像给本讲的学说提供了一个双向的例证。一方面，它确实显示出希腊人对身体比例的极端敏感，这种敏感与毕达哥拉斯学派的训练同源。另一方面，当后人试图把这种敏感还原为一组数字时，得到的往往是自己的期待。美的根据也许真在关系里，但关系不等于一个常数。

:::

## 七、思想联系

向前看，毕达哥拉斯学派的直接前身是埃及与近东的度量传统。埃及雕塑与壁画使用方格网确定人体比例，这套技术提供了「美可以被规范」的实践基础；希腊人的推进在于把规范从手艺口诀变成可论证的比率。

向后看，影响的路径有三条。其一是柏拉图。《蒂迈欧》把宇宙描述为由数学秩序构成的活体，四元素按比例结合，灵魂按音程划分——这套宇宙论几乎是把菲洛劳斯的框架改写成了神话叙事。其二是文艺复兴的比例理论。阿尔伯蒂在《论建筑》里把音乐协和音程的比例移用到建筑立面，帕乔利写《神圣比例》为黄金比辩护，这两步把听觉的比率正式转成了视觉的规范。其三是近代的形式主义与实验美学。汉斯力克在《论音乐的美》里主张音乐的内容就是乐音的运动形式，可以看作毕达哥拉斯纲领的现代版本；费希纳在 19 世纪用大量被试测试矩形偏好的实验，则第一次用统计方法检验「比例令人愉悦」这一假设，结果并不整齐——偏好分布在若干比值上，且受文化与呈现方式影响。

这三条线索合起来说明一件事：毕达哥拉斯学派留下的主要是一套提问方式，而不是一组答案。「美的根据能否被形式化」这个问题，至今仍是美学的基本问题之一。

## 八、本节总结

::: key 本讲要点
- 学派的主张是「结构可表示为比率」，而非「万物由数字构成」；数字与比率必须分开。
- 音程证据（2:1、3:2、4:3）是全部推论的支点，它把美从感受变成可测量的关系。
- harmonia 的原义是「接合」，指部分被调成可承力的整体，先有结构义，后有听觉义。
- 黄金分割与毕达哥拉斯学派没有可靠联系，它是欧几里得以后的数学事实与近代的审美归纳。
- katharsis 在学派那里指用音乐把失调的灵魂调回秩序，属于医学-宗教的净化，与亚里士多德的悲剧理论不是同一件事。
:::

这套学说的贡献在于给了美学第一个客观主义纲领：美不依赖某人的口味，而依赖可复核的结构。它的局限在于把「有秩序」当成了「美」的全部，于是无法处理秩序之外的东西——分寸、生气、情境。下一讲的苏格拉底正是从这一侧进攻：他换了一个问法，不问「比例是多少」，改问「这东西对什么有用」。

值得继续追问：如果美真是比率，为什么同一比率在教堂立面上显得庄重，在广告图上显得呆板？是比率变了，还是比率所服务的目变了？
