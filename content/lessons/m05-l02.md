## 一、本节导入

一七八七年十二月，康德写信给耶拿的莱因霍尔德，说自己发现了一条「新的先天原则」，它属于愉快与不快的情感，不属于认识，也不属于欲求。两年后，《判断力批判》出版。

一个写完两大批判的人，为什么还需要第三部？通常的解释是：前两部留下了裂缝。第一部把自然写成现象界的因果系统，人在其中只是自然的一部分；第二部把自由交给本体界的道德法则，人作为理智存在者服从它。问题是，这两幅图景如何共存？道德法则要求我们在感性世界里实现目的，可自然并不保证这些目的能实现，甚至不保证自然与道德有任何关系。

裂缝可以这样表述：知性为自然立法，理性为自由立法，两种立法各有领地，互不侵犯，也因此互不沟通。人同时属于两边，却找不到中介。第三批判要做的，就是找这个中介。

## 二、核心知识：判断力、合目的性、先验原则

::: def 判断力（Urteilskraft）
把特殊归摄到普遍之下的能力。康德把它的运用分成两种：普遍已给定时，它做规定；只给定特殊时，它要自己去寻找普遍。
例子：医生看到皮疹，若已知病名，把症状归入其中，这是规定；面对一种从未见过的病症，先要问「这是什么」，为它找一个类，这是反思。
:::

::: def 反思判断力（reflektierende Urteilskraft）
只给定特殊、须自行寻找普遍的判断力。它不宣布对象是什么，只为理解对象而给自己一条原则。与之相对的是规定判断力（bestimmende Urteilskraft）：普遍已被给出，判断力只负责归摄。
例子：植物学家在雨林里见到一株不认识的植物，先比较它的叶序、花冠、子房位置，再决定它属于哪一科。此时没有现成的分类表等着他，他必须先假定「这株植物属于某个类」，才能开始工作。
:::

::: def 合目的性（Zweckmäßigkeit）
一个对象的各部分只有通过它们与整体的关系才可能，整体的概念先于部分，这种结构称为合目的性。康德区分两种：外在的（如钟表，目的在制作者心里）与内在的（如树，树是自己的原因与结果）。
例子：一只表的齿轮为指针服务，指针为读时服务，目的在钟表匠的设计里；一棵树的叶子为整棵树输送养分，落叶又滋养树根，因果在这里是循环的。后者才是「自然目的」的模型。
:::

::: def 先验原则（Prinzip a priori）
不来自经验，却使某类经验成为可能的原则。它不告诉我们对象有什么性质，只告诉我们必须以什么方式去理解对象。
例子：因果性。我们无法从经验里「看到」因果，但凡把两次相继的事件理解为客观序列，就已经预设了它。
:::

三个概念合起来，就是这部书的骨架。判断力是一种能力，反思判断力是它的一种运用，合目的性是它给自己的一条先验原则。三者的关系是「能力—运用—原则」的层级，并非并列。

三大批判可以列成一张表：

| | 对象域 | 高级认识能力 | 立法 | 先天原则 |
|---|---|---|---|---|
| 《纯粹理性批判》 | 自然（现象界） | 知性 | 为自然立法 | 因果性等知性范畴 |
| 《实践理性批判》 | 自由（本体界） | 理性 | 为自由立法 | 道德法则 |
| 《判断力批判》 | 自然与自由的中介 | 判断力 | 不给他者立法，只给自己立法 | 自然的形式合目的性 |

第三行有一处特别：判断力没有自己的领地。它不为自然立法，也不为自由立法，只给自己一条反思的原则，康德称之为「自律」（Heautonomie）。它不宣称自然真的合目的，只规定自己应当怎样去看自然。

## 三、代表人物：康德

康德（Immanuel Kant，1724—1804）一生的活动范围几乎没有超出柯尼斯堡。早年做编外讲师，教逻辑、形而上学、自然地理与人类学，收入靠听课费，直到一七七〇年才拿到教授职位。他的写作节奏是沉默多年，然后一次爆发。一七八一年《纯粹理性批判》，一七八三年《导论》，一七八五年《道德形而上学奠基》，一七八八年《实践理性批判》，一七九〇年《判断力批判》。

第三批判的写作动机有两层。一层是体系的：两大批判留下的鸿沟必须处理，否则哲学分成两截，人也被分成两截。另一层是论战的：一七八〇年代，雅可比公布了对斯宾诺莎泛神论的解读，赫尔德与狂飙突进的自然观也在流行，康德需要一个既能保住机械因果、又能给生命与美留位置的说法。合目的性正好承担这个任务：它让自然可以被「看作」有安排，却不侵犯机械规律。

康德的贡献是把「目的」从形而上学命题降格为反思的立场。他的局限也在这里：一旦目的只是立场，它就无法回答自然究竟有没有目的。这个限制在第三部书的最后部分变成公开的困难，康德自己承认，目的论只能证明我们有理由如此看，不能证明事情本来如此。

## 四、理论解析：鸿沟与桥梁

**第一步：确认鸿沟。** 导论说，自然概念的领地与自由概念的领地之间横着一道「不可估量的鸿沟」（大意）。两者共享同一个感性世界，却按不同法则被规定：一边是必然，一边是自由。自由的概念要在感性世界里实现目的，自然就必须至少被设想为与这些目的相容。这个「至少被设想为」是全部问题的入口：它要求一个可思的框架，证明在此既不可能也不需要。

**第二步：找中介。** 康德的心灵能力表分三层：认识能力、愉快与不快、欲求能力；对应的高级能力是知性、判断力、理性。愉快与不快夹在认识与欲求之间：它不像认识那样给出对象，也不像欲求那样推动行动，只表示主体在表象中如何被触动。判断力因此成了结构上的中介。这一步靠建筑术的对称，经验并未提供证据，因此常被讥为「按图纸找人」。

**第三步：给反思判断力一条原则。** 反思判断力面对的世界是杂多的：经验规律无穷，知性只能先天给出少数最普遍的规律。若这些规律彼此毫无亲缘，经验研究就无法进行。于是反思判断力给自己一条原则：自然的诸经验规律具有系统的统一，仿佛有一个知性为我们的认识能力作了安排。这原则不主张自然事实上统一，只主张我们必须如此假定；它不由经验归纳得来，恰恰是经验研究的前提；它不规定对象，只规定反思的进程。三点合起来，说明它是先验的、调节性的、自律的。

**第四步：分成两支。** 审美的用法：对象的形式让我们愉快，我们把它看作仿佛为认识能力而设，不需要目的概念，这是主观的形式合目的性。目的论的用法：我们把某个自然物看作自然目的，各部分互为因果，这需要目的概念，是客观的合目的性。前者归审美判断力批判，后者归目的论判断力批判；两支共享同一条原则，方向相反。

**第五步：桥梁的机制。** 「桥」有三重含义，常被混为一谈。

1. 从自然到自由：审美判断让我们感到自然与能力合拍，这种合拍可以类比于道德情感。
2. 从自由到自然：合目的性让「自由的目的应当在自然中实现」至少可以被思考。
3. 体系统一：判断力把理论哲学与实践哲学连成一个整体。

**桥通到哪里。** 支持者认为康德完成了一件了不起的事：既没有独断地断言自然有目的，也没有把自由还原为自然，只给出一个让两者可共存的立场。反对意见同样有力。第一，调节性原则不等于构成性原则：桥只通到「可思」，不通到「已知」。第二，「仿佛」承担了太多重量：自然的系统统一若只是假定，经验研究为何总能成功？康德只能回答，成功属于幸运，构不成保证。第三，黑格尔认为康德的和解停留在主观的「应当」，真正的统一要在绝对精神的历史运动中实现。第四，达尔文之后，目的论从科学中退场。

公允的判断是：桥梁的成就不在证明，而在重新描述问题。它把「自然与自由如何统一」从形而上学问题改写为反思的立场问题。改写本身是成功的，许诺的证明没有兑现；后续的德国古典美学，几乎都在替康德补这张支票。

::: warn 「合目的性」就是「有目的」
最常见的误读是把「合目的性」当成「有一个目的」。康德的用法恰好相反：合目的性描述的是形式的结构，即部分与整体互为条件；它可以在没有目的、没有设计者的情况下被设想。一朵花的形式显得「像是为了被看而长成这样」，这句话里没有花的目的，也没有园丁。正因如此，审美判断才能既合目的、又无目的。
:::

## 五、经典原著：《判断力批判》

《判断力批判》一七九〇年出版，是三大批判的最后一部。全书分两部分：「审美判断力批判」与「目的论判断力批判」。前者包括美的分析论、崇高的分析论、纯粹审美判断的演绎、以及审美判断力的辩证论；后者包括目的论判断力的分析论、辩证论与方法论。书前有两篇导论，较长的一篇在康德生前未发表，后称「第一导论」。

导论是全书的关键，因为它交代了「哲学如何分为两部分」「判断力如何居中」。整部书的任务因此被定义为「过渡」问题，「美是什么」退居其次。

::: quote 《判断力批判》导论（大意，据通行中译）
在自然概念的领地与自由概念的领地之间，横着一道不可估量的鸿沟。
:::

引文之后，康德紧接着说，自由的概念应当在感性世界中实现它的目的，因此自然必须被设想为与自由的目的相容。这两句话合起来，就是桥梁的全部任务：它不要求自然变成自由，也不要求自由变成自然，只要求两者的过渡可以被思考。

## 六、艺术案例：帕特农神庙

雅典卫城上的帕特农神庙建于公元前五世纪中叶，供奉雅典娜。它的基本形制是围柱式：东西各八根柱，南北各十七根，台基三级，内部是前后两进的神室。

形式上有几处不寻常的处理，近代测量才逐渐确认。台基的中部略略隆起，两端下沉，整条台基线呈极缓的弧线；柱身中部微微外凸，称为「收分」，并非笔直圆柱；四角的柱子比中间的略粗，与邻柱的间距略小；几乎所有的「垂直」线都向内微微倾斜。

效果很明确：站在庙前看，一切都显得直、稳、匀。若按严格的几何直线建造，人眼反而觉得台基中间下陷、角柱偏细。这些调整像是为了观看者的眼睛而作的。

用康德的术语，这正是「主观形式的合目的性」：形式显得仿佛为我们的认识能力而设，我们却指不出它为了什么目的。说它「为了好看」不准确，因为「好看」算不上目的；说它「为了结构」也不准确，因为几何上更直的线同样稳固。合目的性在这里是一个纯粹的「仿佛」。

但这个例子也暴露了分类的困难。神庙有明确目的：供奉与祭祀。按康德的分法，它属于「依附美」，以「神庙应当是什么」的概念为前提。同一个对象上，审美判断与目的论判断并存，框架要求我们分清层次，实际经验却总把两层混在一起。

::: fig a-parthenon | 帕特农神庙：台基的缓弧、柱身的收分与角柱的加粗，都是肉眼几乎不可见的调整，效果却是整体显得笔直
:::


## 七、思想联系

向前追溯，合目的性来自亚里士多德的目的因：自然物的「何所为」内在于它自身，橡子朝着橡树生长。康德保留了这一结构，抽掉了它的形而上学断言，只留下反思的立场。另一条线索是莱布尼茨的前定和谐：身心之间、自然与心灵之间的协调由上帝预先安排。康德的「合目的性」可以看作前定和谐的先验化：不再有安排者，只剩下「仿佛被安排」的形式。

向后看，席勒把合目的性转为教育问题，谢林让自然成为「可见的精神」，黑格尔把目的论纳入辩证法。达尔文之后，自然的目的问题被自然选择接管，康德的调节性原则却在另一处复活：法伊欣格的「仿佛哲学」与二十世纪的科学哲学都借用了「仿佛」的结构。

## 八、本节总结

::: key 本讲要点
- 第三批判要填平自然与自由之间的鸿沟，方式是寻找一个中介能力。
- 反思判断力只给定特殊、须自行寻找普遍；它给自己一条先验原则，即自然的形式合目的性。
- 合目的性有两种用法：审美的主观形式合目的性，与目的论的客观合目的性；两者共享原则，方向相反。
- 判断力没有自己的领地，只有自律；它不宣称自然合目的，只规定自己如何看自然。
- 桥梁通到「可思」，未通到「已知」；这个限制是康德的诚实，也是后来者的靶子。
:::

如果把这部书压缩成一句话：它用「仿佛」取代了「就是」，用反思的立场取代了独断的证明。这个替换让哲学避免了一次僭越，也让它失去了一次确定。

值得继续追问的问题：一座桥若只保证两岸「可以同时被看见」，它还算桥吗？今天的生态哲学在谈论「自然的目的」时，究竟是在使用康德的调节性原则，还是已经悄悄回到了亚里士多德？
