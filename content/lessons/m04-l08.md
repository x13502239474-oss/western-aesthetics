## 一、本节导入

一个学生查英文词典，发现「美学」写作 aesthetics，而「美」是 beauty，两个词不同源。再翻 1750 年那本以此为名的拉丁文著作，第一节的定义里竟找不到「美」这个字：它说这门学问是「感性认识的科学」。

奇怪的地方在这里。今天我们把美学理解为「关于美的哲学」，可这门学科的名字来自希腊语 aisthesis（感知）。命名的理由与研究对象之间有一道缝，缝里藏着学科史：一门研究「感性认识如何完善」的学问，怎样变成研究「美是什么」的学问。

鲍姆嘉通（Alexander Gottlieb Baumgarten，1714—1762）做的不只是取名字。他要为一个被判定为「低级」的认识能力争取合法性，说明诗与感官经验有自己的一套完善标准。这次争取成功了一半：学科建起来了，地盘却始终带着「低级」的印记。

## 二、核心知识：三个术语

::: def 美学（aesthetica）
鲍姆嘉通在 1750 年《美学》第 1 节给出的定义是：美学是感性认识的科学。它同时被称作「自由艺术的理论」「低级认识论」「美的思维的艺术」「理性类比的技艺」。
例子：判断一首诗的好坏，靠的是对字音、意象、节奏的直接感受，而非证明；研究这种感受如何形成、如何趋于完善，就是 aesthetica。
:::

::: def 感性认识（cognitio sensitiva）
与理性认识相对的一类认识：它通过感官与想象把握对象，得到的是具体、丰富、混杂的表象，而非抽象的概念规定。
例子：看见一个人，你立刻认出「这是熟人」，同时感到他的疲惫、他衣服的颜色、他站立的姿态。这些内容无法一次翻译成命题，却真实地被认识到了。
:::

::: def 完善（perfectio）
经院—莱布尼茨传统里的核心概念：一物之完善，指它符合自身的概念，各部分协同构成一个统一体。用在认识上，指表象的丰富、鲜明与彼此一致。
例子：一幅肖像画得「完善」，指它不仅像，而且眼神、姿态、衣褶都指向同一个人格；若五官精确而神情散乱，就谈不上完善。
:::

要理解这次命名的必要性，得先看它想在哪个坐标系里占位置：

| 认识等级 | 拉丁术语 | 特征 | 传统归属 | 例子 |
|---|---|---|---|---|
| 模糊 | obscura | 不足以分辨对象 | 不算认识 | 雾里看见一团影子 |
| 清晰而混淆 | clara et confusa | 能分辨对象，分不清其内部规定 | 无人认领 | 一眼认出是熟人的脸，却说不出五官关系 |
| 清晰而明晰 | clara et distincta | 既能分辨对象，也能分辨其内部规定 | 逻辑学、形而上学 | 解剖学地说明这张脸的骨骼结构 |

第二行是空着的：沃尔夫体系把它叫作「混淆的认识」，承认它清晰，却排在「明晰」之下，当作过渡阶段。鲍姆嘉通要做的，就是给这一行填上学科名称。

::: warn 「美学」的原义是「感知学」
aesthetica 来自希腊语 aisthesis（感知、感觉），形容词 aisthētikos 意为「可感知的」。鲍姆嘉通造这个词时，强调的是「感性认识」这一认识类型，与「美」的关系是间接的：美是感性认识达到完善时的状态。把 aesthetica 直接读成「关于美的学问」，等于用结果替换了对象。
「美学＝美的哲学」的等式形成于十九世纪末的转译链。通行说法是：明治时期的日本学者西周在介绍欧洲学科分类时把 Ästhetik 译作「美学」（他此前也用过「善美学」「佳趣论」等说法），汉语学界随后沿用。这个译名挑出了学科最醒目的结果，丢掉了它的认知义；加上二十世纪中国美学教材多以「美是什么」为第一问题，等式就固定了。若要贴近原义，译作「感性学」较为吻合；但学科早已按这个名字生长，改名已不可能。
:::

## 三、代表人物：鲍姆嘉通

鲍姆嘉通生于柏林，父亲是柏林驻军教会的牧师，家境清寒。1730 年入哈雷大学，学神学与哲学，深受沃尔夫体系与哈雷虔敬主义的双重影响；哈雷当时正是沃尔夫被驱逐后争论的中心。1735 年他以《关于诗的若干哲学沉思》取得任教资格，其中已经出现用希腊词根构造的「感性论」一词，并把诗定义为「完善的感性言说」。1740 年任哈雷大学教授，1750 年出版《美学》第一卷，1758 年出版第二卷，未及完成便于 1762 年去世，年仅四十七岁。

他的处境说明了问题意识。所受的训练要求他把一切知识纳入「清晰—明晰」的阶梯，而他读诗、讲诗时发现，诗的力量恰在「不明晰」处：具体的形象、饱满的细节、情绪的浓度。他要为这块经验找到位置，又不背叛体系。贡献是给了它名字与合法性；局限是接受了「低级」这个定位，从此这门学科总要靠「比逻辑学低一级」来定义自己。

## 四、理论解析：为感性争一块地盘

### （一）问题：清晰性作为唯一门槛

沃尔夫的体系把认识能力排成阶梯，越往上越抽象：感觉最低，想象居中，知性最高。判断一门学问是否成立，看它的对象能否被清晰分解为概念。按这条标准，诗与绘画提供的知识永远停在半路：形象太具体，无法化约为定义；感动太私人，无法进入证明。

尴尬由此产生：诗被公认为重要，却在哲学的法庭上没有席位。布瓦洛式的规则可以教人写得合格，却说不清诗为什么是一种认识。鲍姆嘉通要回答的正是这一问。

### （二）第一步：为「混淆」平反

关键在词义。拉丁语 confusa 的字面意思是「融合在一起」，指多种规定尚未被分开辨析，并不指「糊涂」。一个「清晰而混淆」的表象，清晰到足以认出对象，又丰富到无法一次拆开。

鲍姆嘉通由此提出一个反转：这种「未拆开」属于另一种完善的形式。逻辑学追求「内涵的清晰」，概念的规定越少越明确越好；感性认识追求「外延的清晰」，同一瞬间呈现的规定越多、越鲜明越好。一首诗写「月光像水一样漫过台阶」，「月光」的内涵没有增加，被照亮的外延却扩大了。两种清晰各有方向，不能用一把尺子量。

这一步的支撑是现象描述：我们确实能在没有概念的情况下分辨极细微的东西（一张脸上的疲惫、一段旋律里的犹疑）。若承认这类分辨是认识，就得承认它有优劣，也就可以有一门研究其优劣的学问。

### （三）第二步：命名的四个同位语

《美学》第 1 节的定义带有四个同位语，每一个都在为这门新学科找靠山：

1. **自由艺术的理论**（theoria liberalium artium）——把诗、绘画、音乐纳入同一个理论对象，此前它们分属不同的技艺传统。
2. **低级认识论**（gnoseologia inferior）——与逻辑学并列，构成认识论的两支；「低级」指对象在阶梯上的位置，不含贬义，却也不免费。
3. **美的思维的艺术**（ars pulchre cogitandi）——给出可训练性：思维可以按美的要求被训练。
4. **理性类比的技艺**（ars analogi rationis）——最要紧的一个。感性认识虽不能推理，却有「类似理性」的运作：比较、联结、概括，只是以形象的方式做。

第四个是枢纽。它让感性认识免于「非理性」的指控：诗有它的逻辑，只是与三段论不同构。后世所谓「想象力的逻辑」，源头可追到这个词组。

### （四）第三步：美作为感性认识的完善

定义落到美上：美是感性认识的完善（perfectio cognitionis sensitivae）。要理解这句话，得把「完善」的用法还原到它的形而上学背景。

在莱布尼茨—沃尔夫的框架里，完善是一个目的论概念：一物之完善，指它充分地是它该是的东西。用在认识上，完善指表象的完备：该有的都在，且彼此协调。感性认识的完善因此有三重内容——材料的丰富、形象的鲜明、各部分的一致。三者齐备，对象就在感官面前呈现「圆满」，这就是美。

这个定义有两个后果。第一，美被安放在认识论里，成为认识的一种性质，而非对象的属性；这与英国经验主义把美归于情感不同路。第二，美与真共用同一个结构（完善），只是层面不同：真属于概念，美属于表象。于是「美是感性层面的真」在鲍姆嘉通这里有根据。

::: note 「可感知物的科学」这一译解
aesthetica 常被译作「可感知物的科学」（scientia cognitionis sensitivae 也可读作「关于感性认识的科学」）。两读的侧重不同：前者把对象放在「可感之物」上，接近后来的感性学；后者放在「感性认识」上，强调这是认识论的子学科。文本同时支持两读，学界至今并用。
:::

### （五）第四步：范围与野心

《美学》的内容比「美」宽得多：感性的自然禀赋、训练、审美的艺术，也讨论丑、错误、冗赘、晦涩，即感性认识的各种失败形态。这门学问从一开始就包含「不美」的研究。

野心的顶点出现在他对诗人的描述里。他早年把诗人比作「另一个世界的创造者」（heterocosmos），大意是：诗人造出一个自足的世界，其成员按自身关联成立，不必对应现实。这为艺术虚构争到本体论位置，也预示了「审美自律」的议题。

### （六）问题与三条反对

第一条来自康德。他在《纯粹理性批判》「先验感性论」的注释里大意说：德国人用「感性论」指别人称为「趣味批判」的东西；鲍姆嘉通想把对美的批判纳入理性原则，这项努力是徒劳的，因为那些规则是经验的，无法充当先天法则。这一击很准：「完善」若要充当规范，必须证明感性有先天的合法则性，而他只给出描述。

第二条来自黑格尔，措辞更狠：

::: quote 《美学》第一卷，全书序论
这个名称实在是不完全恰当的，因为“伊斯特惕克”的比较精确的意义是研究感觉和情感的科学。
:::

黑格尔接着说，正因如此，这门学问的正当名称应当是「艺术哲学」或「美的艺术的哲学」。他承认这个名称已被语言采用，只好沿用。这段评价代表德国古典哲学对鲍姆嘉通的总体判断：命名有功，格局太窄——把美学建在「感觉」上，等于把艺术降为感官的练习。

第三条是内在的循环。「美是感性认识的完善」与「完善是美的」互相支撑：要知道哪种感性认识算完善，得先知道什么是美；要知道什么是美，又得先有完善的标准。他可以用「完善」的形而上学定义（符合概念）来打破循环，但那个定义预设了目的论，十八世纪以后已难维持。

## 五、经典原著：《美学》

《美学》1750 年出版第一卷，1758 年出版第二卷，全书未完成。写作形式很特别：拉丁文，按编号段落推进，每段之下附密集的引例与注疏，引例多取自拉丁与希腊诗人。这种写法表明它的定位——一部教学用的系统手册。

结构上大致分两部分：理论美学讨论感性认识的本性、完善与失败形态；实践美学讨论如何训练感性、如何写作。第一卷开头的定义段是全部论证的起点，也是后世引用最多之处：

::: quote 《美学》§1
Aesthetica (theoria liberalium artium, gnoseologia inferior, ars pulchre cogitandi, ars analogi rationis) est scientia cognitionis sensitivae.
:::

中译大意：美学（自由艺术的理论、低级认识论、美的思维的艺术、理性类比的技艺）是感性认识的科学。四个同位语把学科的四个面向一次说完：对象、位置、方法、根据。句子的密度很高，也暴露了困难：四个面向之间没有推导关系，只是并列。

## 六、艺术案例：拉斐尔《雅典学园》

1509 至 1511 年，拉斐尔为梵蒂冈签字厅绘制《雅典学园》，画古希腊哲学家聚于一堂。画面宽约七米，人物五十余，分列于一座带拱券的古典建筑中。

形式上有几处关键处理。第一，建筑给出一个可测的空间：连续的拱券向纵深退去，消失点落在中央两位人物之间的缝隙上，观者的视线被透视直接送到那里。第二，两位中心人物用手势分工：柏拉图手指向上，亚里士多德掌心向下，两种哲学在一组对立的手势里被同时呈现。第三，人群结成若干小组：前景左侧毕达哥拉斯在书写，右侧欧几里得在作图，台阶上斜卧着第欧根尼；各组自成一个动作单元，又被视线与身体的朝向串起来。第四，光线均匀，人物在地面投下方向一致的阴影，空间因此可信。

用鲍姆嘉通的术语说，这幅画给出的是「外延的清晰」：五十多个人物、书籍、仪器、姿态在同一瞬间涌来，第一眼的印象极丰富，却无法一次分辨；若要「明晰」化，得逐一辨认谁是托勒密、谁捧着什么书，这需要知识与时间，而画的力量恰在辨认之前发生。这正是「感性认识的完善」的范例：圆满不靠命题正确，靠表象在感性层面的丰盈与协调——手势与手势呼应，空间的深远与人群的密度互相支撑。

反面的检验同样清楚。若把人物减到十个，空间的感染力立刻下降；若把手势改成一致的朝向，两种哲学的对峙就消失。可见「完善」是可操作的：增减某一组关系，完善程度随之变化。这一点支持鲍姆嘉通——感性层面确有优劣，且优劣可被指认。

这个案例也暴露了他的困难。每个人物之所以「合适」，最终取决于他是否符合「某位哲学家」这个概念：第欧根尼必须慵懒，欧几里得必须俯身。感性的完善要靠概念的恰当来担保，美学于是又回到逻辑学的监护之下。

::: fig a-school-of-athens | 《雅典学园》：拱券把视线引向中央的柏拉图与亚里士多德，一手向上、一掌向下，人群分成若干动作小组
:::

## 七、思想联系

向前追溯，线索从莱布尼茨的「混乱的认识」开始：他承认有一种认识能分辨个体却说不明理由，并以海的轰鸣为例——人听见涛声，却说不出每一道浪的声音。沃尔夫把这个想法系统化为认识能力的阶梯，鲍姆嘉通做的就是在某一级上挂牌建系。

向后看，三条线都从这里出发。康德接受「感性论」这个词，却把它改造成研究时空形式的先验感性论，同时否定把美学建成科学的企图；他在《判断力批判》里改用「反思判断力」处理审美，把合法性建立在认识能力之间的关系上。黑格尔把美学改名为「艺术哲学」，把美的根据从感性认识移到理念的感性显现。克罗齐在二十世纪初重提「直觉即表现」，把「感性认识的完善」改写为「直觉的自足」。

## 八、本节总结

::: key 本讲要点
- 美学 1750 年获得名称与学科位置，定义是「感性认识的科学」，与逻辑学并列构成认识论的两支。
- 命名的动词是 aisthesis（感知），学科原义接近「感性学」，与「美的哲学」的等式是后世转译的产物。
- 鲍姆嘉通为「清晰而混淆」的认识平反：它有自己的完善方向，即外延的清晰。
- 美被定义为感性认识的完善，完善意味着表象的丰富、鲜明与一致，真与美因此共用同一个结构。
- 三条反对：康德说它无法给出先天法则，黑格尔说它格局太窄，循环论证的指责则指向「完善」这个目的论概念。
:::

命名的功绩是让散落的经验有了共同的名字与可讨论的规则；代价是把学科钉在「低级」的位置上，从此它总要向上证明自己。二十世纪以后，研究对象扩张到崇高、丑、日常经验、身体，反而更像回到 aisthesis 的原义。

值得继续追问的问题：如果美学的研究对象本来就不是「美」，那么今天把它译回「感性学」，会改变这门学科的问题清单吗？
