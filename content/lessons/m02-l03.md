## 一、本节导入

朋友说这幅画很美，你问：它美在哪里？他指给你看颜色、构图、气氛。你再问：这些东西为什么让人愉快？他说因为它们配合得好。你最后问：配合得好就是美吗？一台配合得极好的机器也配合得好。于是他沉默了。

苏格拉底（Sokrates）一辈子在做这件事：把人人都以为自己懂的事逼到说不出话为止。他留下的最大遗产是提问方式，答案寥寥。这也解释了他的美学立场为何难定：他没写过一行字，我们看到的苏格拉底至少有两个版本，一个在色诺芬的回忆里，一个在柏拉图的对话里。

先看那个著名的例子。色诺芬《回忆苏格拉底》卷三第八章记载，苏格拉底讨论美时举出两只器物对比：一只编得结实、合用、形状趁手的粪筐，与一面镶金却打造得拙劣的盾牌。他的判断是前者美、后者丑。他还说，对奔跑而言美的身体，对摔跤而言就丑，因为需要不同。

这个答案让现代读者不舒服：它似乎把美降格为实用。先别急着判定。这个看似粗俗的答案背后有一条推理链，把「有用」推到「万物各安其位」，再推到一位设计宇宙的神。

## 二、核心知识：两条史料，两个苏格拉底

研究苏格拉底的第一道难关是史料。他没有著作，记载都是旁人写的，而旁人的目的各不相同。最要紧的两条来源差别极大。

| 比较项 | 色诺芬《回忆苏格拉底》 | 柏拉图早期对话 |
|---|---|---|
| 作者身份 | 雅典军人、史家，苏格拉底的追随者 | 哲学家，苏格拉底的学生 |
| 写作目的 | 为老师辩护，证明他不敬神、不教坏青年 | 呈现哲学探究的过程 |
| 苏格拉底形象 | 劝善的教师，乐于给建议 | 提问者，常自称无知 |
| 论美的方式 | 给出标准：有用、合适、合目的 | 追问定义，反复驳倒候选答案 |
| 对美的结论 | 美与善、有用同一，相对于用途 | 「美本身」尚未找到，探究以困局收场 |
| 史料可靠性 | 熟悉其人，但哲学能力有限，可能简化 | 哲学深刻，但文学化程度高，难以当作实录 |

这张表提出一个方法要求：谈「苏格拉底的美学」时必须说明依据哪条线；混在一起，会得到一个既断言美就是有用、又否认有用是美的定义的苏格拉底。

第一条线的核心是功能主义，关键概念是 ergon（功能、作品）与 arete。arete 在早期希腊语里并不专指道德：一把刀的 arete 是锋利，一匹马的是能跑，一个人的是能把人的事做好。于是美被安放在「适合其功能」这个位置上——一个东西美，因为它的形式恰好实现了它该做的事。

::: def arete（ἀρετή）
常译「德性」，本义更接近「优良」「适合性」。它评价的是事物是否充分实现了自己的功能：刀的 arete 在锋利，眼的 arete 在看得清，人的 arete 在把人的活动做好。苏格拉底把美与 arete 绑在一起，等于说美是「做得好」在形式上的显现。
:::

第二条线的核心是定义追问。柏拉图早期对话里的苏格拉底不断问「什么是X」，并且常常在得到几个答案后把它们一一驳倒，最后承认自己不知道。《大希庇阿斯篇》就是典型：全篇只讨论「美是什么」，结束时问题仍然开着。这条线关心的是后者：使美的东西成为美的，究竟是什么。

## 三、代表人物：苏格拉底与色诺芬

苏格拉底（约前 469—前 399）是雅典人，父亲是石匠。他参加过伯罗奔尼撒战争的几次战役，《会饮篇》写他能在严寒中赤足行走、在战场上背着重甲撤退。公元前 399 年，他以「不敬城邦之神」与「败坏青年」的罪名受审，被判死刑，饮毒芹汁而死。他没有留下著作，思想通过柏拉图的对话、色诺芬的回忆与亚里士多德的零星评述传下来。

他的思想转折有明确记载：年轻时热衷自然哲学，想用因果解释一切，后来对这类答案失望，转向「什么是X」的定义问题。自然哲学问万物由什么构成，定义问题问一个词凭什么被用在同一类事物上；前者产生宇宙论，后者产生概念分析。美学作为追问「美是什么」的学科，其提问形式正是从这里成形的。

色诺芬（约前 430—前 354）也是雅典人，苏格拉底的学生，以雇佣军身份参加波斯王子居鲁士的远征，后被雅典放逐，在斯巴达赐予的领地上务农写作。《回忆苏格拉底》四卷本是一部辩护之作，想把老师写成虔诚、自制、对城邦有益的人。这个目的决定了取材：他多记录苏格拉底的劝告与日常谈话，很少记录那些把人逼到绝境的追问。研究者通常认为，他的材料在事实层面有价值，哲学层面偏于浅显。

## 四、理论解析：从「有用」到「各安其位」

先说「美即有用」。它可以有两种读法，差别很大。

强读法把它理解为彻底的相对主义：美完全取决于使用者的需要，没有任何跨情境的标准，于是「美」只是「对我合用」的另一个说法。弱读法把它理解为功能主义：美是相对于种类与功能的适配，但功能本身是客观的，所以美仍然是客观的。一只粪筐之所以美，因为作为筐它编得结实、形状趁手；这里有标准，并非任意口味。

我倾向于弱读法，理由在文本里。色诺芬笔下的苏格拉底作判断时用「做得好」「适合」这类词，不用「我喜欢」。他给出的是跨种类的标准：一个东西美，因为它的构造实现了用途。这个标准可争论，争论方式是检查构造与用途是否匹配；强读法会取消这种争论，而文本里的争论还在进行。

弱读法也有它的难题，而且难题很硬。

1. 无用的美。落日、野花、无标题的旋律没有用途，却常被认为美。功能主义对此只能沉默。
2. 有害的美。能诱惑人、使人做出坏决定的东西，往往极有效地实现了它的功能——它恰好「合用」于诱惑。若美即有用，它就该是美的；这与我们的判断冲突。
3. 目的的来源。说某物有功能，先要说清功能由谁规定。人工物由制作者规定，自然物呢？
4. 循环的风险。若「有用」被理解为「有益」，而「有益」又被理解为「好」，那么美就被善吞掉了，定义失去独立内容。

第三个难题把苏格拉底推向目的论。色诺芬《回忆苏格拉底》卷四第三章记有他的一套论证：神给人眼睛来看，给眼睑保护眼睛，给手做工，给灵魂认识；万物各有用处，互相配合，构成对人有利的整体。

::: def teleology（目的论）
以「目的」（telos）解释事物之所是的思路：一件事物是什么，取决于它为了什么。刀刃为了切割，所以薄而硬；眼睛为了看，所以透明而能感光。目的论的强弱取决于「目的」的来源：人工物的目的来自制作者，自然物的目的若要有同等地位，通常需要一个设计者。
:::

从「有用」推到「各安其位」，需要三步。

1. 功能步。每个事物有一项它特有的工作（ergon），做得好就是它的 arete。此步由日常技艺支撑，几乎没有争议。
2. 整体步。事物的功能彼此衔接：草养羊，羊养人，人的身体各部分互相服务。此步靠观察，说服力取决于观察的广度。
3. 设计步。如此精巧的衔接不会自发形成，必有一位安排者。此步是跳跃，它把「看起来有目的」直接读成「被赋予了目的」。

三步走完，结论是：宇宙是一个各安其位的秩序，美是这个秩序在每一处的显现。美依然是功能性的，但功能不再由人的需要临时决定，而由神的规定固定下来。美因此重新获得客观性，代价是引入神学前提。

::: warn 苏格拉底并非功利主义者
把「美即有用」读成功利主义，是一个流传很广的误读。功利主义是 18 世纪末以后才成形的学说，主张行为的价值取决于后果的效用；苏格拉底的功能主义主张的是「形式与功能的适配构成美」，两者的问题层次不同。更要紧的是，色诺芬笔下的苏格拉底并不认为人的欲望可以作标准：他强调自制，强调服从神所安排的秩序。把他读成「有用就美」的实用主义者，会漏掉这个维度。
:::

现在看第二条线。《大希庇阿斯篇》的方法示范，可以拆成一组可重复的动作。

1. 提出要求。苏格拉底请希庇阿斯回答「美是什么」，并明确排除举例：他要的是那个使一切美的东西成为美的性质，而非一份美的清单。
2. 接受一个定义。希庇阿斯答：美是一位年轻漂亮的小姐。
3. 找反例。苏格拉底指出，一匹美的母马、一把美的竖琴、一只美的陶罐也可以被称为美；如果「美」等于「小姐」，这些说法就都错了。定义过窄。
4. 加压强。他引赫拉克利特的话（篇中明说是引用）：最美的猴子与人相比也是丑的。于是连「小姐最美」也不成立；同一物在比较中既美又丑，说明「美」不能是任何一个具体事物。
5. 修正定义。希庇阿斯改答：美是黄金。凡是配上黄金的东西就显得美。
6. 再找反例。苏格拉底提到菲狄亚斯为雅典娜雕像所用的材料：面部用象牙，眼睛用石头，因为石头更适合做眼睛。若黄金总是美，这些选择就无法解释。
7. 继续修正。候选定义依次换成「恰当」「有用」「有益」「视觉与听觉的快感」，每一个都被相应的反例击破。
8. 收场。苏格拉底承认不知道美是什么，只留一句谚语式的感叹。

这套动作的意义在于摆出了「定义」的三项要求：覆盖全部被定义项（普遍性），说明被定义项为何如此（因果性），不把待定义的东西偷用进定义里（非循环）。这三项至今是概念分析的门槛。

::: quote 《大希庇阿斯篇》篇末
美是难的
:::

这句是全书最后一句，也是全部探究的唯一结论。它说的并非「美很复杂」，而是：按刚才那种方式追问美，走不通。柏拉图让对话停在这里，把出路留给了后面的理念论。

## 五、经典原著：两部作品的分工

《回忆苏格拉底》四卷，写作目的是辩护。第一卷回应「不敬神」与「败坏青年」两项指控，以后三卷用日常谈话展示苏格拉底的为人。论美的段落集中在卷三第八章，论神的安排集中在卷四第三章。读这两章要注意文体：它们是「记录＋转述」，苏格拉底在这里给出的多是结论性的建议，少有逐步推进的论证。这与柏拉图的对话形成鲜明反差。

《大希庇阿斯篇》篇幅不长，结构是一段框架对话：苏格拉底向一位无名听者转述他前一天与希庇阿斯的谈话。这个双层结构有戏剧作用：苏格拉底在转述时仍在表演。对话中的希庇阿斯是历史人物，来自埃利斯，以背诵与演说闻名，自称能就任何题目即席长篇大论。他与苏格拉底的对峙，一半是哲学方法与修辞术的对峙。此篇在古代归于柏拉图名下，近代有学者怀疑其真伪，主要理由是文中苏格拉底的态度格外咄咄逼人；目前多数学者仍把它当作早期真作处理。

两本书的分工可以这样概括：色诺芬回答「美的东西凭什么美」，答案是合用；柏拉图回答「美本身是什么」，答案是尚未找到。前者给出一个可操作的判准，后者给出一个不可回避的问题。

## 六、艺术案例：拉奥孔群像与「合目的」的边界

拉奥孔群像（梵蒂冈博物馆藏，约前 1 世纪，罗德岛的阿格桑德罗斯父子三人作）是检验功能主义的好场合。题材取自特洛伊传说：祭司拉奥孔警告城邦不要接受木马，海神派两条巨蛇将他与两个儿子缠死。

先看形式。三个人物被蛇身连成近似三角形的块体，顶点是拉奥孔仰起的头，底边是两个儿子被缠住的腿。两条斜边由蛇身勾出，视线沿斜边上下移动，不会停在局部。拉奥孔的躯干反向扭转，右臂弯折而未完全伸出——这个「未伸出」很关键，它让力量看起来被约束在有限空间里。面部眉头紧锁，嘴角下压，口张开却不夸张。整组重心压在中轴附近，四面观者都能找到一个完整轮廓。

温克尔曼在《论希腊雕刻与绘画的模仿》里把它当作希腊艺术的典范，用「高贵的单纯与静穆的伟大」概括，并解释说拉奥孔之所以不号啕，是因为希腊人把痛苦节制在「观念的」层面。这个解释后来受到莱辛质疑，但它指出的形式事实准确：力量来自克制。

把这个事实放到功能主义里会怎样？群像的功能是纪念碑与警示，需要可辨认的叙事与足够强烈的视觉冲击。问题在于，功能要求更强的表情、更夸张的姿态，这件作品却以节制取胜。用「合目的」解释它的题材选择尚可，解释形式分寸则失效。分寸属于趣味与判断。这个缺口正是柏拉图要填的地方——他要找一个不依赖用途的美。

:::

## 七、思想联系

向前追溯，苏格拉底的「有用」与智者派的相对主义共享一个时代背景。普罗塔戈拉说「人是万物的尺度」，把标准交给人的感知；苏格拉底接受这个挑战，却想在人之中找到不随欲望漂移的尺度，于是转向功能与目的：保留了相对主义的问题意识，拒绝了它的结论。

向后看，三条影响最明显。其一是柏拉图的理念论：正因为「有用」无法给出跨情境的标准，《大希庇阿斯篇》才要把美从事物里抽出来，设一个「美本身」。其二是亚里士多德。他接手 telos 这个概念，却把美从使用中解放出来：《诗学》论美在于秩序、对称与确定的大小，《尼各马可伦理学》把「美」用于为行为本身而选择的行为。其三是近代功能主义。十九世纪的建筑理论把「形式跟随功能」当成原则，二十世纪的工业设计与包豪斯把它制度化。这条线索可以看作苏格拉底式提问的远亲，它少了目的论那一半，只谈使用效率。

## 八、本节总结

::: key 本讲要点
- 两条史料必须分开：色诺芬给出「美即有用」的判准，柏拉图早期对话只追问「美本身」，两者结论不同。
- 「美即有用」的弱读法是功能主义：美相对于种类与功能的适配，功能本身客观，因此仍有标准。
- 目的论由「有用」推出，需要三步：功能—整体—设计，第三步是跳跃，靠引入神的设计来补足。
- 《大希庇阿斯篇》示范了定义的三个要求：普遍性、因果性、非循环；全篇以困局收场，未给定义。
- 拉奥孔群像显示功能主义的边界：它能解释题材，解释不了分寸。
:::

苏格拉底在美学史上的位置可以这样描述：他把「美是什么」变成了一个必须回答却暂时无法回答的问题。前一代人满足于描述美如何起作用，他要求给出定义；他没给出定义，却把标准立了起来。兑现这个标准，是柏拉图的工作。

值得继续追问：如果美是「合乎目的」，那么谁的目的算数？使用者的、制作者的，还是宇宙安排者的？三种答案会导出三种完全不同的美学。
