## 一、本节导入

1872 年 1 月，巴塞尔，一位二十七岁的古典语文学教授出版了他的第一本书，扉页题献给瓦格纳。书的前半部分不讲希腊的宁静，讲的是梦与醉：一面是奥林匹斯神祇的清晰形象，一面是狂欢队伍撕开个体界限的咆哮。

这与我们熟悉的希腊相距很远。博物馆里的白色大理石、温克尔曼以来的「高贵的单纯与静穆的伟大」，构成了两百年的常识。尼采要说的恰好相反：那种宁静是结果，前面有一场艰苦的搏斗；希腊人先看见了存在的恐怖，才造出这些形象来承受它。

于是问题变成了：一个民族为什么要花这么大力气造一层面纱？这层面纱又为什么在某个时刻破了？

## 二、核心知识：两种冲动

::: def 日神（apollinisch）
希腊神话中的光明之神，尼采用它命名一种艺术冲动：在梦（Traum）的状态中给出清晰形象、尺度与界限。它的法则是不越界、不失形，因此对应造型艺术与史诗。
例子：雕塑的轮廓就是日神的：正因为有边缘，形体才成立；梦中我们看见形象，却不去追问它是否真实。
:::

::: def 酒神（dionysisch）
用酒神狄奥尼索斯命名的另一种冲动：在醉（Rausch）中，个体的界限崩溃，人与他人、与自然、与神重新合一。它对应音乐与抒情诗。
例子：狂欢节的人群里，姓名与身份暂时失效，人不再知道自己是谁，这种「不知道」同时是恐惧与极乐。
:::

::: def 个体化原理（principium individuationis）
叔本华的术语，来自印度哲学的「摩耶之幕」：个体性属于表象的形式，是把统一的生命之流切成一个个「我」的那道刀口。
例子：看悲剧时忘记自己是「某某」，散场后重新记起——忘记的那一刻，就是个体化原理被撕开的一刻。
:::

::: def 形而上学慰藉（metaphysischer Trost）
悲剧提供的安慰：个体毁灭了，生命本身不灭。观众在英雄的毁灭中感到「生命在根底上仍然强大而快乐」，哀悼与振奋同时在场。
例子：看《安提戈涅》最后一场，悲痛与某种奇异的振奋同时出现，后者就是这种慰藉。
:::

两种冲动的差别可以列成一张表。这张表是全书的地图，但要注意：尼采要讲的是二者的结合，单独的日神或单独的酒神都不构成悲剧。

| | 日神 | 酒神 |
|---|---|---|
| 状态 | 梦 | 醉 |
| 界限 | 严守界限，个体化原理成立 | 突破界限，个体化原理崩溃 |
| 艺术门类 | 造型艺术、史诗 | 音乐、抒情诗、舞蹈 |
| 自我 | 有形象、有名字的个体 | 与太一合一的「无我」 |
| 真理形态 | 假象、外观（Schein） | 深渊、痛苦与狂喜的同体 |
| 危险 | 只剩形式，变成僵硬的古典主义 | 只剩狂乱，变成自我毁灭的混沌 |

## 三、代表人物

尼采（Friedrich Nietzsche，1844—1900）生于普鲁士萨克森的一个牧师家庭，1864 年在波恩学神学与古典语文学，次年转莱比锡，受业于里奇尔。1865 年他在旧书店买到叔本华的《作为意志和表象的世界》，自称被一种「恶魔式的」力量抓住。1869 年，二十四岁的他没有博士学位就被聘为巴塞尔大学古典语文学教授。此后数年他频繁出入瓦格纳在特里布申的宅邸，把对方当作德国文化复兴的希望。

《悲剧的诞生》就是这段关系的产物，也是它的第一次裂痕。书出版后古典学界反应冷淡乃至敌视，1879 年他因健康原因辞去教职，此后十年在瑞士与意大利之间漂泊写作，1889 年在都灵精神崩溃。

他面对的问题是「一个如此敏感的民族如何忍受存在」，「希腊艺术是什么」只是入口。这个问题把美学从鉴赏理论转成了治疗学，也决定了这本书的方法：它要的不是考据，是诊断。

## 四、理论解析：一本用艺术解释希腊的书

**问题先要重新提。** 温克尔曼的希腊是静穆的、完整的、值得模仿的。尼采接受这个描述的一部分，却拒绝把它当作天性。他引用一个古老故事：弥达斯王追问西勒诺斯，对人来说最好的事是什么；对方答，最好的事是不要出生，次好是尽快死去。尼采的读法是：希腊人知道这个答案，所以他们需要奥林匹斯诸神，好让自己能继续活下去。

**论证可以拆成六步。**

第一步，设定前提：希腊人对存在的恐怖异常敏感。支撑它的是那个民间智慧，以及他们对命运、罪、家族诅咒的执着。

第二步，日神造出形象来遮盖恐怖。奥林匹斯神谱是一个「梦的世界」，诸神自己也在受苦、争斗、恋爱，但这套形象让生活显得值得过。尼采把这叫「审美神义论」：为世界辩护的方式，从道德换成了外观。

第三步，日神有边界。形象之外还有音乐与狂欢，那里个体化原理失效，人重新落入太一（das Ur-Eine）的痛苦与狂喜。这一步的支撑是酒神祭的实存，以及音乐的「无形象性」。

第四步，悲剧从合唱队（Chor）中诞生。萨提尔歌队先于舞台存在，舞台上的英雄是歌队投射出的幻象。这一步的支撑是词源：tragoidia 意为「山羊之歌」，歌队是起源，情节是后来的追加。

第五步，悲剧的结构因而是两层的：酒神的音乐（歌队）加上日神的形象（人物、对话、情节）。观众先在音乐中感到深渊，再在形象中看到深渊被赋予形状，于是获得形而上学慰藉。

第六步，悲剧死于欧里庇得斯与苏格拉底。欧里庇得斯把观众请上舞台，用家庭、辩论、可理解的心理取代神话；苏格拉底代表「理论人」，相信一切存在都可被认知、被根据、被修正。神话被逻辑取代，歌队的深渊被台词填平。

**第四步是全书的关键，也最容易被误读。** 亚里士多德在《诗学》里把情节（mythos）定为悲剧的灵魂，尼采把这个次序倒过来：情节是日神的外观，歌队才是酒神的内核（参见第 2 模块第 6 讲）。这个倒转属于哲学决定，考据给不出它：他要问的是悲剧与「存在」的关系，写作技法在其次。

**这一步的弱点也很明显。** 词源学只能证明名称的来源，不能证明本质的来源；把「起源」当作「本质」，是典型的起源学谬误。萨提尔歌队的解释同样依赖构造：尼采需要一个「尚未个体化的集体」，于是把歌队读成了它。他对欧里庇得斯的评价也与当时雅典观众的接受史相悖——欧里庇得斯在舞台上极受欢迎，这是尼采必须解释却解释得很勉强的事实。

**形而上学慰藉的内容值得单独看。** 它说的是：尽管现象界一切生灭，生命在根底上是坚不可摧的、快乐的。这句话把悲剧的效果从「净化」改成了「肯定」。亚里士多德的卡塔西斯消除了怜悯与恐惧，尼采的慰藉不消除痛苦，而把痛苦纳入对生命的肯定——观众为英雄的毁灭而悲痛，同时为「生命居然能承受这种毁灭」而振奋。

这个改写的代价是：它需要一个「背后世界」来担保。生命不灭，靠的是叔本华的意志形而上学；个体只是现象，太一才是真实。于是悲剧的安慰变成了形而上学的安慰，而形而上学的安慰在逻辑上依赖一个无法证实的前提。

::: warn 《悲剧的诞生》是古典学的定论
它不是。1872 年出版后，年轻的古典学家维拉莫维茨发表小册子《未来的语文学！》，指控尼采滥用材料、混淆神话与历史、连基本的考证规范都不遵守。尼采的朋友罗德写文章回击，未能挽回局面；古典学界基本站在维拉莫维茨一边，尼采在巴塞尔的语文学课程也受到影响。这本书在学术上是一次失败，在效果史上是一次成功。
:::

**苏格拉底的位置需要说清。** 尼采的「理论人」是一种立场，并不指向某个历史人物：相信知识可以穷尽存在，错误可以被修正，德行可以教。这种乐观主义创造了科学，也创造了现代世界。尼采的态度相当复杂：他承认苏格拉底主义的伟大，又指出它有界限——当科学追问到自身的前提，它会撞上无法被根据的东西，那时「科学精神」会转化为悲剧。这个转折是全书最像预言的一段，也是最缺少论证的一段。

**「歌剧的诞生」那一节常被忽略，其实是全书的政治锋芒。** 佛罗伦萨的卡梅拉塔会社以为自己在复兴希腊悲剧，结果造出一种「理论人」的艺术：歌词优先，音乐沦为伴奏，情感被台词解释。尼采把它读成现代文化的缩影——用概念模仿文化，用学问冒充生命。这条线索直接通向他对 1871 年之后德国自满的批评：刚刚打赢战争的国家以为自己有了文化，其实只有文明。

**接受史必须交代。** 1886 年，尼采为这本书补写了一篇序《自我批判的尝试》。他在其中承认，这本书是「用艺术家的透镜看科学」，写得沉重、激情过剩，被叔本华与瓦格纳的双重影响束缚，本质上是一个浪漫主义者的书。他承认了独断，却没有撤回问题。二十世纪之后，这本书的声誉一路走高：剑桥仪式学派从酒神祭里找宗教起源，弗洛伊德从「醉」里找无意识，海德格尔把尼采读成形而上学的完成者，表现主义绘画与舞蹈把「酒神」当作口号。古典学内部则长期保持距离，直到二十世纪中期之后才有学者重新认真对待它的提问方式。

我倾向于这样判断：维拉莫维茨在材料层面的批评是有效的，但这本书的力量不在材料。它真正的主张——「一个文化如何承受它看见的真理」——无法用考据解决。最强的反对来自另一处：「日神与酒神是一对不可证伪的诗学范畴，它们能解释一切，因此什么也没解释」。指出史料错误，反而比较容易回答。

## 五、经典原著：《悲剧的诞生》

此书 1872 年出版，全书二十五节，1886 年加序。结构大致分三段：前段建立日神与酒神的对立；中段讨论悲剧的诞生、歌队与神话；后段处理欧里庇得斯、苏格拉底、歌剧与现代文化的再生。最后几节把希望寄托在瓦格纳与德国的复兴上，这也是全书最有时效性、最容易被后人诟病的部分。

它的写法值得一提：论证、诗、预言、论战混在一起，没有脚注，没有文献综述。这种写法在古典语文学里是失礼的，在哲学里却是自觉的选择——它要用「整体印象」对抗「碎片考据」。

::: quote 《悲剧的诞生》第 5 节（通行中译，大意）
只有作为审美现象，世界的存在才有充分的理由。
:::

这句话是全书纲领。它把莱布尼茨式的神义论换成了审美神义论：不再问世界是否合乎道德，而问它能否在艺术中被肯定。这个转换很彻底，也很危险——它把「辩护」保留了下来，只是换了法庭。尼采后来放弃的正是这个「法庭」本身。

## 六、艺术案例：帕特农神庙

帕特农建于前 447 至前 432 年，台基约 69.5 × 30.9 米，外围 8 × 17 根多立克柱，柱高约 10.4 米。它的形式里有一组很能说明日神的处理。

柱身有收分（entasis），中段略鼓、向上渐细；角柱加粗，并与相邻的柱子靠近；台基与檐部略呈凸曲线，全建筑几乎没有一条真正的直线。这些做法不为实用，而为抵消人眼造成的凹陷错觉，让建筑「看起来」是直的。这就是古代所谓的视觉矫正。用尼采的语汇说，它承认眼睛会骗人，然后为眼睛造一个更精确的假象——这几乎就是日神的定义：假象仍然在，只是被做得有尺度、可居住。

比例上也有文章。正立面八柱、侧面十七柱，打破了旧制六柱的惯例；外部用多立克，内部用爱奥尼，两种柱式在同一座建筑里分工。把不同来源的形式收进一个秩序，与「古典」的自我理解相当吻合。

但这座庙的边缘并不安静。排档间壁上的浮雕是半人马之战、亚马逊之战、巨人之战；山花里是神祇的搏斗。文明与野蛮、秩序与暴力被刻在建筑的边框上——它们没有被消除，只是被安置在可以被观看的位置。用尼采的框架读，这恰好是日神的功能：它不否认深渊，它给深渊一个边框。

::: fig a-parthenon | 帕特农：收分与视觉矫正让建筑「看起来」是直的，为眼睛造出有尺度的假象
:::

这里有一处史实值得点出。温克尔曼 1768 年去世，帕特农的雕刻 1801 至 1805 年间才被额尔金伯爵运到伦敦，他没有见过原作，他的「静穆」是从罗马复制品与文献里推出来的。尼采反的那个温克尔曼，其证据基础本身是间接的。这一条既不证明尼采对，也不证明温克尔曼错，它只说明「希腊」这个形象从一开始就是构造出来的。

类比也有界限。帕特农是建筑，不是悲剧；它能说明日神的形式逻辑，不能证明悲剧起源于歌队。把两者直接等同，会犯尼采自己犯过的错。

## 七、思想联系

向前追溯，这本书承接三样东西：温克尔曼与歌德建立的古典形象（它要推翻的对象）、亚里士多德的《诗学》（它要倒转的次序）、叔本华的意志形而上学与音乐理论（它借用的地基）。瓦格纳的「整体艺术作品」提供了现实样本，也提供了政治希望。

向后看，它的影响分成两路。一路在艺术实践：表现主义绘画、现代舞、斯特拉文斯基式的节奏暴力，都把「酒神」当作口号。一路在理论：剑桥仪式学派从酒神祭追溯宗教与戏剧的起源，弗洛伊德从「醉」与「集体」追溯无意识，海德格尔把尼采读成形而上学的完成者。古典学内部也有修正，例如多兹在《希腊人与非理性》里重新评估希腊的疯狂、梦境与萨满传统——他既继承了尼采的问题，又拒绝了尼采的形而上学。

## 八、本节总结

::: key 本讲要点
- 日神是梦、形象、界限与个体化原理；酒神是醉、界限崩溃与太一。悲剧是二者的结合，任一方单独都不成立。
- 悲剧诞生于合唱队：歌队先于舞台，舞台是歌队的幻象。这个论证依赖词源与哲学构造，考据上薄弱。
- 形而上学慰藉：个体毁灭而生命不灭。它把卡塔西斯的「净化」改成「肯定」，代价是需要一个背后世界。
- 悲剧死于欧里庇得斯与苏格拉底：理论人以可理解性取代神话；歌剧的诞生是现代版本的重复。
- 该书在学术上失败、在效果史上成功；1886 年的自序承认它「用艺术家的透镜看科学」，但未撤回问题。
:::

这本书真正换掉的是问题：艺术不再被问「是否美」，而被问「是否让人能活下去」。这个换法把美学接到了生命哲学上，也把美学带离了学院。

值得继续追问的问题：如果悲剧的安慰依赖一个「生命不灭」的形而上学前提，那么在没有这个前提的时代，悲剧还能提供什么？或者说，我们今天的「酒神」还剩什么，是强度，还是仅仅是刺激？
