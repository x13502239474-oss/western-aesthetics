## 一、本节导入

读《包法利夫人》，福楼拜写爱玛的眼睛时只给了几个词：瞳孔在暗处放大，睫毛低垂。你读到这里，脑子里出现了一张脸。那张脸有具体的眼白、具体的肤色、具体的鼻梁高度，可这些文字一个字也没写。

这些没被写出的东西，是作品的一部分吗？如果算，那么每个读者读到的都是不同的作品，文学批评就没有共同对象；如果不算，那么我们读到的究竟是什么？我们明明「看见」了房间、街道、人物的手势，这些看见又确实由文字引起。

二十世纪对这个问题的回答分两派。一派说作品就是文字，读者的想象属于读者的心理；一派说作品就是读者的体验，文字只是引子。两派各有道理，也各有代价：前者解释不了为什么文字能唤起形象，后者解释不了为什么不同读者的体验会趋向一致。现象学提供了第三条路：作品是一个「意向对象」，它既不在纸上，也不在头脑里，而在两者之间的构成关系里。

## 二、核心知识：意向性、层次、未定点

::: def 意向性（Intentionalität）
布伦塔诺重新提出、胡塞尔加以改造的概念：一切意识都是「关于某物的意识」。意识活动（noesis）总指向一个对象（noema），而这个对象并不因为被指向就成为心理内容。
例子：你想起一座从未去过的城市，这个「想起」有一个对象，它不在你脑中，也不在现实中，却可以被讨论、被修正、被判断对错。
:::

::: def 层次结构（Schichten）
英伽登的术语，指文学作品由若干异质层次叠合而成，每一层有各自的材料与功能，整体意义在层的配合中产生。层与层之间是「奠基」关系：上层依赖下层，下层不决定上层。
例子：一句诗的节奏（语音层）使它的意义（意义层）得以被把握，但节奏本身并不等于意义。
:::

::: def 未定点（Unbestimmtheitsstelle）
再现对象中未被文本确定的部分。英伽登主张，任何文学作品都必然包含大量未定点，因为语言无法穷尽一个具体对象的全部规定。
例子：小说写「一个人走进房间」，没有写他的身高、发色、鞋的样式；这些就是未定点。
:::

::: def 具体化（Konkretisation）
读者在阅读中填补未定点、使图式成为生动形象的活动及其结果。具体化不等于作品本身：同一作品可以有多种具体化，彼此不同却都可以是忠实的。
例子：同一部《哈姆雷特》，两位演员演出两种王子；两种演出都是具体化，作品仍是那一部。
:::

英伽登的四层可以列成一张表：

| 层次 | 构成 | 在作品中的功能 | 一个具体例子 |
|---|---|---|---|
| 语音层 | 字音、词音、句子的节奏与语调 | 让意义获得可感的载体 | 荷马六音步的节拍 |
| 意义单元层 | 词义、句义、句群的意义 | 构成事态，建立「准判断」 | 「女神，歌唱佩琉斯之子的愤怒」 |
| 图式化观视层 | 对象被观看的方式被简化为图式 | 让对象以某个侧面呈现 | 从营帐外看见阿喀琉斯的背影 |
| 再现客体层 | 人物、事件、世界 | 构成作品的世界 | 特洛伊战争、英雄的命运 |

## 三、代表人物：胡塞尔与英伽登

胡塞尔（Edmund Husserl，1859—1938）生于摩拉维亚，数学博士出身，1884 至 1886 年在维也纳随布伦塔诺学习，此后在哈勒、哥廷根、弗莱堡任教。1900 至 1901 年的《逻辑研究》以「回到事情本身」为口号，批判当时流行的心理主义：逻辑规律若只是心理事实，就无法说明它的必然性。1913 年的《观念一》提出先验现象学与「现象学还原」，把世界的存在「加括号」，只保留意识及其对象的结构。

英伽登（Roman Ingarden，1893—1970）生于克拉科夫，1912 年前往哥廷根随胡塞尔学习，后随其到弗莱堡，1918 年获博士学位。他在利沃夫任教，二战期间留在城中，战后迁往克拉科夫。1931 年的《文学的艺术作品》是他的代表作，此外还有《关于艺术作品的本体论研究》（1962）与《体验、作品与价值》（1969）。

英伽登属于「实在论现象学」一派。他接受胡塞尔的方法，却拒绝其结论：如果世界只是意识的构成物，那么实在论就无法成立。他要用现象学的描述证明，实在世界不依赖意识而存在。文学作品正好是一个理想的试验场：它明明是意识的产物，却又明明不随某个人的意识而变。

## 四、理论解析：从意向对象到四层结构

**第一步：问题的定位。** 关于作品的存在方式，有两种常识答案。物理主义说作品就是印着字的纸、刻着纹的石头、振动着的空气；心理主义说作品就是读者或听众心中的感受。两者都有致命困难。物理主义无法说明为什么同一份乐谱的两次演奏都是「这首曲子」，也无法说明为什么纸张烧掉后作品仍可被重印。心理主义无法说明为什么我们可以争论「这一段该怎么理解」，如果作品只是各人的感受，争论就没有共同对象。

**第二步：意向性如何提供第三条路。** 胡塞尔的分析是：意识活动指向对象，对象在活动之中被构成，却不等于活动本身。看一棵树，树的显现依赖我的视角，树本身却不等于我的视角。把这个结构用到作品上：作品是作者意识行为的产物，也是读者意识行为的对象，但它在两端之间保持了自己的同一性。英伽登给这种存在方式一个名字：「异在的」（heteronom）存在——它依靠意识而存在，却不等于任何一次意识。

**第三步：为什么必须分层。** 作品由多种异质材料构成：声音、意义、形象、对象。若把它们压成一层，就会得出荒谬结论。比如把文学等同于语音，那么翻译就不可能；把文学等同于意义，那么诗与散文就没有区别；把文学等同于再现对象，那么抒情诗就没有对象。分层的作用是让每种材料各归其位，并说明它们如何互相奠基。

**第四步：四层逐一说明。**

1. **语音层。** 指字音、词音、句子的节奏与语调，英伽登称之为「语言的声音构造」。它是被理解的语音格式塔；物理声波只是它的载体。这一层让意义可以被把握，也让作品获得审美上的直接性：一首诗的节奏本身就是意义的一部分。
2. **意义单元层。** 由词义、句义、句群的意义构成。英伽登有一个关键区分：文学作品中的句子是「准判断」（Quasi-Urteil）。它看起来像判断，有主词谓词，却不承担真假；读者不会因为「阿喀琉斯发怒」而去核实，也不会因此判它撒谎。这个区分解决了虚构作品的地位问题：虚构不假，因为它根本不在真假的层面上。
3. **图式化观视层。** 事物总是以某个侧面被看到，文学无法给出全部侧面，只能给出「图式」：一个框架，读者据此补出具体的看。写「他推开门，屋里很暗」，文本给的是一个观视的图式，读者补出光线、气味、家具的轮廓。
4. **再现客体层。** 由人物、事件、空间构成的世界。这一层的对象是「意向的」，它们有确定的骨架，也有大量未定点。英伽登还提到一类不属于层次却依附于层次的东西：「形而上学质」，如悲剧性、崇高、神圣。它们无法被句子直接说出，只在诸层的配合中显现，像一种氛围。

**第五步：未定点与具体化。** 这是整套理论最有生命力的部分。作品是图式的，因此必然有未定点；阅读是具体化，因此必然要填补。英伽登坚持两个命题：第一，未定点是作品的必要属性，不是缺陷；第二，具体化不等于作品。由此推出一个重要的后果：作品的存在是「图式的」，它的完整形态只在具体化中实现，却没有一次具体化能穷尽它。

**第六步：读者因此进入本体论。** 在英伽登之前，读者只是欣赏者；在他之后，读者成了作品存在的条件之一。这个转向影响了整个接受美学。但英伽登本人对读者保持警惕：他反对把作品化约为「被经验到的」，因为那样一来，作品就失去了跨越时代的同一性。他要的是「作品—具体化」的双层结构：作品是骨架，具体化是血肉，骨架不因血肉而改变。

**第七步：反对意见。** 第一，层次说来自语言的结构，能否推广到音乐、建筑、绘画？英伽登在《关于艺术作品的本体论研究》里分别处理了音乐、绘画、建筑与电影，但他自己也承认，各门艺术的存在方式差异很大，音乐作品就没有文学那样的四层。第二，作品与具体化的区分使作品成为不可触及的「自在之物」：我们每次接触的都是具体化，那么凭什么说作品存在？第三，「未定点」究竟是文本的属性，还是阅读的效果？伊瑟尔后来把它改写为「空白」（Leerstellen），把重点从本体论转向阅读的动力学：空白是文本故意留下的空隙，用来激发读者的建构。第四，历史性被低估：四层结构被描述为一切文学作品的本质，可不同时代的作品对层的倚重并不相同，口传史诗与意识流小说显然不在同一套配置里。

::: warn 四层是四个部分
常见的误解是把四层当成作品的四个「组成部分」，像一栋楼的四层楼板。英伽登的「层」是异质的构成维度，它们同时在场、互相奠基。读一句诗时，你同时听到声音、把握意义、看见图式、进入世界；四层是分析出来的，不是拼装出来的。
:::

## 五、经典原著：《文学的艺术作品》（1931）

全书分三部分。第一部分处理方法问题：如何把文学作品从心理主义与物理主义中区分出来；第二部分逐一描述四个层次；第三部分讨论作品的存在方式、它与具体化的关系，以及作品与「真理」的关系。

英伽登的写法是描述性的：他不给定义，而是逐步指出「当我们读一部作品时，必然已经假定了什么」。这种写法来自胡塞尔的「本质直观」：通过变更例子，找出不可省略的结构。它的力量在于细致，它的风险在于把特定文化里的阅读习惯当成了本质。

::: quote 《文学的艺术作品》第二、三部分（术语，据通行德文本）
Unbestimmtheitsstelle——未定点；Konkretisation——具体化。作品是「图式的」（schematisch），具体化则在阅读中完成。
:::

这两个术语构成了一对张力：作品必须不确定，才能被多次具体化；作品又必须足够确定，才能保证多次具体化指向同一部作品。英伽登的整个本体论，就是在这两极之间找平衡。

## 六、艺术案例：《拉奥孔》

梵蒂冈的《拉奥孔》约作于公元前一世纪，1506 年在罗马出土，作者据老普林尼记载是罗得岛的三位雕刻家。整组雕像表现拉奥孔与两个儿子被海蛇缠住、奋力挣扎的瞬间：父亲坐在祭坛边，身体向右扭转，左腿伸直，右腿弯曲，双臂一高一低地抓住蛇身；两个儿子被蛇缠住，一个已经倒下，一个惊恐地回头；三条蛇把三个人串成一个上升的三角形。

形式上有三处值得看。第一，构图：三个人物构成一个金字塔，塔尖是父亲的头，塔基是倒下的儿子与蛇尾，视线沿着蛇身螺旋上升。第二，肌肉：躯干的肌肉被刻成紧绷的块面，腹部的凹陷与胸口的扩张同时存在，把「用力」与「无力」放在同一具身体上。第三，材质：大理石的白与光滑让痛苦显得被距离化，血与汗都不在场。

用英伽登的框架读它，会看到层的分离。大理石是真实的物理物，有重量、有纹理、会风化；拉奥孔这个人是再现客体，只存在于意向之中；我们看到的「痛苦」通过图式化观视层呈现，由扭转的角度与肌肉的紧张唤起。三层同时在场，却不能互相还原：石头不会痛，痛也不在石头的分子里。

未定点在这里格外清楚。拉奥孔的表情究竟是极度的痛，还是「高贵的克制」？温克尔曼在十八世纪读作后者，莱辛在《拉奥孔》里反驳说，雕刻家为了美必须节制痛苦的表达。这场争论本身就是两种具体化：同一件作品，两种读法，都忠实于文本的骨架，却给出不同的血肉。

作品的物质层还提出一个更尖锐的问题。拉奥孔原来的右臂在出土时缺失，十六世纪被补成向外伸直；1905 年，考古学家在罗马一家石匠铺里找到了原臂的残段，证明原姿态是弯曲的、手向后抓向头部；1960 年，这只手臂被重新装回。装回之后，整个构图的重心改变了。若作品等于石头，那么修复就是替换；若作品是意向对象，那么修复改变的是具体化的条件，作品本身仍是那一件。英伽登的框架在这里显出力量，也显出代价：它能说明「为什么修复之后还是同一件作品」，却难以说明「为什么装回原臂之后，我们看到的痛苦更可信」。

:::

## 七、思想联系

向前追溯，意向性概念来自中世纪的经院哲学，布伦塔诺在 1874 年的《从经验立场出发的心理学》里把它重新引入，用来区分心理现象与物理现象。胡塞尔接过这个词，把它变成整个现象学的起点。另一条线索是康德：审美对象与认识对象的分野、现象与本体的区分，都在英伽登的「异在存在」里留下了痕迹。

向后看，英伽登的层次论直接影响了伽达默尔的解释学与接受美学。伊瑟尔把「未定点」改造为「空白」，把注意力从作品的存在方式转向阅读的建构过程；姚斯则以「期待视野」处理作品与读者的历史关系。在英美，古德曼 1968 年的《艺术语言》用另一套词汇处理同一组问题：他区分「亲笔的」艺术（绘画，原件不可复制）与「代笔的」艺术（音乐，乐谱即作品），把「何时为艺术」替代了「什么是艺术」。海德格尔与梅洛-庞蒂则从英伽登的另一个方向出发：他们不关心作品的层次，关心作品如何开启一个世界（参见本模块第 6、8 讲）。

## 八、本节总结

::: key 本讲要点
- 意向性使作品摆脱两难：它既非物理物，也非心理内容，而是被构成的意向对象。
- 英伽登把文学作品分为语音、意义、图式化观视、再现客体四层，层间是奠基关系。
- 文学句子是「准判断」，不承担真假，虚构因此获得独立的存在方式。
- 作品是图式的，必然含未定点；阅读是具体化，具体化不等于作品。
- 「作品—具体化」的双层结构保住了作品的同一性，也把读者带进了本体论。
- 主要反对：层次说难以推广到非语言艺术；作品与具体化的区分使作品不可触及；历史性被低估。
:::

把这一讲压成一句：英伽登让作品既不住在纸上，也不住在心里，而住在「被理解」这件事本身之中。

值得继续追问的问题：如果作品只在具体化中完成，那么一次从未被阅读的作品还算存在吗？今天的电子文本、超链接与交互叙事，是否正在把「未定点」从读者的补白变成作者的接口？
