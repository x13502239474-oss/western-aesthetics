## 一、本节导入

1944 年，洛杉矶。霍克海默与阿多诺在流亡中写完一部书稿，1947 年由阿姆斯特丹的 Querido 出版社出版，题为《启蒙辩证法》，副标题是「哲学断片」。这个副标题值得停留：它承认自己不成体系。

书要回答的问题很具体。培根以来以「解放」为承诺的理性，为什么在 20 世纪结出了殖民、种族灭绝与消费社会的顺从？为什么一个已经「祛魅」的世界，又长出了新的神话？

两位作者给出的答案是一个悖论式的命题：启蒙与神话互为表里。本讲要拆开这个命题的结构，再把它落到一个具体对象上——文化工业。

## 二、核心知识：四个概念

::: def 工具理性（instrumentale Vernunft）
把理性缩小为「选择手段、计算效率」的能力，对目的本身是否合理不作追问。**例**：一座城市用成本收益模型决定防洪堤修在哪一段，模型算得精确，却不回答「谁的房子可以被淹」，因为后者已作为前提交给模型之外。
:::

::: def 文化工业（Kulturindustrie）
以工业化的方式生产与发行文化商品：类型化、可复制的形式，加上对接受行为的预先计算。**例**：一首三分钟的流行歌，前奏八小节内进主歌，副歌在四十秒前到达，因为电台与流媒体的注意力曲线要求这样安排。
:::

::: def 大众文化（Massenkultur）
从民众自身的生活经验中生长出来的文化形式：民歌、地方戏、市集表演、口传故事。它与文化工业的产品在来源、生产方式与社会功能上都不同。**例**：一首山歌的曲调在几代人的劳作与迁徙中变形；一首工业制作的「民谣风」歌曲，其音阶与「质朴」音色由制作人按市场调查选定。
:::

::: def 肯定性文化（affirmative culture）
马尔库塞 1937 年《文化的肯定性质》中的术语：资产阶级社会把美、精神与幸福安置在一个与日常生存分离的领域，使人在观念上得到补偿，从而不去改变现实。**例**：19 世纪的音乐厅里，听众在交响曲中体验「自由」，散场后回到账房。
:::

四个概念的关系可以这样记：工具理性是病理，文化工业是机制，大众文化是被替换的对象，肯定性文化是效果。另有一个术语须在此交代——**伪个性化**（pseudo-individualization），指在标准化内核上做可替换的表面差异，使产品显得独特。

## 三、代表人物

**霍克海默**（Max Horkheimer，1895—1973）1930 年接任法兰克福大学社会研究所所长，把方向从思想史转向跨学科的社会研究。1933 年流亡，1934 年迁至纽约，1941 年迁往洛杉矶，1950 年回法兰克福重建研究所。他的写作偏纲领性，《工具理性批判》（1947）与《启蒙辩证法》共享同一套诊断。

**阿多诺**（Theodor W. Adorno，1903—1969）受过作曲训练，在维也纳随贝尔格学习。1938 年赴美，先在普林斯顿参与拉扎斯菲尔德的广播研究项目，1941 年起与霍克海默合作。他与流行音乐的关系是终身的。

**马尔库塞**（Herbert Marcuse，1898—1979）1930 年代加入研究所，1937 年写《文化的肯定性质》，后来在《单向度的人》（1964）里把这一概念扩展为对发达工业社会的总体批判。

**哈贝马斯**（Jürgen Habermas，1929— ）是第二代的核心。他在《公共领域的结构转型》（1962）里把文化工业问题重述为公共领域的「再封建化」，在《交往行为理论》（1981）里用「系统对生活世界的殖民」替代工具理性批判。

## 四、理论解析

### （一）启蒙为什么自我反转

论证分三步。

1. **启蒙的纲领是祛魅。** 它用概念取代形象，用可计算性取代相似与交感；培根的「知识即力量」把认识与支配绑在一起。
2. **认识以支配为形式，就必须把对象化为可重复的量。** 自然被简化为可测量的物质；为了自我保全，主体也把自己工具化，把欲望、身体、时间当作可管理的资源。
3. **理性只剩手段合理性，在目的问题上就空了。** 空出的位置由「给定」填补：事实、民族、命运、市场。这些给定不能被追问，因此具有神话的功能。结论就是那个命题：启蒙倒退为神话。

支撑这个论证最强的段落是对《奥德赛》的解读。奥德修斯是第一个启蒙主体：他让划桨手用蜡封住耳朵，把自己绑在桅杆上。他听到歌声（享受），船员听不到（劳动），船继续前进（支配）。这个安排同时是自我的确立与自我的压抑：主体通过放弃直接满足来维持自身。两位作者把这一结构称为自我保全的辩证法。

::: warn 「启蒙辩证法」不是历史阶段论
常见的读法是：先有神话，然后启蒙，启蒙又变成新的神话。这把辩证法读成了循环论。作者的意思更接近：神话里已有启蒙（奥德修斯用计谋对付神话力量），启蒙里始终残留神话（它对「事实」的崇拜）。两者是同一种结构的两个面向。这一读法上的差别，决定了批判是回顾性的还是当下的——后者才是他们想要的。
:::

弱点也要说。这是哲学-历史的大叙事，几乎无法被经验证伪；「工具理性」的外延过宽，任何目的-手段的计算都能被归入其中，于是它无法区分技术效率与支配。哈贝马斯正是在这里提出「交往理性」。另外，把「自我保全」当作主体性的基本结构，会让人怀疑是否存在非压抑的主体位置。

### （二）文化工业的五个机制

**标准化。** 类型、公式、时长、结局都可预测：西部片的对峙、侦探片三分之一处的转折、流行歌的副歌位置。

**伪个性化。** 表面差异掩盖结构同一。歌手的「独特音色」、明星的「个性」、品牌的「调性」，都是在标准化内核上做的可替换装饰。阿多诺的说法大意是：个性本身成为可以被生产的东西，因此它恰好取消了个性。

**供给塑造需求。** 消费者以为自己在选择，实际上选项的范围与呈现方式已被预先设定。两位作者的表述大意是：在文化工业中，消费者被当作客体而非主体，他们不是衡量尺度，是被计算的对象。

**广告与艺术的合流。** 广告成为最纯粹的形式：几秒内完成吸引、说服与记忆。电影、流行歌、展览的视觉语言都向它靠拢，广告则借用艺术的手法掩饰目的。

**娱乐作为净化。** 这里有一个反讽的用法：亚里士多德的卡塔西斯被搬到电影院。观众在笑声与泪水中把对处境的抵触释放掉，情绪得到排解，第二天照常上班。娱乐许诺的解放，是把人从劳动中暂时释放，好让他继续劳动（大意）。

### （三）爵士乐与好莱坞：两个具体判断

关于爵士乐，阿多诺在 1930 至 1940 年代的一系列文章（《论爵士乐》《论流行音乐》）中主张：所谓的即兴受严格的和声与曲式框架约束，即兴部分是装饰性的替换；切分音破坏的是表面的节奏感，底层的节拍与结构从未被触动。他把这种结构当作伪个性化的典型：每次演奏听起来都不同，听起来而已。

这一判断的问题今天看得清楚。他的参照系是欧洲古典调性，对布鲁斯音阶与呼应式演奏缺乏分析；研究者通常认为，他把一种成熟的演奏传统误读成了「受束缚的装饰」（这是解释，并非阿多诺原话）。

关于好莱坞，他与霍克海默的论断大体如此：影片的结局在开头已给定，情节的功能是填充这段时间；预告片已把整部影片说完，观众进影院是为了确认自己已经知道的东西。这个论断的力量在于，它描述了一种接受方式。

### （四）「文化工业」与「大众文化」的差别

四个层面。来源：大众文化从生活世界生长，文化工业从企业的生产计划中生成。生产者：前者作者往往不可考，后者有明确的团队与预算。结构：前者随使用场景变化，后者为跨场景复制而设计。功能：前者确认一个共同体的经验，后者制造「大家都在其中」的错觉。

阿多诺坚持用「文化工业」而不用「大众文化」，理由在第一与第四层：用「大众文化」会让人误以为这是从大众中自发产生的文化，从而掩盖生产端的工业化。

::: warn 「文化工业」与「文化产业」不能互换
德文 Kulturindustrie 在中文里有两个译法。「文化工业」是批判概念，指一套以标准化与商品化方式生产文化、并产生意识形态效果的系统；「文化产业」是产业政策与经济学的中性范畴，对应 cultural industries / creative industries，指一个产值与就业部门。

混用的后果是双向的。把「文化工业」译成「文化产业」，批判锋芒被中和成一门生意；反过来，用「文化工业」批判一切产业化的文化生产（独立唱片、小成本游戏、网络文学），则是范畴误用——阿多诺的靶子是同一性逻辑在生产端的实现。他所针对的，是文化被变成确认现状的机制；技术与大众本身不在其列。
:::

### （五）经验研究的反驳

第一击来自受众研究。甘斯（Herbert Gans）在《流行文化与高雅文化》（1974）里提出「品味公众」（taste publics）：不同阶级、年龄、族裔的群体各有口味与使用方式，流行文化是多元趣味的产物。受众在其中是使用者，有挑选与挪用的能力。

第二击来自传播研究。拉扎斯菲尔德一系的「有限效果」模型表明，媒介对态度的影响远小于早期「皮下注射」假设；舒德森（Michael Schudson）在《广告，艰难的说服》（1984）里论证，广告的效果被高估，受众的怀疑是常态。

第三击最强，来自霍尔的《编码／解码》（1973）。霍尔指出，生产端的编码与接受端的解码不必一致，解码至少有主导-霸权式、协商式、对抗式三种位置。同一个节目可以被不同观众读成相反的意思。这一模型保留了「生产端有权力」的判断，同时否定了「受众被动」的假设。

第四击是历史学的。文化工业的黄金期之后，媒介环境经历了制片厂解体、频道增殖与平台化，集中化与多样化同时发生，「一体化」的诊断需要重写。赫斯蒙德夫（David Hesmondhalgh）在《文化产业》（2002）里用「文化产业」替代「文化工业」，保留标准化与伪个性化的分析工具，放弃总体化的意识形态判断。

::: note 反驳成立到什么程度
这些研究有效地推翻了「受众被动」这一假设，却没有推翻全部诊断。生产端的集中、类型的公式化、注意力的商品化，在平台算法时代反而更容易观察。较为公允的说法是：法兰克福学派高估了意识形态效果的确定性，低估了受众的能动性；他们描述的生产结构，比他们描述的接受效果更站得住。
:::

### （六）对美学的转折意义

在《启蒙辩证法》之前，马克思主义美学的主流问题是「艺术如何反映社会」。这本书换了问题：在一个把文化变成商品的社会里，艺术还能不能保持不服从？

答案是：只有在艺术拒绝迎合的时候。这个答案把审美自主性从可疑的资产阶级概念，翻转为批判的位置。阿多诺后来在《美学理论》里把它系统化（参见本模块第 12 讲）。法兰克福学派对美学的真正贡献在此：问题从「艺术是什么」移到了「艺术在什么条件下还能说不」。

## 五、经典原著：《启蒙辩证法》

成书过程：1944 年在洛杉矶与纽约完成初稿，以油印本《哲学断片》流传；1947 年由 Querido 正式出版。全书由长文《启蒙的概念》、两篇附论（《奥德修斯或神话与启蒙》《朱莉埃特或启蒙与道德》）以及《文化工业：作为大众欺骗的启蒙》等章节组成，体例不一。

「文化工业」一章的写法值得注意：它几乎不做经验描述，用的全是判断句与悖论式修辞。这种写法是纲领的一部分——它拒绝用社会科学的方式呈现一个它认为无法被社会科学把握的对象，代价是留下「不可检验」的把柄。

全书的核心命题可以概括为一句话（转述，非逐字原文）：神话已经是启蒙，启蒙倒退为神话。

1969 年重印时，两位作者写了新前言，承认书中某些判断（尤其对技术与科学潜力的估计）说得过于绝对，同时坚持核心诊断（转述，不引原文）。这一自我修正在研究史上常被引用，说明他们并非不知道经验层面的薄弱。

## 六、艺术案例：一首三分钟的流行歌与一张蒙德里安

先看形式。1930 年代美国 Tin Pan Alley 的流行歌大多采用 32 小节 AABA 结构：八小节一句，四句成篇，第一、二、四句旋律相同，第三句换和声。这个结构的功能是可记忆：听众第二遍就能跟着唱，第三遍不腻。和声常用 I–vi–IV–V，因为它把紧张与解决放在最短的循环里。

生产端同样可见。作曲、填词、编曲、录音分工明确；电台按时段安排三分钟左右的长度，这一长度与 78 转唱片的容量相互塑造。所谓「标准曲」是可反复翻唱的模板：同一首歌由几十位歌手录制，差异在音色、速度与配器。标准化与伪个性化在此同时发生。

::: fig a-broadway-boogie-woogie | 蒙德里安《百老汇布吉伍吉》：矩形色块在网格中跳动，标题借用了当时最商业化的流行乐种
:::

对照的作品是蒙德里安 1942—1943 年在纽约画的《百老汇布吉伍吉》。标题直接借用了 boogie-woogie，一种以固定低音型重复为特征的流行钢琴音乐。画面却完全自律：黄、红、蓝、灰的小矩形在网格中跳动，色块的边界不闭合，节奏靠间距与色值制造。

这个对照说明，「文化工业」的对立面不在材料。同一种流行乐种，可以是标准化生产的模板，也可以成为自律绘画的标题与节奏来源。差别在形式的组织方式：流行歌的形式服务于重复与记忆，蒙德里安的形式不允许替换，挪动任何一块，整幅画的张力就变了。

这也提示了法兰克福学派判断的薄弱处：他们常从生产条件直接推出形式效果，而蒙德里安表明两者可以并存。要说明这种并存，需要更细的中介分析。

## 七、思想联系

向前，黑格尔的「艺术是精神的感性显现」被改写为「艺术是社会矛盾的密码」；马克思的商品分析提供了「商品形式」，韦伯的合理化论题提供了工具理性的谱系，弗洛伊德的压抑模型提供了「替代满足」的思路。卢卡奇的「物化」（1923）是直接的先行概念，阿多诺把物化从意识推到文化生产。

向后，文化研究（霍尔、威廉斯、费斯克）继承文化生产的视角，把受众的能动性放回中心；法国情境主义（德波《景观社会》1967）以更激进的语气重述文化工业；哈贝马斯的「生活世界殖民」是最重要的德语改写；詹姆逊把文化工业接到后现代主义理论上。

## 八、本节总结

- 启蒙辩证法的核心：祛魅的理性同时是支配的理性，因此启蒙会生产新的神话。
- 论证的枢纽是对《奥德赛》的解读：主体的确立以放弃直接满足为代价。
- 文化工业的五个机制：标准化、伪个性化、供给塑造需求、广告合流、娱乐作为净化。
- 「文化工业」强调生产端的工业化，「大众文化」指从民众中生长的形式，混用会取消批判锋芒。
- 肯定性文化把美与幸福隔离到另一个领域，使人获得补偿而不改变处境。
- 经验研究推翻了「受众被动」，却没有推翻生产端的集中与公式化。

值得追问：如果受众的能动性比法兰克福学派设想的强得多，「文化工业」的批判今天还剩下什么？一种回答是：剩下的是关于生产结构的描述——预算、算法、版权的分配方式决定了什么样的形式能被做出来。

::: key 本讲要点
- 工具理性把手段计算绝对化，目的问题被交给「给定」，于是启蒙生产神话。
- 文化工业＝标准化内核＋伪个性化表面＋对接受的预先计算。
- 「文化工业」是批判概念，「文化产业」是产业范畴，译名混用会抹掉锋芒。
- 肯定性文化在观念上补偿现实，效果是顺从。
- 经验研究击中了「被动受众」，未击中「集中生产」。
:::
