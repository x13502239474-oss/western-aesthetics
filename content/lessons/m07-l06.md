## 一、本节导入

海德格尔在《艺术作品的本源》里提到梵高的一幅画。他不谈构图，不谈色彩，只盯住一个细节：鞋口内壁那一圈被脚长年磨出来、发黑、潮湿、塌陷的暗洞。

这个细节值得停下来想。它无法靠「观察」得到：一双鞋摆在面前，从任何角度都看不见那个洞的深度与贴脚的形状；只有穿过它、走过泥路、在夜里脱下它的人，才知道那里会磨成什么样。海德格尔由此提出一个颠覆性的说法：我们接近器具的方式是使用，观看离器具最远。

接着是更奇怪的一步：画让我们「看见」这个只能在使用中被知道的东西。不可见的使用痕迹被搬到可见的表面上，这双鞋于是在画里第一次作为「鞋」出现。

若作品的功能是揭示器具的存在，则讨论作品之前得先知道器具是什么；可要知道器具是什么，又得先有一件作品。海德格尔清楚这个圈子，并且不打算绕开它。

## 二、核心知识：三个词与一个问法

::: def 物性（Dingheit）
使某物成为物的那个东西，即物的「什么」（Was）与「如何存在」。传统哲学追问物性，是要找一个能覆盖石头、水罐、云、人的普遍规定。**例子**：一块花岗岩的物性是什么？是硬度、重量、颜色，还是它「在那里」这件无法被属性说尽的事？
:::

::: def 器具（Zeug）
介于纯物与作品之间的存在者：由人制作、为某种用途而在。它的存在方式是「为了作……」（Um-zu），所以总已牵涉一个使用者的世界。**例子**：锤子、水罐、一双下地的鞋。器具越称手越不引人注意，它退到用途后面去了。
:::

::: def 可靠性（Verlässlichkeit）
海德格尔用来规定器具之器具存在的词。它指器具把使用者稳稳托付给一个意义世界的那种性质：因为这东西可靠，人可以依赖它，并经由它依赖世界。**例子**：一双合脚的鞋让人忘记鞋，只感到路面的远近。可靠性在磨损与用旧中反而更清楚。
:::

::: def 真理（Wahrheit）
本讲只作引子：海德格尔把真理理解为「无蔽」（Unverborgenheit），即存在者不再被遮蔽、得以作为它自己所显现的状态。**例子**：同一双鞋，在仓库里是一堆皮革，在画里成了一个世界的入口。
:::

三个词排成一条线：物—器具—作品。海德格尔先问物，再问器具，最后回到作品。

| 环节 | 要回答的问题 | 用到的例子 | 得到的结果 |
| --- | --- | --- | --- |
| 物 | 物之所以为物是什么 | 花岗岩、水罐、云 | 三条传统路径都失败，问法本身可疑 |
| 器具 | 器具之所以为器具是什么 | 锤子、鞋、水罐 | 可靠性；但它自己不显示自己 |
| 作品 | 作品之所以为作品是什么 | 梵高的画 | 让器具的存在显现，并引出真理 |

关键在中间一栏：器具是唯一一种「存在藏在用途里」的东西。

## 三、代表人物：从存在问题到艺术问题

马丁·海德格尔（Martin Heidegger，1889—1976）生于德国西南部小镇梅斯基尔希，天主教家庭出身，早年读神学，后专攻哲学。1919 年起任胡塞尔的助手，1927 年出版《存在与时间》，1928 年接任胡塞尔在弗莱堡的教席。1933 年出任校长及其后的政治牵连不在本讲范围。

他面对的问题是：西方形而上学一直在问「存在者是什么」，却从不问「存在本身是什么意思」。在这个诊断里，美学也是一个病症——它把作品当作「物」加上「意义」，把艺术变成主体的一种体验，从而错过了作品最要紧的东西。

1930 年代是他的转折期：他连续讲尼采、讲荷尔德林、讲真理问题，《艺术作品的本源》正写在这个交叉口上。它读起来像美学论文，目标却在美学之外。

## 四、理论解析：一条必须绕圈的路

### 第一步：为什么先问「物」

任何走进展厅的人都会承认，画首先是块涂了颜料的布。美学的通行做法是把这句话拆成两层：底下是物（质料），上面是意义（形式、精神内容）。海德格尔要问：你说的那个「物」，究竟是什么？

这一问看似铺垫，实际上已经动了手术：一旦承认作品是「物 + 意义」，物因素就成了必须先被规定的基底，基底说不清，叠加结构就悬空。更要紧的是，他认为「物性是什么」这个问法本身就属于传统形而上学。理由有三层。

其一，它问的是「一切物的共同什么」（Washeit）。这种问法要求把个别物归入普遍概念之下，物的个别性——「这一个」、此时此地、不可替代——在提问时就被排除。

其二，它默认以命题结构为引导。我们习惯说「这块石头是硬的」：主词承载属性，系词连接两者。这套语法被不假思索地搬到物身上，物于是被想成一个「基底 + 属性」的小型命题。

其三，它预设主客对立：问「物是什么」的人已站到物的对面，把物当成可被规定的东西（Gegenstand），物只能作为「被表象者」出现。

三层合起来就是「形而上学问法」的意思：它不问物如何存在，只问物被我们表象为什么。第一部分因此有双重任务，既证明旧答案不行，也证明旧问题不该这样问。

### 第二步：三条传统路径及其失败

海德格尔依次检查三条路，顺序有讲究：从最抽象到最贴近感官，再到最像「制作」。

1. **物是属性的承担者**。原型是「实体—偶性」结构，源头可追到希腊语的 hypokeimenon，字面是「躺在下面支撑着的东西」。批评是：它把语句结构投射到物上。你说花岗岩「坚硬、灰、重」，这些话都没错，却没有说出它在那里这件事。

2. **物是感官杂多的统一**。物被规定为「通过感官被给予的东西」（aistheton），成了感觉的组合。批评有两条：物被拉得太近，近到消失在感觉里，只剩颜色、硬度、气味；而且它循环——感觉总得由物引起，物在解释开始前已被预设。

3. **物是质料与形式的复合**。这条路最顽固，也最像常识：物是「被赋形的材料」。海德格尔在这里花的力气最大，因为他要证明这对概念的出身并不清白。

| 路径 | 物的规定 | 引导线索 | 失败之处 |
| --- | --- | --- | --- |
| 属性承担者 | 实体加偶性 | 命题的主词—谓词结构 | 语法被当成物性，个别物消失 |
| 感官杂多 | 感觉的统一体 | 知觉、感官生理学 | 物消散为感觉；且暗中预设了物 |
| 质料—形式 | 被赋形的材料 | 器具的制作 | 把器具的存在结构推广到一切存在者 |

前两条路的失败比较容易接受，第三条才是全篇枢纽。

### 第三步：质料—形式来自器具，故不能把握物

先看出身。「质料—形式」（hyle—morphe）这对区分从哪里来？海德格尔的回答：从制作（Herstellen）来。做一件器具的过程是这样的：先有一个「为了什么」（Um-zu），比如罐子要盛水、要倾倒；用途决定形状——要有腹、有颈、有口；形状又决定选什么材料——陶土要能成形、能烧硬。

压缩成一句话：用途给出形式，形式挑选材料。所以「质料—形式」原本是器具的存在结构，它从「做人要用的东西」这件事里长出来，并非从一块石头里读出来。

::: warn 「质料—形式」并非普遍范畴
一个流行的读法：既然一切事物都有材料与形状，这对概念当然最普遍。海德格尔恰恰要否掉这个「当然」。在他看来，这对概念取自器具制作，带着「为了什么」这个目的论尾巴；推广到纯物与作品时，也把两者偷偷器具化了。后果是：物只剩「材料」，作品只剩「被赋形的材料加意义」。20 世纪的「媒介论」——把颜料、声音、大理石称为「感性材料」——在谱系上属于这次推广的后代。
:::

这一步同时清算了美学的底层假设：美学以为在谈「感性材料的形式组织」，其实谈的是器具的结构。材料、形式、媒介这些词听起来中立，背后都藏着「为了什么」。

### 第四步：为什么绕道器具

三条路都断了。海德格尔提出一个折中的对象：器具同时沾着两边——有物性的一面（材料、重量、质地），也有作品的一面（被制作、有形状、可被看见），站在物与作品的中间。

怎么接近它？方法论的决断在这里：接近器具的途径是使用，而非观察。你盯着锤子端详，看到的是木柄和铁块；你拿它钉钉子，它才作为锤子存在。他把这种存在方式叫「上手状态」（Zuhandenheit）；当器具坏掉、缺失、挡路时，它才以「现成在手」（Vorhandenheit）的样子突兀出现。

结论是反直觉的：器具的正常状态是「不显眼」，用得越顺越退到用途后面，一把好锤子在使用中几乎不存在，你只感到钉子进木头。器具的存在是一种自我隐蔽的存在，因此要看见「器具是什么」，就需要一个不是器具的东西来替它显示。

### 第五步：农鞋与可靠性

梵高的画在这个位置入场。海德格尔的描述不落在画面上，而落在鞋「里面」：那圈磨出来的暗洞、皮革上干了的土、鞋底在暮色中走过的田埂的沉重。大意是：这双鞋属于大地，而在它的可靠性中，农妇被托付给大地无声的召唤，她对自己的世界是有把握的。

「可靠性」指一种双重托付，并非「结实耐用」这种物理性质。器具因为可靠，把使用者托付给劳作、季节、土地；也正因为可靠，它自己可以隐去。农妇不去想鞋，她想着土豆、天气、晚祷；可靠性恰恰体现在她不必想它。

于是出现一个精确的对位：器具的存在在使用中消耗自己、隐藏自己，无法在使用的当下被看见；作品的功能是把这个「无法自己显示的东西」显出来。

### 第六步：圈子，以及海德格尔的处理

现在可以把循环摆明：我们要问作品的作品性，却先借一幅作品来揭示器具的存在；而这幅作品之所以被选中，又因为它是作品、能揭示器具。前提里用到了结论。

海德格尔不否认，处理分两层。第一层是承认：他明确说我们走了一条弯路（Umweg），而这条路回到了起点；大意是，这不是应当绕开的逻辑错误，思必须进入这个循环，并且要以正确的方式进入。

第二层是重新描述：如果器具的存在与作品的存在本来就互相照明，那么这种「相互指引」属于事情本身的结构，不属于论证的瑕疵。循环在这里被当成解释学的循环，而非形式逻辑的谬误。

这个处理有力量，也有代价。力量在于诚实：他没假装自己从某个中立前提出发。代价是约束力下降——一旦循环被允许，「作品揭示真理」这个结论就无法独立于它自己挑的例子被检验。换一幅画着崭新皮鞋的广告，可靠性还在吗？框架没有判据，只说「真正的作品」会揭示，等于把问题推给了「谁是真正的作品」。

### 第七步：这一步得到了什么

第一部分收束时手里有三件东西。其一，器具的器具存在是可靠性，而可靠性在使用中隐藏自己。其二，作品的功能是让这个隐藏的东西显示，所以作品有一种「开启」的力量，无法用「物 + 意义」解释。其三，作品的物因素不能从物出发被规定，只能从作品出发被理解。第三点正是对美学的判决：从「感性材料」出发，方向从一开始就反了。

但「开启」到这里还是空的。作品开启的是什么？凭什么说这种开启与真理有关？这是下一讲的任务。

## 五、经典原著：一篇讲演的三个部分

《艺术作品的本源》（Der Ursprung des Kunstwerkes）先是一次讲演：1935 年 11 月在弗莱堡艺术科学学会讲，1936 年 1 月在苏黎世重讲。全文 1950 年收入文集《林中路》（Holzwege）首次刊行，此后作者又写了后记与附记；版本情况下一讲再说。

标题里的「本源」（Ursprung）有双义：历史的起源，与本质的来源（Wesensherkunft），他要问的是后者。全文开头还摆出一个连环：艺术家是作品的本源，作品又是艺术家的本源，两者互为本源，于是问题被推给「艺术」（Kunst）。这与第一部分的循环是同一个手法。

正文分三部分：物与作品（Ding und Werk）拆解物性追问、绕道器具、落到梵高的画；作品与真理讲世界与大地的争执；真理与艺术讲真理的自行置入作品。这个排列本身是论证：先证明旧框架失效，再建立新框架。

::: quote 《艺术作品的本源》，德文关键术语（中译为笔者所加，非引用汉译本）
das Ding / das Dinghafte / die Dingheit；das Zeug / das Zeughafte；das Werk / das Werkhafte
物 / 物因素 / 物性；器具 / 器具因素；作品 / 作品因素
:::

词尾 -haft 表示「……的」：物因素不是物，器具因素不是器具。他从不问「作品像什么」，只问「作品之成为作品靠什么」。

## 六、艺术案例：梵高的一双鞋

海德格尔 1930 年在阿姆斯特丹看到一幅梵高画的鞋，讲演里描述的就是它。通常认为即今藏阿姆斯特丹梵高博物馆的《一双鞋》（1886，布面油画，约 37.5 × 45 厘米）。

看形式。画面极浅：一双磨旧的皮鞋放在一片暖褐色地面上，背景是一层斑驳的绿褐，地面与背景之间没有明确分界，鞋因此悬在一片没有坐标的空处。一只鞋立着，另一只侧倒，鞋带垂下来，松垮地搭在鞋帮上。透视略微俯视，观者被放在一个弯腰低头的位置。笔触厚而短，皮革的褶皱、鞋底边缘、鞋带转折都用断续的线画出，颜料堆在受光处，阴影处薄而透。这个画法排除了几乎所有让鞋变好看的因素：没有桌布，没有衬布，没有主人的脚，构图也不讲究平衡。

海德格尔读出的正是「可靠性」：鞋越旧，越说明它被长期依赖；鞋的塌陷不是缺陷，是它曾经承重的证据。

**最强的经验反驳来自艺术史家迈耶·夏皮罗（Meyer Schapiro）**。他在 1968 年的一篇文章里指出：海德格尔认错了鞋。据其考证，梵高画的更可能是画家自己的城市皮鞋——梵高在给弟弟提奥的信里提到过自己买的一双鞋，画中鞋的样式与磨损方式同田间劳作并不吻合。若此说成立，那段「农妇的世界」的著名描写就成了投射：他先有一套关于农民与土地的哲学，再把画填进去。

这场争论的细节是否成立，学界仍有讨论；但有一件事相当清楚——海德格尔对画面本身几乎没有兴趣，他不提笔触，不提那个悬空的地面。从他的立场，题目是「真理如何发生」，技法属于艺术学；从批评者的立场，把画降为插图就等于放弃了对作品之为作品的解释权。德里达后来在《绘画中的真理》里又拆了一层：双方都在追问「这双鞋属于谁」，而这个追问预设了所有权与指称的逻辑。

## 七、思想联系

向前，这条论证有两个源头。一是亚里士多德：质料因与形式因的配对经经院哲学固定为通用范畴，第一步拆解针对的正是这个后果。二是康德：他把审美判断建立在主体的心意状态上，艺术因此成为「体验」（Erlebnis）的对象；海德格尔说「美学」是近代主体性的产物，矛头正指向这条线。黑格尔的公式「美是理念的感性显现」在他眼里是顶点：真理被设为内容，感性被设为外衣。

向后，影响分三支。伽达默尔在《真理与方法》（1960）里接过「艺术的真理」，扩展成解释学经验，同时弱化了「大地」这一维度。阿多诺把「真理内容」改写成一种否定性的、与社会对抗的概念，与「发生」正好相反。德里达指出「真理置入作品」仍依赖「框架」的隐喻，而「框架」恰是海德格尔想摆脱的残余。

分析美学的反应留到下一讲，因为那场争论的核心在「真理」这个词上。

## 八、本节总结

- 「物性」追问被判定为形而上学问法，因为它以普遍概念、命题结构、主客对立为前提，问的是物被表象为什么。
- 三条传统路径依次失败；第三条最要紧，因为「质料—形式」出身于器具制作，用途决定形式，形式挑选材料。
- 器具站在物与作品的中间，接近它的方式是使用而非观察，其正常状态是退隐。
- 可靠性把使用者托付给一个世界，同时让自己不被看见；作品的功能是让这个不被看见的东西显示。
- 这一步构成循环；海德格尔承认它，把它重新描述为解释学的必经之路，代价是「谁是真作品」的判据被悬置。

值得继续追问的是：如果在无画、无摄影、无博物馆的时代，器具的存在只能在使用中被「信赖」而无法被看见，那么「看见」的特权就落给了艺术——而艺术恰恰是「博物馆艺术」的产物。

::: key 本讲要点
- 三重追问的顺序是物→器具→作品，且必须绕圈：器具的存在要靠作品显示。
- 「质料—形式」出身于器具制作，是器具学的范畴，不是存在论的普遍范畴。
- 可靠性＝双重托付；器具在使用中隐藏，作品让它显示。
- 海德格尔承认循环，把它改写为解释学的必经之路，代价是真假作品的判据被悬置。
:::
