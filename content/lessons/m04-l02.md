## 一、本节导入

1649 年，《论灵魂的激情》在阿姆斯特丹出版。笛卡尔（René Descartes，1596—1650）在书里给激情列了一张清单，六种基本激情，排在第一的是「惊叹」（admiration）。奇怪的地方在于：这部讲情感的书，没有一页讨论美。

读者若去找「笛卡尔的美学」，通常找不到。他没有写下「美是……」这样的定义，也没有艺术理论的专著。可是他关于「清晰分明」的真理标准、关于激情的机械论分析，被整个法国古典主义当作思想背景使用。一个几乎不谈美的人，成了那个世纪最有影响的美学权威之一。

这个反差值得追。本讲要弄清三件事：清晰分明的标准如何渗进艺术规范；惊叹在六种激情中的特殊位置；以及「美可证明吗」这个问题为什么在他那里必然悬空。

## 二、核心知识

::: def 清晰分明（clair et distinct）
笛卡尔在《哲学原理》第一部分区分的两个观念属性。清楚指观念当下呈现于专注的心灵；分明指观念与其他观念界限明确、不含混杂成分。两者合起来是最高的认识标准。
例子：三角形的观念是清楚的；一个「差不多是三角形」的图形既不清楚也不分明——你能感到它不规整，却说不出哪条边出了问题。
:::

::: def 激情（passion）
笛卡尔指灵魂的被动感受，由动物精气的运动引起、维持并加强。它处在身心交界处：先有身体的准备，才有灵魂的感受。
例子：看到猛兽扑来，精气先冲向内脑与心脏，肌肉收紧、心跳加快，恐惧的感受随后到来。感受并非凭空产生，它有生理的前件。
:::

::: def 惊叹（admiration）
遇到新奇罕见之物时，精气骤然聚向大脑，使心灵转向并专注于该对象的激情。它在六种基本激情中排在首位，也是唯一没有相反激情的一种。
例子：第一次见到一头长颈鹿，你停住、张口、忘了原本要办的事——此刻没有愉快也没有不快，只有「这是什么」的悬置。
:::

六种基本激情的差别可以列表看清：

| 激情 | 触发对象 | 身体变化 | 相反的激情 |
|---|---|---|---|
| 惊叹 | 新奇罕见之物 | 精气骤聚于脑，心跳血流几乎不变 | 无 |
| 爱 | 令人愉悦的对象 | 血脉扩张、心跳加快 | 恨 |
| 恨 | 有害的对象 | 血脉收缩 | 爱 |
| 欲望 | 未来可欲之物 | 精气激荡不定 | 有（逃避一类） |
| 快乐 | 当下之善 | 血液畅流 | 悲伤 |
| 悲伤 | 当下之恶 | 血液滞缓 | 快乐 |

这张表的排序有讲究。后五种都以「对象对我是好是坏」为前提，惊叹发生在评价之前：对象先以「新」占据心灵，善恶判断尚未开始。

## 三、代表人物：笛卡尔

笛卡尔 1596 年生于图赖讷的拉艾，在耶稣会的拉弗莱什学校受教育，1618 年结识数学家贝克曼，1628 年移居荷兰，此后二十年不断换住处以避开干扰。主要著作按年排出：1637 年《谈谈方法》，1641 年《第一哲学沉思集》，1644 年《哲学原理》，1649 年《论灵魂的激情》。同年他应瑞典女王克里斯蒂娜之邀赴斯德哥尔摩，次年病逝。

思想形成的关键是数学。解析几何把图形问题化成方程，同一套符号既能描述圆，也能描述椭圆，这让他相信一切知识都可由清楚分明的观念推出。1643 年起他与波希米亚的伊丽莎白公主通信，公主反复追问身心如何相互作用，这些信件是《论灵魂的激情》的直接起因。

他的贡献是提供了一个「判断的主体」：美学的问题从对象转到判断。局限也在这里——他把审美判断划到知识之外，等于承认理性主义无法自立一门美学。

## 四、理论解析

### （一）清晰分明怎样波及艺术规范

这条线索分三步走，每一步都可以找到具体制度。

1. **知识模型。** 清楚分明的观念可以组合成体系，因此凡能被分解为可辨识部分的对象，就能被评价。移用到作品上，就是要求有单一的情节主线、明确的视觉中心、可计算的模数比例。
2. **语言与文体。** 1662 年波尔—罗亚尔修道院的《逻辑学》把「清楚」列为表达的第一要求，同一圈子的语法教学要求句子成分界限分明。双关、繁复的隐喻、学究式的堆叠被当作缺陷，理由是无法分解。
3. **学院教学。** 1660 年代起，巴黎皇家绘画雕塑学院以讲座形式把绘画拆成素描、表情、构图、色彩；勒布伦（Charles Le Brun，1619—1690）关于表情的演讲把每种激情对应到眉、眼、口的位置，后来编成《绘制情感的方法》。三一律的辩护者如奥比尼亚克（François Hédelin d'Aubignac，1604—1676）在《戏剧实践》里，最终依据用的是理性与可信性，亚里士多德只作为佐证。

三步合起来，艺术的「可教部分」被放大，不可教的部分被当作剩余。这正是新古典主义的技术基础。

### （二）为什么他几乎不给美下定义

笛卡尔的理由可以整理成三步。

第一，美是关系。在给梅森纳（Marin Mersenne）的一封信里，他大意是说：被称为美的东西，指的是我们的判断与对象之间的某种关系；同一件东西对一人美、对另一人丑，因为各人带入的关系框架不同。

第二，关系无穷。任何对象都能与无数其他对象构成关系——比例、用途、回忆、身份、场合。没有理由选取其中一组作为「美的本质」，也没有办法证明某种选取比另一种更正确。

第三，结论。美没有确定的概念，因此不能被清楚地认识；关于美的判断属于「判断」，不属于「知识」。

这个结论有代价：美被移出认识论，美学不能成为科学的一个部门。它也有收获：审美判断的第一性被说清楚了——感受先于概念，且不能被概念替代。18 世纪的趣味论从这里出发。

### （三）惊叹的位置

惊叹排在第一位，理由在于它不预设评价。其余五种激情都要先判定对象对我是善是恶，惊叹只需要对象是新的。它是一种「注意力的激情」。

三个特征值得记住。其一，它没有相反的激情。轻蔑是尊重的反面，属于评价层面；新奇没有反面，因为「不新奇」只是一件普通之物，构不成一种激情。其二，它几乎不改变心跳与血液。笛卡尔说，惊叹时精气骤聚于脑，身体其余部分安静——这使它成为六种激情中最接近纯心灵的一种。其三，它可以是好的，也可以是坏的：惊异于伟大之物使人向学，被琐碎的新奇钉住则使人僵滞，不能求知。

这一条为超出概念的东西留了位置。当对象大到无法被关系框架容纳，心灵的反应不再是判断，而是惊叹。1674 年布瓦洛译出朗吉弩斯《论崇高》，把「心灵的骤然提升」引入法国古典主义，走的正是这条侧门。

最强的反对意见是：惊叹若不含评价，它与单纯的「没见过」有什么区别？笛卡尔自己的回答把惊叹交回给判断——好坏取决于对象是否值得惊异。这一回答保住了体系，却也让惊叹失去独立性，它成了判断的预备，而非另一种认识。

::: warn 「惊叹就是崇高」
把笛卡尔的 admiration 直接等同于博克的崇高，是一种常见的追认。两者确有交集：都起于对象超出常规，都使身体暂时失去行动能力。但崇高在 18 世纪的理论里含有痛感、危险感与自我保全的机制（参见本模块第 7 讲），惊叹只是认知的悬置，不含恐惧，也不含随之而来的解脱。较为稳妥的说法是：惊叹为崇高预留了位置，它本身还不是崇高。
:::

### （四）两难：美可证明吗

理性主义必须在三条路中选一条，每条都有代价。

1. **证明论。** 把美还原为比例关系，像证明定理一样证明某物美。代价是循环：比例本身需要被选取，而选取哪一组比例的标准又是美。
2. **约定论。** 由规则与权威规定什么是美。代价是无法解释规则的变更，也无法解释天才——最好的作品常常在规则之外成功。
3. **趣味论。** 承认美是不可还原的直接判断。代价是美学退出知识论，成为鉴赏而非科学。

笛卡尔倾向第三条，却没有把它写成理论；布瓦洛倾向第二条，却用第一条的语言表述。这个错位是 17 世纪美学的常态。

清晰分明在这里有双重身份，这一点容易被忽略。

作为敌人，它要求分解，而美感恰恰是整体清楚、细节混乱的。你一眼看出这张脸「对」，却说不出哪几处比例造成了这个判断；若强迫自己逐项测量，那个「对」就消失了。莱布尼茨后来给这种状态起名叫「清晰而混乱」，正是接着笛卡尔讲。

作为盟友，它提供了可共享的骨架。批评之所以可能，是因为我们能指出「这里含混」；教学之所以可能，是因为结构可以被指认、被复述、被修改。没有清晰，趣味只能沉默。

所以理性主义美学的真实立场可以这样表述：清晰是门槛，不是内容。它管作品能否被辨认、被讨论，不管感受本身如何发生。这条界线一旦被越过——要求感受也必须清晰——美学就变成了逻辑学；一旦被放弃——承认作品不可辨认也无妨——批评就失去了语言。

### （五）布瓦洛的继承与简化

布瓦洛 1674 年的《诗的艺术》第一章以「爱理性」的祈使句开场，把理性确立为文学的最高法庭。这一步的实质是把笛卡尔的「清晰」翻译成「理性」，同时删掉了「关系」的相对性。笛卡尔说美依赖判断者带入的框架，布瓦洛说好作品的标准对一切时代有效。

简化带来力量：标准统一，批评可以执行，教学可以复制。简化也带来代价：无法解释崇高，无法解释天才，无法解释趣味的时代差异。他同年译出《论崇高》，等于在体系内开了一道侧门——规则管不了的地方，用「崇高」命名。这道侧门在 18 世纪被博克与康德走成了正门（参见本模块第 7 讲）。

## 五、经典原著：《论灵魂的激情》

《论灵魂的激情》1649 年出版，三部分。第一部分论激情的一般性质与生理机制，第二部分列六种基本激情及其组合，第三部分论尊重、轻蔑、希望、恐惧、嫉妒等复合激情。写法接近医学论文：先定义，再分机制，再举例。这种写法本身就是宣言——情感可以被分析。

定义惊叹的那一句，核心短语是：

::: quote 《论灵魂的激情》第一部分
une subite surprise de l'âme（灵魂的一次突然惊异）
:::

这个短语后面接着说明：它使灵魂转向，去专注地考察显得罕见而奇特的对象。三个要素都在里面。突然，指它不由意志控制，说来就来；惊异，指认知的停顿，评价尚未开始；专注，指注意力的转向，心灵被对象占住。三者合起来，说明惊叹是一种关于注意力的激情，与善恶无关。

这句定义的分量在于它的位置：它排在六种激情之首，却不是最强烈的激情。笛卡尔把「第一」给了最薄的一种，等于承认心灵有一个先于评价的开口。

## 六、艺术案例：两幅截然相反的激情图像

普桑（Nicolas Poussin，1594—1665）的《日耳曼尼库斯之死》（1627，明尼阿波利斯美术馆）可以当作「分辨的激情」的样本。罗马将军日耳曼尼库斯中毒将死，床榻横贯画面，人物沿一条水平带排开，身体轴线与画面平行。光从左上均匀照入，几乎没有戏剧性的阴影；色彩以红、蓝、黄、赭几块平涂为主，边界清楚。表情靠手势与头部转角交代：左侧士兵举剑宣誓复仇，右侧妇女以手掩面，中部有人记录遗言。每一种悲痛都有一个可命名的位置。

这种安排与笛卡尔的清单同构：激情被分类、被定位、被赋予一个可以指认的对象。观众的任务因此是辨认：把每一种悲痛放到它该在的位置上。

贝尼尼（Gian Lorenzo Bernini，1598—1680）的《圣特雷莎的狂喜》（1647—1652，罗马胜利圣母堂科尔纳罗礼拜堂）走的是另一条路。天使手持金箭，圣女半卧云上，口微张、眼半闭、手足失力；织物褶皱深而翻卷，金色光柱从隐藏的窗口射下，把整组雕像从暗处剥离出来。

::: fig a-santa-teresa | 圣特雷莎的狂喜：光柱、翻卷的衣褶与失力的身体把观看者置于惊叹的位置
:::

两幅画放在一起，正好显示惊叹的位置。普桑的画面里没有惊叹：所有情感都被分辨完毕，观众处于认知状态。贝尼尼的画面里只有惊叹：身体先被光与姿态压倒，评价来不及发生。前者是清晰分明的胜利，后者是它的边界。

## 七、思想联系

向前追溯，清晰这一标准有更长的前史。奥古斯丁把美与「光辉」（claritas）连在一起，光既是物理的明亮，也是形式的可辨识；经院哲学讨论「清楚而分明」时，用的仍是光的隐喻。笛卡尔的改动在于把光从形而上学的来源挪到心灵这一侧：衡量标准变成观念对心灵呈现的清楚程度。

向后看，三条线索都从这一讲出发。莱布尼茨提出「清晰而混乱」的认识，为感性争取了一个独立层级，鲍姆嘉通据此建立美学（参见本模块第 8 讲）。布瓦洛把清晰翻译成规范，建立了新古典主义的纲领（参见本模块第 3 讲）。朗吉弩斯的崇高经由布瓦洛的译本进入法国，再经博克与康德变成与美并列的范畴。

## 八、本节总结

::: key 本讲要点
- 清晰分明是观念的两个属性：当下呈现，界限明确。它作为认识标准渗入文体、学院教学与三一律的辩护。
- 笛卡尔几乎不给美下定义，因为美是判断与对象之间的关系；关系无穷，故美无确定概念，审美判断被划出知识之外。
- 惊叹在六种基本激情中居首，是唯一没有相反激情、几乎不改变心跳血流的一种，属于注意力的激情。
- 理性主义美学的两难是美可证明吗：证明论循环，约定论无法解释变更，趣味论使美学退出知识论。
- 清晰对美感既是敌人又是盟友：它分解感受，也提供批评与教学所需的共享骨架。清晰是门槛，不是内容。
:::

一句话收束：笛卡尔把美赶出了知识，却留下了判断的主体与惊叹这个开口；布瓦洛用清晰造了房子，又在墙上开了一道叫崇高的门。

值得继续追问的问题：如果「清晰」只是可讨论性的条件，那么一件完全含混、无法被指认结构的作品，是否还能被批评？还是说，批评在这种情况下只能改写作品？
