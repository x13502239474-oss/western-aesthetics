## 一、本节导入

站在一幅塞尚的静物前，会同时发生两件互不兼容的事。一方面，你清楚那些苹果是颜料，画布是平的，你不能伸手去拿；另一方面，你又分明「看见」苹果饱满的体积、桌布的褶皱、空气的厚度。这个苹果到底是存在的，还是不存在的？

这个问题不是钻牛角尖。它牵出 20 世纪美学里一场真正的分歧：审美经验究竟属于「意识」，还是属于「身体」？萨特站在意识一边，认为我们被画打动，靠的是想象把现实「虚无化」、把不存在的苹果摆出来；梅洛-庞蒂站在身体一边，认为打动我们的是身体在世界中的原初知觉，苹果的体积与深度是肉身与可见世界之间的缠绕。

两人同出于法国现象学运动，师承关系很近，结论却分道扬镳。把这两条路放在一起看，最能看清现象学美学的力量所在，也最能看清它的裂口。

## 二、核心知识：想象、肉与知觉

::: def 想象（l'imaginaire）
萨特意义上的想象是一种意识行为：意识把现实世界「虚无化」，转而设定一个不在场、非现实的对象。它不同于知觉（知觉指向在场之物），也不同于回忆（回忆指向过去在场之物）。**例子**：我「想象」一位不在身边的朋友，他此刻并不实存于我的感知场里，却作为想象对象被摆在我面前。
:::

::: def 肉（chair）
梅洛-庞蒂的晚期概念，指「可见者与可见者之间的缠绕」：身体既是能看的（看者），又是被看的（可见者），因此它属于它所观看的那个世界本身。肉既非物质，也非精神，它指可见性与触觉性交织的共同纹理。**例子**：我触摸自己的手，这只手既是被摸的对象，又是正在摸的主体，触与被触在同一只手上翻转。
:::

::: def 知觉（perception）
梅洛-庞蒂所说的知觉是身体与世界之间前反思的、原初的接触，先于任何概念与判断。知觉并非被动的接收，它由身体主动地组织世界。**例子**：我们不用测量就「感到」房间的深度、楼梯的高度，这种对空间的把握先于几何计算。
:::

::: def 自由（liberté）
在萨特那里，自由指意识的虚无化能力——意识总能超越现实、否定给定之物、投向尚未存在的可能性。在梅洛-庞蒂那里，自由是处境中的自由，它总已被身体与世界承载。**例子**：萨特会说，即使囚徒也能通过想象脱离牢房；梅洛-庞蒂会说，囚徒的想象仍带着牢房的寒冷与铁栏的触感。
:::

四个词已经透露分歧：萨特把审美引向「想象」与「虚无」，梅洛-庞蒂把审美锚定在「肉」与「知觉」上。

## 三、代表人物：两条从胡塞尔出发的路

萨特（Jean-Paul Sartre，1905—1980）与梅洛-庞蒂（Maurice Merleau-Ponty，1908—1961）同出于巴黎高等师范学校，1930 年代都在德国接触胡塞尔的现象学。萨特 1933—1934 年旅居柏林研究胡塞尔与海德格尔，回国后写《想象》（1936）、《想象物》（1940）与《存在与虚无》（1943），战后成为存在主义与「介入」文论的中心。梅洛-庞蒂则把现象学落到身体与知觉上，1945 年出版《知觉现象学》，1952 年入法兰西学院，晚期转向「肉」的存在论，1961 年《眼与心》成为其美学遗嘱。

两人面对的共同问题，是胡塞尔遗留下来的：意识如何「构成」对象？萨特的回答偏重意识的主动性（虚无化、自由），梅洛-庞蒂的回答偏重身体的被动—主动交织（知觉、肉）。这一个岔口，决定了他们对艺术的全部判断。

## 四、理论解析：想象的自由与知觉的扎根

### 萨特：想象是自由的证明

萨特的想象论要解决一个具体的困难：如果把心理「影像」当成头脑里的一张小图片，就会陷入循环——为了解释影像如何被认识，又得假定一个看图片的小人。胡塞尔的意向性理论已把这个问题引向正途：想象并非「有一个影像」，它其实是「指向一个对象」的意识行为。萨特再进一步：想象指向的对象是「非存在」。

论证分三步，每步有支撑。

1. **知觉与想象的区分**。知觉指向在场之物，想象指向缺席之物。我「看见」的椅子有确定的时空位置，我「想象」的椅子则没有——它不在房间里，也不在任何具体时刻。这一步靠现象学的描述支撑：比较「看」与「想见」两种经验，二者的对象存在方式确实不同。

2. **想象是一种虚无化**。意识要把现实「括起来」，才能摆出一个非现实的对象。想象一幅画中的世界，意味着画布、颜料、墙这些现实物暂时退场，被意识否定了。这一步支撑着萨特的存在论：虚无化正是自由的根源——意识能对现实说「不」，所以才不被现实决定。

3. **审美对象是非现实物**。由此，一幅画的审美对象并不等于画布上的颜料，它是由想象把握的那个「非现实」的图像世界。美不落在现实物上，落在想象物上。萨特的大意是：查理八世的肖像画的审美对象，是那个被想象唤起的非现实的人，而非画布与油彩。

这个论证把「艺术如何打动我们」的答案落到了自由上：艺术之所以有感染力，在于它召唤我们的想象，而想象是自由的直接显现。这个主张有力，也有代价：它把审美对象与它的物质载体（画布、颜料、文字的肌理）切开了，美成了漂浮在「非现实」里的东西。

### 萨特：散文介入，诗歌不介入

《什么是文学？》最初以系列文章连载于《现代》杂志 1947 年，1948 年结集出版。萨特在这里提出一个著名的二分：散文与诗歌处于两种完全不同的地位。

散文家把词语当符号，词语对他透明，指向意义、指向世界；诗人的词语则是不透明的物，诗人像画家对待颜色、音乐家对待声音一样对待词语本身。由此推出一个结论：散文（连同小说、戏剧、随笔）能够、而且必须「介入」（engagement），因为说话就是行动——说出一种处境，就是揭露它，而揭露是改变它的第一步。作家为时代写作，写作是对读者自由的呼吁。诗歌则按其本性不承担这一任务，它停留在语言本身的物质性里。

::: warn 「介入」不等于「政治宣传」
一个流行的误解是把萨特的「介入文学」等同于让文学喊口号。萨特的原意是：散文家的选材、措辞、立场本身已经是一种对世界的表态，无法中立；介入并非外加的任务，它属于散文文类的内在结构。他反对的是那种假装「纯文学」「为艺术而艺术」的欺骗性中立。
:::

**介入主张的内在困难**是这一节最该说清的地方。困难在于文学自律与政治效用之间的张力：如果文学的价值在于形式与语言的自足，那么让它服务于政治揭露就会伤害文学本身；如果文学的价值在于现实效果，那么它又何以区别于社论与宣传？萨特用「散文=行动」试图缝合两者，但缝得并不牢——他后来自己也承认，纯粹的介入会让文学滑向功利工具，而完全的自律又抽空了文学的现实锋芒。这个张力，20 世纪下半叶的「介入文学」之争一直没能真正解开。

### 梅洛-庞蒂：身体是世界的肉

梅洛-庞蒂的路正好从萨特的缺口进去。萨特把审美对象悬到「非现实」里，梅洛-庞蒂要问：那个「非现实」的苹果，它的体积与深度从哪来？答案是身体：作为知觉主体的身体，而非生理机器。

《知觉现象学》（1945）的核心概念是「身体图式」（schéma corporel）：身体前反思地、整体地组织知觉，先于任何概念。我们不用先测量再理解房间的深度，身体已经「知道」如何在其中活动。到了《眼与心》（1961），这个概念升级为「肉」：身体是可见世界的一部分，它既能看又被看，所以世界能反过来「看」身体——塞尚的绘画正是「可见者对身体的反向观看」的典型。画家并非把世界复制到画布上，他让世界在画家身上自己呈现自己。

**深度**在这里是关键。萨特式的想象把画布当平面、把图像世界当「非现实」，梅洛-庞蒂则指出：塞尚画里的苹果之所以饱满，依靠的并非线性透视计算出来的几何距离，那深度来自颜色与体积的相互缠绕——冷色后退、暖色前伸、笔触的并置让平面自己鼓起。这种深度是存在论的维度，是身体在世界中在场的直接显现，先于几何。

### 两人对照

| 维度 | 萨特 | 梅洛-庞蒂 |
| --- | --- | --- |
| 身体 | 自为存在的事实性（facticity），是意识要否定的给定处境 | 世界之肉的一部分，知觉的主体，先于主客之分 |
| 自由 | 意识的虚无化能力，绝对的、超越现实的自由 | 处境中的自由，总已由身体与世界承载 |
| 审美对象 | 非现实物，靠想象把握 | 可见世界借身体的反向显现，不脱离物质 |
| 艺术的核心 | 召唤读者的自由（介入） | 让世界的可见性在身体中显现 |
| 典型文类 | 散文、小说、戏剧 | 绘画（塞尚） |

这张表暴露的是同一个现象学内部的根本分岔：一个强调意识的「否」，一个强调身体的「在」。

## 五、经典原著：五本书的骨架

萨特的两部想象研究构成一组。《想象》（1936）批判传统影像论，清理从笛卡尔到当时的心理主义；《想象物》（1940）正面建立想象的现象学，结尾抛出「想象是自由的证明」这一结论，为《存在与虚无》的自由观铺路。《什么是文学？》（1948）则是把哲学立场转译成文学宣言，其中「散文是意义的、诗歌是物的」这组区分（此为转述，非逐字引文）与「介入」的呼吁，构成法国存在主义文论的纲领。

梅洛-庞蒂的《知觉现象学》（1945）重写胡塞尔：知觉不再是意识的构成活动，而是身体在世界中的原初接触。《眼与心》（1961）篇幅很短，却是美学上最集中的文本，核心命题是「画家把他的身体借给世界」（此为转述），绘画因此是「可见者对身体的反向观看」的发生地。这部晚年文本明显带着海德格尔的印记——艺术让存在显现，但显现的载体从「存在」落到了「肉」。

l'imaginaire 想象物；la chair 肉；la perception 知觉；la liberté 自由
:::

## 六、艺术案例：塞尚的苹果与深度

塞尚（Paul Cézanne，1839—1906）是梅洛-庞蒂反复援引的画家，也被他当作「肉身知觉」的见证。以塞尚晚期的静物画为例：画面放弃单点透视，桌子的前缘与后缘不在同一条视线上，观者像是同时从几个角度在看；苹果用层层叠叠的短笔触塑造，颜色以并列的色块取代平涂，绿里透红，红里压着蓝灰，冷暖交替地「捏」出体积；背景与桌面常常连成一片，没有明确的轮廓线把对象从环境里切出来。

按梅洛-庞蒂的读法，这些形式特征恰恰是「深度」的存在论证明：塞尚画的是身体在苹果周围走动、触摸、呼吸时所经验到的苹果，而非从某个固定视点「看」到的那个。那种无法用几何透视还原的深度，是「肉」的厚度——可见世界与观看的身体在画布上互相缠绕。塞尚自己那句常被引用的话，大意是：自然在内部，深度与颜色、形式不分（此为转述）。

对照萨特，分歧立刻显形。萨特会说，我们被塞尚的苹果打动，是因为想象把画布虚无化、把「非现实」的苹果唤出来。梅洛-庞蒂则会反问：那个「非现实」苹果的体积感，恰恰来自颜料、笔触、冷暖色这些现实物质在身体知觉里的运作——抽掉这些物质，想象就无米下锅。谁更接近真相，取决于你把审美经验的重心放在「意识的否定」还是「身体的在场」上。

## 七、思想联系

向前，两人都继承胡塞尔的意向性（参见第 7 模块第 5 讲），但各自取了意向性的一个侧面：萨特取「意识的指向与否定」，梅洛-庞蒂取「身体—世界的交织」。海德格尔的影响同样可辨：梅洛-庞蒂的「肉」与「可见者显现」带有《艺术作品的本源》的印记，萨特的「虚无」则与海德格尔的「无」保持着一种紧张的关系。

向后，萨特的「介入」主张直接塑造了战后法国的存在主义批评与「倾向性文学」（littérature engagée）运动，也启发了后来文学政治功能的所有争论；梅洛-庞蒂的身体—知觉理论则成为现象学美学、艺术史（如对塞尚与视觉的研究）乃至认知科学里「具身认知」的先声。两条路到今天仍是「意识优先」与「身体优先」两个阵营各自的源头。

## 八、本节总结

- 萨特区分知觉与想象：想象指向非存在，是一种虚无化，因而是自由的直接证明。
- 萨特主张散文介入、诗歌不介入，因为散文把词语当符号，说话即行动。
- 介入主张的内在困难在于文学自律与政治效用之间的张力，萨特未能真正缝合。
- 梅洛-庞蒂以「身体图式」与「肉」重写知觉，认为审美扎根于身体在世界中的在场。
- 塞尚画中的深度是存在论维度，源于颜色、笔触与身体的缠绕，而非几何透视。
- 两人共享现象学起点，却在「意识优先」与「身体优先」上彻底分岔。

值得继续追问的是：如果审美经验既需要想象（萨特）又离不开身体（梅洛-庞蒂），二者是相加还是对抗？这个问题恰好通向杜威——他主张审美经验既不归于意识，也不归于身体，而归于「经验」本身的完成。
