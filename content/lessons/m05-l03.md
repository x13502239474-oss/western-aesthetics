## 一、本节导入

先设想一个普通的场景。你在房产中介的橱窗里看到一张山景照片，觉得好看，站着看了半分钟。中介走出来说：那片山明年要开发成度假村，一期只剩三套。你的感受立刻变了。山的轮廓没变，光线没变，变的是你与它的关系：它从「一个好看的景象」变成了「一个可以占有的资源」。

再设想另一个场景。朋友新买了一只杯子，你觉得它美，拿在手里转了两圈，然后放回桌上。你没有想买，也没有想拿走。若有人问「你为什么觉得它美」，你会说「釉色和把手的角度配得好」；若他说「我觉得很一般」，你多半会回一句「你不觉得这个蓝很沉吗」。

两个场景的差别，就是第一契机要处理的东西。前者里，愉悦和对象的实存绑在一起；后者里，愉悦只和对象的样子绑在一起。康德把前一种叫利害，后一种叫无利害。这个区分是全部鉴赏理论的地基。

## 二、核心知识：利害、无利害、普遍性

::: def 利害（Interesse）
在康德的术语里，利害指愉悦与对象之「实存」的连结：我因对象存在、可能属于我、或能够被我享用而愉快。它含欲求的成分，总与我的处境有关。
例子：饿了的时候觉得一碗面「好」，这个「好」包含「我要吃它」；一幅面包的静物画也能让我愉悦，但我不打算吃画里的面包。
:::

::: def 无利害（interesselos）
审美判断的愉悦不依赖对象的实存，也不包含占有、使用、消费的欲求，只与对象的表象方式有关。它描述的是愉悦的结构，与感受的强度无关。
例子：听一首曲子，你希望它继续，却不希望把它装进口袋；可以反复听，听得入神，这仍然是强烈的愉悦。
:::

::: def 主观普遍性（subjektive Allgemeinheit）
审美判断是单称的（「这朵花美」），却要求所有人同意；这种普遍性不靠概念，靠人人共有的认识能力之和谐，因此称为主观的。
例子：我说「这朵花美」，不会加一句「对我而言」。我默认你也会同意；你若不同意，我会觉得你的感受「还没到位」，却拿不出论证。
:::

::: def 共通感（sensus communis）
康德用来指人人共有的、使审美判断得以要求同意的那种能力：想象力与知性的自由和谐，原则上可以被每个人感到并传达。
例子：一群人看晚霞，有人说「这像烧起来的绸子」，其他人立刻明白。这种明白不靠定义，靠一种共有的感受力。
:::

三种愉悦的差别可以列成一张表：

| | 快适（angenehm） | 美（schön） | 善（gut） |
|---|---|---|---|
| 愉悦与对象实存 | 依赖，含欲求 | 不依赖 | 依赖，含认可 |
| 是否涉及概念 | 不涉及 | 不涉及 | 涉及（目的概念） |
| 普遍性 | 无，各人各异 | 有，但无概念 | 有，且有概念 |
| 典型说法 | 「这让我舒服」 | 「这美」 | 「这好」 |
| 例子 | 温水浴、甜酒 | 一朵花、无标题音乐 | 一件善行、一件合用的工具 |

表里最容易被忽略的是第一行与第三行的组合。快适没有普遍性，善有普遍性但靠概念，美夹在中间：有普遍性，却没有概念可依。整部鉴赏理论要解决的，就是这个中间项如何可能。

::: warn 无利害就是冷漠、不关心
这是最常见的误读。「无利害」听起来像「无所谓」，其实相反：看画看得入迷，正说明你在乎它。康德否定的只是与对象实存相关的欲求，包括占有、使用、消费、炫耀，保留的是对表象本身的全部注意力。
判据很简单：对象消失或归别人所有，你的愉悦是否随之消失？若消失，那是利害；若你仍愿意再看一次，那更接近无利害。
:::

## 三、代表人物：康德与休谟

康德（Immanuel Kant，1724—1804）在第一批判里已把「感性」一词留给空间与时间，因此处理美时必须另找地基。他找到的是「判断力」：一种把特殊归摄到普遍之下的能力，而在审美中，普遍并没有被给出。这个起点决定了他不问「美是什么性质」，只问「审美判断凭什么要求同意」。

休谟（David Hume，1711—1776）是重要的对照。他在《论趣味的标准》里承认趣味因人而异，却又想找到标准，办法是诉诸「共同的人性」与「有资格的判断者」：作品经过时间检验、被有教养的批评家一致赞许，就可以作为标准。这个方案是经验论的；康德的方案是先验的，普遍性不来自统计，来自认识能力的普遍结构。

康德的贡献是把「无利害」从心理描述提升为审美判断的规定。局限在于，这个规定越纯粹，能装进去的经验越少。

## 四、理论解析：两个契机与一个悖论

**第一契机：质。** 论证可以拆成三步。

1. 鉴赏判断规定的对象是愉悦，而非对象的性质。我说「这美」，说的是我的表象方式带来的愉快，与对象身上的属性无关。
2. 若这愉悦依赖感觉的刺激或概念的认可，它就与对象的实存或目的相关，因而带有利害。
3. 审美愉悦既不起于感官刺激，也不起于概念，所以与实存无关，是无利害的。

第三步靠前两步的排除。这个论证的形式是否定式的：它不告诉我们愉悦是什么，只告诉我们愉悦不依附于什么。康德的用意是清场，把欲望、利益、道德认可都请出去。

这一步的收获很实在。它解释了为什么审美判断可以不计较归属：我可以觉得别人家的花园美，而不想搬回家。它也解释了为什么利害会污染判断：当收藏家看画只看升值空间，他看到的已经不是画。

**第二契机：量。** 鉴赏判断是单称的，主词是「这一朵花」「这一幅画」，不能像「所有的花都美」那样量化。可它又要求普遍同意。这个「要求」有特殊的语法。

第一，它不是预测。我说「这美」时，并没有先做民意调查再预言你也会同意。若只是预测，我就该说「多数人会觉得这美」，而不会在你反对时说「你的感受不对」。

第二，它是要求，用的是「应当」的语气。康德说鉴赏判断「要求」每个人同意，而不只是「期待」同意（大意）。这个「应当」有前提：你也具备健全的认识能力，并且真的面对了对象。因此它既非道德义务，也非逻辑必然，只是一种有条件的请求。

第三，它的普遍性没有概念作中介。一般判断的普遍性靠概念：因为这是三角形，所以内角和为两直角。审美判断没有这样的概念，「美」本身不能充当概念，否则就可以争论、可以证明。于是康德说，鉴赏判断的普遍性是「主观的」：它关乎人人共有的主观条件，而非对象的共同属性。

**共通感：前提还是结论。** 普遍性从哪来？康德的回答是共通感。论证的骨架是：认识若要成立，认识诸能力的和谐就必须能够普遍传达；既然能普遍传达，就预设了一种人人共有的感受能力；审美判断所感到的正是这种和谐，因此它可以要求同意。

这个论证有循环的嫌疑：要证明普遍性，先预设了共通感；而共通感本身又要靠普遍性来辩护。研究者对此有长期争论。一种读法认为康德的演绎确实失败，因为他只能证明「我们必须假定」共通感，无法证明人人事实上同意（盖耶一类的批评）；另一种读法认为，这个「假定」是先验论证的正常结构，它不承诺事实上的全体一致，只说明要求同意是理性的（艾利森一类的辩护）。分歧在于对「先验演绎」的期待有多高。

**最强反对：内容去哪了。** 无利害说最容易被攻击的地方，是它把我们对作品内容的投入排除在外。看《格尔尼卡》时的愤怒、读小说时为人物命运的焦虑、听一首歌被歌词击中的震动，都算不上「对表象方式的静观」。席勒在《审美教育书简》里接过「自由游戏」，却把感性与理性一起放进游戏，纯粹性因此被稀释；尼采在《论道德的谱系》里把「无利害的沉思」当作禁欲理想的一个变体，认为它把「旁观者」虚构为唯一合法的审美姿态；布尔迪厄指出，这种姿态需要闲暇与教养，距离来自对必然性的距离。

康德有回应的余地。他可以把这类经验放进「依附美」，或归给「魅力」与「激动」，说它们不属于纯粹鉴赏；也可以用「审美理念」解释内容为何能引发无尽的思想。但这些补救都有代价：纯粹鉴赏的地盘越缩越小，最后只剩花、壁纸与无标题音乐。一个理论若只能解释最稀薄的经验，它的普遍性就成了问题。

## 五、经典原著：美的分析论的前两个契机

《判断力批判》的「美的分析论」按质、量、关系、模态四个契机展开，次序借自第一批判的范畴表，却把质提到量之前。研究者一般认为有用意：审美判断最先被给予的是愉悦。

第一契机的核心工作是把「快适—美—善」三者分开，指出只有美既无利害又无概念。康德还处理了一个难题：如果愉悦无利害，它凭什么比快适更有价值？他的回答是，无利害的愉悦可以普遍传达，可传达性本身带来「社交的愉悦」。

第二契机提出「主观普遍性」，并引入共通感。康德区分「感官的共通感」（人人感官构造相似）与「反思的共通感」（认识能力的自由和谐可以互相传达）；前者是经验事实，后者是先验预设。混淆两者，就会把论证读成心理学假设。

两个契机合起来，得到一个悖论式的结构：审美判断是个人的，又是普遍的；没有概念可依，因此无法争论；有普遍性可要求，因此无法互相漠视。康德用一句话概括：关于趣味可以争，却不能靠证明来裁断（大意）。

::: quote 《判断力批判》美的分析论（大意，据通行中译）
美是一个无须概念而普遍令人愉快的对象。
:::

这句定义把两个契机压在一起：无须概念，是质的方面的延伸；普遍令人愉快，是量的方面的要求。康德说的是「普遍令人愉快」，一个规范性的说法，而非「人人实际上愉快」。

## 六、艺术案例：莫奈《印象·日出》

一八七二年，莫奈在勒阿弗尔港画了一幅小画，约四十八厘米高、六十三厘米宽。左上一轮橙红的太阳，下方水面用短促的横向笔触铺开，蓝灰的调子里夹着橙色反射；中景是模糊的船影与桅杆，远景是工厂的烟囱。色调偏冷，太阳与倒影是唯一的暖色，轮廓几乎没有。一八七四年展出时，批评家勒鲁瓦借它的标题写讽刺文章，把参展者统称为「印象派」。

从康德的框架看，这幅画近乎「无利害」的教科书。它不讲述故事，不提供教训，愉悦来自色彩的互补、笔触的速度、水面与天空之间那条几乎不存在的界线。观者注意的是「怎么画」。

同一个例子也能反过来支持反对意见。画的内容并非无关：烟囱与吊车是工业化的港口，雾与光是现代城市的空气。当时的观众愤怒，部分原因在于题材庸俗；学院派要求笔触隐匿、轮廓明确，这幅画公然露出笔触，于是被讥为「草稿」「壁纸」。这说明审美判断带着关于「画应当是什么」的概念，按康德的分类已进入依附美。

康德的框架能解释它「为什么让人愉悦」，却解释不了它「为什么让人愤怒」。前者靠形式的合目的性，后者靠趣味的社会史。

:::

## 七、思想联系

向前追溯，「无利害」在英国经验论里已有雏形。哈奇生讨论美感时，明确把它与「对利益的计较」分开；沙夫茨伯里在道德感理论里也用过类似的区分。康德的改动在于把它先验化：无利害从心理描述变成审美判断的构成条件。

向后看，叔本华把无利害发展为「意志的暂时熄灭」；布洛提出「心理距离」，把它改写成可调节的态度；布尔迪厄从社会学角度拆解它，指出「纯粹的目光」预设了与必然性的距离，而这距离本身是阶级的产物。分析美学重新讨论无利害是否必要，卡罗尔（Noël Carroll）等人主张，许多艺术引发的情感与认知投入无法被它容纳。

## 八、本节总结

::: key 本讲要点
- 利害指愉悦与对象实存的连结；无利害否定的是欲求与占有，保留的是对表象的专注。
- 三种愉悦的差别在于「是否依赖实存」与「是否涉及概念」；美是唯一既无利害又无概念的。
- 审美判断是单称的，却要求普遍同意；这个要求是「应当」，而非预测。
- 普遍性的根据是共通感，但它究竟是先验前提还是规范理想，学界仍有争论。
- 最强反对指出：无利害无法解释我们对作品内容的投入，也无法解释趣味的社会条件。
:::

质与量两个契机合起来，得到一个奇怪的结论：审美判断最个人，又最要求普遍；最无凭据，又最不肯让步。关系与模态留到下一讲。康德之后的德国美学，几乎都在处理这个结构：席勒想让它变成教育，黑格尔想让它变成历史，尼采想把它拆掉。

值得继续追问的问题：如果「无利害」是一种历史地形成的态度，而非人性的普遍结构，那么康德的分析还剩下多少？当我们说「这部电影让我愤怒，所以它好」时，我们是在做审美判断，还是在做别的事？
