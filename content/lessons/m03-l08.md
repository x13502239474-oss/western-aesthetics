## 一、本节导入

威尼斯学院美术馆藏有一张纸，约 34.6 厘米高、25.5 厘米宽，用钢笔与金属尖画着一个裸体男子，四只手、四条腿。同一个人被画了两次：一次双臂平伸、双腿并拢，落在一个正方形里；一次双臂上举、双腿张开，落在一个圆里。图的上方与下方各有一段镜像书写的笔记。这就是《维特鲁威人》。

第一次看的人常会问：为什么把人画两遍？答案在一个几何难题里——如何让圆与方共享同一个身体。背后是一整套信念：人体是宇宙比例的缩影，测量人体就是测量世界。

但同一时期的另一批图像会让人不安。提香在 1538 年画了一个躺着的裸女，她睁眼直视画外。她不在测量什么，她被观看。本讲要处理的问题因此有两层：比例凭什么被当作美的根据？当比例遇到「优雅」与「性别」，它为什么开始不够用？

## 二、核心知识：三种尺度

::: def 维特鲁威比例
指维特鲁威在《建筑十书》第三书中提出的人体比例系统，以及由此推导神庙比例的做法。基本单位是「掌」：四指为一掌，四掌为一足，六掌为一肘，身高为四肘。它同时包含一个更强的命题：人体可内接于圆与方，因此是「完满图形」的载体。**关键在于**，它把美定义为部分与整体之间可通约的数的关系，又把这种关系当作宇宙秩序的证据。
:::

::: def 优雅（grazia）
文艺复兴艺术理论中用来指一种无法由规则导出的愉悦品质。它接近英文的 grace，含义更世俗：形体动作的舒展、线条的流动、分寸上的自制。**它的问题在于**，它总被定义为规则之外的东西：你能感到它，却说不出它由哪几条比例构成。阿尔伯蒂与瓦萨里都用过这个词，后者尤其爱用它解释某些作品「看起来比量起来更好」。
:::

::: def 男性凝视（male gaze）
指视觉再现中把女性身体设定为被看对象、把观看位置默认为男性的结构。这个术语由劳拉·穆尔维在 1975 年的电影理论文章《视觉快感与叙事电影》中提出，用在 16 世纪绘画上属于回溯性使用。**使用时需小心**：它描述图像所预设的观看位置，与某位具体观者的心理无关；其价值在于提示我们，构图与姿态可以携带权力关系。
:::

三把尺度的关系构成本讲主线：比例是**可通约**的，优雅是**不可通约**的，凝视是**不对称**的。文艺复兴同时使用三者，也因此埋下了自我反驳的种子。

## 三、代表人物：一位古人，两位时人

**维特鲁威**（Vitruvius，活动于公元前 1 世纪）是奥古斯都时期的建筑师，著有《建筑十书》，献给皇帝。此书在中世纪以抄本零散流传，1416 年由波焦·布拉乔利尼在圣加仑重新发现，此后成为文艺复兴建筑与艺术理论的共同底本。他面对的问题是：如何给建筑的美找一个可论证的基础。答案是把人体当作模数。

**卡斯提利奥内**（Baldesar Castiglione，1478—1529）出身曼图亚贵族家庭，长期在乌尔比诺与罗马的宫廷任职，1528 年在威尼斯出版《廷臣论》。全书以四晚对话描写理想廷臣的品质：武力、学识、谈吐、风度。他面对的问题是：贵族的行为标准能否被教授？答案是「可以，但不能显出被教过」。

**提香**（Titian，约 1488/1490—1576）生于卡多雷，在威尼斯成名，长期为哈布斯堡宫廷与意大利诸侯作画。技法特征是厚涂与透明罩染并用，晚期笔触近乎书写。他面对的问题是：如何让商业共和国的绘画既满足赞助人趣味，又保持感官强度。答案是把色彩当作主要结构，而非素描的附庸。

## 四、理论解析：比例的五道裂缝

### 第一步：圆与方，一个未解的几何

维特鲁威的原文说，若把人仰面放置、手脚展开，以肚脐为圆心画圆，圆周会经过手指与脚趾；同时，展开的宽度与身高相等，可构成正方形。这两句合起来要求：圆与方面积相等而中心同在一处。

这在几何上做不到。以脐为圆心的圆，与以身高为边的方，无法既保持各自定义又共享中心。中世纪的抄本插图因此常画得含糊：圆与方勉强套在一起。莱奥纳多的处理是把「同一个身体」拆成两个姿态：方用平伸的手臂与并拢的腿，圆用上举的手臂与张开的腿。两个图形各自成立，代价是人被画了两次。

这一步值得玩味：它用「多做一次」解决了「做不到」的问题。测量人体的计划，从一开始就包含无法闭合的缝隙。

### 第二步：两个中心，两种秩序

更细的一层在中心。图上正方形的中心落在**耻骨部位**，圆形的中心落在**肚脐**。维特鲁威传统把方理解为「身高的界限」，其中心自然是身体中点；圆被理解为「生成的循环」，其中心落在脐，即生命与养分的来源。

两个中心相差一掌左右。这个小小的错位承载两套秩序：方对应可测量的、静止的、此世的身体；圆对应循环的、宇宙的、生成的身体。人被放在两者之间，既是尺度，也是尺度的使用者；「小宇宙」观念在这里被画成了图形（参见第 6 讲）。

::: warn 这张图不是「完美比例」的说明书
流行读物常说《维特鲁威人》证明了「人体符合黄金比」。这是后世的附会。图中给出的是整数分数（脸为身高的十分之一、头为八分之一之类），与黄金比没有直接关系；黄金比在艺术中的系统运用要等帕乔利 1509 年的《神圣比例》之后才被广泛讨论，而该书中莱奥纳多所画的插图是正多面体。把两者混为一谈，会让这张图失去最有意思的地方——它是一个未完成的几何方案。
:::

### 第三步：优雅，规则之外的那一点

如果比例可以算，为什么还要发明「优雅」？因为算得准的画不一定好看。阿尔伯蒂在《论绘画》第三卷讨论画家修养时，已把「愉悦」与「合规则」分开谈；瓦萨里评画时更常用 grazia 解释那种「说不出为什么好」的效果。

理论化在《廷臣论》里达到顶点。卡斯提利奥内提出，廷臣的一切动作都应伴随一种 **sprezzatura**，其**大意**是：把技艺隐藏起来，让人以为什么都做得不费力、几乎不假思索。这个要求有自我指涉结构：你要努力练习，才能显得不努力；你要精通规则，才能显得不受规则约束。它无法写成手册，因为一旦写出「如何显得不费力」的步骤，效果立刻消失。

这与比例的关系是紧张的。比例可教、可核对、可传递；sprezzatura 不可教，只能示范与体会。瓦萨里时代的艺术教育因此分裂：学院教比例与素描，宫廷教风度与从容，最受赞赏的作品被认为同时具备两者。美开始需要两种互不翻译的语言。

| 维度 | 比例论 | 优雅论 |
| --- | --- | --- |
| 美的根据 | 部分与整体的数的关系 | 动作与分寸的恰到好处 |
| 可否教 | 可教，可写入手册 | 不可教，只能示范与模仿 |
| 判断者 | 会测量的人 | 有品味的人（廷臣、内行） |
| 失败形态 | 僵硬、正确而无生气 | 做作、刻意、露出用力 |
| 典型文本 | 维特鲁威、阿尔伯蒂、帕乔利 | 卡斯提利奥内、瓦萨里 |

### 第四步：被看的身体

1538 年，提香把一幅画寄给乌尔比诺公爵圭多巴尔多二世。画中一位裸女斜卧榻上，右手持花，左手覆在身体中央；身后是深绿帷幔，远处两个女仆开箱取衣，脚边卧一只小狗，窗台上有一盆桃金娘。

把它与乔尔乔内约 1510 年的《沉睡的维纳斯》并置，差别一眼可见：乔尔乔内的女神闭眼，身体顺着风景起伏展开，像自然的一部分；提香的女神睁眼，直视画外，身体横陈在封闭室内，床单褶皱与帷幔垂线把她框成明确的观看对象。

三个形式装置值得指出。**视线对接**：她的目光与观者视线在同一水平线相遇，这在肖像画里是亲近的标志，在裸体画里则把观者变成被邀请的一方。**手的安置**：覆在身体中央的手既遮挡又指示，构图上的作用是稳定重心，观看上的作用是延长注视。**日常物的编码**：狗象征忠诚，桃金娘象征婚姻，开箱的女仆提示嫁妆——这些物件把神话人物放进婚姻语境，使这幅画可同时被读成神话题材与婚房图像。

「男性凝视」这个术语要到 1975 年才出现。较吻合史料的说法是：这幅画由一位男性公爵委托，预设的悬挂位置是私密空间，画面结构把观者放在一个被允许长时间注视的位置上。观看的权力在这里不靠强迫，靠布置。

::: note 裸体与裸像
肯尼斯·克拉克在 1956 年的《裸体》里区分「裸体」（naked）与「裸像」（nude）：前者是脱下衣服的状态，后者是被构造出来的艺术形式。这个区分常被引用，也被批评为掩盖了性别差异——琳达·尼德在 1992 年的《女性裸体》里指出，文艺复兴的「裸像」传统几乎只把女性身体当作可被形式化的对象，而男性裸体承载的是行动与德性。
:::

### 第五步：18 世纪的收尾

「美能否被穷尽为数学比例」在 18 世纪被重新提出，答案明显偏向否定。

哈奇生在 1725 年的《论美与德性观念的起源》里提出「整齐中的多样」，看似回到比例论，却把美的根据放在「内在感官」上：比例令人愉悦，因为它被感知为秩序，与客观数值关系不大。荷加斯在 1753 年的《美的分析》里反对固定比例，主张美在「蛇形线」——起伏、变化、引导眼睛运动；他嘲讽按比例制作的画，认为它们正确而呆板。伯克在 1757 年的《论崇高与美》里把美归结为小、光滑、渐变、柔弱，与比例几乎无关。康德在 1790 年的《判断力批判》里区分「自由美」与「依附美」，把审美判断建立在反思性的愉悦上。

这条线索的落点可以概括为：比例不够，虽然它并不错。它是美的必要条件之一，却从来不是充分条件。黑格尔在讨论自然美的抽象形式时，把这层意思说得相当清楚：

::: quote 《美学》第一卷，第二章「自然美」，B. 抽象形式的外在美
整齐一律和平衡对称这两种形式既然纯粹是外在的统一和秩序，所以它们主要地属于数量大小的定性。
:::

黑格尔的下一层意思是：这类形式美只涉及量，触及不到「生气灌注」的整体；在生命与心灵里，它要让位给更高的统一。用这句话回看文艺复兴，可以得到较均衡的判断：比例提供了可传达的骨架，优雅与凝视填充骨架之外的部分，而后者恰恰是理论最难处理的。

## 五、经典原著：两段文本，两种语气

维特鲁威的第三书是技术手册，语气干燥：先讲神庙的对称如何依循人体，再列一串分数。他没有为「美」下定义，只把比例当作工匠可执行的规范。这说明在古代，比例首先是工艺问题。

《廷臣论》的语气完全不同：它是对话，有玩笑、有反驳、有在场者的互相打趣。sprezzatura 是在谈话中被提出的，提出者立刻被要求举例，场面颇为自嘲。这种文体选择并非偶然——一个关于「不能显得用力」的理论，只能用轻松的谈话来演示。

对比提示：比例论属于规范的话语，优雅论属于趣味的话语。前者能写成教科书，后者只能在宫廷与沙龙里流传。文艺复兴美学因此有两套并行的传播机制；18 世纪把后者抬升为「鉴赏判断」，实际上是把宫廷的趣味话语改写成了哲学。

## 六、艺术案例：一张素描与一幅油画

### （一）《维特鲁威人》的构造

先看几何。画面下半部是正方形，边长即身高，四边分别切过脚底、头顶与两臂指尖；上部是圆，圆心在脐。两个图形在肩部附近相交，交线恰好穿过胸部——这是最容易被忽略的细节：它让上下两个系统在身体上有一个共享界面。

再看姿态。方形姿态双臂水平、双腿并拢；圆形姿态双臂上举约四十五度、双腿张开。四个手臂与四条腿的端点都被细线标注并连到图形边界，形成一张「测量网」。这张网的功能是让观者直接在图上核对比例，不必依赖文字。

最后看文字。上方与下方的镜像书写，一段讨论人体各部位与建筑的关系，一段给出具体换算。图文在这里互相校验：图形给直观，文字给数值。图文互证是当时人体测量的基本态度。

### （二）《乌尔比诺的维纳斯》的构图

主对角线从左上帷幔垂线延伸到右下脚踝，身体沿这条线斜置；水平的床沿、墙脚线与画面下缘构成三条平行带，把身体托住。光源从左侧来，经帷幔遮挡变得柔和，受光面集中在胸腹与大腿，暗部退入床单褶皱。体积因此显得柔软，与《维特鲁威人》硬边的测量线条形成对照。

构图的权力在于视线方向。画中女仆背对观者、低头开箱，构成一个「不看」的区域；狗卧脚边，也不看；唯有维纳斯看向画外。于是整个画面只有一个出口，就是她的眼睛，而那个出口正对站在画前的观者。不需任何叙事动作，观看关系本身成为画面的内容。

## 七、思想联系

向前，人体作为尺度的观念可追到毕达哥拉斯的数的和谐，经柏拉图《蒂迈欧》的宇宙身体，到维特鲁威的工程化。中世纪把比例神学化（第 4 讲），文艺复兴把它人类学化（第 6 讲），本讲显示它在两个方向遇到阻力：质的方面遇到优雅，社会方面遇到性别。

向后，18 世纪的趣味理论把「不可规则化」的部分正式纳入哲学：哈奇生的内在感官、伯克的经验分类、康德的反思判断，处理的是同一个问题——美如果可以被算尽，就不需要判断力了。20 世纪，布迪厄在《区分》里把趣味与社会位置联系起来，伯格与穆尔维把观看与权力联系起来；两条线索都可看作对「优雅」的批判性继承：优雅从来不是中性品质，它属于特定阶层与特定性别的位置。

## 八、本节总结

- 维特鲁威比例把人体当作模数；圆与方的构造在几何上无法闭合，莱奥纳多以双姿态解决了矛盾。
- 方与圆的双重中心（耻骨与脐）对应两种秩序：可测量的此世身体与循环的宇宙身体。
- 优雅与 sprezzatura 指向规则之外的分寸感，其结构自我指涉，因而无法写成手册。
- 提香的维纳斯通过视线、手的位置与日常物编码，把观者安置在一个被允许注视的位置上。
- 18 世纪从哈奇生到康德，逐步把美的根据从客观比例移向主体的判断力。
- 比例是必要条件，优雅与观看是它无法覆盖的剩余；这一剩余正是近代美学的起点。

值得追问的是：如果优雅不可教，它凭什么在宫廷里被当作可评价的标准？一种无法被规则化的品质，如何反过来成为区分人的规则？

::: key 本讲要点
- 《维特鲁威人》是一次未完成的几何方案，把它当作「黄金比证明」是后世的附会。
- 双重中心承载双重秩序，测量与生成在同一个身体上错位。
- 优雅与 sprezzatura 的价值在于不可量化，它们构成比例论的内在限度。
- 女性人体的观看结构由构图与视线布置，而非由题材决定。
:::
